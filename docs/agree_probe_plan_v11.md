# v1.1 agree 쓰기 목표: 실행 전 고정한 probe 계획

2026-09-26. 이 계획은 probe 결과를 보기 전에 작성했다.

**상태: 미실행, 사용자 지시에 따라 대체됨.** 코드 점검도 실행하기 전에 질문을
‘후반에 풀린 퍼즐의 장기 미해결 셀이 교정된 작용’으로 변경했다.
현재 계획은 `late_puzzle_probe_plan_v11.md`를 따른다.

## 판정할 명제

현재 체크포인트의 seg16 상태에서 시작할 때, seg17–32의 쓰기 목표에
**현재 agree를 사용하는 것이 직전까지의 EMA agree를 사용하는 것보다,
seg128의 추가 퍼즐 해결에 유리하다.**

이는 `g * attn_beta * agree`가 최적의 목표라는 명제가 아니다.
이미 학습된 모델에서 현재 관계를 쓰는 선택과 과거 평균 관계를 쓰는 선택의
효과를 비교한다. 학습하지 않은 다른 모델이나 130k 체크포인트로 일반화하지 않는다.

## 고정 조건

- 체크포인트: `checkpoints/v1.1_step160000.npz`, EMA. 로컬에 130k는 없다.
- 데이터: `data/sudoku_lt_1k.npz`, 테스트의 0-based 인덱스 512–767, 256개.
- FP32, CUDA autocast와 TF32 끔. 체크포인트의 대형 텐서는 fp16 저장본이다.
- 같은 정상 seg16 상태에서 모든 조건을 분기한다.
- 쓰기 개입은 블록 129–256, 즉 seg17–32에만 한다.
- 블록 257–1024, 즉 seg33–128은 각 분기의 상태에서 원래 규칙으로 실행한다.
- 읽기식, eta, lambda, gain, 주소 창, MLP, 재주입, 정규화의 규칙은 유지한다.
  분기 후 상태가 달라지므로 주소 창이나 값 벡터의 수치까지 동일한 것은 아니다.
- 라벨은 평가와 개입 전 코호트 정의에만 사용한다. 쓰기 목표에는 사용하지 않는다.

## 개입

공통적으로 `K = g * attn_beta`, `A = agree`, `G = K * A`이다.
실제 코드의 곱셈 순서는 정상 경로와 동일하게 유지한다.

1. `current`: 원래 쓰기 그대로.
2. `past_mean`: `A` 대신 해당 분기에서 직전 블록까지 누적한 EMA `A_bar`를 쓴다.
   EMA는 메모리와 동일한 헤드별 eta를 쓰며 첫 A로 초기화한다.
   이는 기존 메모리 누수에 더해 agree 자체를 시간 평활화하는 대안이다.
3. `shuffle_0/1/2`: `A`의 행과 열에 같은 순열을 적용한다. 순열은 퍼즐·헤드별로
   seed 0/1/2에서 정하고 개입 구간 동안 고정한다. A의 대칭성 및 원소 분포를
   보존하면서 셀 대응을 훼손한다. 매 블록 새 노이즈를 주입하지 않는다.

대안들의 G는 각 퍼즐·헤드별 **비대각 Frobenius norm**을 해당 분기의
현재 G와 맞춘다. 대각은 현재 G의 대각을 그대로 둔다. 따라서 주 비교는
전체 쓰기 크기나 자기 결합보다 비대각 관계의 배분·부호·상대 크기에 초점을 둔다.
이 스케일 보정이 없는 raw EMA와 동일한 실험이라고 해석하지 않는다.

## 주 지표와 판정

- 주 코호트: 공통 seg16에서 완답하지 못한 퍼즐. 미래 성공 여부로 고르지 않는다.
- 주 결과: seg128의 퍼즐 완답 여부. 중간 최고치, 최초 완답 시점으로 바꾸지 않는다.
- 주 대조: `current - past_mean`의 완답률 차이.
- 퍼즐을 독립 단위로 하는 paired bootstrap 10,000회, seed 20260926,
  percentile 95% CI를 사용한다. 셀·헤드·블록을 독립 표본으로 세지 않는다.
- CI 전체가 양수: 이 조건에서 최신 agree의 사용을 지지.
- CI 전체가 음수: 이 조건에서 agree를 추가 평활화하는 편이 유리.
- CI가 0을 포함: 이 실험으로 우열을 판정하지 않는다. 동등성의 증거로 바꾸지 않는다.
- 효과 크기와 승패 퍼즐 수를 함께 보고한다. 둘 다 같은 퍼즐을 푼 경우
  차이가 0이라는 사실만 보고하며, bootstrap 폭이 0이어도 모집단 동등성을 주장하지 않는다.

shuffle 3개는 별도의 정보 훼손 대조군이다. 평균 효과와 seed별 효과를 모두
보고하며 가장 나쁜/좋은 seed를 고르지 않는다. current가 shuffle보다 낫다는
사실을 current가 past_mean보다 낫다는 근거로 대체하지 않는다.

전체 퍼즐의 완답 수, seg16 완답의 유지, 빈칸 손실, 중간 궤적은 보조 지표다.
즉시 손실·현재 예측 강화·특징 분포로 주 판정을 뒤집지 않는다.

## 내부 상태 관측과 검증

- 정상 block runner가 원래 모델의 1세그먼트 실행과 일치하는지 확인한다.
- 모든 분기의 초기 h, w, A_bar가 같은지 확인한다.
- 대안의 대각 보존과 비대각 norm 일치를 수치 검증한다.
- 개입 중 G의 상대 변화량 및 현재 G와의 cosine을 퍼즐·헤드별로 기록한다.
- 개입 종료의 h, w 차이를 기록해 실제로 내부 상태가 달라졌는지 확인한다.
- 각 세그먼트 예측을 저장하여 결과와 코호트 분류를 재검산할 수 있게 한다.
- 먼저 8문제, 짧은 horizon으로 코드 동등성·메모리 사용만 점검한다.
  이 점검은 주 표본과 겹치지 않으며 가설·개입 선택에 사용하지 않는다.

## 해석의 한계

이 실험은 checkpoint 조건부의 쓰기 정책 개입이다. 개입 구간 중 새로운 상태가
생기므로 매 블록 동일한 상태의 G만 비교하는 실험은 아니다. 원래 모델과 별도
정책을 함께 학습한 비교도 아니다. 양의 결과만으로 생물학적 STDP, 수렴,
전역 최적성, 메커니즘 전체를 입증했다고 해석하지 않는다.

범위·주 지표·방향 판정의 변경이 필요하면 기존 결과를 본 뒤 바꾸었다는 사실을
기록하고, 새 실험으로 구분한다.
