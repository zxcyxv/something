# 7→3, 2→1: 8→6 사례와 동일한 연결 해부

2026-09-26. v1.1 160k, 기존 12문제 FP32 배치, autocast/TF32 off.
실행: `python lt/analyze_read_kernel_v11.py --puzzles 209 230`.

새로운 상태 교체 실험은 하지 않았다. 8→6과 동일하게 기존 history
기여 순위에서 가장 높은 스도쿠 이웃 연결을 골라, 주소·위상 → G → W →
실제 읽기 계수 → 숫자별 점수 기여를 계산했다. 해당 연결만 W→G,
대상 셀의 기억 읽기 전체 W→G, 기존 129블록 G 읽기 분기를 각각 재현했다.
개입 결과를 본 뒤 연결을 바꾸지 않았다.

두 사례 모두 T−128부터 T+1까지 정상 전체 배치 예측과 기존 G 분기의
해당 퍼즐 전체 예측이 저장된 궤적과 매 블록 정확히 일치했다.
주소의 위상 분해는 실제 커널과 2e−6 이내, 전체 로짓 기여의 재구성은
2e−6 이내에서 일치했다. 숫자별 기여는 해당 정상 출력의 공통 phi 분모를
사용한다. 유한 크기 W→G 개입은 phi까지 다시 계산한 실제 argmax다.

## 1. 퍼즐 209: 3행2열의 7→3, T=3778

소스는 같은 행의 3행1열, 정답 7이며 T 직전 예측도 7이다.
대상은 정답 3이며 T 직전 예측은 7이다. 세 번째 헤드다.

### 주소·위상

| 항 | 값 |
|---|---:|
| 상대 위치 | 행 0, 열 +1 |
| 위상 적용 전 주소 내적 | +0.765364 |
| 위치 위상만 적용한 내적 | +0.617677 |
| 위치와 ψ를 적용한 내적 | −0.548707 |
| 거리 감쇠 D | 0.953995 |
| 실제 a_psi | −0.523463 |
| 실제 a_beta | +0.588967 |

가장 큰 음의 기여는 43번째 복소 좌표다. 내용 위상 +0.253071°,
위치 위상 +0.344112°, psi −179.881218°, beta −0.380794°다.
같은 주소 관계가 읽기에는 −0.260993, 쓰기에는 +0.261011을 기여한다.
다음으로 큰 16번째 좌표도 읽기 −0.130408, 쓰기 +0.130897이다.
읽기 커널의 대칭 cos 성분은 −0.534376, 반대칭 sin 성분은 +0.010913이다.

### 쓰기와 읽기

`G = 2.789472 * 0.588967 * 0.410265 = 0.674027`

`W = 0.374009 + 0.029175 * (0.674027 - 0.374009) = 0.382762`

`J = 0.809877 * (-0.523463) + 0.190123 * 0.382762 = -0.351169`

| 숫자 점수 | 이웃의 값을 계수 +1로 읽을 때 | 실제 J로 읽을 때 |
|---|---:|---:|
| 정답 3 | +1.954489 | −0.686356 |
| 직전 오답 7 | +4.555829 | −1.599866 |

두 숫자 점수를 모두 내리지만 7을 더 많이 내려 3−7에 +0.913510을 준다.
나머지 모든 성분은 +4.432834이고 합계 +5.346344, 실제 예측은 3이다.
이 연결의 메시지 중 ψ는 +1.102814, 기억은 −0.189304를 기여한다.

이 연결만 W 대신 G로 읽으면 a_psi는 그대로이고 J는 −0.295793으로
약해진다. 이 연결의 3−7 기여는 공통 분모에서 +0.769458로 줄어든다.
phi까지 다시 계산한 전체 3−7 차이는 +5.195771, 실제 출력은 여전히 3이다.
대상 셀의 기억 읽기 전체를 G로 바꿔도 3−7 차이 +3.756714로 3이다.

### 실제 전환 전후

| 시점 | 읽기 전 소스 예측 | 읽기 후 대상 예측 | J | 단위 값의 3−7 투영 | 이 연결의 3−7 기여 |
|---|---:|---:|---:|---:|---:|
| T−16 | 3 | 7 | −0.361911 | +10.026361 | −3.628654 |
| T−8 | 3 | 7 | −0.372207 | +4.582320 | −1.705571 |
| T−4 | 3 | 7 | −0.369018 | +2.702546 | −0.997288 |
| T−2 | 3 | 3 | −0.351971 | +0.056102 | −0.019746 |
| T−1 | 7 | 7 | −0.338337 | −1.377592 | +0.466091 |
| T | 7 | 3 | −0.351169 | −2.601339 | +0.913510 |
| T+1 | 7 | 3 | −0.354500 | +0.346922 | −0.122984 |

T−16에는 소스가 틀린 3을 예측하고 대상은 틀린 7을 예측한다.
이때 이웃 값을 음수로 읽는 메시지는 정답 3을 상대적으로 억제한다.
소스가 7로 교정되는 구간에서 값의 3−7 투영이 음수로 바뀌고,
같은 음의 연결이 대상의 7을 상대적으로 억제하는 방향으로 작용한다.
단, 소스의 출력 숫자만으로 한 헤드 값의 방향을 결정할 수는 없다.
T+1에는 소스 예측이 여전히 7인데 이 헤드의 3−7 투영은 다시 양수다.
T는 대상이 처음 3을 낸 시점이 아니라, 마지막 오답 뒤 안정 교정 시점이다.

### 기존의 긴 G 읽기 분기

T−128부터 대상의 기억 읽기 전체를 G로 바꾼 분기에서도 정답 3이 나온다.
T의 소스는 읽기 전에 아직 3이고, 이번 읽기 후 7로 바뀐다. 대상은
이미 T−1에서 3으로 교정되어 있다. 이 분기에서 a_psi=−0.530341,
G=1.357885, J=−0.171346, 단위 값의 3−7 투영=+0.131473이다.
해당 연결의 기여는 −0.022527이고 나머지가 +3.954503이어서 전체
마진은 +3.931975, 출력은 3이다. 선택한 연결 하나가 교정의 필요조건은 아니다.

## 2. 퍼즐 230: 4행2열의 2→1, T=3649

소스는 같은 열의 6행2열, 정답 2이며 T 직전 예측도 2이다.
대상은 정답 1이며 T 직전 예측은 2이다. 세 번째 헤드다.

### 주소·위상

| 항 | 값 |
|---|---:|
| 상대 위치 | 행 −2, 열 0 |
| 위상 적용 전 주소 내적 | +0.437389 |
| 위치 위상만 적용한 내적 | +0.599538 |
| 위치와 ψ를 적용한 내적 | −0.547196 |
| 거리 감쇠 D | 0.910106 |
| 실제 a_psi | −0.498007 |
| 실제 a_beta | +0.544103 |

43번째 복소 좌표의 내용 위상은 −168.314497°, 위치 위상은
+161.483553°로 합치면 −6.830944°다. psi −179.881218°를 적용하면
읽기 기여 −0.217200, beta −0.380794°를 적용하면 쓰기 기여 +0.216969다.
16번째 좌표도 읽기 −0.216211, 쓰기 +0.216235로 크게 기여한다.
읽기 커널의 대칭 cos 성분은 −0.489504, 반대칭 sin 성분은 −0.008503이다.

### 쓰기와 읽기

`G = 2.789472 * 0.544103 * 0.633544 = 0.961567`

`W = 0.396368 + 0.029175 * (0.961567 - 0.396368) = 0.412858`

`J = 0.809877 * (-0.498007) + 0.190123 * 0.412858 = -0.324831`

| 숫자 점수 | 이웃의 값을 계수 +1로 읽을 때 | 실제 J로 읽을 때 |
|---|---:|---:|
| 정답 1 | +0.198814 | −0.064581 |
| 직전 오답 2 | +5.033477 | −1.635027 |

두 숫자 점수를 모두 내리지만 2를 훨씬 더 많이 내려 1−2에 +1.570446을
준다. 나머지 모든 성분은 +0.536476으로 합계 +2.106922, 실제 예측은 1이다.
이 연결의 ψ 기여는 +1.949937, 기억 기여는 −0.379491이다.

이 연결만 W 대신 G로 읽으면 a_psi는 그대로이고 J는 −0.220508로
약해진다. 이 연결의 1−2 기여는 공통 분모에서 +1.066084로 줄어든다.
phi까지 다시 계산한 전체 마진은 +1.600149, 실제 출력은 여전히 1이다.
대상 셀의 기억 읽기 전체를 G로 바꿔도 전체 마진 +1.360519로 1이다.

### 실제 전환 전후

| 시점 | 읽기 전 소스 예측 | 읽기 후 대상 예측 | J | 단위 값의 1−2 투영 | 이 연결의 1−2 기여 |
|---|---:|---:|---:|---:|---:|
| T−128 | 6 | 2 | −0.377503 | +0.025727 | −0.009712 |
| T−16 | 2 | 1 | −0.348674 | −2.736327 | +0.954087 |
| T−8 | 9 | 1 | −0.331403 | −1.520498 | +0.503898 |
| T−4 | 9 | 2 | −0.331494 | −2.034518 | +0.674431 |
| T−2 | 2 | 2 | −0.325428 | −2.231739 | +0.726270 |
| T−1 | 2 | 2 | −0.324128 | −3.926354 | +1.272640 |
| T | 2 | 1 | −0.324831 | −4.834662 | +1.570446 |

소스와 대상은 안정화 전에 예측을 바꾼다. T 직전 몇 블록에서는
J가 거의 −0.325인 채로 값의 2 쪽 성분이 커져, 1−2에 대한 양의 기여가
증가한다. 이것도 새롭게 음의 ψ가 생기는 현상은 아니다.

### 기존의 긴 G 읽기 분기

이 분기에서는 T의 소스가 정답 2 대신 6을 예측하고, 대상도 2에 머문다.
수치적으로 a_psi=−0.515299, agree=+0.038355, G=+0.057644,
J=−0.406369다. 정상보다 J가 더 음수인데도, 단위 값의 1−2 투영이
−1.194243에 그쳐 해당 연결의 양의 기여는 +0.485304다.
나머지는 −16.632122이고 합계 −16.146818, 실제 출력은 2다.

| 대상 전체의 1−2 기여 | 정상 분기 | 긴 G 읽기 분기 |
|---|---:|---:|
| 준비된 자기 상태 q | −9.277518 | −15.793601 |
| ψ로 읽은 메시지 전체 | +15.890700 | +4.974037 |
| 기억 경로로 읽은 메시지 전체 | −4.472933 | −5.293926 |
| 분류기 편향 | −0.033327 | −0.033327 |
| 최종 마진 | +2.106922 | −16.146818 |

따라서 이 긴 분기의 실패를 ‘G가 커져 음의 ψ를 상쇄했다’로 설명할 수
없다. 이미 소스의 값과 대상의 상태를 포함한 궤적이 달라져 있다.
여기서는 그 다른 상태에서 같은 forward의 실제 숫자 흐름까지 확인한
것이며, 어떤 이전 변화가 그 궤적 차이를 처음 만들었는지에 대한 추가
상태 교체 실험은 수행하지 않았다.

## 비교의 범위

세 사례의 선택한 이웃 연결에서는 모두 약 π의 ψ가 음의 읽기를 만들고,
양의 G와 W가 그것을 일부 상쇄한다. 정상 전환 시점에는 W<G여서 기존
W로 읽을 때 오답 숫자를 상대적으로 더 억제한다. 8→6은 해당 차이가
전체 판정 경계를 넘겼지만, 7→3과 2→1은 그 차이를 없애도 정답 마진이
남았다. 이는 세 번째 헤드의 선택된 연결들에 대한 결과다.
