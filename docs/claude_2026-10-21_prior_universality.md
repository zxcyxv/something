## 0. 결론

1. **원칙.**
   - 보편성은 아래 세 층(형식, 계산 지지, 선택 원리)에서 설계로 보장한다.
   - 사전 지식은 코드 층(L3)에만 두고 학습으로 채운다. 그 출처는 학습 분포(L4)다.
   - 사전을 학습으로 푸는 것이 맞다. 학습으로 풀 수 없는 것은 두 가지뿐이다. 계산 지지(표현할 수 없는 것은 학습이 살리지 못한다)와 학습 기제 자체(단순성 원리)다.
2. **지금 버릴 것.** 사전을 아래 층으로 내려 지지를 자른 것들이다. ARC 형식 사실만으로 판정된다(§3.1, §5).
   - 고정 격자 크기, 고정 시범 수, "0 = 배경"
   - 원환 위상과 원환 푸리에 기저, 규칙 경로의 RoPE 키
   - C·X·Wᵀ를 규칙의 유일한 통로로 두는 것
   - 손으로 열거한 후보, 손 DSL과 손 MDL, `rule_prior`
   - 퍼즐 임베딩
   - 학습 목표로서의 원환 토이 분포
3. **보편성으로 풀었을 때의 상한은 세 겹이다(§3).**
   - 지지: 지지를 자르지 않으면 100%다.
   - 식별: ARC-2 평가 과제는 전부 사람 2명 이상이 두 번 안에 풀었다. 그래서 맞는 사전만 있으면 시범이 답을 정한다.
   - 학습: 그 사전을 학습 과제에서 배울 수 있는가. 실제로 재야 하는 것은 이것뿐이다.
     - 정보량으로는 가능하다. ARC-1 학습을 전부 덮는 손 DSL이 압축해 6.4 KiB이고, 학습 풀 1,033과제의 시범은 압축해 118 KiB다.
     - 위험은 평가 과제의 새로움이다. ARC-2 평가에는 ARC-1 평가 표본에 없던 연산이 반복해 나온다(조립 탐색, 상태를 가진 시뮬레이션, 격자 안 유추). 이것이 학습 분포에 충분히 있는지는 실험으로만 정해진다.
4. **짧은 기술은 존재한다(§4).**
   - ARC-2 평가 120개를 직접 읽으면 108개(90%)가 정확한 연산으로 적힌다. 과제당 쓰인 연산 종류는 평균 3.9개다.
   - 11개는 연산 종류는 보이나 세부(정지 조건, 맞춤 기준)가 불확실하다. 안 보이는 것은 1개다.
   - 그러니 "보편화하면 학습하지 못한다"는 편견을 데이터가 뒷받침하지 않는다.
5. **손 클래스가 덮는 범위는 상한이 아니다.**
   - 예: rank-1 C·X·Wᵀ가 ARC-2 평가의 1.7%만 표현한다는 것.
   - 이것은 손 사전의 지지를 잰 숫자다. 보편화한 뒤 학습 가능성에 대해서는 아무것도 말하지 않는다. 그래서 부록 B로 내렸다.

## 1. 긴장의 정식화

### 1.1 사전은 필요하다

- **선택이 답을 정한다.** 덮어쓰기에 닫힌 족에서는 시범과 일치하는 규칙들이 시험 입력에서 모든 출력을 낸다(10-20 논증 1). 표현력이 아니라 선택 규칙이 답을 정한다.
- **균등 사전으로는 안 된다.** 시범 밖 정답률이 1/|Y|다(10-20 논증 2).

### 1.2 보편성은 지지와 가중의 두 조건이다

- 혼합 ξ = Σ_ν 2^(−K(ν))·ν는 모든 계산 가능한 과제 분포 μ에 대해 −log ξ ≤ −log μ + K(μ)를 만족한다.
- 이것은 두 조건이 합쳐진 것이다.
  - 모든 계산 가능한 규칙에 양의 확률이 있다(지지).
  - 가중이 정상적인 부호 길이다.
- 참조 기계 U를 바꾸면 K는 상수만큼만 바뀐다. 그러나 시범이 2–4개뿐이면 이 상수가 시범의 정보보다 크다.
  - 숫자로 보면: arc-dsl로 적은 ARC-1 학습 풀이는 과제당 평균 약 59바이트(압축)다. 시범 전체는 과제당 약 92바이트(압축, 입력 격자 포함)다(§3.3).
  - 정답 규칙은 시범과 일치하는 모든 대안보다 짧아야 뽑힌다. 그래서 U가 ARC에 맞춰져 있어야 하고, 이것이 사전 지식이다.

### 1.3 맞추는 방법은 둘이고, 보편성에 미치는 영향이 다르다

| | 지지를 자른다 (하드) | 가중을 바꾼다 (소프트) |
|---|---|---|
| 수학 | 족 밖의 규칙은 확률 0 | 족 밖의 규칙은 비트가 더 든다 |
| 보편성 | 깨진다 | 유지된다(상수만 바뀐다) |
| 신경망에서 | 표현할 수 없는 꼴 | 학습된 코드, 희소성 비용, 반복 횟수 |
| 학습으로 고칠 수 있나 | 없다 | 이것이 곧 학습이다 |

사전을 학습으로 넣으면 소프트가 된다. 손으로 넣은 사전은 대개 하드가 된다. 손으로 정할 수 있는 것은 꼴(무엇이 표현되는가)이고, 가중(무엇이 짧은가)을 손으로 정하기는 어렵기 때문이다.

## 2. 설계 층위

### 2.1 여섯 층

| 층위 | 이 층이 정하는 것 | 보편성 조건 | 사전 지식 | 지금 어긋난 것 |
|---|---|---|---|---|
| L0 형식 | 격자와 시범을 텐서로 넣는 법 | 손실 없음. 크기 1–30, 시범 2–10개, 시험 입력 여러 개, 10색 대등 | 넣지 않음 | 4×4 고정, K = 3 고정(격자 7개), "0 = 배경" |
| L1 계산 지지 | 무엇을 계산할 수 있는가 | 합성과 반복에 닫힘(국소 규칙 반복만으로 계산 보편). 반복을 학습 지평 밖으로 늘릴 수 있음. 처음 보는 과제에 추론 경로가 있음 | 넣지 않음. 넣으면 지지를 자르고, 학습으로 복구되지 않는다 | rank-1 C·X·Wᵀ가 규칙의 유일한 통로. 내용으로 기준점을 옮기는 기제가 없음(빈자리) |
| L2 선택 원리 | 시범과 맞는 규칙 중 무엇을 고르나 | 과제와 무관한 단순성 원리. 오차 LTP(델타) + 희소 LTD | 원리만 둔다. 무엇이 짧은지는 넣지 않는다 | 손 열거 후보(판 C 128단어), 손 DSL + 비트 MDL, `rule_prior` |
| L3 코드 (참조 기계) | 무엇이 "짧은가" | 손실 없음(단사), 크기 일반, 기준점 이동 가능 | **사전 지식의 유일한 자리. 학습한다** | 원환 푸리에 기저, 규칙 경로의 RoPE 키, 손 원-핫 값, 고정 크기 Q |
| L4 학습 분포 | L3이 배우는 사전의 출처 | 대상 분포(ARC 과제)와 그 대칭(D4, 색 순열) | 데이터로만 들어온다 | 원환 토이 분포(학습된 Q를 원환 푸리에로 끌고 갔다) |
| L5 과제별 빠른 상태 | 이 과제의 규칙 | 시범과 격자 안 범례를 읽는 가소성으로만 | 없음(시범 데이터) | 퍼즐 임베딩(처음 보는 과제에 지지가 없다) |

### 2.2 긴장이 생기는 곳

- **충돌하지 않는 배치.** 보편성 조건이 L0–L2에, 사전 지식이 L3에 있으면 둘은 충돌하지 않는다. 시범 2–4개에서는 L3 사전이 반드시 필요하다(§1.2). 그래서 요구는 "사전 없음"이 아니라 "사전은 L3에서 학습으로"다.
- **충돌 1: 사전을 L0–L2로 내리는 경우.**
  - 하드 제약이 되어 지지를 자르고, 학습으로 복구되지 않는다.
  - 10-20까지의 손 사전들은 전부 이 경우였다. 고정 크기·K·원환은 L0–L1, rank-1 유일 통로는 L1, 열거 후보와 손 MDL은 L2다.
  - 손 코드는 L3에 있지만, 학습할 자리를 손으로 채운 것이라 같은 문제가 된다.
- **충돌 2: L4가 평가 과제의 새로움을 담지 못하는 경우.**
  - 학습된 가중이 그 규칙을 짧게 만들지 못한다.
  - L1의 지지 덕에 도달은 할 수 있지만, 시범이나 계산이 더 든다.
  - 설계로 없앨 수 없는 남은 긴장이다. 실험으로 재야 하는 상한이 이것이다(§3.3).

### 2.3 색별 분해와 C·X·Wᵀ의 자리

- **색별 분해(색 × 위치 one-hot)는 L0이다.** 정보를 잃지 않고, ARC 격자의 정의 그 자체다.
- **C·X·Wᵀ는 L1의 여러 통로 중 하나다.** L0이 주는 두 축(색, 위치)에 각각 연산을 거는 꼴이다. 영상의 병진 구조에서 합성곱이 나오듯 형식에서 나온 구조이고, 사전 지식이 아니다.
- **지지를 자르는 것은 이것이 규칙의 유일한 통로일 때뿐이다.** 여러 통로 중 어느 것을 짧게 볼지는 L3이 학습한다.

## 3. 상한: 지지, 식별, 학습

### 3.1 지지 상한: ARC 형식 사실

지지가 보편이면 표현 상한은 100%다. 깎는 것은 지지를 자르는 설계뿐이다. 무엇이 자르는지는 사전을 쓰지 않고 ARC의 형식 사실로 정해진다.

| 형식 사실 | ARC-1 학습 | ARC-1 평가 | ARC-2 학습 | ARC-2 평가 | 깨는 설계 |
|---|---:|---:|---:|---:|---|
| 과제 수 | 400 | 400 | 1,000 | 120 | |
| 시범 수 범위 (K = 3인 비율) | 2–10 (59%) | 2–7 (55%) | 2–10 (58%) | 2–6 (51%) | 고정 K, 격자 2K + 1 |
| 시험 입력 2개 이상 | 3.5% | 4.8% | 6.9% | 37.5% | 시험 입력 1개 가정 |
| 최대 변 ≤ 4 | 3.8% | 0.8% | 1.9% | 0.0% | 4×4 고정 |
| 최대 변 ≥ 20 | 17.5% | 33.2% | 25.6% | 81.7% | 작은 고정 캔버스 |
| 입력 크기가 쌍마다 다름 | 49.0% | 61.5% | 58.9% | 74.2% | 절대 좌표의 고정 크기 코드 (크기 상대 프레임이 필요) |
| 입출력 크기가 다름 | 34.5% | 32.5% | 32.0% | 32.5% | 정사각 W, 같은 코드 공간 가정 |
| 모든 격자에서 0이 최빈색 | 53.2% | 54.8% | 44.8% | 19.2% | "0 = 배경" |
| 비배경 칸 수 보존 | 18.8% | 20.8% | 21.4% | 13.3% | 점유 보존 가정(`rule_prior='mean'`의 근거) |
| 순환 이동으로만 설명되는 과제 | 0.0% | 0.2% | 0.1% | 0.0% | 원환 위상 |
| 바뀐 칸 비율 중앙값(크기 같은 과제) | 15.7% | 15.6% | 15.9% | 10.7% | (깨는 것 없음. 항등 운반자 위의 희소 편집) |

ARC-2 학습 1,000개 중 767개는 ARC-1 과제의 쌍을 재배치한 것이다. ARC-2 평가 과제 중 ARC-1과 ID가 겹치는 것은 6개다.

### 3.2 식별 상한: 사람 보정

- ARC-2 평가 과제는 전부 사람 2명 이상이 두 번 안에 풀었다. 보정에는 일반인 400명 이상이 참여했다.
- 따라서 사람이 가진 사전으로는 시범 2–4개가 답을 정한다.
- 맞는 사전만 있다면 식별 상한은 사실상 100%다.

### 3.3 학습 상한: 정보량과 새로움

**정보량(가능성의 근거).**

| 대상 | 크기 |
|---|---:|
| arc-dsl `dsl.py` (프리미티브 160개 = ARC-1 학습을 덮는 사전) | 35 KB, xz 6.4 KiB |
| arc-dsl `solvers.py` (400과제 풀이, 중앙값 9문장) | 150 KB, xz 22.9 KiB (과제당 약 59바이트) |
| ARC-1 학습 시범(입출력 격자) | xz 36 KiB (과제당 약 92바이트) |
| 학습 풀: ARC-1 학습·평가 + ARC-2 새 과제 233 = 1,033과제 | xz 118 KiB |

- **사전 자체는 작다.** ARC-1 학습 전부를 덮는 사전(6.4 KiB)은 학습 풀 시범 정보(118 KiB)의 약 5%다. 정보량만 보면 데이터에서 그 정도 크기의 사전을 배울 수 있다.
- **과제 하나의 시범은 아슬아슬하다.** 규칙 기술(과제당 약 59바이트)과 시범 정보(약 92바이트, 입력 격자 포함)가 비슷한 크기다. 정답 규칙이 대안보다 확실히 짧으려면 사전이 좋아야 한다. ARC가 그렇게 설계되어 있다.
- **둘 다 압축기 기준의 대략적인 크기다.** 신경 표현에서 사전의 크기는 이보다 클 것이다.

**새로움(위험).**
- 학습된 사전은 학습 분포에 있는 연산들을 짧게 만든다. 평가 과제가 그 합성 범위 밖의 연산을 요구하면, 지지만 남고 짧지 않다.
- 직접 읽기(§4)에서 ARC-2 평가에 반복해 나왔지만 ARC-1 평가 표본 30개에는 없었던 연산은 다음과 같다. ARC-1에서의 빈도 자체는 재지 않았다.
  - 조립 탐색(exact cover, 조각 맞추기): 10개 이상
  - 상태를 가진 주체의 시뮬레이션(방향을 가진 광선·뱀·공이 만나고 꺾임): 8개 이상
  - 격자 안 유추와 절차적 열쇠(범례가 연산 자체인 경우): 7개 이상
  - 경로 추적(교차의 위·아래, 길이 보존)
- arc-dsl에도 조립 탐색이나 최단 경로 같은 프리미티브는 없다. 이름이 비슷한 `cover`는 물체를 배경색으로 지우는 연산이다.
- 이 연산들이 ARC-2 학습 1,000개에 충분히 있는지는 이 문서에서 재지 않았다. 학습 실험으로 정해진다.

## 4. 직접 읽기: 과제마다 짧은 연산이 보이는가

**방법.**
- 하위 에이전트 5개가 과제를 렌더링해 직접 읽었다. 과제마다 규칙, 부록 A 좌표계로 쓴 연산식, 보이는 정도를 적었다.
- "정확히 보임"은 모든 학습 쌍과 시험 쌍에 맞는 정확한 연산을 적을 수 있다는 뜻이다.
- 이것은 모델에 넣을 사전을 찾는 작업이 아니다. "짧은 기술이 존재하는가"를 가늠하는 측정이다(§3.3).

| | ARC-1 평가 표본 30 | ARC-2 평가 120 |
|---|---:|---:|
| 정확히 보임 | 29 (97%) | 108 (90%) |
| 연산 종류는 보이나 세부가 불확실 | 1 | 11 (9%) |
| 안 보임 | 0 | 1 (1%) |
| 수치로 확인 | 30 | 62 (그중 정확히 보임 59) |
| 과제당 쓰인 연산 종류(평균) | 2.9 | 3.9 (분포: 1개 4, 2개 5, 3개 25, 4개 54, 5개 29, 6개 이상 3) |
| 물체 분할(C1)이 들어감 | 22 | 113 (94%) |
| 물체 사이 관계(C4)가 들어감 | 12 | 62 (52%) |
| 격자 안 규칙 지정(범례, 문맥 전환, 합성)이 들어감 | 7 | 46 (38%) |
| 고정점 반복(B2)이 들어감 | 7 | 39 (33%) |
| 개수(D1)가 들어감 | 4 | 23 (19%) |
| 좁은 손 신호(부록 B)가 걸림 | 16 | 7 (6%) |

ARC-2 평가에서 핵심 난점이 놓인 층위의 분포는 다음과 같다.

| 층위 | 과제 수 |
|---|---:|
| 내용 무관 사상 | 5 |
| 국소·반복 | 22 |
| 물체 | 46 |
| 축약 | 10 |
| 대칭·주기 | 8 |
| 격자 안 규칙 | 27 |
| 좌표계 밖 | 2 |

읽는 법:
- **ARC-2 평가도 90%가 짧은 합성으로 적힌다.** 과제당 연산 종류는 대개 3–5개다. 좁은 손 신호가 걸리는 것은 6%뿐이다. 그러니 손 클래스가 덮지 못한다는 것과 일반 연산으로 짧게 적힌다는 것은 별개의 사실이다.
- **모델 쪽에서 무게가 실리는 곳은 세 군데다.**
  - 물체 분할과 물체 프레임: 94%
  - 격자 한 영역에서 쓰는 빠른 시냅스: 38%
  - 반복 깊이: 33%
  - 각각 L1(기준점 이동, 반복)과 L5(격자 안 쓰기)의 요구다.

**좌표계에 깔끔하게 들어가지 않으면서 반복해 나온 연산.** 에이전트 보고를 묶은 것이고, 괄호 안은 수학적 꼴이다.

1. **상태를 가진 주체의 궤적** (칸 상태에 방향·색·계수 채널을 더한 국소 규칙의 반복)
   - 방향을 가진 광선, 뱀, 공이 튕기고, 만나서 합쳐지고, 꺾인다. 부피가 보존되는 액체, 받침 규칙이 있는 낙하도 여기 든다.
   - 예: `142ca369`, `195c6913`, `2b83f449`, `28a6681f`, `36a08778`, `da515329`, `cb2d8a2c`, `b6f77b65`
2. **제약 만족과 조립 탐색** (이산 배치 위의 제약 전파와 가정. 스도쿠와 같은 종류)
   - 조각 맞추기, exact cover, 회전 도킹, 미로 속 블록 밀기, 그래프 최단 경로
   - 예: `16b78196`, `4e34c42c`, `7b3084d4`, `5dbc8537`, `cbebaa4b`, `e8686506`, `f560132c`, `2c181942`, `332f06d7`, `7b0280bc`
3. **격자 안 유추와 절차적 열쇠** (빠른 시냅스의 값이 색이 아니라 연산)
   - 예시 한 쌍이 연산 자체를 정의하거나, 열쇠가 타일·마스크·기준점·회전 같은 매개변수를 준다.
   - 예: `4c7dc4dd`, `a32d8b75`, `abc82100`, `9385bd28`, `a251c730`, `136b0064`, `e87109e9`
4. **개수가 다른 연산의 매개변수** (축약 → 주소 사상의 매개변수)
   - 이동량, 두께, 회전 횟수, 출력 크기가 개수로 정해진다.
   - 예: `6ffbe589`, `409aa875`, `271d71e2`, `f931b4a8`. ARC-1 표본에서는 `52fd389e`, `64a7c07e`, `e7b06bea`
5. **물체 틀에서 정의된 무늬를 합동인 다른 물체로 옮기기, 두 면 타일** (기준점 이동 + 틀의 방향(행렬식 부호)에 따른 색 사상)
   - 예: `64efde09`, `4c416de3`, `6e4f6532`, `a25697e4`
6. **칸 단위와 타일 단위를 오가는 사상, 마스크 ⊗ 타일** (내용으로 정해진 거친 격자 위의 두 층 좌표)
   - 예: `b99e7126`, `bf45cf4b`, `eee78d87`, `a395ee82`. ARC-1 표본에서는 `8a371977`, `c64f1187`
7. **경로 추적** (그래프 위의 궤적)
   - 교차에서 위·아래 결정, 길이를 보존하는 밧줄, 전선
   - 예: `8b7bacbf`, `a47bf94d`, `800d221b`, `88bcf3b4`, `faa9f03d`
8. **가림 복원, 대칭을 맞추는 삭제** (물체 프레임 안의 대칭·주기 완성, X ⊙ g·X)
   - 예: `a6f40cea`, `8e5c0c38`
9. **모든 출력이 같은 숨은 그림** (시범 출력을 빠른 기억에 담고 위치를 찾기)
   - 예: `269e22fb`
10. **그 밖의 것**
    - 성장하는 수열의 외삽(`20a9e565`)
    - 위상을 보존하는 다시 그리기(`2d0172a1`)
    - 변형된 사본 사이의 대응(`3a25b0d8`)

## 6. 다음 설계에 요구하는 것

1. **L0: 크기와 시범 수에 무관한 형식.**
   - 크기 1–30, 시범 2–10개, 시험 입력 여러 개를 받는다.
   - 10색을 대등하게 둔다(배경을 따로 다루지 않는다).
2. **L1: 내용으로 기준점을 옮기는 기제.**
   - 지금 지지에서 가장 큰 빈자리다.
   - 물체 분할은 ARC-2 평가의 94%(113/120)와 ARC-1 평가 표본의 22/30에 나온다. arc-dsl 풀이의 54%가 `objects`(연결 성분)를 쓴다.
   - 어느 기준점을 쓸지는 L3이 학습한다. 다만 기준점을 옮길 수 있는 능력 자체는 L1에서 설계해야 한다.
3. **L1: 반복의 깊이와 칸 상태.**
   - 채우기, 광선, 연결 성분, 상태 시뮬레이션은 고정점이다. ARC-2 평가의 33%가 이것을 쓴다.
   - bands의 외삽(10-18, 1만 블록까지 단조 개선)이 여기에 쓰인다.
   - 상태를 가진 주체(방향, 계수)는 칸마다 은닉 상태 채널이 있으면 국소 규칙의 반복이 된다. LT의 은닉 상태가 맡을 자리다.
   - 조립 탐색은 제약 전파와 가정이다. 스도쿠에서 LT의 재귀가 하던 일과 같은 종류다.
4. **L2/L5: 빠른 시냅스를 격자의 한 영역에서도 쓴다.**
   - 범례와 격자 안 유추는 시범 읽기와 같은 기제다. ARC-2 평가의 38%가 격자 안에서 규칙을 지정한다.
   - 열쇠가 색이 아니라 연산(타일, 마스크, 회전)을 주는 과제가 많다. 그래서 빠른 시냅스의 값이 연산자일 수 있어야 한다.
   - 범례를 양방향으로 쓰는 과제(`b20f7c8b`)는 자기연상 인출을 요구한다.
5. **L3: 코드는 ARC 과제에서 학습한다.**
   - 크기 일반이어야 하고, 기준점(모서리, 중심, 물체, 격자로 나뉜 칸의 거친 좌표)을 바꿔 쓸 수 있어야 한다.
   - 개수가 기하 매개변수가 되는 과제가 반복해 나온다. 위상 코드에서는 n칸 이동이 위상 n·θ라 개수를 위상으로 옮기는 경로가 자연스럽다. 다만 이것도 손으로 고정하지 않고 학습할 자리다.
6. **L4: 학습 분포는 ARC 과제 자체다.**
   - ARC-1 학습·평가, ARC-2 학습, ConceptARC에 대칭 증강을 더한다.
   - 토이는 기제를 확인하는 측정 도구로만 쓴다.
7. **상한의 실측.** 위 조건을 갖춘 모델을 학습 풀로 학습시킨다. 학습 과제 수에 따라 처음 보는 과제의 성능이 어떻게 변하는지를 재면, 그것이 §3.3 학습 상한의 실측이다.

## 8. 한계

- **이 문서는 학습 가능성의 증거가 아니다.** 형식 사실과 상한만 다룬다.
- **직접 읽기는 하위 에이전트의 판단이다.**
  - `checked`가 수치 확인 여부를 표시한다.
  - ARC-1 표본 30개는 30개 모두 학습·시험 쌍에 대해 수치로 확인했다.
  - ARC-2 평가는 120개 중 62개를 수치로 확인했다. 나머지는 손으로 따라갔고, 확신도는 평균 0.87이다(§4).
- **arc-dsl은 사람이 학습 과제를 보고 쓴 풀이다.** 평가 과제로의 일반화는 말하지 않는다.
- **정보량 비교는 압축기 기준의 대략적인 크기다.**

## 부록 A. 측정 좌표계: ARC 연산 대수

과제를 "어떤 연산으로 풀리는가"로 적을 때 쓴 좌표계다. 모델에 넣을 사전이 아니라 분석자의 측정 언어다. 격자 X는 one-hot {0,1}^(10 × |Ω|)다.

| 기호 | 연산 | 수식 | 모델에서 해당하는 것 |
|---|---|---|---|
| P1 | 색 축 선형 사상 | X ↦ C·X | 값 투영, C 시냅스 |
| P2 | 위치 축 선형 사상(주소) | X ↦ X·Wᵀ | 규칙 시냅스 W, 어텐션 읽기 |
| P3 | 칸별 곱(게이트) | X ⊙ X′, F(X[π₁p], …, X[π_m p]) | FFN 비선형, 곱 게이트 |
| P4 | 국소 선형 연산 | Σ_δ K_δ·X·S_δ | 상대 위치 어텐션 |
| P5 | 고정점 반복 | Φ^∞ | 블록 반복과 외삽 |
| P6 | 축약 | Σ_p, max, argmax (전체, 물체별, 줄별) | 토큰 합, 풀링 |
| P7 | 내용으로 정해지는 프레임 | T_{a(o)}·W·T_{a(o)}⁻¹ | 없음(빈자리) |
| P8 | 문맥 안 쓰기·읽기 | M = argmin ‖V − M·K‖² + λ‖M‖₁ | 빠른 시냅스 |
| P9 | 집합 위 병렬 적용 | Σ_o F(X_o) | 공유 블록 |

- **P3·P4·P5만으로도 지지는 보편이다.** 국소 다항 규칙의 반복은 셀 오토마톤이고, 셀 오토마톤은 계산 보편이다.
- **그래서 이 좌표계로 "표현 가능한 비율"을 재면 100%가 나와 의미가 없다.** 직접 읽기에서 본 것은 "짧은 합성이 보이는가"다.

## 부록 B. 손 클래스가 덮는 범위 (상한이 아님)

손으로 정한 한 단계짜리 클래스의 oracle 범위다(`arc_prior_audit.py`). 손 사전의 지지가 얼마나 좁은지를 보여 줄 뿐이다. 보편화한 뒤 학습 가능성의 근거로 쓰지 않는다.

| 클래스 | ARC-1 학습 | ARC-1 평가 | ARC-2 학습 | ARC-2 평가 |
|---|---:|---:|---:|---:|
| rank-1 C·X·Wᵀ (전역 색 함수, 주소 사상족, 크기 고정의 일반 주소 사상) | 14.2% | 8.8% | 8.9% | 1.7% |
| 반쪽 겹치기, 자기 크로네커 곱 | 3.2% | 3.2% | 2.6% | 0.0% |
| 채우기·광선·중력 | 12.2% | 7.8% | 8.7% | 0.8% |
| 물체별 재색칠·거르기·재배치 | 8.2% | 10.5% | 9.5% | 1.7% |
| 물체 자르기·부분 격자 | 7.2% | 4.5% | 5.1% | 0.0% |
| 대칭·주기 완성 | 4.8% | 4.8% | 3.1% | 0.8% |
| 하나라도 걸림 | 44.5% | 35.5% | 35.0% | 4.2% |

- **결정성 간극.** 손 족 안에서도 시범이 답을 정하지 못하는 경우가 많다.
  - 주소 사상족: oracle 8.5% 중 시범으로 결정되는 것 4.8%(ARC-1 학습)
  - 크기 고정의 일반 주소 사상: oracle 10.5% 중 결정 2.0%
  - 족을 넓힐수록 선택 원리(L2)와 코드(L3)가 일을 한다는 뜻이다.
