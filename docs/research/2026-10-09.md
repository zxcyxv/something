## 1. 위치 불변 위상

pairangle의 K 위상은 RoPE 회전 후 단위 주소의 쌍 각도였다. 회전 후 각도는 `φK + θ·pos_n`이므로 창
`W(φV − φK)`가 저장되는 칸의 절대 위치에 의존하고, 읽기의 상대 위치 불변성이 깨진다. 같은 상대 거리에서
절대 위치만 옮기는 수치 검사에서 읽기가 19% 변했고, 회전 전 각도를 쓰면 0이었다(테스트로 고정).

변경은 K 위상의 출처 하나다: `φK_nB = atan2(k̂_n의 쌍 B)` (회전 전). Hebbian 곱의 회전된 K와 읽기는 그대로이고
V 정규화는 없다(10-08 pairangle과 같은 조건).

- 위치 정보가 위상에 섞여 일반화가 낮아졌던 것으로 본다(회전 후 위상과 훈련 적합은 비슷하고 held-out만 높음).

  재귀를 거스르는 기울기 감쇠는 Hebbian·rotated·unrotated가 초기화에서 같다.

## 2. 일반형 창 `1 + αW`

```text
G_ab = Σ_n v_na · k̂r_nb · (1 + α_h W(φV_na − φK_nb))  =  G_Hebb + α_h · G_STDP
```

W(δ)는 주기화 tanh·sech(τ_φ = 2, R = 2)로 홀함수라 직류 항이 없다. 상수 1은 시간 창의 순적분(발화율
Hebbian 항)에 해당하는 주기화의 직류 성분이다. α_h는 헤드별 학습, 상한 없음, weight decay 없음(1차원 파라미터).
나머지는 1절 unrotated와 같다.

- **α 초기값 0** (`pairangle_unrotated_dc_tau2_r2_qkl2_sum_20261009`): 0스텝에서 B-only와 같다. α = 0에서는
  위상 경로의 기울기가 0이고, α는 3,000스텝 동안 −0.014~+0.013(헤드마다 부호가 섞임)에 머물렀다. 3,900스텝에서 중단.
- **α 초기값 1** (`pairangle_unrotated_dca1_tau2_r2_qkl2_sum_20261009`): 초기화 시점 읽기 RMS ×1.27,
  어텐션 잔차/hidden 비 0.41 → 0.53(이후 RMSNorm). 초기 loss는 160.7 vs 160.2로 같다.

## 3. 학습된 STDP의 직접 관측 (α = 1, 20k EMA)

forward의 STDP 변수를 hook으로 읽었다. 다시 계산한 쓰기·읽기는 모델 값과 상대오차 7e-7 이내로 일치하고,
계측한 forward는 공식 평가(418 / 2048)를 예측 불일치 없이 재현한다. 용어: 채널 쌍 = 뉴런(pre = K 쌍 B,
post = V 쌍 A), 칸 = 동시 발화 관측, 쌍의 각도 = 위상, Δ = φV − φK, gain = 1 + αW(Δ)(> 1 강화, < 1 약화, < 0 반전).

**크기와 LTP/LTD** (동시 발화 크기 가중; `lt/analyze_stdp_direct.py`)

| | LTP 비율 | gain < 0 | ‖αG_S‖ / ‖G_H‖ | cos(G_S, G_H) |
| --- | ---: | ---: | ---: | ---: |
| 초기화 | 0.50 | 0.00 | 0.73 | −0.02 |
| seg 1 | 0.31 | 0.31 (균일 위상이면 0.16) | 0.98 | −0.35 |
| seg 16, 푼 퍼즐 | 0.40 | 0.24 | 1.04 | −0.26 |
| seg 16, 못 푼 퍼즐 | 0.30 | 0.30 | 1.02 | −0.48 |

- seg 1에서는 푼 퍼즐과 못 푼 퍼즐의 모든 지표가 같다. 못 푼 퍼즐은 seg 2부터 지표가 고정되고 빈칸 정답률이
  0.48에서 움직이지 않는다.
- 칸과 무관한 시냅스별 고정 gain(최소제곱 마스크)으로 설명되지 않는 G_S 비율: seg 1에서 0.46, 푼 퍼즐 seg 16에서
  0.61, 못 푼 퍼즐 0.46(`lt/probe_stdp_token_timing.py`).

**사례: 퍼즐 30** (`lt/case_stdp_puzzle.py`). 단서 26, 빈칸 55. 솔버 기준 28칸은 single 규칙만으로(L1),
27칸은 한 번의 가정-모순 소거 뒤에(L2) 확정된다. 모델은 블록 48(seg 6 끝)에 완성했다.

- 확정 블록 중앙값: L1 2, L2 38. 논리 단계와 확정 순서의 Spearman 0.65. L2 칸은 확정 전에 예측을 중앙값 5번 바꿨다.
- 맞은 L2 칸 수: 블록 8에서 17 → 블록 26에서 9 → 블록 48에서 27.
- 칸별 LTP 비율(모든 시냅스 합): 풀이 중(seg 2~6) 0.29~0.32로 평평하고, 맞은 칸과 틀린 칸이 같다.
  완성 6~8블록 뒤부터 81칸이 함께 0.39~0.40으로 오른다.

**칸 사이 메시지** (풀린 퍼즐 418개; `lt/stdp_message_flow.py`). 칸 t가 칸 n을 읽는 메시지의 STDP 대 Hebbian 비
`κ_tn = 1 + Σ_h⟨r^S_tn, r^H_tn⟩ / Σ_h‖r^H_tn‖²`는, n의 스파이크 쌍 gain을 이 메시지를 싣는 시냅스들로 가중평균한
값이다. 메시지 합은 모델의 읽기와 7e-7 이내로 일치한다.

| 보내는 칸 (풀이 중, 빈 이웃에게) | κ | 강화된 메시지 비율 | 메시지를 싣는 시차의 강화 쪽 비율 |

| 단서 | 1.31 | 91% | 0.58 |

  seg 1에서 미확정 칸은 0.61~0.63. 풀린 뒤 확정 칸은 1.23.
- 칸 n이 확정되는 블록에 맞춘 κ(빈 이웃에게): −16~−1블록 0.81~0.85, 0블록 0.87, +1 0.93, +3 1.01, +8 1.12, +16 1.20.

- 시차 분포: 단서에서 나가는 메시지는 Δ = +60°~+120°에, 미확정 칸에서 나가는 메시지는 −120°~−60°에 몰린다.
- 헤드별 α·W(단서 / 확정 / 미확정-맞음 / 미확정-틀림): 헤드 6(메시지 가중 50%) +0.56 / +0.28 / +0.18 / +0.16,
  헤드 2(30%) +0.03 / −0.22 / −0.33 / −0.35. 나머지 헤드는 상태와 무관하게 −0.13~−0.73.
- 개별 시냅스(헤드 6): A30←B5, A41←B5, A30←B28 등은 단서 +0.9~+1.1, 빈칸(확정·미확정) −1.0~−1.2.
  A25←B5, A32←B5, A46←B5 등은 단서 +0.9~+1.1, 확정 −0.4~−0.25, 미확정 −0.95~−0.7.

칸 평균 위상(채널 "고유 위상")과 그 집중도는 81칸을 평균한 결과라 퍼즐 사이에서 거의 같아지며, STDP 규칙이 쓰는

## 코드

- `lt/experiment_free_phase_windows.py`: `--phase-frame rotated|unrotated`, `--dc-hebbian`, `--dc-alpha-init`.
  재개·평가·hybrid·probe 스크립트가 protocol의 새 항목을 읽는다.
- `lt/train.py`: cfg `save_at_boundary`(기본 True). False면 평가 경계 저장을 건너뛴다.
- `lt/resume_free_phase_windows.py`: `--no-boundary-save`.
- 분석: `lt/probe_gradient_flow.py`, `lt/analyze_stdp_direct.py`, `lt/probe_stdp_token_timing.py`,
  `lt/case_stdp_puzzle.py`, `lt/stdp_message_flow.py`. 출력 정리: `2026-10-09/print_stdp_direct.py`,
  `2026-10-09/print_message_flow.py`, 두 시점 비교 `2026-10-09/compare_interp_steps.py`.
- 급락 분석: `lt/probe_collapse.py`(완답·규칙 위반·단서 정확도, 그룹별 노름과 raw–EMA 거리),
  `lt/hybrid_eval_free_phase.py`의 그룹 q·k·v·o·ffn·io·theta·alpha, `lt/track_raw_ema.py --keep-every N`
  (평가 전에 대기 중인 체크포인트를 하드링크로 잡아 두고, N의 배수 스텝은 `raw_ema_kept/`에 보관).
- 외삽: `lt/extrapolate_free_phase.py`, 표 정리 `2026-10-09/extrap_summary.py`.
- 테스트: `python -m unittest lt.test_free_phase_windows lt.test_tanhsech_phase_window` (18개 통과). 추가분: unrotated 위상의
  위치 이동 불변성, `1 + αW` 쓰기 = Hebbian + α·pairangle 쓰기, gradcheck.
- 새 쓰기 연산자는 학습 설정(compile + activation checkpoint + BF16)에서 한 스텝의 eager/compiled gradient cosine을
  확인했다(최소 0.999999).
