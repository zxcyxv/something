# 2026-10-08 후보: 단위 복소 주소의 각도를 위상으로 쓰는 STDP

2026-10-08 논의를 정리한 설계 후보다. 같은 날의 B-only 대조 실험(QK L2 정규화 +
토큰 합산)이 KV 계열의 평가 붕괴를 없앤 결과를 바탕으로, 상태 의존 위상·공통
주파수·그에 맞는 창을 가장 단순한 형태로 고정한다. 블록 간 시냅스 누적은 마지막 절에
연결점만 적는다.

> **수정 (2026-10-08 오후).** 아래 "쓰기"·"읽기" 절의 첫 형태(실수 P×P G =
> `sum |v||k| W(delta)`, `--window complex`)는 구현·학습했으나 **설계 오류로 실패**했다.
> 창이 Hebbian 곱 `v conj(k)` 를 **대체**하면 G 가 K 의 위상을 잃고, 읽기 `G q` 에서
> q 와 k 의 위상을 비교하는 항이 사라진다. RoPE 위치가 전부 위상에 있으므로 토큰 매칭과
> 위치 정보가 함께 없어진다 (훈련 칸 51~58% 정체, warmup 뒤 loss 상승;
> [로그](2026-10-08/logs/complex_phase_tau2_r2_qkl2_sum_20261008/)).
> **채택한 형태는 `--window pairangle`**: 창이 Hebbian 곱을 **곱한다**.
>
> ```text
> phiK_n,pair(b) = atan2(RoPE pair of unit-L2 K_n),  phiV_n,pair(a) = atan2(pair of V_n)
> G_ab = sum_n V_na K_nb W(phiV_n,a - phiK_n,b)      (실수 104 x 104; 쌍의 두 성분이 위상 공유)
> read = RoPE(Q) G^T                                  (변경 없음)
> ```
>
> 2026-10-06 diagonal 모델과 쓰기·읽기가 같고 **위상의 출처와 창의 주기화만** 다르다.
> 복소 G (`sum v conj(k) W`, 복소 읽기)는 다음 단계 후보로 남긴다. (1)~(3) 절과
> 창 계수는 그대로 유효하다.

## 배경: 왜 지금 위상이 상수인가

현재 diagonal 생성기는 채널 j의 위상을 같은 채널의 활동 크기에서 만든다.

```text
phiK_j(n) = (pi/2) * tanh(thetaK_j + aK_j * K_nj)
```

"언제 발화하는가"가 "얼마나 세게 발화하는가"(`K_nj`)의 함수이므로 타이밍이라는
독립 정보가 없다. 학습된 모델에서 gain `a`가 0.01~0.02에 머물고 토큰 간 위상
표준편차가 0.003~0.013 rad인 것(10-06, 10-08 측정)은 이 구조의 결과로 본다.

같은 날 B-only 실험은 주소를 크기가 아니라 방향으로 두어야 함을 보였다
(원시 QK + /81: 13,671스텝 완답 30 → L2 + 합산: 260, 20,000스텝 334).
복소 공간의 방향은 크기 프로파일(내용)과 위상 프로파일(타이밍)로 나뉜다.
이 후보는 그 위상 프로파일을 STDP의 시간 좌표로 쓴다.

## 설계

### (1) 상태 의존 위상 = 단위 복소 주소의 각도

```text
k_n = W_K h_n in R^104          -> 52 complex:  k_nj = k_n[2j] + i k_n[2j+1]
k^_n = k_n / (||k_n|| + eps)     (현재 --qk-l2 와 동일; 104 실수 전체의 L2)
k^_nj <- k^_nj * exp(i theta_j pos_n)   (현재 RoPE 와 동일; 쌍 회전 = 복소 곱)

|k^_nj|  = 채널 j 의 세기 (내용)
phiK_nj  = arg k^_nj   (타이밍; h_n 의 함수 + 위치 회전)
```

V 도 같은 방식으로 52 복소로 읽되 정규화하지 않는다. `|v_ni|` 가 내용,
`phiV_ni = arg v_ni` 가 타이밍이다. Q 는 K 와 같이 단위 정규화한다.

새 파라미터는 없다. `theta_k_raw`, `theta_v_raw`, `phase_local_gain` 은 제거한다.
위치는 RoPE 각도 `theta_j pos_n` 으로 타이밍에 들어간다 (v1.7 의 `theta * pos` 회전과 같은 역할).

### (2) 공통 주파수

명시적 omega 는 두지 않는다. 모든 채널이 같은 omega 를 공유한다는 가정은
"서로 다른 채널의 arg 를 그대로 뺄 수 있다"는 형태로만 들어가고, omega 는
창 폭 `tau_phi = omega * tau` 하나에 흡수된다.

- 첫 실험: `tau_phi` 고정 스칼라.
- 두 번째: 헤드별 학습 (`softplus`), gradient 는 아래 계수 `b_r(tau_phi)` 를 통해 흐른다.

채널마다 omega 가 다르면 위상차가 `(omega_i - omega_j) t` 로 흘러 홀함수 창의
시간 평균이 0 이 된다. 공통 주파수는 이 해석의 전제다 (10-04 의 "공통 carrier 소거" 가정과 같다).

### (3) 창 = 주기화된 tanh·sech

위상이 각도이면 `Delta t = delta / omega` 는 주기 `T = 2 pi / omega` 모듈로만 정해진다.
같은 omega 로 반복 발화하는 두 뉴런 사이의 STDP 는 모든 주기의 쌍을 합하므로,
위상차의 함수로 본 실효 창은 시간 창의 주기화다.

```text
W(delta) = sum_m L((delta + 2 pi m) / tau_phi)
```

`L(t) = tanh(t) sech(t)` 의 푸리에 변환은 지수적으로 감쇠하므로 사인 급수가 빨리 끊긴다.

```text
W(delta) = s * sum_{r=1..R} b_r(tau_phi) sin(r delta),
b_r = tau_phi^2 * r * sech(pi r tau_phi / 2)
```

| tau_phi | b1 | b2 | b3 | b4 | 필요한 R |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 0.399 | 0.173 | 0.054 | 0.015 | 4 |
| 1.5 | 0.423 | 0.081 | 0.012 | 0.002 | 3 |
| 2 | 0.345 | 0.030 | 0.002 | 0.000 | 2 |
| 3 | 0.162 | 0.003 | 0 | 0 | 1 |

(수치 검산: 주기화 급수 직접 합과 계수 일치, 2026-10-08.)

- 첫 실험 추천: `tau_phi = 2`, `R = 2`, 스케일 `s` 는 peak 가 1 이 되도록.
- `tau_phi` 를 배우게 하면 "거의 사인(복소 Hebbian)" 과 "날카로운 순서 판정" 사이를 모델이 고른다.
- 비교: 부호 지수창 `sign(t) exp(-|t|/tau)` 의 주기화는 닫힌 꼴
  `sinh((pi - delta)/tau_phi) / sinh(pi/tau_phi)` 이고 계수가
  `(2/pi) r tau_phi^2 / (1 + r^2 tau_phi^2)` 로 느리게 감쇠해 어느 tau_phi 에서도
  순수 사인이 되지 않는다 (b2/b1 >= 0.5). 매끄러운 창이 주기화에 유리하다.
- 짝수 조화는 부호에 둔감하다 (`sin(2(delta + pi)) = sin(2 delta)`). 역위상 = 반주기 차이라는
  진동자 해석의 결과이며 `tau_phi = 2` 에서는 b2 가 b1 의 9% 다.

### 쓰기

```text
G_ij = sum_n |v_ni| |k^_nj| W(phiV_ni - phiK_nj)
     = sum_r s b_r Im[ A_r^T conj(B_r) ]_ij
A_r[n, i] = |v_ni| (v^_ni)^r,   B_r[n, j] = |k^_nj| (k^_nj)^r     (단위 위상자의 r 제곱)
```

조화 r 마다 복소 GEMM 하나 (실수 GEMM 2개). r = 1 항은 정확히 `Im(V^T conj(K))`,
복소 Hebbian 곱의 허수부다. 토큰 합산(/81 없음)은 B-only 결과대로 유지한다.
G 는 실수 52 x 52 다.

### 읽기

G 를 복소 q^ 에 실수 행렬로 적용한다: `Re(q^)` 와 `Im(q^)` 에 같은 G 를 곱해 104 실수로
되돌리고 `out_proj` 로 보낸다. 선형이고 출력 차원이 그대로라 가장 작은 변경이다.
v1.7 처럼 읽기에도 창(psi)을 두는 것은 다음 단계다.

## 염두에 둘 것: 블록 간 누적

주기화 창은 "같은 위상으로 매 주기 반복 발화"를 이미 합한 것이므로, 블록을 한 주기로
보면 이전 블록의 쌍은 급수의 m = -1 항이다. 상태가 블록마다 바뀌면 그 항이 달라지며,
그것을 `G_k = lambda G_{k-1} + dG_k`, `lambda = exp(-T / tau_c)` 로 받는 것이
[2026-10-07 계획](2026-10-07-cross-block-stdp-plan.md)의 자리다. 이 후보는 `tau_c` 를
두지 않고 블록마다 G 를 새로 만드는 구조를 유지한다.
