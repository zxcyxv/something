## 1. 혼합형 시간: 왜, 무엇을

### 1.1 런3의 결함
런3(10-13, `--clock displacement`)의 시각은 각 채널 쌍이 자기 회전을 누적한 각도 φ다. 블록 안의 LTP/LTD는 정상이지만(시각이 사건마다 하나, 상태에서 계산,
차이에만 의존, 홀수 창), 각도는 원 위에서 접히므로 **블록 사이에 시간이 흐르지 않는다**. 블록 b와 b−3의 사건은 그 사이 변위 합이 0이면 같은 시각이고
2π를 넘으면 순서가 뒤집힌다. Rule110에서 학습 후 블록 순서와 부호가 무관했다(0.344/0.344, `scripts/rule110_order_trained.py`).

### 1.2 설계
사건의 시각을 진행 부분과 유계 부분의 합으로 둔다:

    τ = n·ωT + c·sin φ        n = 퍼즐 시작 뒤 지나간 블록 수(첫 블록 0), ωT = 블록 간격, c·sin φ = 뉴런별 유계 지연

같은 블록 짝은 |Δτ| ≤ 2c, k블록 떨어진 짝은 k·ωT ± 2c. 따라서 **ωT > 2c 이고 K·ωT + 2c < π** 이면 블록 차 1 ≤ k ≤ K인 모든 짝의 sin(Δτ) 부호가
블록 순서와 일치한다. 채택값 c = 0.14, ωT = 0.34, K = 8(세그먼트 길이). λ = 0.5 고정. 파라미터는 없다(시계·가소성 모두). 위상자로 구현하면 흔적이
블록마다 λe^{−iωT}를 곱하고 창은 감쇠 사인 λ^k sin(kωT)가 된다.

주기성은 두 군데 있고 둘 다 쓰기 항에 들어가지 않는다. 절대 시각 n·ωT의 감김은 쓰기에 차이 e^{i(τ_post − τ_pre)}로만 들어가므로 블록 차 k만 남고
(정상 창), 창 sin(kωT)는 k = π/ωT ≈ 9.2에서 부호를 바꾸지만 λ^k가 먼저 죽인다(뒤집힌 꼬리 0.2%). 조건은 λ^{π/ωT} ≪ 1이고 λ를 0.9로 학습시키면
0.9¹⁰ ≈ 0.35로 주기성이 돌아오므로 λ를 고정했다.

### 1.3 순전파(논문 §3용)

```text
inj = E[x] + E_puz;  u = h_{b−1} + √d inj;  q, k, v = heads(W u);  q̂, k̂ = L2;  q̃, k̃ = RoPE(q̂), RoPE(k̂)   (학습된 2D 각도)
δ_r = wrap(ang(r_b) − ang(r_{b−1}))  (r = k̂ 쌍, v 쌍; 첫 블록 0);  φ_r ← wrap(φ_r + δ_r);  τ_r = c sin φ_r + n ωT;  n ← n + 1
E_K ← λE_K + (1−λ) k̂ e^{−iτ_K};  D_V = λE_V;  E_V ← D_V + (1−λ) v e^{+iτ_V}
S_b = Σ_t [(v e^{iτ_V}) RoPE(E_K)ᵀ + D_V (k̃ e^{−iτ_K})ᵀ];  G_b = Σ_t v k̃ᵀ + α_h Im S_b;   read = q̃ G_bᵀ
h' = RMSNorm(u + W_O read);  h_b = RMSNorm(h' + W_D(silu(g) ⊙ a)),  [g; a] = W_gu h'
```
STDP 짝은 **같은 칸**의 K 사건(pre)과 V 사건(post) 사이에서 블록을 넘어 맺어지고(흔적이 칸별), 칸 사이 통신은 읽기 q̃·k̃에서만 일어난다.
창 W(Δt) = δ(Δt)(Hebb, 같은 블록) + α·sin(Δτ)·λ^k(홀수). 짝수 창(cos)은 넣지 않았고 그것이 STDP 고유성의 대조군이다. B는 W_b = ρW_{b−1} + Im S_b,
G_b = Hebb_b + α_h W_b. 세그먼트 경계에서 흔적·시계·W detach.

## 4. 정리: Im S의 순서/지연 분해와 고정점 (`scripts/stdp_order_decomp.py`, 46,872 EMA, 512문제, 128블록, torch 경로 FP32)

k블록 떨어진 짝의 무게 sin(kωT + Δa)(Δa = 지연 차 c sin φ_V − c sin φ_K)를 전개하면 Im S_b는 두 성분으로 유일하게 나뉜다:

    O_b = Σ_k (1−λ)λ^k sin(kωT) [cosΔa · v(b)k̃(b−k)ᵀ − cosΔa′ · v(b−k)k̃(b)ᵀ]              순서부: 부호 = 어느 블록이 먼저인가. 시간 반전에 홀수
    L_b = Σ_k (1−λ)λ^k cos(kωT) [sinΔa · v(b)k̃(b−k)ᵀ + sinΔa′ · v(b−k)k̃(b)ᵀ] + (1−λ) sinΔa · v(b)k̃(b)ᵀ   지연부: 부호 = 누구의 자기 시계가 앞서는가. 짝수

**정리.** 재귀의 고정점(v, k̃, φ가 블록마다 같음)에서 O_b ≡ 0, L_b = κ·SB_b, SB_b = Σ_t sin(Δa_t) v_t k̃_tᵀ, κ = (1−λ)(1−λ²)/(1 − 2λcos ωT + λ²) = 1.221.
증명: 흔적의 기하급수를 닫으면 S_∞ = Σ v k̃ᵀ e^{iΔa}(1−λ)[1/(1−z) + z̄/(1−z̄)], z = λe^{iωT}, 대괄호 = (1−λ²)/|1−z|² 실수.
따름정리: 10-10 기준 모델(창 sin(φ_V − φ_K), 역사 없음)은 이 모델의 고정점 극한과 같은 꼴이고, 두 모델의 차이는 과도기에만 있다.
측정은 시간 반전으로 한다: 같은 궤적에서 ωT → −ωT인 그림자 흔적을 함께 돌리면 Im S(+) − Im S(−) = 2O, 합 = 2L.

결과(푼 퍼즐 250, 못 푼 262):
- ‖L‖/‖SB‖ = **1.218**(예측 1.221), cos(L, SB) = 0.999, 블록 6부터 끝까지, 수렴 여부와 무관.
- ‖O‖/‖Hebb‖: 푼 퍼즐 0.164(블록 3) → 0.016(48) → **0.000**(128); 못 푼 퍼즐은 블록 32부터 **0.054** 바닥에서 배회(‖Δh‖도 안 죽음).
- 정착 블록(O가 자기 최고치의 10% 아래로 내려가 머무는 블록)과 풀린 블록의 스피어만 **0.994**, 중앙값 36 대 24. O만으로 풀림/안 풀림 판정 **97%**
  (못 푼 262 중 255 미정착, 7은 틀린 고정점; 푼 250 중 249 정착).
- 학습된 STDP 항의 크기는 대부분 지연부(‖L‖/‖Hebb‖ ≈ 0.22 일정)이고 순서부는 과도기 신호다.

## 6. O의 정체: TD 델타 규칙

k = 1 항을 전개하면 Hebb + αO₁ = Hebb + αc₁·Δv k̃ᵀ − αc₁·v Δk̃ᵀ (c₁ = (1−λ)λ sin ωT; 전체는 γ = Σ k c_k = 0.662). 읽기 행렬은

    G ≈ (v + αγΔv)(k̃ − αγΔk̃)ᵀ        값은 한 블록 앞으로, 키는 한 블록 뒤로 외삽한 Hebb

학습된 α로 외삽 폭을 재면 αγ가 헤드별 0.66~1.20, 평균 **0.91** — 모델은 거의 정확히 한 블록 앞을 읽도록 α를 맞췄다. 이것으로 §5가 한 줄로 설명된다:
O는 한 발 앞 예측이라 전파를 당기고(1.32 → 1.03), 부호를 뒤집으면 한 블록 전 값을 읽는 지연 되먹임이라 진동한다. "변화를 나른다"의 내용은
Δv = W_V·Δh, 즉 칸의 믿음(후보 집합, §7) 변화이고, 둘째 항 −v Δk̃ᵀ는 칸의 주소가 돈 만큼 옛 자리에서 내용을 철회한다.

DeltaNet(Schlag 2021; Yang 2024: S_t = S_{t−1} + β_t(v_t − S_{t−1}k_t)k_tᵀ)과 비교하면, 칸들의 키가 직교하고 키 회전이 작을 때 첫 항이 DeltaNet 1스텝(β = αc₁)과
같다. 다른 점: DeltaNet의 오차는 기억의 실제 읽기 v − Sk(다른 토큰의 간섭 포함)이고 우리는 같은 칸의 과거 값 v(b) − v(b−k)(자기 수정)다. 즉 DeltaNet은
겹치는 키를 간섭으로 보고 지우지만 우리는 겹침이 피어 간 통신 간선이라 보존한다(§8의 근거 간선이 Hebb에 있는 이유). 또 DeltaNet에 없는 키 이동 철회 항과
지연 게이트 L이 각각 §5.2와 §5.1을 담당했다. 누적(B의 ρ)은 Gated DeltaNet의 감쇠 자리에 해당한다.

## 7. 논리적 깊이와 결정 순서, 후보 집합 (`scripts/sudoku_depth.py`, 50,778, 512문제, 128블록)

깊이 = **L0 동기식 단일 후보 라운드**: 앞 라운드까지 확정된 칸만 보고 naked single과 hidden single을 전부 동시에 확정하는 한 번. 칸의 깊이 = 확정되는 라운드.
한 수 내다보기(가정 + 전파 끝까지)는 L0가 몇 라운드든 걸려 푸는 칸을 전부 1라운드로 접어 층을 없애므로 티어로만 쓴다: L0 / L1(가정 하나) / 너머(가정 2개 이상).
데이터셋: 주어진 칸 25.0, L0가 푸는 퍼즐 75/512, L1 172, 너머 340(빈 칸의 65%).

| 퍼즐 티어 | 퍼즐 | 모델이 푼 것 | 그 티어 칸 정확도 | 결정 블록 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| L0 | 75 | 73 (97%) | 99.3% | 3 |
| L1-only | 97 | 72 (74%) | 87.8% | 10 |
| 너머 | 340 | 123 (36%) | 64.4% | 13 |

- 결정 블록(argmax가 최종값으로 굳는 블록)을 L0 깊이별로 보면 1 → 2.1, 2 → 3.0, 3 → 4.4, 4 → 5.4, 6 → 7.7, 8 → 9.5, 10 → 12.7, 12 → 16.1(평균).
  기울기 **1.06 블록/라운드**, 스피어만 0.64(퍼즐 안 0.47). 같은 깊이 칸 쌍의 결정 시각 차 2.6블록, 다른 깊이 3.8.
  **순차 구조는 있고 공간이 아니라 논리적 깊이를 따른다. 블록 하나 ≈ 동기식 전파 한 라운드.**
- 로짓은 블록 2부터 후보가 1.0~1.5개로 일찍 확정하지만(솔버 후보는 3 이상), 은닉 상태에서 "이 숫자가 아직 가능한가"(미확정 칸, 9개 이진)를 릿지 probe로 읽으면
  블록 3~8에 **98.7%**(로짓 94.7%, 다수결 58%). 후보 집합은 argmax 밑 은닉 상태에 있다. 다만 읽히는 것은 주로 1홉 정보(이웃 확정값의 제외)다.
- 모델은 가정 2개 이상이 필요한 퍼즐 123개를 푼다(푼 268개 중 195개가 그런 칸 포함). 그 칸들은 늦게, 정확도 64%로 결정된다. 전파로 닿지 않는 이 부분의 기제는 미해명.

## 8. 부정 결과 셋

- **공간 파동은 없다**(`scripts/stdp_wave.py`): 순서 읽기의 주 원천은 제약 이웃 66%·빈 칸 97.5%(Hebb는 이웃 81%·주어진 칸 46%)이지만, 이웃 칸끼리 결정 시각 차는
  비이웃과 5%만 다르다(10.2 대 10.8). 순차성은 §7의 깊이에 있다.
- **근거 간선은 Hebb가 나른다**(`scripts/stdp_justification.py`): 칸이 결정되는 블록에 들어오는 읽기 중 솔버의 근거 칸(naked: 확정된 피어, hidden: 단위의 나머지 8칸)
  집중은 Hebb 밀도비 1.76(naked)·1.32(hidden)이고, 순서 읽기는 확정 칸을 피한다(0.81). "STDP가 제약 전파를 시냅스 수준에서 구현한다"는 간선 수준에서 불지지.
- **추론 때 기억 연장은 순손실**(`scripts/memory_sweep.py`): λ 0.6/0.7/0.8 → 253/216/201, STDP 항 EMA ρ 0.5/0.8/0.9 → 257/253/251(기준 264). 새로 풀림 7~13 < 잃음 16~66.
  "못 푼 퍼즐은 기억이 짧아 같은 오답을 되풀이한다"는 가설은 λ = 0.5에 맞춰진 가중치의 분포 이동과 갈라지지 않아, 긴 기억으로 **학습한** 모델(B의 ρ)로만 검증 가능.

## 9. B: 누설 바깥 적분 캐글 셀 (`kaggle/phaseclock_bounded_leaky_cell.py`, `kaggle/README_phaseclock_bounded_leaky.md`)

A + W_b = ρ·W_{b−1} + Im S_b(ρ 0.5), 읽기 q̃(Hebb + α_h W)ᵀ. W는 carry 필드 `stdp_w`([B,H,D,D] FP32), 새 퍼즐 0, 세그먼트 경계에서만 detach, 체크포인트 저장.
λ = 0.5 고정. 파라미터 8,541,747(런3와 같음). 자체검사 6/6(태그·Im S·W·읽기의 명시적 합, 2×3 = 6블록, 레인 리셋, 전 파라미터 기울기 = 중앙차분, 저장→복원; 변이 검사 7종).
ρ = 0에서 저장소 `--clock bounded`와 로짓 3e-6, 기울기 1e-6 일치. 4090 bf16 265 ms/step(10 GiB), FP32 470 ms(T4/P100 경로). 캐글: 11.5시간에 저장 후 정지, `resume_from`.
§8의 기억 가설을 보려면 `b_outer_rho` 0.9에 `b_alpha_init` 0.1(평형 ‖W‖ = ‖증분‖/(1−ρ) 보정)로 한 런을 더 두는 것이 다음 안이다.
