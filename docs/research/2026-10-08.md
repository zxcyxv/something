## 5. 주기화 창 (이론)

위상이 각도이면 `Δt = δ/ω`는 `T = 2π/ω` 모듈로만 정해진다. 공통 ω로 반복 발화하는 두 뉴런의
STDP를 모든 주기에 대해 합하면 창은 주기화된다: `W(δ) = Σ_m L((δ+2πm)/τ_φ)`, `τ_φ = ωτ`.

- 부호 지수창: `W(δ) = sinh((π−δ)/τ_φ)/sinh(π/τ_φ)` (δ∈(0,2π)), 계수 `(2/π) r τ_φ²/(1+r²τ_φ²)`.
  어느 τ_φ에서도 순수 사인이 아님 (b₂/b₁ ≥ 0.5). 최근접 쌍 STDP와 같은 모양.
- tanh·sech: `b_r = τ_φ² r sech(πrτ_φ/2)`. τ_φ=2에서 b₂/b₁=0.087, R=2로 충분.
- 수치 검산 통과. 자세한 것은 [후보 문서](2026-10-08-complex-phase-candidate.md).

### 6a. `complex` — 실패 (설계 오류)

`G_ij = Σ_n |v_ni||k_nj| W(φV−φK)` (실수 52×52), 읽기는 G를 Re(q), Im(q)에 적용.
창이 Hebbian 곱을 **대체**해 K 위상이 G에서 사라지고, 읽기에서 q/k 위상 비교 항이 없다.
RoPE 위치가 전부 위상에 있으므로 토큰 매칭과 위치가 함께 소실. 훈련 51~58% 정체, warmup 뒤 loss 상승.
5,050스텝 중단 ([로그](2026-10-08/logs/complex_phase_tau2_r2_qkl2_sum_20261008/)).

### 6c. `softangle` — 약한 채널의 위상 결맞음을 낮춤

단위 위상자 `z/|z|` 대신 `z̃ = ρ·z/|z|`, `ρ = |z|/√(|z|² + (κ·rms_pairs)²)`, κ = 0.5.
창은 `W̃ = Σ_r b_r (ρV_i ρK_j)^r sin(rδ)`: 강한 채널은 pairangle과 같고 약한 채널은 매끄럽게 0.
atan2 없음(복소 거듭제곱의 실수 연산). 바닥은 토큰·헤드의 RMS에 상대적이라 전체 스케일로 피할 수 없다.

- **첫 판 (게이트에 gradient)**: 실패. 에너지를 소수 채널에 몰면 그 채널의 ρ→1이 되므로 V를 집중·팽창시킴.
  1,000스텝에 v rms 18~25, 읽기 rms 73~110 (hidden rms 1), `b_down` 노름 2.0으로 붕괴, loss 2.28 정체.
  ([로그](2026-10-08/logs/softangle_attached_gate_f0.5_20261008/))
- **둘째 판 (ρ detach, 대수적 단위 벡터)**: 실패했지만 모델 탓이 아니었다. 3k스텝까지 loss 2.0 정체.
  같은 init·배치로 eager 학습하면 pairangle과 같은 곡선인데 **torch.compile(2.11)에서만** 다르다.
  한 스텝 eager/compiled 비교: loss는 일치하지만 파라미터 gradient의 cosine이 ~0.
  원인은 `z * rsqrt(|z|²+eps)` 단위 벡터의 backward가 activation checkpointing + compile에서 잘못 생성되는 것

### 6d. 해석: 위상이 내용과 같은 벡터에서 나오면 STDP는 커널을 부풀린다

R=1 창에서 토큰 하나의 쓰기는 `V_a K_b sin(φ_a−φ_b) = (V_a sinφ_a)(K_b cosφ_b) − (V_a cosφ_a)(K_b sinφ_b)`,
패턴당 rank-2 외적이다. φ가 같은 벡터의 각도이므로 `V_a sinφ_a`는 내용 벡터의 2차 삼각 특징이고,
`G = Σ_n Φ(v_n)Ψ(k_n)ᵀ`(Φ, Ψ는 고정 2차 특징 사상)가 된다. Hopfield로 보면 패턴 대신 패턴의 2차 특징을
외적하는 것: 커널이 선형→2차로 올라 저장 용량이 늘고 훈련 퍼즐을 더 외운다. 잡음이 아니라 표현력이며,
softangle이 무효인 이유다. softmax 어텐션과의 차이는 비선형성의 유무가 아니라 축이다: softmax는 (t,n) 토큰 쌍
점수에 걸려 `점수×값` 분해를 유지하고, 이 창은 (n,a,b) 채널 쌍에 걸려 토큰마다 값을 채널별로 재가중한다.
같은 토큰 안의 채널 쌍에는 토큰 단위 위상이 소거되므로(`ψ_n − ψ_n`), 이 축의 위상은 필연적으로 채널 벡터에서
나와야 하고 그래서 커널 부풀림을 피할 수 없다.

STDP가 Hebbian에 더해야 하는 것은 인과 순서이고, 이 모델에서 실제로 존재하는 시간은 재귀다.
블록 k의 채널 b → 블록 k+1의 채널 a가 진짜 pre/post다. 10-03의 블록 간 G/M 비교는 붕괴하는 원시 QK /81 바탕에서
나왔으므로 무효이며, L2 + 합산 바탕에서 다시 측정해야 한다 ([10-07 계획](2026-10-07-cross-block-stdp-plan.md)).

### 6e. V 정규화 (`--v-norm unit_gain`): 표현력을 두고 일반화를 복구하는 첫 시도

"표현력이 늘었다"를 결함으로 두지 않고, 늘어난 자유도에 표준 처치를 적용하는 쪽으로 태도를 바꿨다
(사용자 지적: 같은 파라미터에서 표현력만 늘어 과적합한다면 SwiGLU도 ReLU보다 과적합해야 한다 — 체제의 문제다).
첫 처치는 Hopfield식 패턴 노름 고정: `v ← softplus(g_h)·v/(‖v‖+ε)`, g_h 헤드별, 초기 √dh.
pairangle과 다른 점은 이것뿐이다 ([로그](2026-10-08/logs/pairangle_vunit_gain_tau2_r2_qkl2_sum_20261008/)).

| step | V 단위+게인 | pairangle | softangle | B-only L2 |
| ---: | ---: | ---: | ---: | ---: |
| 7,812 | 65.8% / 79 | 63.4% / 47 | 63.1% / 37 | 68.1% / 243 |
| 11,718 | 66.8% / 124 | 63.7% / 42 | 62.5% / 15 | 68.8% / 237 |
| 15,624 | 66.8% / 255 | 65.7% / 126 | 65.6% / 64 | 69.2% / 289 |
| 19,530 | **67.8% / 323** | 65.9% / 153 | 65.5% / 66 | 69.4% / 347 |
| 20,000 | 67.2% / 299 | 65.6% / 121 | 65.3% / 70 | 69.5% / 334 |

- pairangle보다 전 구간 2~3%p 높고 완답은 2배(19.5k: 323 vs 153). 정체가 아니라 단조 상승이다.
- 훈련 적합은 오히려 더 높다 (18k–20k 완답 45.1% vs pairangle 42.6%, B-only 22.8%). **표현력을 줄이지 않고 held-out만 올랐다.**
- 게인은 9.7~10.7로 초기값(10.2)에서 거의 움직이지 않았다. 모델이 쓰기 스케일을 바꿀 이유가 없었다.
- 위상 ablation (20k, 1,024문제): 정상 66.7%/126 → 섞기 39.0%/0 → 채널 평균 37.5%/0. 위상은 여전히 계산을 운반한다.
- 그래도 B-only L2(69.5%/334)에는 못 미친다.

### 6f. 이론: K는 주소여야 하고, 타이밍은 주소의 재부호화여서는 안 된다

B-only에서 K는 단위 벡터, 즉 순수한 주소다. pairangle의 K 쪽 패턴 `k⊙cosφ_k`, `k⊙sinφ_k`는 φ_k가 k의 쌍 각도이므로
`k_x²/|k_j|, k_xk_y/|k_j|, k_y²/|k_j|`: 메모리가 주소를 **2차 단항식**으로 본다. Krotov–Hopfield의 dense associative
memory처럼 차수가 오르면 용량이 `N^{n−1}`로 뛰고 훈련 퍼즐 특유의 주소가 생긴다. "K가 내용을 표현하게 됐다"는 뜻이
정확히 이것이다. V 정규화가 효과를 낸 것은 V 쪽 확장을 줄였기 때문이고, K 쪽 2차 확장이 남아 B-only를 못 넘는다.

더 올라가면, K=pre·V=post 해석은 **클램프된 이종연합 저장**으로만 정당화된다: 저장 때 pre를 단서 k_n에, post를
목표 v_n에 클램프하고 외적을 더하며, 인출 때 pre에 q_t를 제시한다. 클램프 저장에는 시간이 없다 — v_n은 k_n이
일으킨 활동이 아니라 같은 h_n의 다른 읽기다. 그래서 블록 안 위상은 원리적으로 패턴의 재부호화가 될 수밖에 없었다.
STDP의 Δt는 패턴 밖의 동역학에서 와야 한다: (A) 지연 부호 `φ = g(|drive|)` (고정 g, 학습 없음),
(B) 재귀를 따라 흐르는 이완 위상 상태 `φ^{(k+1)} = φ^{(k)} + ω + κ·f(activity)` (f 고정, ω·κ만 스칼라),
(C) 실제 인과 경로인 쓰기 시각과 읽기 시각의 차이를 (B)의 연속 위상으로 재는 것. 10-03식 블록 단위 시간은 쓰지 않는다
(사용자: 시간은 연속적으로 이완되어야 표현력이 충분하다). 구현은 사용자 승인 후에만 한다.
