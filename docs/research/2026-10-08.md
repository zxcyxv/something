## 실패: QK L2 바탕에서도 STDP의 일반화가 B-only보다 낮다

같은 QK L2 + 합산 바탕에 STDP 창을 얹은 런은 모두 B-only에 미달했다.

| 런 | 20k (또는 중단 시점) |
| --- | ---: |
| B-only QK L2 + 합산 (기준) | **69.5% / 334** |
| `pairangle` + V 단위·게인 | 67.2% / 299 (19.5k 67.8% / 323) |
| `pairangle` | 65.6% / 121 |
| `softangle` κ=0.5 | 65.3% / 70 |
| tanh·sech diagonal | 11.7k 63.4% / 51 (중단) |
| `complex` | 3.9k 55.7% / 0 (중단) |
| `relaxphase` κ=1 | 2.0k 38.8% / 0 (중단) |

pairangle 계열은 훈련 적합이 B-only보다 높고(종료 세그먼트 완답 27~45% vs 16~23%) held-out은 낮다.

## 도구 메모

새 쓰기 연산자는 학습 설정(compile + activation checkpoint + BF16)에서 한 스텝의
eager/compiled gradient cosine을 확인한다. torch 2.11에서 `z * rsqrt(|z|²+eps)` 단위 벡터의
backward가 잘못 컴파일된 사례가 있었다
([로그](2026-10-08/logs/softangle_miscompiled_rsqrt_f0.5_20261008/)).
