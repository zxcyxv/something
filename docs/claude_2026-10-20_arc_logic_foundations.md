# 2026-10-20 ARC 풀이의 수리논리학적 기반

> **성격**: Claude의 이론 정리다. 앞선 문서의 "ARC에서는 과제마다 바뀌는 것이 내용이 아니라 규칙이다"(`docs/claude_2026-10-20_rule_synapse_theory.md` 0절, `docs/claude_2026-10-20_rule_synapse_architecture.md` 1절)는 정의 없이 쓴 문장이고, 아래 명제 1에 따라 틀렸다. 이 문서가 그것을 대체한다. 인용한 정리는 표준 결과다. 신경망과의 대응은 대응 관계로만 적었다.

## 1. 대상
- 색 집합 C(|C| = 10, 0 = 배경은 관례). 격자 x: Ω → C, Ω = [h]×[w], 1 ≤ h, w ≤ 30. 모든 격자의 집합 𝒳는 유한이다.
- 격자를 유한 순서 구조로 본다: 𝔊_x = (Ω; <_행, <_열, (P_c)_{c∈C}), P_c(ω) ⇔ x(ω) = c.

**정의 1 (규칙 = 논리적 해석).** 논리 L(FO, FO[TC], FO[LFP], 세기 확장 등)의 해석 Θ는 다음으로 이루어진다.
- 출력 크기 (h′, w′)를 정의하는 식
- 색마다 φ_c(i, j): 출력 칸 (i, j)의 색이 c ⇔ 𝔊_x ⊨ φ_c(i, j) (칸마다 정확히 하나의 c)

Θ는 함수 f_Θ: 𝒳 → 𝒳를 정의한다. 기술 길이 |Θ|는 식의 기호 수다.

## 2. 과제와 풀이
과제 τ = (D, x*), D = {(x_i, y_i)}_{i=1..n}. Θ ⊨ D는 모든 i에서 f_Θ(x_i) = y_i라는 뜻이다.

**정리 1 (미결정성).** L ⊇ FO이고 x* ∉ {x_i}이면, 모든 y ∈ 𝒳에 대해 Θ ⊨ D이고 f_Θ(x*) = y인 L-해석이 있다.
*증명.* 유한 구조는 1차 문장 χ_x 하나로 동형까지 특정된다. "χ_{x_i}이면 y_i, χ_{x*}이면 y" 꼴의 경우 나눔으로 Θ를 만들고, 고정 격자 출력은 순서와 유계 크기(≤ 30) 덕에 FO로 쓴다. ∎

**함의.** 시범만으로 답은 정해지지 않는다. 풀이는 가설 위의 선호(사전분포)를 고정한 뒤의 최적화다.

**정의 2 (Occam 풀이와 s-결정).**
- Sol_L(D, x*) = { f_Θ(x*) : Θ ∈ argmin{|Θ| : Θ ⊨ D} }.
- 확률판: P(Θ) ∝ 2^{−|Θ|}, 사후 ∝ P(Θ)·1[Θ ⊨ D].
- s-결정: |Θ| ≤ s이고 Θ ⊨ D인 모든 Θ가 x*에서 같은 답을 낸다. Mini-ARC 천장 측정(`toy_g/miniarc_ceiling.py`)은 작은 L들에 대해 이것을 셌다.

**표본 수.** Occam 면도날 정리(Blumer, Ehrenfeucht, Haussler, Warmuth 1987)는 m ≥ (1/ε)(s ln 2 + ln(1/δ))개의 i.i.d. 예로 오차 ≤ ε를 보장한다. m = 3이면 이 한계는 쓸모가 없다. 시범 3개로 풀리는 근거는 PAC가 아니라 s-결정성이다. 시범 하나는 출력 칸 수 × log|C| 비트의 제약을 준다.

## 3. 층위
**생성 모형 (가정).**
- (A1) 과제 사이에 공유: L, 어휘, |·|, 즉 P_L
- (A2) 과제마다: Θ_τ ~ P_L
- (A3) 쌍마다: x_i ~ P_τ, y_i = f_{Θ_τ}(x_i)

**명제 1.** (A1)~(A3)에서 과제 안에서 불변인 것은 Θ_τ, 과제 사이에서 불변인 것은 P_L이다. 입력 격자는 쌍마다(따라서 과제마다도) 바뀐다. "과제마다 바뀌는 것이 내용이 아니라 규칙"은 틀렸다.

**TEM과의 대응.**

| TEM | ARC |
|---|---|
| 환경 e (ω_e) | 쌍 i (x_i) |
| 공유 구조 (S, T) | 과제 안의 공유 규칙 Θ_τ |
| 구조 하나를 많은 환경에서 학습 | Θ_τ를 n ≈ 3쌍에서 추론 |
| 없음 | 과제 사이의 사전분포 P_L |

TEM의 편향은 과제 안에서는 맞다. 어긋나는 것은 구조를 몇 쌍에서 정해야 한다는 점과, 그에 필요한 구조들 위의 사전분포 층이다.

## 4. 기술 복잡도
**표준 결과** (순서 있는 유한 구조)
- FO[<, BIT] = DLOGTIME-균일 AC⁰ (Barrington, Immerman, Straubing 1990)
- FO[TC] = NL (Immerman 1987)
- FO[LFP] = P (Immerman 1986, Vardi 1982)
- 그래프 도달 가능성 ∉ AC⁰ (패리티 환원, Furst–Saxe–Sipser 1984, Ajtai 1983)

**ARC 규칙의 분류.**
- 색 바꾸기, 고정 반경 이웃 규칙, 고정 매개변수의 대칭·이동·자르기·타일: FO, 상수 깊이
- 물체(연결 성분), 채우기, 막힐 때까지 연장: 크기와 무관하게 쓰려면 TC 또는 LFP, 즉 반복 깊이가 지름에 비례
- 물체 수 같은 수량: 세기 필요

**단서.** 격자가 유계(≤ 30×30)라 모든 규칙은 긴 FO 식으로 정의된다. 그래서 논리 사이의 차이는 표현 가능성이 아니라 기술 길이이고, 논리의 선택이 곧 사전분포 P_L이다.

**신경망 대응** (정리 아님). 공유 블록의 재귀는 걸음 함수의 반복 Φᵏ이다. 블록이 FO식 걸음 하나를 표현하면, 반복이 LFP 단계를 따라갈 수 있다. "재귀 = 고정점 반복"이다.

## 5. 우리 실험의 위치
- **토이:** f(x)(ω) = κ(x(r(ω))), r ∈ D4 ⋉ Z₄². 정해진 r에서 양화사 없는 식이다.
- **판 A (문법 줌):** 사전분포 = L_토이 위의 균등 분포. 100%.
- **판 C (자유 구조, `runs/rs/C_free_K4_N6_d32`):** 학습된 원시 연산 위의 단어 5,461개가 후보였다. 학습 목표는 학습 규칙 112개가 어떤 단어로든 구현되면 0이 되고, 그런 의미 배정의 대부분은 준동형이 아니다. 합성적인 구문이 처음 보는 단어에서 맞는 의미를 보장하지 않으므로, 그룹 2의 실패(2~12%, 구현된 처음 보는 변환 0~1/16)는 학습 목표가 준동형을 식별하지 못한다는 데서 나온다.
- **Mini-ARC 천장:** 작은 L들의 s-결정 비율. 회전·반사 계열 약 5%, 내용과 무관한 단일 칸 읽기 전체가 신탁 기준 28%.

## 6. 설계 요구
ARC 풀이기는 세 부품으로 나뉜다.
1. 언어와 길이 (L, |·|): 과제 사이에서 학습
2. 추론: argmin{|Θ| : Θ ⊨ D}의 근사, 과제마다
3. 실행: f_Θ(x*), 고정점 규칙이면 반복

퍼즐 임베딩과 문맥 내 추론은 2번의 구현 방식 차이다. 퍼즐 임베딩은 과제마다 경사하강, 문맥 내 추론은 순전파 안에서 한다. 1번은 둘 다 망의 몸통에 암묵적으로 들어 있다. 설계를 비교할 때는 세 부품마다 무엇을 주장하는지부터 명시해야 한다.

## 8. 왜 되는가: 증명된 것과 아닌 것 (2026-10-20)

**보조정리 1 (곱 덮기).** |T| > |G|/2이면 T·T = G다.
*증명.* g ∈ G에 대해 T와 gT⁻¹은 모두 크기가 |G|/2보다 커서 교집합이 있다. 따라서 g = t₁t₂로 쓸 수 있다. ∎
토이 확인: |T| = 112 > 64, T·T = G, ⟨T⟩ = G.

**정리 2 (정확성 ⇒ 닫힘 ⇒ 일반화).** 다음을 가정한다.
- 길이 ≤ L인 단어에서 실현 의미가 글자 단위로 합성적이다: r_{wj} = π_j∘r_w, π_j는 순열.
- 각 학습 규칙이 길이 ≤ ℓ인 단어로 실현되고, 2ℓ ≤ L이다.

그러면 G 전체가 길이 ≤ 2ℓ인 단어로 실현된다. 실현 집합은 글자들이 생성하는 케일리 공과 같다.
*증명.* 합성성을 귀납하면 r_{w₁w₂} = r_{w₂}∘r_{w₁}이고, 여기에 보조정리 1을 쓴다. ∎

**정리 3 (이상화한 두 부분 부호).** 가설을 정확한 라이브러리와 단어별 예외표로 제한한다.
- 구조 해의 기술 길이: 4 × log₂16! + 112 × 4.19 × 2 ≈ 1,115비트
- 암기 해의 기술 길이: 112 × 44.25 ≈ 4,956비트

MDL은 구조를 고르고, 맞추기만 보는 목표는 둘을 구별하지 못한다. 이상화한 가설 공간에서는 규칙이 약 5개 이상이면 구조가 이긴다(4 × 44.25 / (44.25 − 8.38) ≈ 4.9).

- "길이 벌점이 정확성(구조 발견)을 낳는다"는 근거가 없다. 벌점은 필요조건이 아니었다.

## 9. 내용 의존 규칙의 정의 (2026-10-20)

**어휘.** 위치 어휘 τ_pos = {<_행, <_열} (필요하면 좌표 산술), 색 어휘 τ_col = {P_c}.

**정의 1 (주소 함수).** 식 α(o, x)가 출력 칸마다 입력 칸을 하나씩만 정하면 주소 함수 a를 정의한다. α가 τ_pos만 쓰면 내용 무관 주소(격자 크기에는 의존 가능), τ_col도 쓰면 내용 의존 주소다.

**정의 2 (읽기 폭).** 출력 색 = f(x(a₁(o)), …, x(a_k(o))) 꼴에서 k의 최솟값. 토이는 내용 무관·폭 1, 3×3 이웃 규칙은 내용 무관·폭 9다. 폭을 격자 전체로 허용하면 모든 규칙이 내용 무관이 되므로, 폭은 격자 크기와 무관하게 유계여야 한다.

**정의 3 (내용 의존 규칙).** 내용 무관 주소로는 폭이 격자 크기와 함께 커져야 하지만, 내용 의존 주소를 허용하면 유계 폭으로 쓰이는 규칙.

**명제 1.** "유일한 색칠 칸의 색을 (0, 0)에 복사"는 내용 의존·폭 1이지만, 칸 수보다 작은 어떤 유계 폭의 내용 무관 규칙으로도 쓰이지 않는다.
*증명.* 내용 무관 폭 k에서 (0, 0)은 고정된 k칸만 읽는다. 칸 수 > k이면 그 밖의 위치 p가 있다. p에만 색 c를 칠한 입력에서 출력은 f(0, …, 0)으로 c와 무관하므로 모순이다. ∎

**주소 정의에 필요한 논리.** 경계상자 모서리, 가장 위의 c색 칸: FO. 칸이 속한 물체의 기준점: FO[TC] 또는 LFP. 가장 큰 물체, 물체 수: 연결성 + 세기.

**정의 4 (닻 규칙).** a(o; x) = A_{θ(x)}(o). A_θ는 내용 무관 변환의 족이고, θ(x)는 입력에서 정의되는 유한 매개변수(닻)다. 물체별 규칙은 a(o; x) = A_{θ(obj(o), x)}(o)다.

**명제 2.** 닻 규칙은 내용 의존 선택자 θ와 내용 무관 변환 A_θ의 합성이고, 규칙의 정의 가능성은 θ의 정의 가능성과 같다. (정의를 펼치면 나온다.)

**측정의 위치.** 토이와 Mini-ARC 천장의 항등·D4·이동·아무 고정 주소 계열은 내용 무관·폭 1이다. 경계상자 닻 계열은 θ ∈ FO인 닻 규칙이다(Mini-ARC에서 과제 1개 추가). 나머지는 다음 셋으로 나뉜다.
- (i) 폭 > 1 (국소 규칙)
- (ii) θ에 연결성·세기가 필요한 닻 규칙
- (iii) 물체별 규칙

**함의.**
- 명제 1: 고정 주소 위의 규칙 시냅스로는 내용 의존 규칙이 원리적으로 안 된다.
- 명제 2: 닻 θ만 내용에서 계산하면 A_θ는 내용 무관 구조로 남는다. 푸리에·RoPE 코드에서는 닻에 따른 이동이 내용으로 정한 위상 회전이다.
- 다음 토이: 닻 규칙 과제군. θ = 경계상자(FO) 판과 θ = 물체 기준점(연결성) 판으로, 필요한 논리를 한 단계씩 올린다.

## 12. 부품 선택 실행기 3판: 만든 술어, 학습된 사전, 베이즈 평균 (2026-10-20)

**구성** (`toy_g/pse3.py`, 결과 `runs/pse3_cv.json`, `runs/pse3_nested.json`).
- 술어: 정해진 문법으로 만든 술어 67개를 1판에 더했다. 모두 126개다.
  - 개수 특징 16개의 [f ≥ k], k = 1, 2, 3
  - 거리 8개의 [d ≥ k], k = 2, 3
  - 같은 색 4·8이웃 수
  - 네 이웃이 한 색인 빈칸
  - 술어 함수 자체를 149과제로 학습하면 답을 외우므로, 학습할 대상은 어떤 술어가 싼가로 두었다.
- 후보: 과제마다, 시범과 일치하고 시험 예측이 완전한 프로그램을 비트 순으로 최대 3만 개 남겼다(10개 과제에서 잘림).
- 사전: log P(p | 시범) = −w·φ(p). φ는 비트, 족, 원천 종류, 특징 종류별 개수, 키 수, 한 칸에만 나온 키 수, 복사 비율, m이다. w의 시작값은 1판 부호(비트에 ln 2)다.
- 예측: 가장 짧은 프로그램(MAP), 또는 시험 출력별 사후 질량의 최댓값(베이즈 평균).
- 학습: 정답 후보가 있는 훈련 과제에서 Σ_t log P(y_t | 시범_t)를 최대화하고, 시작값 쪽 L2를 건다. 과제 5겹 교차검증이며 평가 겹의 시험 답은 쓰지 않는다.

**결과** (149과제).

| 방법 | 맞힘 |
|---|---|
| 남긴 후보 안의 신탁 | 66 |
| 1판 (특징 59, 비트, MAP) | 54 |
| 3판 술어 + 사전 부호, MAP | 57 |
| 3판 술어 + 사전 부호, 베이즈 평균 | 58 |
| 학습된 사전 24개, L2 = 0.01 고정, MAP / 베이즈 평균 | 52 / 55 |
| 학습된 사전, 중첩 교차검증으로 L2 선택: 24개 / 4개(비트·키·한 칸 키·m) | 58 / 58 |

- 사전 학습은 이 자료 규모에서 이득이 없다. L2를 약하게 고정하면 과적합한다. 학습된 가중치는 같은 색 특징 −8.8, 스캔 원천 +7.1처럼 극단적이었다. 겹마다 정답 후보가 있는 훈련 과제는 50개 남짓이다. 중첩 교차검증에서는 바깥 겹 다섯 중 셋에서 가장 센 정규화가 골라졌고, 결과는 사전 부호와 같은 58이었다.
- 1판에서 3판으로 바뀐 과제는 넷이다. 41(테두리 안 광선, [위 개수 ≥ 2])은 의도한 규칙이다. 74, 99, 56은 임의 이동 원천이라 우연이다. 56은 MAP 동률을 베이즈 평균이 깼다.
- 의도한 규칙과 같은 것은 38개(1판 37 + 41)다.

**결론.**
- 선택은 이미 신탁의 88%(58/66)에 이르렀으므로, 남은 병목은 표현 범위(신탁 66)다. 단계 합성, 순환 이동, 확대, 반복 이동이 필요하다.
- 학습할 부분(사전, 술어 가격, 제안망)은 과제 수가 훨씬 많은 분포가 있어야 의미가 있다.

## 13. 규칙 시냅스: 오차 LTP/LTD + 희소 LTD, 학습된 구조 코드 (2026-10-20)

**구성** (`toy_g/ltd_rule.py`, 진단 `toy_g/ltd_diag.py`, 런 `runs/ltd/learned_Q`). 4×4 원환 토이이고, 데이터·분할·고정 인스턴스는 판 C와 같다.
- 과제마다(빠른 쪽):
  - 색별 그림 u_a = Σ_{색 a} g(x)를 만든다.
  - 위치 시냅스 W(16×16)와 색 시냅스 C(4×4)를 시범에서 150회 반복으로 쓴다.
    - W: 오차(세 번째 요소) × 입력 그림으로 갱신하고 복소 soft threshold를 건다. FISTA 가속.
    - C: 오차와 W로 옮긴 그림의 내적으로 갱신하고, 음수 제거, 문턱, 열 정규화를 건다.
  - 후보 나열이나 사후 계산은 없다.
- 과제 사이(느린 쪽): 기저 Q(16×16 유니터리, Haar 무작위에서 시작)와 스칼라 6개를 학습한다. 마지막 50회 반복을 펼쳐 역전파한다. 배치 512, 3,000스텝.

**존재 확인 (Q 고정, 학습 없음, 시범 3개).**

| 기저 | 학습 과제 / 처음 보는 쌍 / 처음 보는 변환 | 색 시냅스 정답 | W에서 0이 아닌 칸 |
|---|---|---|---|
| 푸리에 | 96.3 / 94.8 / 95.3% | 96.1% | 16 |
| 단위행렬 | 4.9 / 5.9 / 5.5% | | |
| 무작위 | 6.0 / 8.6 / 4.7% | | |

- 앞선 검사에서는 위치 시냅스에 색 순열을 줬을 때, 델타만 25/400, 델타 + 희소 LTD 399/400이었다.
- 위치와 색을 합친 64×64 결합 시냅스는 0/400과 2/400이었다. 격자 하나가 벡터 하나라서 방정식이 부족하다.

**학습된 기저 결과.**
- 정답률(k = 3): 학습 과제 95.9%, 처음 보는 쌍 94.8%, 처음 보는 변환 94.5%. 500스텝에 도달했다. 참고로 판 C는 처음 보는 조합에서 95.3–95.6%였다.
- 기저는 크게 움직였다(‖Q − Q0‖/‖Q0‖ = 1.14).
- 에너지의 90% / 99%를 담는 칸 수:

  | 기저 | 법칙 규칙 128개 | 무작위 순열 |
  |---|---|---|
  | 학습된 기저 | 15 / 20 | 152 / 220 |
  | 시작 기저 | 154 / 223 | |
  | 푸리에 | 15 / 16 | |

  학습된 기저는 법칙에 맞는 규칙을 희소하게, 아닌 순열을 조밀하게 만든다.
- 학습된 채널은 대체로 푸리에 모드 두 개를 반씩 섞은 꼴이다(주 모드 질량 중앙값 0.50).
- 제거 실험:
  - 희소 LTD를 끄면 2.8–3.4%로 떨어진다.
  - 기저를 시작값 Q0로 바꾸면 5–7%다.
  - 기저를 푸리에로 바꾸면 96.3 / 94.8 / 95.3%다.
- 시범을 읽은 뒤의 W는 실제 연산자와 상대오차 중앙값 0.075이고, 에너지 90%를 15칸에 담는다.

**결론.**
- 구조 코드(기저)는 과제에서 학습되었다.
- 규칙 선택은 시범을 읽는 동안의 가소성(예측 의존 LTD + 희소 LTD)으로 이뤄진다.
- 처음 보는 변환까지 판 C·푸리에 기준과 같은 수준으로 일반화한다.
- 남은 4%는 시범에 없던 색이다.

**정정.** 학습 로그에 찍힌 기저 진단값(lawful_median 246)은 틀린 식 conj(Q)·Pᵀ·Qᵀ로 계산한 것이다. 맞는 식은 Qᵀ·P·conj(Q)이고, 위 표는 맞는 식으로 다시 계산한 값이다.

**범위.** 시범 전체에 같은 연산자가 통하는 규칙(군 원소 + 색 순열)만 다룬다. 다음은 LT 흔적곱으로 옮기는 2단계다.
