# 자율 연구 목표와 판단 기록

## 유지할 목표

위상 기반 STDP 원리로 v1.1의 구성요소와 추론 중 가소성의 역할을 설명하고,
그 원리에서 더 단순하고 유용한 아키텍처 가설을 도출한다. 구조를 정당화하는
말만 바꾸거나, 체크포인트의 성분 중요도를 끝없이 나열하는 것은 완료가 아니다.

사용자 요청: 자리를 비운 동안 목표를 분명히 세우고, 주기적으로 그 목표를
확인하며 자율 연구를 진행한다. 이 연구는 사용자의 후속 지시에 따라 이어진다.

추가된 시간 범위: 2026-09-13 06:20:30 UTC부터 30분, **06:50:30 UTC에 종료**한다.
시간 안에 얻은 결과와 남은 문제를 구분해 보고한다. 시간 제한을 이유로
검증하지 않은 성능 개선을 주장하거나 연구 목표를 바꾸지 않는다.

## 판단 기준

- 셀의 물리적 발화 선후를 새로 가정하지 않는다. 위상 관계를 출발점으로 삼는다.
- STDP와 활동 동역학을 구분하되, 같은 모델 안에서 둘의 연결을 설명한다.
- 정답·스도쿠 제약을 추론 규칙에 넣거나 에너지 모델로 문제를 바꾸지 않는다.
- 가설 → 수학적 예측/반례 → 필요한 진단 → 구조 판단 순서를 지킨다.
- 항등식, 모델링 가정, 기존 관측, 새 검증, 성능 가설을 구분한다.
- 새 구조는 기저의 빠른 위상 반응과 value 사영의 역할을 검토해야 한다.
- 성능 개선은 재학습/평가 증거가 있을 때만 주장한다.

## 작업 범위와 실행 환경

2026-09-13 시작 시점에 v1.1 체크포인트와 기존 분석 산출물을 다시 확인했다.
`arc_analysis/train_arc_s.py` 학습 프로세스 두 개가 실행 중이고 GPU 사용률은
100%, 메모리는 약 15 GiB였다. 기존 학습과 ARC 파일은 변경하지 않는다.
우선 CPU에서 수식·작은 모델·저장된 상태로 검증한다.

## 현재 연구 순서

1. 가소성 창을 위상으로 표현하는 데 필요한 가정을 명시하고, 기존 Fourier 문서의
   항등식과 추가 가정을 감사한다. `phase × agree`가 하나의 활동 상관으로
   유도되는 조건을 실제 적분과 코드 커널로 검산한다.
2. 그 조건이 쓰기·기억의 대칭성, 양의 준정부호성, 대각선에 주는 제약을
   도출한다. 이 제약에서 삭제/통합 가능한 요소를 찾는다.
3. `w−G`가 아닌 실제 활동→쓰기→다음 활동의 되먹임을 분석한다.
   필요하면 저장된 v1.1 상태에서 방향 미분을 구해 가설을 판정한다.
4. 증거가 지지하는 최소 후보를 격리된 연구 코드로 구현한다.
   동치 부분은 원본과 대조하고, 달라진 부분에는 명시적 예측과 평가 조건을 둔다.

## 진행 기록

### 시작 점검

- 이전 작업은 진전으로 분류한다: `baseline_plasticity_v11.md`를 작성했고,
  `Δw=−η(w−G)/(1−η)`를 검산하여 과거 보정과 실제 갱신의 해석을 수정했다.
- 현재 목표는 아직 완료되지 않았다. 기저+가소성이라는 재표현만으로 새로운
  구조의 유용성이 입증되지는 않았다.
- 첫 가설: 정규화된 내용 벡터가 위상별 활동의 진폭을 정한다고 가정하면,
  `phase × agree`는 분리 가능한 집단 활동의 단일 상관으로 정확히 얻어진다.
  이 가정은 주소와 value 사영을 같게 만들 필요가 없다.
- 이 가설이 맞으면 β=0 쓰기는 Gram 행렬이 되어 구조적 성질이 생긴다.
  단순한 모양의 유사성보다 강한 예측이므로 이를 먼저 검증한다.

### 연구 주기 1: 활동 모델의 구성과 후보 수정

- 위상 집단 활동의 이중 적분과 실제 커널의 동치성을 CPU에서 검산했다.
  적분 오차 <3.56e−15, 체크포인트 커널 재구성 오차 <1.23e−15.
- 실제 cos β의 일부가 음수라는 반례를 확인했다. 따라서 β=0이나 양의
  준정부호 기억을 우선 강제하는 후보는 보류한다.
- 새 우선 가설: 전달의 ψ는 유지하고, 가소성 창만 학습 가능한 짝수
  위상 창으로 표현한다. c=λg cos β로 초기화하면 원본의 대칭 쓰기를 보존한다.
- `대칭 과거 보정만 유지` 실험과 `모든 가소성을 대칭화`한 구조는 다르다.
  현재 반대칭 쓰기의 제거까지 포함하므로 변환 검증 뒤 별도 평가가 필요하다.
- 목표 점검: 실제 수식의 가정에서 축소 후보가 나왔으므로 진전이다.
  아직 후보의 학습 가능성·성능을 입증하지 않았으므로 목표는 계속 유지한다.

### 연구 주기 2: 후보 구현과 독립 검산

- `EvenLT` 후보를 별도로 구현했다. 빠른 ψ와 두 사영을 보존하고,
  c=λg cos β를 직접 학습하며 대칭 기억을 위 삼각형으로 저장한다.
- 기준식과 8블록 연속 비교 오차 <8.0e−15, 수치 미분과 역전파 오차 <1.73e−11.
- 후보의 결합 carry 원소 수는 52,488→26,568이다. 전체 메모리나 속도
  개선으로 확대하지 않는다. 학습 매개변수 감소는 8개뿐이다.
- 새 16문제에서 재학습 없이 1024블록 비교를 완료했다. 양쪽 모두
  128블록 5/16→1024블록 6/16이며 최종 해결 집합도 같았다.
- β≈0에서는 짝수 창의 변화가 2차, 홀수 창의 변화가 1차라는 사실에서
  직접 c를 학습할 이유를 얻었다. 합성 커널 목적에서 좌표별 기울기 차이를 검산했다.
- 실제 기존 학습 하네스로 CPU 6스텝, 새 파라미터의 weight decay 정책,
  EMA·체크포인트 저장/재개를 확인했다. GPU 학습을 실행한 것은 아니다.

### 연구 주기 3: 실제 가소성 반응과 안정화의 구분

- `w−G` 대신 결합된 블록의 A,B,C 도함수를 직접 계산하고 연쇄법칙과
  두 크기의 중심 수치 미분으로 검산했다.
- 저장 상태 152·192, 사전 지정한 두 방향에서 반응 부호가 지평과 방향에
  따라 달랐다. 가소성이 모든 교란을 항상 줄이는 법칙이라는 해석은 배제한다.
- 안정된 상태에서는 정상 기억을 재생해도 특정 오답 방향의 교란이 줄었다.
  이미 형성된 결합의 작용과 추가 쓰기의 반응을 구분해야 한다.
- 목표 점검: 기존 구조의 후속 정당화에 머물지 않고, 유도 가능한 후보·구현·
  학습 좌표의 가설·작은 비교를 얻었다. 본 규모 재학습의 우위는 아직 미확인이다.
