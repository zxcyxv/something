## 0. 목표: 성질은 무엇을 위한 것인가

기록에 적힌 목표는 셋이다(10-12 누적 계획 "목적", 10-13 §11).

- **G1. 학습 지평(16세그먼트 = 128블록)에서의 정확도**
- **G2. 외삽**: 지평 밖에서 더 돌리면 성능이 오르고, 그 개선을 추론 중 가소성이 만든다. 프로젝트의 본래 목표다.
- **G3. "쓰기 = STDP"가 비유가 아니라 수식상 참일 것**: 사용자 명세 P1~P5의 취지다.

성질은 이 셋 중 무엇에 필요한지로 나눠야 한다. 그렇지 않으면 "STDP다운 것"과 "작동에 필요한 것"이 섞인다. 실제로 섞였던 예가 두 가지 있다.
- 순서부 O는 G3의 핵심인데, 빼도 G1은 그대로다(263 대 264, 10-14 §5).
- ωT = 0이어도 G1은 269다.

## 1. 동역학 (G1, G2의 전제)

| | 성질 | 왜 필수인가 | A | B (ρ 0.5) |
| --- | --- | --- | --- | --- |
| D1 | **자율성(시간 이동 불변)**: 블록 사상이 절대 블록 번호에 의존하지 않는다 | 지평 밖의 블록이 학습 때와 같은 사상이어야 외삽이 정의된다 | ✓ [A] n·ωT는 위상차로만 들어간다. 카운터를 0과 1000에서 시작한 Im S 차이 8.6e−14 | ✓ |
| D2 | **유계성**: 이력이 길어져도 쓰기와 읽기의 크기가 유계다 | 무정규화 Q/K는 읽기가 이력 진폭 c에 대해 c³로 커진다(10-08). 무감쇠 누적 M은 경로 적분이다(10-03) | ✓ Q/K L2, 흔적 이득 (1−λ), RMSNorm | ✓ ρ < 1 |
| D3 | **고정점 보존**: 가소성 항을 넣어도 풀린 상태가 계속 고정점으로 남는다 | 정규화하지 않은 누적은 고정점 결합 크기를 바꾼다(v1.71, g ≠ 1) | ✓ 고정점에서 O = 0, L = κ·SB(10-14 §4, [A] κ). 기준 모델과 같은 꼴이지 같은 고정점은 아니다 | ✓ W → Im S/(1−ρ) |
| D4 | **읽기 동기성**: q가 맞추는 키와 가져오는 값의 시점 어긋남이 유계이고, 고정점에서 0이다 | 키와 값을 통째로 누적해 읽는 J 읽기는 비동기 반복이 되어 붕괴한다(10-12 §10.1, §11.1: λ = 1에서 13~16) | 부분: 한쪽만 과거인 쌍만 있다(L자 지지). 고정점에서 소멸 | A보다 약함: 과거 운반자를 담은 Im S를 누적한다(STDP 성분의 J 읽기) |

D4의 원형은 10-12 §10.1의 "스칼라 효력만 적분하고 운반자는 현재로 둔다"다. A와 B 모두 이 원형을 구현하지 않는다. A는 한쪽만 과거인 근사다. [주장]

## 2. 시간 의미론 (G3)

| | 성질 | 내용 | A |
| --- | --- | --- | --- |
| C1 | **공통 시계** | dφ = ω·dt에서 위상차가 시간차가 되려면, 한 쌍을 이루는 pre와 post가 같은 시간 좌표와 같은 ω를 써야 한다. 쓰기가 외적이라 헤드 안 모든 채널이 짝지어지므로, 공유 단위는 최소 헤드 전체다. 채널별 ω는 위상차에 (b−k)(ω_a − ω_j)를 남겨 위반이다(2026-10-15, 사용자 지적) | ✓ nωT 공유 |
| C2 | **영점 고정과 게이지 불변** | 시간 원점이 퍼즐 시작으로 고정되어야 한다. 가중치를 재매개화(쌍 기저의 상수 회전)해도 태그가 바뀌지 않아야 한다. 그렇지 않으면 "시각"이 학습 가능한 내용 좌표가 된다(pairangle의 결함, 명세 P2) | ✓ 변위 태그 = sin(θ_b − θ_0) [A] |
| C3 | **태그는 관측량이고 추가 자유도가 없다** | 태그를 h의 자유 사영으로 만들면 최적화가 그것을 내용 특징으로 쓴다. integrate 생성기는 α가 꺼졌고, leaky 생성기는 배치를 암기했다(10-13, 요구 조건 (2)·(4)) | ✓ 파라미터 없음 |
| C4 | **인과 부호 일치** | 기억이 미치는 범위 안의 모든 쌍에서 sin Δτ의 부호가 블록 순서와 같아야 한다. 블록 안에는 계산상 인과가 없으므로(10-12 §4.1), 실제 순서는 블록 사이에만 있다. 지연이 그 순서를 뒤집으면 안 된다 | ✓ ωT > 2c, K·ωT + 2c < π, k ≥ 10 꼬리 0.1% [A] |
| C5 | **정상성과 쌍당 1회** | 쌍 가중치가 (블록 차, 지연차)만의 함수이고, 각 쌍이 정확히 한 번 계산된다 | ✓ 흔적 = 쌍 합 정리 [A] |

B는 C5의 "쌍당 1회"를 지키지 않는다. W가 과거 Im S를 다시 더하므로 같은 쌍이 ρ^m 가중으로 반복된다. 이것을 "느린 시냅스 J"로 읽으려면 D4의 원형(운반자는 현재)이 필요한데, B는 그렇지 않다. [주장]

## 4. 필수가 아니라고 드러난 것

| 항목 | 근거 |
| --- | --- |
| 창의 정확한 모양 | 2차 조화를 빼도 ±2%(10-10 §6) |
| G1에 대한 순서부 O | 빼도 263 대 264. O는 속도와 안정을 맡는다 |
| G1에 대한 ωT | ωT = 0이어도 269, 느려지기만 한다(1.14블록/라운드) |
| 지연부 L의 "STDP다움" | |Δa| ≤ 0.28에서 1.3% 오차로 게이트된 Hebb 특징과 같다([해체](claude_analysis_expressivity.md) §5) |

따라서 G1은 Hebb 운반자와 내용 게이트로 대부분 설명된다. 시간 의미론 C1~C5는 G1이 아니라 G3, 그리고 풀이 속도와 안정성을 위한 성질이다. [주장]

## 5. 비어 있는 것: G2를 보장하는 성질

현재 어떤 성질도 G2(추론 중 가소성이 만드는 외삽)를 보장하지 않는다. [주장]

- D3 때문에 가소성은 정의상 과도 구간에서만 작동한다. 풀린 퍼즐의 고정점은 그대로다.
- 따라서 외삽 이득은 수렴하지 않은 궤적에서만 나올 수 있다. 못 푼 퍼즐은 O/Hebb ≈ 0.054에서 배회한다(10-14 §4).
- 필요한 것은 "수렴하지 않은 궤적에서 가소성 항이 상태를 같은 오답으로 되돌리지 않는다"는 종류의 성질이다. 예를 들면 미수렴 동안 단조 감소하는 양(Hopfield 에너지형)이 있거나, 같은 끌개로 되돌아오는 것을 막는 항이 있어야 한다.
- 이것은 D3와 긴장 관계에 있다. 고정점을 바꾸는 탈출 장치(위반 적분, 10-12 누적 계획 "다른 선택지")는 D3를 어긴다. 그래서 "풀린 상태의 고정점은 보존하고, 미수렴 상태에서만 작동한다"는 조건부 형태가 필요하다.
- O는 라벨 없이 미수렴을 97% 판정한다(10-14 §4). 그러니 이 조건부 장치의 신호로 쓸 후보가 이미 있다.

## 6. 쓰는 법

새 구조나 확장을 제안할 때는 먼저 다음을 적는다.
- D1~D4, C1~C5, L1~L3 중 무엇을 유지하고 무엇을 깨는지
- 깨는 것은 그 이유와, 대신 무엇을 얻는지
- G2에 대해 무엇을 주장하는지
