## 1. 지금 상태

**모델 cmap** (`lt/cmap.py`): 느린 지각(격자 안 + 짝 입력→출력, softmax 어텐션, 학습된 위상 RoPE, 색은 "같은 색" 관계로만) + 학습된
틀(칸별 기준점·색, 격자별 마스크와 모멘트) + 빠른 규칙 시냅스(A_j, Π, Γ, B̂; 읽기에 선형, 쓰기 = 재귀 걸음마다 근접 경사 한 걸음,
걸음 η_t ≤ 0.15 학습) + 재귀 16걸음(마지막 2걸음만 역전파) + 관측/추론 흐름 분리.

현재 권장 설정(오늘 최고 판의 구성 + 내일 기본):
```
python -m lt.cmap_train --data data/miniarc_pairs.npz --out runs/NAME --seed 0 --compile --steps 15000 --batch 64 \
  --eval_every 1000 --log_every 100 --opt adamatan2 --lr 3e-4 --warmup 2000 --wd 0.1 --ema 0.999 \
  --set group_average=false d=256 heads=8 use_emb=false 'attn_impl="sdpa"' 'frame_impl="sdpa"'
```
- `--set` 값은 JSON이다. 문자열은 반드시 `'attn_impl="sdpa"'`처럼 따옴표를 넣는다(빠뜨리면 JSONDecodeError로 즉시 종료).
- 평가마다 `[EVAL]`(임베딩 켬)과 `[EVAL-NOEMB]`(임베딩 0)를 같이 찍는다. `use_emb=false`면 둘이 같다.
- `--resume`: `OUT/last.pt`(모델, EMA, 옵티마이저, 스텝)에서 이어 돈다. 데이터 난수는 다시 시드된다.

**완료:** `runs/cmap_noemb_sf_s0` — 위 설정 그대로, 15,000스텝, 최종 **39/149**(칸 0.847). 해석·절제는 결과 문서 §4b(성능은 전부 규칙 시냅스 쓰기에서, 그 안에서는 Γ 항이 주 경로, A·Π는 보조).
평가 정확 추이: 1,000 → 0, 2,000 → 2, 3,000 → 10, 4,000 → 24, 5,000 → 26, …, 15,000 → 39.
비교 기준: 시그모이드 틀 + 임베딩 없음 판 7,000스텝 22/149(중단), URM 같은 시간 판 최고 25/149.

**테스트:** `python -m unittest discover tests` 125개 통과(9개 건너뜀). cmap 전용: `tests/test_cmap.py`(증강 등변성, 질의 출력 칸의
쓰기 기여 0, 쓰기 걸음마다 목적함수 감소, D4 코드 순열 등).

**URM 비교 하네스:** `toy_g/urm_harness.py` + `lt.train`. 오늘 추가: `ce: "softmax"`, `decay_all: true`, `grad_blocks`(URM 절단

ARC-1 원본 연산량 시간 측정 `configs/arc1_urm_timing.json`.

**데이터:** `data/miniarc_pairs.npz`(Mini-ARC 쌍 저장소), `data/miniarc_v104.npz`(URM 형식 104판), `data/arc1_ctx10_trans.npz`(ARC-1

## 2. 내일 할 일: ViT식 패치 토큰

**왜.** ARC-1 30×30에서 비용의 대부분이 지각(격자 12개 × 900칸 × 재귀 16걸음)이다. 틀은 오늘 SDPA로 바꿔 메모리 1/3, 질의당
0.336 → 0.110초(배치 16, URM 0.26초)가 됐다. 남은 메모리는 역전파 걸음의 지각 활성값(레인당 약 1.3 GB)이라 배치 16이 한계다.
p×p 칸을 토큰 하나로 묶으면(손실 없는 재배열, 풀링 아님) 지각 토큰이 p²분의 1, 어텐션 비용이 p⁴분의 1이 된다. 풀링형 CNN은 칸 단위
정확성을 잃으므로 쓰지 않는다(사용자와 합의).

**설계 지시.**
1. 칸 흐름(셀 단위 은닉)은 그대로 둔다. 틀(SDPA), 기억 그림, 규칙 시냅스 쓰기·읽기, 출력은 칸 단위다(비용이 칸 수에 선형).
2. 지각만 패치 단위: 패치화 = 영역 N을 p의 배수로 패딩 → [B,G,N/p,N/p, p²·d_cell] → 선형으로 d. 패치 위치(패치 중심 좌표)로 RoPE.
   격자 안 + 짝 입력→출력 제한은 패치 단위로 그대로. 역패치화 = 선형 d → p²·d_cell → 칸 흐름에 잔차로 더함.
3. 색 등변을 지킨다: 패치 사이 "같은 색" 편향은 칸 단위 ⟨cv_s, cv_t⟩ 대신 패치 색 히스토그램 내적 ⟨hist_s, hist_t⟩(색 순열에
   등변). 패치 안의 색 관계는 칸 흐름(관계적 특징)이 이미 담고 있다.
4. 설정 키 `patch: int = 1`. p = 1이면 지금 모델과 수치적으로 같아야 한다 → 테스트로 확인(fp64, 유효 칸).
5. 학습 데이터·하네스·평가는 바꾸지 않는다.

**초안 있음(10-21 끝에 작성, p > 1은 아직 실행 안 함):** `lt/cmap.py`에 `patch` 키, `perceive`(패치화·역패치화) +
`attend`(토큰 단위 지각 층, 기존 코드를 토큰 수 T로 일반화)를 넣었다. p = 1은 같은 코드 경로라 기존과 같고 `tests/test_cmap.py`
6개 통과. p > 1: 패치 토큰 = 선형(p²·d → d), 관측도 따로 선형, 색 편향 = 패치 히스토그램/p² 내적, 위치 = 패치 중심, 출력은
선형(d → p²·d) 후 rms_norm(h + Δ). 검토 후 쓸 것.

**실험 순서.**
1. p > 1 테스트(형태, 군 평균 켰을 때 D4·색 등변), 전체 테스트 통과.
2. ARC-1 30×30 속도·메모리: p = 1, 2, 3, 5 × 배치 16/32/64(`/tmp/.../scratchpad/arc1_cmap_bench.py`를 참고해 새로 만들 것;
   스크래치패드는 인스턴스에 따라 없을 수 있음). 비교: URM 질의당 0.26초, 18.4 GB(배치 32).
3. 정확도 영향: Mini-ARC(N = 5 → 6으로 패딩, p = 2, 3)에서 p = 1 판과 같은 스텝 비교. 패치가 칸 단위 정확성을 해치는지 보는 것이 목적.
4. 그다음 ARC-1 ≤ 10(`data/arc1_ctx10_trans.npz`, N = 10, p = 2/5)으로 학습 + URM 맞춤 비교(URM 형식 ≤ 10 데이터가 아직 없음:
   `data/prep_arc1.py`에 크기 필터를 더해 만들 것).
5. 선택: 시범 격자 고정(시범은 몇 걸음만 지각, 이후 질의 격자만 반복, 역전파 걸음에서는 시범도 한 걸음) — 패치와 독립인 절약.

**ViT 다음 후보: bands식 쓰기 + 델타 + 소프트 문턱** (이론 요약 §6). 핵심은 쓰기를 충분통계량(Σ y kᵀ, Σ k kᵀ)의 누적으로 바꿔
근접 경사를 작은 행렬 위에서 수렴까지 반복하는 것이다(지금은 16걸음 × 한 걸음이라 lasso 해에 못 미침). 그러려면 읽기를 통계량이
작은 꼴(10-20의 W 하나에 가까운 꼴)로 맞춰야 한다. 창은 시간차가 아니라 슬롯 소속/RoPE 상대 위치로.

## 3. 사용자 규칙 (반드시)

- 한국어로 답한다. 직접적이고 정확하게. 틀리면 분명히 말한다. 수리논리적 논증을 선호한다.
- **질문은 지시가 아니다**: "~아닌가?"에는 따져서 설명하고, 문서·코드를 바꾸지 않는다(메모리 `feedback_questions_not_instructions`).
- 손 사전 금지(고정 기저, 손 코드, 손 읽기, 손 원시 연산). 형식·논리·증강군에서 강제되는 구조만 넣는다. 축 구조(위치/색 분리)는 허용.
- 이미 한 실험을 확인 명목으로 다시 돌리자고 하지 않는다. 배치는 크게 잡고 OOM이면 줄인다. GPU 검사는 배치로.
- 오래 걸리는 명령은 백그라운드로(사용자는 ctrl+b를 못 쓴다). 런은 `setsid nohup bash -c '...; echo EXITCODE $?'`로 띄우고,
  감시는 **실제 파이썬 PID**를 본다(래퍼 PID 금지).
- `pkill -f` 금지(자기 셸을 죽인 적 있음). 프로세스는 PID로 끈다. 대기 루프의 pgrep 패턴이 자기 명령줄과 겹치지 않게 한다.
- `rm -rf $VAR` 꼴은 안전 검사에 막힌다. 새 디렉터리면 지울 필요 없이 `mkdir -p`.
- 비교 기준: URM(ARC-1 53.8%, ARC-2 16.0% pass@1, 전환적, 1000판 다수결). 공정 비교는 파라미터·스텝·역전파 단위·손실·감쇠를 맞추고,
  같은 GPU 시간 비교도 같이 한다.
- 커밋·푸시는 사용자가 하루 끝에 한다. 중간에 묻지 않는다.

## 4. 열린 문제 (이론)

- 임베딩 없는 판이 같은 GPU 시간에서 URM(25)을 넘는가, 시드 변동은 얼마인가.
- Mini-ARC는 모두 5×5라 크기 예측·내용 기준 틀이 거의 시험되지 않았다. ARC-1 ≤ 10에서 확인해야 한다.
- 학습 신호가 지각에 "쓸모 있는 틀"을 실제로 가르치는가(학습된 틀이 무엇을 잡는지 시각화로 확인할 것).
- bands로 승격: 규칙 시냅스(누적·읽기)는 bands 누적기 + 근접 사상으로 옮길 수 있다. 지각은 softmax로 남기는 혼합형이 기본 가설.
