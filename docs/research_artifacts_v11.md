# 2026-09-26 연구 기록의 저장 범위

이번 커밋에는 분석 코드, 보고서, 작은 결과 JSON·CSV, PNG·PDF와 압축된 일부 검산 배열을
포함한다. `runs/`의 기본 ignore 규칙은 유지하고 검토에 필요한 파일만 명시적으로 저장했다.

다음 대용량 생성물은 로컬 실행 디렉터리에 남아 있으며 저장소에는 포함하지 않는다.

- 블록별 전체 hidden·W 스냅샷과 원본 주소 시계열 (`*.pt`, 큰 `*.npy` 등).
- 전체 어텐션 데이터를 내장한 퍼즐별 HTML 뷰어(각 약 97~101 MB).
- 퍼즐별 전체 reasoning JSON(각 약 22~28 MB) 및 큰 중간 배열.

보고서의 HTML 링크와 저장되지 않은 원자료 링크는 해당 생성물을 만든 로컬 작업공간에서
열 수 있다. GitHub에서는 함께 저장한 정적 PNG·PDF와 요약 JSON으로 결과를 확인한다.

재생성 방법과 필요한 체크포인트·baseline은 각 보고서의 재현 절에 명시했다.

- [전체 퍼즐 시각화](puzzle_overview_v11.md)
- [위상·시간주파수 연구](phase_timing_research_v11.md)
- [v1.2 초안과 독립 검산](causal_stdp_candidate_v12.md)

v1.2의 합성 입력을 이용한 규칙 검산은 원본 궤적 없이 실행할 수 있다.
`python -m lt.check_causal_stdp --cuda`는 CPU 수식 검산과 GPU 순전파·역전파를 수행하며,
스도쿠 학습이나 완답 성능 평가를 실행하지 않는다.
