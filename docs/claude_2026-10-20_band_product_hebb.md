# 2026-10-20 곱 형태 기억에서 토닉 Hebb 항: 극점 0인 대역

> **성격: Claude의 분석.** §2의 항등식은 수치로 확인했다. 학습으로는 검증하지 않았다.

## 0. 배경

- bands의 누적 상태 W(EMA)를 두 흔적의 곱으로 대체하는 형태(곱 형태, `band_product`)를 검토했다.
- 2026-10-19 사용자 런: 곱 형태에서 토닉 Hebb 항을 빼고, 창이 Hebb을 내도록 초기화했더니 학습이 느렸다(사용자 보고, 저장소 기록 없음).
- 그래서 곱 형태에서도 토닉 Hebb 항(이번 블록의 Σ_t v k̃ᵀ, 이득 1)을 두기로 했다.
- 이 문서는 그 결정의 근거 중 하나만 적는다: **Hebb 항은 따로 덧붙인 항이 아니라, 같은 창 계열에서 극점이 0인 대역이다.**

## 1. 곱 형태

헤드마다, 대역 r마다, 칸 t마다 흔적은 bands와 같다. 두 흔적 모두 이번 블록의 사건을 포함한다.

    E_K,r ← z_r E_K,r + γ_r k̃,   E_V,r ← z_r E_V,r + γ_r v,   γ_r = √(1 − |z_r|²)
    P_r(n) = Σ_t E_V,r,t(n) conj(E_K,r,t(n))ᵀ            (값 행 × 키 열)
    M(n)   = Σ_r γ_r Re(c_r P_r(n))                       (c_r: 헤드·대역별 복소 계수)
    read   = q̃ (Σ_t v k̃ᵀ + M)ᵀ

별도의 누적 상태 W와 η가 없다.

## 2. 곱 형태는 대역별 EMA와 같다

bands의 창 계수를 a_r = conj(c_r), b_r = c_r로 두고, S_r을 bands 쓰기 S의 대역 r 성분이라 하자.

    S_r(n) = Σ_t [ v Re(a_r E_K,r)ᵀ + Re(b_r D_V,r) k̃ᵀ ],   D_V,r = z_r E_V,r(n−1)

그러면 다음이 정확히 성립한다.

    γ_r Re(c_r P_r(n)) = |z_r|² · γ_r Re(c_r P_r(n−1)) + (1 − |z_r|²) · S_r(n)

- **유도.** P(n) = (D_V + γv)(conj(D_K) + γk̃)ᵀ = |z|² P(n−1) + γ[v conj(E_K(n))ᵀ + D_V k̃ᵀ]이다. 대괄호에 Re(c ·)를 씌우면 a = conj c, b = c인 S_r이 된다. 양변에 γ를 곱하고 γ² = 1 − |z|²를 쓰면 위 식이 나온다.
- **의미.** M_r은 그 대역 S_r의 EMA이고, 망각률은 η_r = 1 − |z_r|²이다. 고정점에서 M_r → S_r이므로 정규화는 bands의 W와 같다.
- **bands와의 관계.** 모든 대역이 |z_r|² = 1 − η이고 a = conj(b)이면, 곱 형태(c = b)와 bands의 W는 블록마다 같다.
- **쌍 커널.** 값의 나이를 i, 키의 나이를 j라 하면 다음과 같다.

      M(n) = Σ_t Σ_{i,j≥0} G(i, j) v_t(n−i) k̃_t(n−j)ᵀ,   G(i, j) = Σ_r γ_r³ Re(c_r z_r^i z̄_r^j)

- **수치 확인 (2026-10-20, FP64, 저장소의 `bands_step`, 12블록).**
  - 극점을 |z|² = 1 − η로 묶은 경우: W와의 최대 상대오차 6.8e−16
  - 극점이 자유로운 경우: 대역별 EMA와의 최대 상대오차 6.5e−16
  - a, b가 서로 독립인 경우: O(1)로 어긋난다
  - 저장소에서는 `tests/test_band_product.py`가 이 항등식, |z|² = 1 − η일 때 bands와의 동치, 쌍 이중합을 FP64로 검사한다.

## 3. 극점이 0인 대역이 토닉 Hebb이다

z = 0이면 γ = 1이고, 흔적은 기억 없이 이번 블록의 값만 담는다: E_V = v, E_K = k̃.

    γ Re(c P) = Re(c) Σ_t v k̃ᵀ,     G(i, j) = Re(c) δ_{i0} δ_{j0}

c = 1이면 이것은 토닉 Hebb 항 그 자체다. 따라서 읽기 전체를 극점 하나를 더한 한 계열로 쓸 수 있다.

    read = q̃ ( Σ_{r=0}^{R} γ_r Re(c_r P_r) )ᵀ,    z_0 = 0, c_0 = 1

§2의 관점에서 극점 0인 대역을 보면 다음과 같다.
- 망각률이 η_0 = 1 − |0|² = 1이라 누적이 없다. 매 블록 M_0 = S_0이다.
- 창은 ℓ(Δ) = δ_{Δ0}이다. 질량이 모두 시간차 0에 있다.
- 이번 블록 이득(l(0))과 고정점 이득(창 넓이)이 둘 다 Re(c_0) = 1이다.

코드에서는 토닉 Hebb을 Σ_t v k̃ᵀ로 직접 계산하지만, 위 대역과 수학적으로 같다.

## 4. 이것이 정리하는 것과 정리하지 않는 것

**정리되는 것.** 이전에 Hebb 항에 대해 제기된 두 가지 문제다.
1. **"Hebb 항이 창에서 나오지 않고, 이득 1인 δ(s)를 밖에서 붙였다."**
   곱 형태에서 δ(s)는 시정수가 0인 극점의 창이다. 다른 대역과 같은 종류의 대상이며, 원점에 놓인 극점이다.
2. **"창의 두 부분이 다른 경로를 탄다(짝수부는 현재 블록에서 바로 읽고, 나머지는 EMA를 거친다)."**
   곱 형태에서는 모든 극점이 같은 경로(흔적의 곱 γ Re(c P))를 탄다. 극점 0만 누적이 없는데, 그것은 별도 경로 때문이 아니라 흔적에 기억이 없기 때문이다(r = 0인 경우의 같은 규칙).

**정리되지 않는 것.**
- 이득 1 자체가 유도되는 것은 아니다. c_0 = 1은 읽기 크기의 기준을 정하는 정규화 선택이다. 다른 대역의 계수는 이 기준에 대한 상대값으로 학습된다.
- c_0를 학습 파라미터로 두지 않고 고정하는 이유: 읽기 전체의 크기가 자유로워지고, 표류하는 전역 스칼라가 하나 생기기 때문이다.

## 5. 이 문서의 범위 밖

- Hebb 항을 두는 다른 근거는 여기 적지 않았다.
  - 스케일 논증: 넓은 창은 이번 블록 이득과 고정점 이득을 동시에 1로 맞출 수 없다.
  - 학습된 bands에서 헤드들이 Hebb을 기준으로 이력을 빼는 구성을 쓴다는 관측.
- 곱 형태 자체의 제약은 별도 문제다.
  - 대역마다 누적 길이가 창 길이의 절반으로 묶인다.
  - 날카로운 순서(Δ = 0에서 부호가 뒤집히는 창)를 오래 누적할 수 없다.
- 구현은 끝났다(`band_product`, `configs/bands_product.json`). 기존 bands와의 학습 비교(비교 기준 `docs/evidence/run_bands/`)는 아직 돌리지 않았다.
