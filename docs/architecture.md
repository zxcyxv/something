날짜별 원 기록, 스크립트, 이전 모델은 `archive/pre-refactor-2026-10-15` 브랜치의 `docs/research/`에 있다.

표기

- 블록 b: 공유된 한 층을 한 번 도는 것
- 세그먼트: 8블록
- 퍼즐 하나는 16세그먼트 = 128블록을 학습한다.

## 1. 순전파

```text
inj = E[x] + E_puzzle
u   = h_{b−1} + √d · inj
q, k, v = heads(W_Q u), heads(W_K u), heads(W_V u)
q̂, k̂ = x / (‖x‖₂ + 1e−4)                          V는 정규화하지 않는다
q̃, k̃ = RoPE(q̂), RoPE(k̂)                          학습되는 2D RoPE(행·열 각도)

시계(칸·헤드·채널 쌍마다, 파라미터 없음):
  θ_r = atan2(쌍)                                   r = K: RoPE 전 k̂, r = V: v
  φ_r ← wrap(φ_r + wrap(θ_r(b) − θ_r(b−1)))        첫 블록의 변위는 0
  τ_r = c·sin φ_r + n·ωT                            c = 0.14, ωT = 0.34

흔적(복소, 칸별):
  E_K ← λE_K + (1−λ) k̂ e^{−iτ_K}                    RoPE 전에 저장하고, 이번 블록 사건을 포함한다
  D_V = λE_V
  E_V ← D_V + (1−λ) v e^{+iτ_V}                     λ = 0.5로 고정

쓰기와 읽기(토큰 합, V 행 × K 열):
  Im S_b = Im Σ_t [ (v e^{iτ_V}) RoPE(E_K)ᵀ + D_V (k̃ e^{−iτ_K})ᵀ ]
  W_b    = ρ W_{b−1} + Im S_b                       모델 A: ρ = 0 (W_b = Im S_b), 모델 B: ρ > 0
  read   = q̃ (Σ_t v k̃ᵀ + α_h W_b)ᵀ                  α_h는 헤드별로 학습한다(초기값 1)

h' = RMSNorm(u + W_O read)
h_b = RMSNorm(h' + W_D(silu(g) ⊙ a)),  [g; a] = W_GU h'
```

구현 위치
- 모델: `lt/model.py` (`LT.block_step`, `memory_step`, `clock_step`, `stdp_step`)
- 융합 Triton 커널: `lt/kernel.py`. ρ = 0 전용이고 RTX 4090에서 약 90 ms/step이다.

carry
- 은닉 상태, 시계 `cat(φ_K, φ_V, z_K, z_V, n)`, 두 흔적, (B의 경우) W
- 세그먼트 경계에서 detach한다.
- 새 퍼즐을 받은 레인은 0으로 초기화한다.
- 시계, 흔적, W, 읽기는 FP32다. 사영과 FFN은 BF16 autocast를 쓴다.

파라미터는 8,538,835개다. 같은 크기의 URM 1-layer는 8,539,650개다.

## 2. 하네스와 블록 골격

URM(arXiv 2512.14693)의 학습 절차를 그대로 쓴다.
- 세그먼트마다 감독하고 carry는 detach한다.
- 16세그먼트를 마친 레인은 새 퍼즐로 교체한다.
- 손실: stablemax CE
- 최적화: AdamATan2, lr 1e−4(2,000스텝 warmup 후 상수), weight decay 1.0, EMA 0.999, 배치 128
- 데이터: Sudoku-Extreme 1k × 증강 1000

| 선택 | 근거 |
| --- | --- |
| 공유 한 층 반복 | 같은 하네스·같은 크기에서 URM 1-layer보다 높다(10-10 §1). 48.8k에서 83.5% / 1,112, URM은 81.3% / 980 |
| 세그먼트 안 8블록 전부 역전파 | no-grad 24 + grad 8블록은 100k에서 held-out 1,121로, 8블록 전부 역전파의 1,236보다 낮다. 외삽도 6.8% 대 14.5%(10-10 §8). R=1 8블록이 R=2와 같은 수준이라 하락 원인은 no-grad 구간이다(10-10 §9). 문헌: TRM 1-step gradient 56.5% 대 재귀 전체 87.4% |
| √d 재주입 | 학습 스칼라 게이지(v1)에서는 310k에 단서 하나를 바꾼 무모순 오답이 107/512까지 자랐다. √d 고정 게이지에서는 0이었다(v1 대 v1.1 비교) |
| 두 residual RMSNorm(어텐션 뒤와 FFN 뒤) | 사용자가 정한 설계 규칙이다([AGENTS.md](../AGENTS.md)). 성능 근거로 주장하지 않는다 |

| softmax 없음 | 읽기 q̃Gᵀ는 부호가 있는 선형 결합이다. softmax를 쓴 채널 위상 생성기는 3k스텝에서 41.9% 대 93.0%로 열세였다(10-05) |

## 3. 기억: 현재 블록의 쓰기만 읽는다

블록 사이에 KV 행렬을 이월하지 않는다. 블록을 넘는 정보는 칸별 위상 태그 흔적 E_K, E_V가 나르고, 읽는 것은 이번 블록의 증분 Σ v k̃ᵀ + α Im S뿐이다.
B의 W는 이 원칙의 예외가 아니다. 효력 Im S만 적분하기 때문이다(§7).

| 근거 | 내용 |
| --- | --- |
| 누적 KV는 계산을 잇지 못한다 | 6,000스텝에서 누적 M 61.8%, B만 92.8%, STDP 항(G)만 78.3%. 고정 가중치로 128블록 재생하면 누적 M은 완답 0%, 누적 없는 쪽은 25.8~53.9%(10-03) |
| 누적은 경로 적분이다 | M = Σ G는 키가 변하면 현재 KV의 추정이 아니다. 주기 상태가 되려면 Σ G = 0이어야 한다(kv_collapse 연구) |
| 읽기 운반자와 query는 같은 블록이어야 한다 | 누적 J를 읽으면 과거 운반자가 섞여 비동기 반복이 된다(10-12 §10.1). 추론 때만 J를 누적하면 λ = 1에서 13~16문제로 붕괴한다(10-12 §11.1) |
| Q/K L2 정규화 | 정규화하지 않으면 이력의 진폭 c에 대해 읽기가 c³로 커진다. 20k에서 B-only + QK L2 + 토큰 합 69.5% / 334, 원시 QK와 ÷81 평균은 58.2% / 19로 held-out이 무너졌다(10-08) |
| 토큰 합 쓰기 | 위와 같은 비교(10-08). 평균(÷81)은 STDP 항의 크기를 칸 수로 희석한다 |
| V는 원시값 | V를 단위화하고 게인을 붙이면 67.2% / 299로 B-only보다 낮다(10-08) |
| RoPE 전 각도로 위상을 잰다 | 회전 후 각도는 창을 절대 위치에 묶는다. 같은 상대 거리에서 위치만 옮겨도 읽기가 19% 변했고, 회전 전 각도로는 0이었다. 20k에서 69.7% / 364 대 65.6% / 121(10-09 §1) |

## 4. 쓰기가 곧 pair-STDP다

**Hebb + α·STDP 창.** 쓰기 G = Σ v k̃ᵀ(1 + α_h W(Δ))에서 상수 1은 Kempter 분해의 발화율(직류) 항이고, 홀함수 W는 타이밍 항이다(10-12 §3).

| α_h 실험 | 결과 |
| --- | --- |
| α 초기값 0 | 위상 경로의 기울기가 0이라 학습되지 않는다(10-09 §2) |
| α 초기값 1 | 20k 71.4% / 418, B-only는 69.5% / 334. 150k 장기 학습 최고 87.5% / 1,342(10-09) |
| α×0 절제 | STDP로 얻은 이득이 100% 사라진다(10-10 §6) |
| 칸 사이 위상 섞기 | 같은 기준으로 100% 사라진다(10-10 §6) |

균형 STDP만 쓰면 B-only보다 낮다. 6k에서 78.3% 대 92.8%(10-03)이고, 연상 기억 장난감에서는 69.4% 대 Hebb 88.8%다(10-04). 그래서 Hebb 운반자는 남긴다.

**흔적 재귀 = 모든 사건 쌍의 합(`tests/test_model.py`가 검사).** 같은 칸의 (post = V, pre = K) 사건 쌍은 퍼즐 시작 뒤 정확히 한 번 들어간다. 가중치는 다음과 같다.

    (1−λ) λ^k e^{i(τ_post − τ_pre)},  k = 블록 차

- 같은 블록의 쌍은 E_K에서만 센다.
- Im S는 홀(STDP) 창이고 Re S는 짝 창이다(쓰지 않는다).
- 칸 사이 통신은 읽기 q̃·k̃에서만 일어난다.
- 위상 태그를 쓰면 Hebb와 STDP의 차이는 복소 학습률의 위상 하나가 된다(10-13 §1).

## 5. 시계: 왜 τ = n·ωT + c·sin φ인가

시계는 다음 네 조건을 지켜야 한다(10-13 §11).
1. 퍼즐 시작에서 영점이 고정된다.
2. 궤적에서 관측되는 양으로 정한다.
3. 상대 잠복기가 내용에 묶이고 유계다.
4. 파라미터를 추가하지 않는다.

**학습되는 생성기는 실패했다(10-13).**
- 위상을 적분하는 전용 head(integrate)
  - 위상이 블록당 2.2~2.7 rad로 계속 돌았고, 칸 사이 분포가 균일해졌다.
  - α는 7개 헤드에서 0.2 이하로 꺼졌다.
  - 이륙은 31k로 늦었고, 50.8k에 81.3% / 983이었다.
- 누설 잠복기(leaky)
  - head의 민감도로 배치를 외웠다. 종료 세그먼트 완답은 86%였지만 carry만 끌고 가면 8/128이었다.
  - 44.9k 69.9% / 413에서 멈췄다.

**변위 태그.** φ_r은 각 채널 쌍이 블록 사이에 돈 각도를 누적한 값이다.
- 쌍 기저의 상수 회전(게이지)은 상쇄된다.
- 파라미터가 없다.
- α가 오르고 배치 암기가 없다(10-13 3런).

그러나 각도는 원 위에서 접혀서 **블록 사이에 시간이 흐르지 않는다**. Rule110 장난감에서 학습 뒤 블록 순서와 쓰기 부호가 무관했다(0.34 / 0.34, 10-14 §1.1).

**블록 간격 + 유계 지연.** τ = n·ωT + c·sin φ로 두면 다음이 성립한다.
- 같은 블록 짝은 지연차 |Δτ| ≤ 2c만 본다.
- k블록 떨어진 짝은 k·ωT ± 2c를 본다.
- 따라서 ωT > 2c이고 K·ωT + 2c < π이면, 블록 차 1 ≤ k ≤ K인 모든 짝에서 sin Δτ의 부호(LTP/LTD)가 블록 순서와 일치한다. K = 8(세그먼트 길이)이고 `tests/test_model.py`가 검사한다.
- Rule110에서 부호–순서 일치가 1.00 / 0.00이 되었다(10-14 §2).
- 위상자로 쓰면 흔적이 블록마다 λe^{−iωT}를 곱하므로, 창은 감쇠 사인 λ^k sin(kωT)다.

**λ를 0.5로 고정하는 이유**
- 창 λ^k sin(kωT)는 k = π/ωT ≈ 9.2에서 부호가 바뀐다. 그 전에 λ^k가 꼬리를 죽여야 한다(뒤집힌 꼬리 0.2%).
- λ를 학습하게 두어 0.9가 되면 0.9¹⁰ ≈ 0.35로 주기성이 되살아난다(10-14 §1.2).
- 헤드별 상수가 학습 후반에 표류해 성능 저하를 운반한 전례도 있다. v1.71에서 100k 시점의 η·λ·g를 넣으면 외삽 감소율이 17.7% → 28.4%로 올랐다.

절대 시각 n·ωT의 감김은 쓰기에 차이 e^{i(τ_post − τ_pre)}로만 들어가므로 블록 차 k만 남는다.

구현 메모: n·ωT는 wrap하지 않는다. 런 A가 그렇게 학습했고, wrap하면 위상자는 같아도 BF16 반올림이 달라져 궤적이 달라진다.

결과(런 A, 10-14 §3)
- 50.8k 83.4% / 1,087. 기준 R=1(블록 간 기억 없는 일반형 창)은 84.2% / 1,139다.
- 이륙 19.5k는 기준과 같다(integrate 31k, displacement 33k). 기준에 있던 11.7~17.6k 급락이 없다.
- α는 1.0 → 1.37로 올랐다.

## 6. 학습된 STDP 항: 순서부 O와 지연부 L

**정리(10-14 §4).** k블록 떨어진 짝의 무게 sin(kωT + Δa)를 전개하면 Im S_b는 두 성분으로 유일하게 나뉜다. Δa = c sin φ_V − c sin φ_K다.

    O_b = Σ_k (1−λ)λ^k sin(kωT) [cosΔa · v(b)k̃(b−k)ᵀ − cosΔa′ · v(b−k)k̃(b)ᵀ]       순서부: 시간 반전에 홀
    L_b = Σ_k (1−λ)λ^k cos(kωT) [sinΔa · v(b)k̃(b−k)ᵀ + sinΔa′ · v(b−k)k̃(b)ᵀ] + (1−λ) sinΔa · v(b)k̃(b)ᵀ   지연부: 짝

- 재귀의 고정점(v, k̃, φ가 블록마다 같음)에서 O_b ≡ 0이다.
- 같은 고정점에서 L_b = κ·SB_b다. 여기서 SB_b = Σ_t sin(Δa_t) v_t k̃_tᵀ, κ = (1−λ)(1−λ²)/(1 − 2λ cos ωT + λ²) = 1.221이다.
- 이 정리는 `tests/test_model.py`가 검사한다.

측정에는 시간 반전을 쓴다. 같은 궤적에서 태그를 τ − 2nωT로 바꾼 그림자 흔적을 함께 돌리면 다음이 된다(`lt/analysis/order_latency.py`).

    O = (Im S(+) − Im S(−))/2,   L = (Im S(+) + Im S(−))/2

측정 결과(46,872 EMA, 512문제, 128블록)
- ‖L‖/‖SB‖ = 1.218(예측 1.221), cos 0.999. 수렴 여부와 무관하다.
- ‖O‖/‖Hebb‖는 푼 퍼즐에서 0.164 → 0.000으로 줄고, 못 푼 퍼즐에서는 0.054 바닥에서 배회한다.
- O가 정착하는 블록과 풀리는 블록의 스피어만 상관은 0.994다.
- O만으로 풀림 여부를 라벨 없이 97% 맞힌다.

따름정리: 블록 간 기억이 없는 기준 모델(창 sin(φ_V − φ_K))은 이 모델의 고정점 극한과 같은 꼴이다. 두 모델의 차이는 과도기에만 있다.

**역할: 추론 개입(10-14 §5, `lt/analysis/interventions.py`).** 512문제, 128블록에서 푼 퍼즐 수와 L0 라운드당 블록이다.

| 읽기 | 푼 퍼즐 | 라운드당 블록 |
| --- | ---: | ---: |
| 기준 Hebb + α(O + L) | 264 | 1.06 |
| α = 0 | 225 | 1.32 |
| L만 (O 제거) | 263 | 1.13 |
| O만 (L 제거) | 222 | 1.03 |
| ωT → −ωT (= Hebb + α(L − O)) | 78 | 4.03 |
| ωT = 0 | 269 | 1.14 |

- **L은 정확도를 맡는다.** L을 빼면 α = 0과 같아진다.
- **O는 속도와 안정을 맡는다.** O를 빼도 정확도는 유지되지만 느려진다.
- O의 부호를 뒤집으면 파국이다. 32블록에서 정착한 뒤 O를 반전하면 194 → 94가 된다. 이때 후보가 다시 열리고(1.03 → 1.61/칸), 깊은 칸부터 풀린다.
- 같은 시점에 L을 반전하거나 30% 잡음을 넣어도 정착은 깨지지 않는다.

**O는 TD 델타 규칙이다(10-14 §6).** 전개하면 G ≈ (v + αγΔv)(k̃ − αγΔk̃)ᵀ다.
- γ = Σ_k k(1−λ)λ^k sin(kωT) = 0.662다.
- 학습된 αγ는 평균 0.91(헤드별 0.66~1.20)이다. 모델은 한 블록 앞의 값을 한 블록 전 주소에 쓰도록 α를 맞췄다.
- DeltaNet(S ← S + β(v − Sk)kᵀ)과 비교하면 두 가지가 다르다.
  - 오차가 다른 토큰의 간섭이 아니라 같은 칸의 자기 수정 v(b) − v(b−k)다. 그래서 칸 사이 겹침이 통신 간선으로 보존된다.
  - DeltaNet에 없는 키 이동 철회 항 −v Δk̃ᵀ가 있다.
- B의 ρ는 Gated DeltaNet의 감쇠 자리에 해당한다.

**무엇을 계산하는가(10-14 §7).**
- 결정 블록(argmax가 최종값으로 굳는 블록)은 L0 동기식 전파 라운드 수에 1.06블록/라운드로 비례한다(스피어만 0.64). 블록 하나가 전파 한 라운드에 해당한다.
- 은닉 상태에서 후보 집합을 릿지 probe로 98.7% 읽어낸다(로짓 94.7%).
- 순차성은 공간 파동이 아니라 논리적 깊이를 따른다([results.md](results.md) 부정 결과).

## 7. 모델 B: STDP 효력의 누설 적분

W_b = ρW_{b−1} + Im S_b이고 읽기는 Hebb + α_h W_b다(`configs/b_leaky.json`, Kaggle 셀 기본값 ρ = 0.5).

동기
- 추론 때만 기억을 늘리면 순손실이다(λ 0.6/0.7/0.8 → 253/216/201, ρ 0.5/0.8/0.9 → 257/253/251, 기준 264; 10-14 §8).
- 그러나 이 결과는 λ = 0.5에 맞춰진 가중치의 분포 이동과 구분되지 않는다.
- 그래서 "못 푼 퍼즐은 기억이 짧아 같은 오답을 되풀이한다"는 가설은 긴 기억으로 학습해야만 시험할 수 있다.

설계
- B는 Hebb 운반자는 누적하지 않고 STDP 항 Im S만 누적한다. 다만 Im S 자체가 과거 v, k̃를 담은 행렬이므로, 10-12 §10.1의 "스칼라 효력만 적분하고 운반자는 현재" 원칙을 지키는 것은 아니다(STDP 성분의 J 읽기).
- ρ = 0이면 A와 같다.

상태: ρ 0.5를 40k까지 학습했다. 이륙이 A보다 4~6k 늦었고, 39k에 81.2% / 954(A 82.3% / 1,038), 40k 외삽 6.8%(A 41k 8.6%)였다([results.md](results.md)). 이전 다음 안(ρ 0.9 + α_init 0.1)은 기억 길이(약 10블록)가 BPTT 창(8블록)을 넘는다.

## 8. 이 문서가 버린 이전 관점

아래 주장은 이후 증거와 맞지 않아 현재 설명에서 뺐다. 원 기록은 아카이브 브랜치에 있다.

1. **"외삽은 결합 기억 w(EMA)에서 온다"** (v1.x README)
   - v1.x 안에서는 측정이 유효하다.
   - KV 모델에서는 추론 때 기억을 늘리면 순손실이다(§7).
   - 현재 모델의 외삽 기제는 미결이다.
2. **"블록 축에는 기억이 없다 / 블록 안 위상이 곧 시간이다"** (10-12 §4)
   - 위상 태그 흔적과 블록 간격 시계로 대체했다(§5).
3. **"각도 변위 시계면 충분하다, 문제는 게이지뿐"** (10-13 §4, §11)
   - 각도 시간은 블록 사이에 흐르지 않는다(Rule110 0.34/0.34). 그래서 bounded 시계를 도입했다.
4. **"생성기 head가 h의 별도 사영인 것이 결함"** (10-13 §11)
   - 10-14에서 삭제했다. 결함은 상대 잠복기가 묶이지 않는 것이었다(§5 조건 3).
5. **"학습 없이 넣은 위상 trace가 외삽을 올린다"** (10-12 §11.2)
   - trace를 넣고 학습한 두 런에서는 trace를 끈 쪽이 9~15문제 나았다(10-12 §12.2). 학습한 증거를 따른다.
6. **"주소 채널은 시간 주파수 은행이다" / Fourier = STDP 동일시** (stdp_fourier)
   - 필요조건 위반으로 기각했다.
   - 남는 것은 두 가지다: 흔적 × 지금으로 다시 쓰는 재배열, 홀 창 ⟺ 순허수 스펙트럼.
7. **"STDP 고유의 순서 정보가 정확도를 만든다"**
   - O를 빼도 정확도는 같고(263 대 264), ωT = 0도 269다.
   - 정확도는 L(지연부)이 맡는다. 순서부 O는 속도와 안정을 맡는다(§6).
8. **"STDP가 제약 전파를 시냅스 수준에서 구현한다"**
   - 간선 수준에서 지지되지 않는다. 근거 간선은 Hebb가 나르고(밀도비 1.76/1.32), 순서 읽기는 확정된 칸을 피한다(0.81).
9. **"학습 중 지표의 train–held-out 격차가 과적합을 보여준다"**
   - 학습 중 지표는 배치 내 적응이 섞인 값이다.
   - 같은 EMA 가중치, 새 carry로 다시 재면 20k 격차는 20.4%p가 아니라 +1.2%p였다(10-10 §6). 측정 규칙은 [AGENTS.md](../AGENTS.md)에 있다.
10. **"쌍선형 FFN ≈ SwiGLU"**
    - Φ 정규화 체제에서만 성립했다(§2).
