# 2026-10-20 규칙 시냅스: ARC 층위로 올린 TEM과 bands 시냅스의 이론

> **성격**: Claude가 진행한 자유 이론 연구의 기록이다. 학습과 실험은 하지 않았다. 항등식과 기댓값은 `toy_g/theory_checks.py`로 FP64 검산했다(각 결과 옆에 표시). 검증하지 않은 주장은 **가설**로 표시한다.

## 0. 질문과 결론

**질문**
- Q1. 과제마다 규칙이 다르고 시범 몇 개로 빨리 정해야 하는 ARC 층위에서, TEM의 두 시냅스(구조 전이 W_a, 내용 기억 M)는 각각 무엇에 대응해야 하는가?
- Q2. 규칙 자체를 빠른 시냅스에 담을 수 있는가? 그 시냅스는 정확히 무엇을 저장하는가?
- Q3. 우리 bands 시냅스(같은 칸의 블록 사이 시간차 창)가 그 역할을 할 수 있는가? 조건은 무엇인가?

**결론**
1. **정리 1 (인수분해)**: 시범 쌍에서 내용이 맞는 (입력 칸, 출력 칸) 코드의 외적을 쌓은 규칙 시냅스는 정확히 R = Ā·P(r)이다.
   - Ā는 입력 격자만으로 정해지는 같은 색 공출현 그램(시간차 0 통계)이고, P(r)는 규칙의 주소 연산자다.
   - 군 구조가 필요 없다. 겹치는 주소 함수와 크기가 바뀌는 함수에서도 성립한다.
2. **충분통계**: 처음 보는 가설까지 포함해 모든 가설 r'의 "설명되는 칸 수"가 ⟨R, P(r')⟩이다.
   - 투표는 R을 연산자 집합 P(G) 위로 사영하는 것이다.
   - 연산자들을 기억으로 둔 현대 Hopfield 한 걸음과 같다.
3. **Yule–Walker**: P(r) = Ā⁻¹·R(관찰된 칸의 부분공간 위에서).
   - 시간차 0 통계는 버릴 것이 아니라, 시간차 결합에서 공통 원인을 나누어 없애는 정규화다.
   - 그래서 두 통계는 더하는 것이 아니라 합성해야 한다.
4. **원환의 조화해석**: P(r)는 푸리에 기저에서 단항 행렬이다.
   - 평행이동은 대각 위상이고, 점 연산은 D4 궤도 안의 모드 순열이다.
   - 대각 위상 구조(RoPE, bands 극점)로 표현할 수 있는 규칙은 평행이동뿐이다. 점 연산은 모드를 섞는 전체 행렬 시냅스가 필요하다.
5. **bands = 빠른 전이 추정기**: bands의 시간차 창은 "앞 블록의 키 → 뒤 블록의 값" 전이를 퍼즐마다 빠르게 추정한다.
   - 블록 n₀에 출력 칸의 구조 코드를, n₀+D에 내용으로 찾은 출처 칸 코드를 두면 W에 규칙 시냅스가 쌓인다.
   - 이때 창은 인과적인 한쪽 방향이어야 하고, l(0) = 0이어야 한다.
   - 홀수(STDP) 창은 자기 역원인 규칙을 기댓값에서 정확히 지운다. 토이에서는 128개 중 44개다(항등 포함).
6. **편향의 층위**: 이 정식화에서 TEM의 편향은 올바른 층위로 옮겨진다.
   - 공유·느림: 칸 코드, 역할 코드, 투영, 창의 모양
   - 과제별·빠름: 규칙 시냅스 W
   - 격자별·빠름: 시간차 0 내용 기억

## 1. 설정

- 칸 집합 Ω_in, Ω_out(서로 달라도 됨). 색 C = {0(배경), 1, …, |C|−1}. 격자 I: Ω_in → C.
- 규칙: O(o) = κ(I(r(o))).
  - r: Ω_out → Ω_in은 주소 함수로, "출력 칸 o가 읽는 입력 칸"이다.
  - κ는 단사인 색 함수이고, κ(0) = 0이다.
  - 토이의 전제 1(칸 하나에서 옴), 2(주소가 내용과 무관), 4(색만의 함수)가 이 꼴이다. 전제 3과 5(군)는 정리 1에 필요 없다.
- 코드: g_in: Ω_in → ℝ^{d_in}, g_out: Ω_out → ℝ^{d_out}. 정규직교, 즉 ⟨g(x), g(y)⟩ = δ_xy.
  - 평균 0 코드(⟨g(x), g(y)⟩ = δ_xy − 1/N)에서는 아래 결과가 r'에 무관한 상수만큼 달라진다.
- 주소 연산자: P(r) = Σ_o g_in(r(o))·g_out(o)ᵀ. 그래서 P(r)·g_out(o) = g_in(r(o))이다.
  - r이 한 공간 위의 전단사이면 P(r)은 직교 행렬이다.
  - r이 군 G의 원소이면 P는 G의 표현이다.
- 시범 D = {(I_k, O_k)}, k = 1..K.

## 2. 규칙 시냅스

### 2.1 정의

    R    = Σ_k Σ_{o, x} w_κ(O_k(o), I_k(x)) · g_in(x)·g_out(o)ᵀ,      w_κ(b, a) = 1[a ≠ 0, b = κ(a)]      (κ를 알 때)
    R_ab = Σ_k Σ_{o, x} 1[I_k(x) = a, O_k(o) = b] · g_in(x)·g_out(o)ᵀ                                    (κ를 모를 때)
    A(I) = Σ_{x, y} 1[I(x) = I(y) ≠ 0] · g_in(x)·g_in(y)ᵀ,   A_ac(I) = Σ 1[I(x) = a, I(y) = c] · g_in(x)·g_in(y)ᵀ,   Ā = Σ_k A(I_k)

R은 출력 칸 o(시냅스 후)와, 그 칸과 내용이 맞는 입력 칸 x(시냅스 전)의 코드 외적을 쌓은 Hebbian이다.

### 2.2 정리 1 (인수분해)

    R = Ā · P(r),      R_ab = Σ_k A_{a, κ⁻¹(b)}(I_k) · P(r)

**증명.**
- 시범 하나와 출력 칸 o를 고정한다. κ가 단사이고 배경을 고정하므로 w_κ(O(o), I(x)) = 1[I(x) = I(r(o)) ≠ 0]이다.
- 정규직교성 때문에 Σ_x 1[I(x) = I(r(o)) ≠ 0]·g(x) = A(I)·g_in(r(o))이다.
- 따라서 R = Σ_o A·g_in(r(o))·g_out(o)ᵀ = A·P(r)이다. 색 쌍마다도 같은 방식으로 성립한다. ∎

**검산**
- 토이의 128개 규칙과 정규직교 코드(16차원), 평균 0 코드(15차원)에서 최대 오차 1.2e−15이다(색 쌍 판 포함).
- 임의의 주소 함수(겹침 허용, 16칸 → 6칸)에서 오차 0이다.

### 2.3 따름정리 1.1 (투표의 충분통계, 투표 = 사영)

모든 가설 r'(임의의 함수)에 대해 다음이 성립한다.

    ⟨R, P(r')⟩_F = Σ_k Σ_o w_κ(O_k(o), I_k(r'(o))) =: m(r')        (r'가 설명하는 출력 칸 수)

- κ를 모를 때는 m(r', κ') = Σ_a ⟨R_{a, κ'(a)}, P(r')⟩이다.
- 증명: ⟨R, P(r')⟩ = Σ_o g_in(r'(o))ᵀ·R·g_out(o)이고, 정규직교성으로 x = r'(o)인 항만 남는다. ∎
- 검산: ⟨R, P(r')⟩ − m(r')가 r'에 무관하다(128개 가설에서 편차 6e−15). 정규직교 코드에서는 그 상수가 0이다.

**의미**
- **충분통계**: d_in × d_out 시냅스 하나(κ를 모르면 |C|²개)가 시범 전체를 요약한다. 학습에 나오지 않은 가설의 점수도 선형 범함수 하나로 읽힌다.
- **MAP**: 출력 칸마다 독립적으로 확률 ε로 다른 색이 된다는 잡음 모형에서는 log p(D | r, κ) = m·log((1−ε)(|C|−1)/ε) + 상수이다. 그래서 argmax m이 균등 사전분포 아래의 MAP이고, 사후확률은 exp(β·m)에 비례한다. 토이 구조 모델의 softmax(β·s) 투표가 이 사후확률이다.
- **사영**: P(r')가 직교이면 ‖R − c·P(r')‖² = ‖R‖² − 2c·m(r') + c²·d이다. 그래서 투표는 R에 가장 가까운 군 연산자를 고르는 것이다.
- **Hopfield**: Σ_{r'} softmax(β⟨R, P(r')⟩)·P(r')는 연산자 P(G)를 기억으로 두고 R을 질의로 쓴 현대 Hopfield 인출 한 걸음이다. TEM-t의 softmax 인출을 연산자 공간에 한 번 더 쓴 것이다. 생성자의 단어로 연산자를 만들면, 이 기억은 저장하지 않고 합성되는 기억이 된다.

### 2.4 따름정리 1.2 (Yule–Walker, 시간차 0의 역할)

- Ā가 관찰된 칸의 코드 부분공간 V_obs 위에서 가역이면, 그 위에서 P(r) = Ā⁻¹·R이다.
- 이것은 선형 동역학의 전이 추정 A = C_1·C_0⁻¹(시간차 1 공분산 × 시간차 0 공분산의 역)과 같은 구조다.
  - Ā는 같은 격자 안의 공출현으로, 공통 원인에 해당한다.
  - R은 입력에서 출력으로 가는 교차 통계다.
  - 교차 통계에는 공통 원인 구조가 곱해져 섞여 있고, Ā로 나누어야 전이만 남는다.
- **우리 모델에 주는 함의**: 지금 읽기 q̃·(Σ v·k̃ᵀ + W)ᵀ는 시간차 0 항과 시간차 항을 **더한다**. 이론은 둘을 **합성**하라고 말한다. 시간차 0은 정규화(나누기)로 쓰거나, 아래 5절처럼 "W로 주소를 얻고 M으로 그 주소를 읽는" 순서로 써야 한다.
- **관찰 가능성**: R의 o번째 열은 Ā·g_in(r(o))이다. 그래서 출처 칸 r(o)가 어느 시범에서든 색칠되어 있을 때만 정보가 있다. 나머지는 사전분포(2.6절)가 채워야 한다.

### 2.5 명제 2 (기댓값과 여백)

토이의 입력 분포를 가정한다. 색칠 칸 수 s ~ U{3, …, 8}이고, 칸은 서로 다르게 무작위로, 색은 독립 균등이다. 칸 기저에서 다음이 성립한다.

    E[A] = (α − β)·I + β·J,    α = E[s]/16 = 0.34375,    β = E[s(s−1)]/(16·15·4) = 0.02882

- **기댓값**: E[R] = K·[(α − β)·P(r) + β·J]이다(전단사에서 J·P = J). 랭크 1 항은 r'에 무관하다(모든 전단사에서 ⟨J, P(r')⟩ = 16). 그래서 기댓값에서 R은 P(r)에 비례하고, 상수 오프셋만 붙는다.
- **여백**: E[m(r) − m(r')] = K·(α − β)·(16 − fix(r, r'))이다. fix는 r(o) = r'(o)인 칸 수이고, 이 식은 (α−β)/2 × ‖P(r) − P(r')‖_F²와 같다.
- **토이의 최소 여백**: 항등이 아닌 원소가 고정하는 칸은 최대 8개다. 고정 칸 수 분포는 0개 95원소, 2개 16원소, 4개 12원소, 8개 4원소다. 그래서 시범 하나당 기대 여백은 최소 8(α−β) ≈ 2.52칸이다.
- **검산**: E[A]의 몬테카를로 오차는 n = 10⁴, 10⁵, 10⁶에서 7.4e−3, 2.5e−3, 6.7e−4로 1/√n만큼 줄었다.

### 2.6 구조의 몫: 관찰되지 않은 칸의 완성

- 가설 공간의 크기를 비교한다.
  - 16칸의 모든 전단사: log₂ 16! ≈ 44비트
  - G = D4 ⋉ Z₄²: 7비트(색 순열이 붙으면 +4.6비트)
- 색칠된 대응 하나가 주는 정보는 log₂ 16 = 4비트 이하다.
  - 구조 없이 정하려면 사실상 모든 칸의 대응이 필요하다.
  - G 안에서는 일반적인 위치의 대응 3개면 충분하다. Z₄²에서 D4 궤도의 크기가 최대 4라서, 차분 벡터 하나로는 점 연산이 하나로 정해지지 않는다.
- 정리 1에 비춰 보면 R은 r를 관찰된 칸에서만 알려 준다(2.4절). 구조 코드(군의 표현)의 몫은 그 정보를 전체 연산자로 완성하는 것이다.
- 이것이 "구조 코드의 가치는 가설 공간을 좁혀 적은 예시로 규칙을 정하는 데 있다"의 정식화다.

## 3. 원환 위의 조화해석

- 푸리에 코드 g(x) = (e^{2πi k·x/4} / 4)_{k ∈ Z₄²}는 정규직교다. k = 0을 빼면 평균 0이 된다.
- 토이의 128개 원소는 모두 Z₄² 위의 아핀 사상 r(o) = M·o + c이다. 점 연산은 격자 중심에 대한 D4이므로 선형부에 오프셋이 붙고, 그 뒤에 평행이동이 온다.
- P(r)·g(o) = g(M·o + c)의 성분 k는 e^{2πi k·c/4}·g(o)_{Mᵀk}이다. 그래서 푸리에 기저에서 P(r)은 이렇게 된다.

      P̂(r)_{k, k'} = e^{2πi k·c/4} · 1[k' = Mᵀ k]        (단항 행렬: 모드 순열 × 위상)

- 검산: 128개 모두 단항 행렬이다(편차 4.6e−16). 평행이동은 대각이고, 모드 순열은 점 연산에만 의존한다.
- 주파수 공간의 D4 궤도: {(0,0)}, {(2,2)} (크기 1), {(0,2), (2,0)} (크기 2), {(0,1), (0,3), (1,0), (3,0)}, {(1,1), (1,3), (3,1), (3,3)}, {(1,2), (2,1), (2,3), (3,2)} (크기 4).
  - P̂(r)은 궤도별 블록 대각이다. 블록 안에서 점 연산은 순열을, 평행이동은 위상을 맡는다.
  - 그래서 규칙 추론은 (i) 지지 패턴으로 점 연산(8개 중 하나)을 고르고, (ii) 위상을 읽어 평행이동을 얻는 일로 나뉜다. 주파수 (1,0)과 (0,1)의 위상 두 개면 c가 정해진다.

**명제 3 (대각 구조의 한계)**
- 모든 평행이동과 교환하는 연산자는 정확히 푸리에 기저에서 대각인 연산자다(합성곱 정리). 점 연산은 평행이동과 교환하지 않는다(G는 비가환이다). 따라서 다음이 성립한다.
  - (a) 고정된 주파수 슬롯에 과제별 위상만 더하는 구조는 평행이동 규칙(가환 부분군 Z₄²)만 정확히 표현한다. 과제별 이동량을 준 RoPE나, 과제별 각도를 준 bands 극점이 여기에 해당한다.
  - (b) 점 연산을 표현하려면 같은 궤도 안의 슬롯 사이로 내용을 옮기는, 과제에 따른 슬롯 순열(비대각 연산자)이 필요하다.
  - (c) 전체 행렬 시냅스(W, D×D)는 어떤 단항 P̂(r)든 담을 수 있다. 그래서 규칙은 대각 동역학이 아니라 전체 행렬인 빠른 가중치에 살아야 한다.
- 우리 모델의 학습 2D RoPE는 평행이동에 대한 대각 위상 코드(Z²로 제한된 TEM의 g)이고, bands 극점 z_r은 대역마다 스칼라 회전(시간 코드)이다. 둘 다 대각이다.
- **가설(검증 안 함)**: 그런데도 LT가 제 루프에서 점 연산이 섞인 그룹 0을 배운 것은 내용 경로 덕일 수 있다. 예를 들어 0번 자리의 앞 토큰을 읽으면 RoPE 각도가 θ·o가 되어 절대 위치가 생긴다.

## 4. bands 시냅스의 해석

### 4.1 창의 꼴 (모델 식에서)

`lt/model.py`의 bands 식을 블록 단위로 풀면 다음과 같다.

    S(n) = Σ_t [ Σ_{D≥0} l(D)·v_t(n)·k̃_t(n−D)ᵀ + Σ_{D>0} l(−D)·v_t(n−D)·k̃_t(n)ᵀ ]
    l(D) = Σ_r γ_r Re(a_r z_r^D) (D ≥ 0),   l(−D) = Σ_r γ_r Re(b_r z_r^D) (D > 0),   W ← (1 − η)·W + η·S

- W는 C_D = Σ_t v_t(n)·k̃_t(n−D)ᵀ(각 칸의 재귀 궤적의 시간차 D 교차공분산을 칸에 걸쳐 더한 것)를 창 l로 거른 것을 블록에 걸쳐 EMA한 것이다.
- 모든 칸에 공통 전이가 있어 v_t(n) = T_D·k̃_t(n−D)이면 C_D = T_D·C_0^{kk}이다. 그래서 W는 퍼즐마다 빠르게 추정한 전이(여기서도 Yule–Walker 꼴)이다.
- 읽기 W·q̃는 "이 키 뒤 D블록에 온 값"을 돌려준다.

### 4.2 TEM과의 대응

- **TEM**: 전이(W_a)는 느리고 환경 사이에 공유되며, 빠른 시냅스 M은 시간차 0 내용 기억이다.
- **우리 모델**: 빠른 시냅스가 둘 있다.
  - 시간차 0 항 Σ_t v_t·k̃_tᵀ: k가 구조를, v가 내용을 실으면 TEM(-t)의 M이다.
  - 시간차 창 W: 빠른 전이다.
- ARC 층위에서 필요한 것이 바로 빠른 전이(규칙)다. 그래서 bands 창은 규칙 시냅스와 꼴이 맞는다. 남은 문제는 "무엇에서 무엇으로의 전이인가"다.

### 4.3 명제 4 (규칙 시냅스가 되는 조건과 창의 방향)

**이상화한 일정을 둔다.**
- 시범 출력 토큰 o의 상태가 블록 n₀에서는 g_out(o)이다.
- 블록 n₀+D에서는 ĝ(o) = Σ_x w_κ(O(o), I(x))·g_in(x)이다. 짝 입력 격자의 내용 기억에서 내용으로 위치를 인출한 것으로, TEM의 x → g 추론에 해당한다.
- 투영은 항등으로 둔다.

**그러면 블록에 걸쳐 쌓인 S는 다음과 같다.**

    S = l(D)·R + l(−D)·Rᵀ + l(0)·Σ_o [g_out(o)·g_out(o)ᵀ + ĝ(o)·ĝ(o)ᵀ],        R = Ā·P(r)  (정리 1)

명제 2를 쓰면 E[Ā·P − Pᵀ·Ā] = K(α−β)·(P(r) − P(r⁻¹))이다(J·P = Pᵀ·J = J). 이를 이용해 창의 방향별로 정리하면 다음과 같다.

| 창 | 쌓이는 것 | 결과 |
|---|---|---|
| 인과적 한쪽 방향 (l(−D) = 0, l(0) = 0) | l(D)·Ā·P(r) | 규칙 시냅스 |
| 홀수 (STDP, l(−D) = −l(D)) | 기댓값 ∝ P(r) − P(r⁻¹) | 자기 역원인 규칙(r = r⁻¹)이 정확히 지워짐. 토이에서는 128개 중 44개(항등 포함) |
| 짝수 (l(−D) = l(D)) | ∝ P(r) + P(r⁻¹) | r과 r⁻¹를 구별하지 못함 |
| l(0) ≠ 0 | 항등에 가까운 항 추가 | 점수에 l(0)·tr P(r')만큼 편향. 고정 칸이 많은 규칙(8칸 4개 → 4칸 → 2칸)이 유리해짐 |

- 결론: 규칙 시냅스에는 인출 시간차 D에서 한쪽 방향이고 l(0) = 0인 창이 필요하다.
- bands는 a(D ≥ 0)와 b(D < 0)가 분리되어 있다. 그래서 b ≈ 0으로 두고 Σ_r γ_r Re a_r = 0이면 된다. l(0) = 0이면서 0이 아닌 창을 만들려면 대역이 2개 이상 필요하다. 지금의 매개화 안에서 실현할 수 있다.
- 순서도 중요하다. 질의 출력 토큰은 W를 읽어 출처 주소를 얻고, 다음 블록에서 시간차 0 기억 M을 그 주소로 읽어야 한다. 두 시냅스의 합성은 한 번의 읽기(Σ v·k̃ᵀ + W)로는 안 되고, 재귀 블록을 차례로 거쳐야 한다.

### 4.4 생성자 단어의 오차 전파 (사전분포 쪽)

- **보조정리**: 생성자마다 ‖ρ̂(s) − ρ(s)‖_op ≤ ε이고 모든 인자의 노름이 1 이하(직교)이면, 길이 L인 단어에서 ‖ρ̂(w) − ρ(w)‖_op ≤ L·ε이다(망원 합).
- **읽기 정확성**: 정규직교 코드에서 주소 a = ρ(w)·g(o) + e는 ‖e‖ < 1/√2이면 옳은 칸을 읽는다. ⟨a, g(r(o)) − g(x)⟩ ≥ 1 − √2‖e‖이기 때문이다.
- **충분조건 비교**
  - 코드 공간 합성(다 곱한 뒤 읽기): L·ε < 1/√2. 토이는 L_max = 10(단어 길이 분포 [1, 4, 9, 16, 22, 24, 22, 16, 9, 4, 1], 평균 5)이므로 ε < 0.071이어야 한다.
  - 칸 공간 합성(생성자마다 칸으로 정리): 걸음마다 ε < 0.71이면 되고, 오차가 쌓이지 않는다.
- 토이 관찰과 맞는다. 생성자가 정확하지 않았던 런(서로 다른 변환 122~126개)은 코드 공간 합성에서 처음 보는 변환이 73~95%였고, 칸 공간 합성에서 100%(여유 9.29)였다. 다만 위 조건은 충분조건일 뿐이다.

## 5. 전체 그림: ARC 층위의 TEM을 우리 모델의 말로

| | TEM | ARC로 올린 정식화 | 우리 모델 |
|---|---|---|---|
| 구조 코드 | g (행동으로 경로 적분) | 칸 코드 g_in, g_out (+ 격자 역할 코드) | RoPE (평행이동만, 대각) + 필요한 역할 코드 |
| 느린 공유 | W_a (전이) | 칸 코드, 표현 ρ(생성자), 투영 | 투영, FFN, 극점과 계수(창의 모양) |
| 빠른 내용 기억 | M (시간차 0, g ⊗ x) | 격자별 M_I (시간차 0) | Σ_t v·k̃ᵀ (시간차 0 항) |
| 빠른 규칙 | 없음 | R = Ā·P(r) → 정리 후 P(r) | 시간차 창 W (인과, l(0) = 0) |
| 정리(끌개) | p 공간의 끌개 | P(G) 위의 Hopfield 사영 | 없음 (열린 문제) |

**블록 일정** (가설적 설계, 검증 안 함)
1. 모든 격자의 내용을 시간차 0 기억에 쓴다. 격자를 구별하려면 역할 코드(어느 시범인지, 입력인지 출력인지)가 구조 코드에 들어가야 한다.
2. 시범 출력 토큰은 자기 내용으로 짝 입력 격자의 기억을 질의해 출처 위치 코드 ĝ(o)를 얻는다. TEM의 x → g 추론이다. 자기연상 기억 Σ p·pᵀ(p = [g; x])는 g와 x 어느 쪽을 단서로 줘도 인출된다.
3. 시간차 D 창이 (g_out(o) → ĝ(o))를 W에 쓴다. 그러면 W ≈ Ā·P(r)이다.
4. 선택 단계로, P(G) 위로 정리하거나 Ā로 정규화한다.
5. 질의 출력 토큰 o*는 W·g_out(o*) ≈ g_in(r(o*))로 출처 주소를 얻고, 다음 블록에서 질의 입력의 기억을 그 주소로 읽는다. 색 대응은 색 쌍 시냅스 R_ab로 추론한다.

## 6. 한계와 열린 문제

- **주소가 내용에 의존하는 경우(전제 2 위반)**: 시범마다 R_k = A(I_k)·P(r(I_k))로 연산자가 달라서, 규칙이 하나의 연산자가 아니다.
  - 내용으로 정해지는 기준틀(물체의 닻 c(I))로 코드를 옮기면 P(r(I)) = T_{c(O)}·P(r̃)·T_{c(I)}⁻¹ 꼴을 기대할 수 있다. TEM-t의 랜드마크 보정과 닮았다.
  - 이때 규칙의 수학적 대상은 군이 아니라 군아(groupoid)가 된다. 열린 문제다.
- **출력 칸이 이웃의 함수인 경우(전제 1 위반)**: 칸 하나를 읽는 구조로는 부족하다. 칸 쌍 코드 g(x) ⊗ g(x')에 대한 고차 시냅스나 여러 헤드가 필요할 수 있다.
- **크기 변화, 겹침, 축소·확대**: 정리 1 자체는 성립한다. 하지만 이런 규칙은 군이 아니라 모노이드라서, 사영할 연산자 집합과 생성자 문법을 새로 정해야 한다.
- **Ā⁻¹를 망 안에서 구현하는 법**: 블록에 걸친 Newton–Schulz 반복이나 두 번째 시냅스 같은 후보가 있다. 열린 문제다.
- **일정의 현실성**: 실제 상태는 블록마다 섞인다. W = Σ_D l(D)·C_D에는 상태 지속(항등)의 오염이 들어온다. 창의 제약(인과, l(0) = 0)은 이 오염의 일부만 없앤다.
- **한 과제 안에 규칙이 여럿인 경우(전제 3 위반)**: 한 W에 겹쳐 쌓이므로 게이트가 필요하다. 헤드 하나는 규칙 하나를 담는다.
