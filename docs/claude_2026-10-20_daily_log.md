## 1. 하루의 흐름

1. **Mini-ARC 천장 측정 (손 문법, 측정 도구).**
   - 닻 + 칸별 술어(주소 1,251, 술어 27, m ≤ 2): 일치 40, MDL 정답 26, 신탁 29 (`toy_g/miniarc_grammar.py`).
   - 일치하지 않는 109과제를 손으로 분류했다. 광선 14, 세기 9, 내용이 변환을 고름 8, 이동 7, 폭 2 이상 7, 색 역할 6 등이다.
2. **손 부품 실행기 1판·3판 (측정 도구로만 의미 있음).**
   - 스캔·세기·요약·폭 2를 더하고 기술 길이를 비트(키 수 포함)로 매기니 MDL 정답 54였다. 3판은 문법 술어와 베이즈 평균을 더해 58이었다.
   - 사전을 과제 149개로 학습하면 이득이 없었다. 중첩 교차검증으로 정규화를 골라도 58이었다.
   - **정정:** 이 부품은 전부 손으로 쓴 것이다. 신경 아키텍처의 결과가 아니다(사용자 지적). 메모리 `feedback_learned_parts`에 기록했다.
3. **판 C에 학습 닻 부품을 붙인 시험 (`toy_g/anchor_*`).**
   - 손 매개변수로는 닻 규칙을 정확히 표현한다. 질의 색이 모두 시범에 나온 인스턴스에서 100%였다.
   - 학습시키면 실패했다.
     - 일반 단어판: 고정 규칙은 학습 과제 80%까지 갔지만, 닻 프로그램은 사후 질량을 잃고 버려졌다.
     - 위치 코드 묶기판: 코드가 원환의 지표로 수렴하지 않았다(덧셈 구조 코사인 0.12).
   - 원인: 닻은 풀링, 코드 구조, 묶기 상수, 단어가 동시에 맞아야 쓸모가 생기는 결합 구조다. 그래서 각 부분에 그래디언트가 거의 가지 않는다.
4. **방향 전환: LTD가 "짧은 기술"을 만든다 (사용자의 논점).**
   - 구조 코드 이론(정리 1 R = Ā·P(r), 따름정리 1.2 Yule–Walker, 푸리에 단항)과 LTD를 잇는 것이 핵심이었다. 아래 3절의 논증 1–4.
5. **규칙 시냅스 독립 검증 (`toy_g/ltd_rule.py`, `toy_g/ltd_diag.py`).**
   - 푸리에 기저 고정, 학습 없음, 시범 3개(과제 400개):

     | 쓰기 | 정답 |
     |---|---|
     | 위치 시냅스, 델타만 | 25/400 |
     | 위치 시냅스, 델타 + 희소 LTD | 399/400 |
     | 위치·색 결합 64×64 | 0–2/400 |

   - W와 C를 함께 쓰는 판(FISTA 150회): 학습 과제 96.3%, 처음 보는 쌍 94.8%, 처음 보는 변환 95.3%. 단위행렬·무작위 기저는 5% 안팎이었다.
   - **기저 Q를 무작위에서 학습:** 95.9 / 94.8 / 94.5%. 판 C와 같은 데이터·분할에서 판 C는 처음 보는 조합 95.3–95.6%였다.
     - 학습된 기저에서 법칙 규칙 128개는 에너지의 90%를 15칸에 담는다. 무작위 순열은 152칸이다.
     - 희소 LTD를 끄면 3%, 기저를 시작값으로 되돌리면 5–7%다.
6. **2단계: LT에 이식 (`lt/model.py`의 `rule_syn`, `tests/test_rule_syn.py`).**
   - 규칙 시냅스는 전용 q/k/v 투영을 쓴다. 격자별 시간차 0 기억(키는 격자 안 위치의 2D RoPE)을 만든다. 시범 쌍에서 위치 시냅스 W와 내용 시냅스 C를 오차 LTP + 문턱 LTD로 쓰고, 블록 사이로 넘긴다. 질의 격자는 C·M_query·Wᵀ를 읽는다.
   - 푸리에 키와 원-핫 값을 넣으면 LT 안에서도 96.3 / 94.8 / 95.3%다.
   - 규칙 읽기 이득 0이면 기존 band_product와 출력이 같다.
   - 전체 테스트 81개 통과, Kaggle 셀을 재생성했다.
   - 내용 시냅스의 사전값이 결과를 갈랐다. 단위행렬이면 28%, 균등(1/D)이면 95%다. 균등 사전을 쓰면 W가 먼저 색과 무관한 점유 그림으로 위치를 맞추고, 그다음 C가 색 순열을 잡는다.
   - 학습 런(문맥 토이, `configs/gtorus_ctx_rule_h64.json`):
     - 스텝당 1.3초라 250스텝(정답 0)에서 껐다. 원인은 블록당 반복 20회 × 16블록이다.
     - C를 블록당 한 번만 푸는 판은 6–9%로 실패해서 되돌렸다(커밋된 코드는 반복마다 C 풀이).
     - 비교용 band_product 단독(`configs/gtorus_ctx_product_h64.json`)은 1만 스텝에서 정답 0/3,072, 칸 정확도 65.9%였다.

## 2. 실수와 정정 (사용자 지적 포함)

- 신경 구조를 묻는 질문에 손 DSL을 만들어 "아키텍처"로 보고했다. 앞으로 부품은 학습되어야 하고, 손 부품은 측정 도구로 표시한다.
- 9절에서 정한 다음 단계(학습 모형의 닻 실험)를 하지 않고 손 측정으로 새서, 논의가 제자리로 돌아왔다.
- LTD 질문의 의도를 놓쳤다. 의도는 구조 코드 기저의 희소성 = 짧은 기술이었다. "LT 감쇠만 바꾸자"는 답은 틀렸다.
- 합성 질문("FFN이 합성을 선형으로 풀어 시냅스에 새기면 되나")에 "안 된다"고 답했는데, 틀렸다. 과제마다 시범으로 쓰는 시냅스에서는 단항 행렬의 곱이 단항 행렬이라 된다. 나는 과제 사이 덧셈 사전 이야기로 잘못 답했다.
- LT 메모리가 EMA라고 옛 구조로 답했다. 지금은 흔적곱(`band_product`)이다.
- GPU 검사를 과제별 루프로 짜서 느렸다. 메모리 `feedback_batch_gpu`에 기록했다.
- 기저 희소성 진단의 식이 틀렸다. conj(Q)·Pᵀ·Qᵀ가 아니라 Qᵀ·P·conj(Q)가 맞고, 다시 계산했다.

## 3. 주요 논증

**논증 1 (선택이 병목이다).**
- 덮어쓰기에 닫힌 함수족에서는, 시범과 일치하는 함수들이 시험 입력 x*에서 모든 출력을 낸다.
- 증명: 일치하는 h를 잡아 x*에서만 바꾸면 된다. 신경망은 검출 단위 ReLU(1 − ‖x − x*‖₁)로 이 덮어쓰기를 구현한다.
- 따라서 표현력이 아니라 사전(선택 규칙)이 답을 정한다.

**논증 2 (공짜 점심 없음과 범용 사전).**
- 균등 사전에서 시범 밖 정답률은 1/|Y|다.
- 혼합 ξ = Σ 2^(−K(ν))·ν는 모든 ν에 대해 −log ξ ≤ −log ν + K(ν)를 만족한다.
- 범용성은 "사전 없음"이 아니라 단순성 사전이다. 이것을 갖추면 퍼즐 임베딩보다 나을 여지가 있다. 퍼즐 임베딩에는 코드 길이 항, 합성 구조, 문맥 안 추론이 없다.

**논증 3 (LTD 꼴별 고정점, 선형 연상기억).**

| 쓰기 | 고정점 |
|---|---|
| 헤브 + 비례 감쇠 | C = E[yxᵀ] |
| 델타(예측 의존 LTD) | CΣ⁻¹ (설명되는 상관 제거) |
| + 일정 LTD | lasso (KKT: C − WΣ ∈ λ∂‖W‖₁) |
| + 약할수록 센 LTD | L0에 가까움 |

- 수치로 확인했다(`ltd_mdl.py` 결과는 3절 대화 기록).
- 시범이 구별해 주지 않는 정확한 중복은 어떤 규칙도 가르지 못한다.

**논증 4 (구조 코드 기저에서 희소 = 법칙).**
- 원환 푸리에 기저에서 토이 변환 128개는 모두 0이 아닌 칸 16개짜리 단항 행렬이다. 무작위 순열은 153–221칸(중앙값 203)이다.
- 정리 1에 따라 헤브 시냅스는 Ā·P(r)다. 예측 의존 LTD가 Ā를 지운다(Yule–Walker). 문서가 "열린 문제"로 둔 Ā⁻¹의 망 안 구현이 이것이다.
- 희소 LTD는 관찰되지 않은 방향을 채운다. 시범 3개가 걸치는 차원은 16 중 5–12(중앙값 9)다. 시험 입력의 에너지 22%가 그 밖에 있고, 델타만으로는 바깥에서 14/394를 맞힌다.
- 단항 행렬의 곱은 단항 행렬이다. 그래서 합성된 규칙도 시냅스 하나에 16칸으로 들어간다.

**논증 5 (합성을 덧셈으로 풀 수 있는 조건).**
- 단사이고 합성을 덧셈으로 바꾸는 부호는 규칙들이 교환 가능할 때만 있다.
- 토이에서 순서쌍의 84%가 교환되지 않는다. 덧셈으로 풀리는 것은 이동 16개뿐이다(푸리에 대각).
- 과제 사이 공유 사전에서는 합성을 단계로 실현해야 한다. 과제마다 쓰는 시냅스에서는 단항 곱이 닫혀 있어 그럴 필요가 없다(논증 4).

**논증 6 (위치·내용 분리).**
- 규칙은 P(r) ⊗ Π(κ)이다.
- 합친 시냅스는 미지수 4,096개에 시범당 벡터 하나라, 정답이 0–2/400이다.
- 나누면 색별 그림 12쌍이 위치 시냅스의 학습 쌍이 되어 399/400이다.

**논증 7 (블록당 반복).**
- 델타 반복은 아핀 사상이라 닫힌 꼴 한 번으로 묶인다.
- 문턱만 비선형이다. 문턱이 하는 일은 지지 집합(살아남는 시냅스)을 정하는 것이고, 이것에 FISTA로 100–150번 반복이 필요하다.
- LT는 순전파당 블록이 16번뿐이라, 블록 안에서 여러 번 반복하게 했다.
- 미검증: 최소 노름 해 + 행별 argmax로 한 번에 지지 집합을 고르는 방안.

## 4. 남은 일

- LT `rule_syn` 런의 속도. 내부 루프를 묶어 컴파일하거나, 앞쪽 반복을 그래디언트 없이 돌리거나, 지지 집합을 한 번에 고르는 방안.
- 규칙 모듈만 두고 band 메모리를 뺀 비교. 지금은 메모리가 둘 겹쳐 있다.
- 입력마다 연산자가 달라지는 규칙(닻·물체별)은 아직 다루지 못한다(이론 문서 6절의 군아 문제).
- 이 문서와 13절은 `docs/architecture.md`, `docs/results.md`에 아직 반영하지 않았다.
