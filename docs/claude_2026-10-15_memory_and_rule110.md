### 5.3 누설 적분과 EMA (`b_ema_inference/`)

- 누설 W ← ρW + x는 전달함수 1/(1 − ρz⁻¹), EMA W ← (1−η)W + ηx는 η/(1 − (1−η)z⁻¹). 극점이 같으면(ρ = 1−η) 모양이 같고 직류 이득(1/(1−ρ) 대 1)만 다르다. 가장 빠른 진동의 상대 이득은 (1−ρ)/(1+ρ). 학습 단계에서는 게인 재조정(읽기 α)으로 동치다.
- 추론 중 ρ를 바꾸면 이득이 바뀌어 고정점이 깨진다. EMA는 η를 바꿔도 고정점이 보존된다. 이것이 "누설은 안 되고 EMA는 된다"의 정확한 의미다.
- 누설 B 40k를 이득 보존 EMA(W′ = 2·EMA_η(Im S))로 추론(`ema_b.py`): η 0.5(= B 그대로) / 0.25 / 0.125 / 0.0625 → 늦은 풀림 15 / 24 / 33 / 29, seg128 234 / 258 / 257 / 242, 깨짐 0.
- EMA는 C5(정상성과 쌍당 1회)에서 쌍당 1회를 지키고 정상성만 깬다(나이 가중). `claude_essential_properties.md` C5를 이날 정정했다.
- "항상성"이라는 표현은 비유에 가깝다(되먹임 없는 전방 정규화). 정확한 말은 "쓰기의 지수 창 시간 평균".

### 5.4 η의 학습 기울기는 긴 기억의 가치를 보나 (`eta_gradient/`, `python etagrad.py <B-EMA 마일스톤>`)

- 세그먼트 안 편미분(학습이 실제로 계산하는 것, carry detach)과 런 전체 유한차분의 부호가 10k/20k/30k 모두 일치. detach는 편향이 아니다(사용자 지적이 맞았음).
- 10k: +0.28(η 감소 = 기억 연장 유리), 20k: −1.40, 30k: −1.58(짧은 기억 유리).
- v1.71의 η 기록: 0.05(초기) → 0.019(50k, 53블록) → 0.026(100k) → 0.061(200k, 16블록; 헤드 4만 145블록). 길어졌다가 포화 뒤에야 짧아짐. 단조 아님. 사용자 해석: 훈련의 포화가 기억을 짧게 만들었을 수 있다. 그래서 η를 고정하기보다 학습 가능하게 두자는 것이 사용자 의견(§4.3 런의 동기).

- 부류(512문제, 128세그먼트): 먼저 푼 262 / 늦게 푼 21 / 못 푼 229. 표본 24 / 21 / 24, 17~64세그먼트 구간. Im S = O(순서부, `OrderLatencyProbe`) + 나머지.

| | 먼저 푼 | 늦게 푼 | 못 푼 |
| --- | ---: | ---: | ---: |
| ‖O‖² / ‖Im S‖² | 0% | 1.9% | 2.9% |
| Im S 시간 변동 중 O의 몫 | 29% | 48% | **79%** |
| O 성분 합의 상쇄, 2블록 창 | 0.49 | 0.83 | 0.73 |
| 같은 지표, 32블록 창 | 0.19 | 0.18 | **0.09** |

- 결론: 못 푸는 퍼즐에서 시냅스를 흔드는 것은 순서부(LTP/LTD)이고, 부호는 블록마다가 아니라 1~8세그먼트에 걸쳐 뒤집힌다(칸이 세그먼트마다 양방향으로 뒤집히는 것과 같은 시간 척도). 그래서 걸러내려면 창도 수 세그먼트여야 한다.
- 풀린 뒤의 W(정답 시냅스)와 창 L의 EMA 사이 코사인(풀리기 전 블록): 늦은 국면 L=1 0.702 → L=16~32 0.734(최대) → 128 0.732, 초반 L=1 0.519 → L=4~8 0.534(최대) → 128 0.526. **최적 기억이 국면마다 다르다**(초반 짧게, 늦은 국면 길게). 학습값 8블록은 초반 최적과 일치. 이는 사후 평균이지 폐루프가 아니며 차이가 0.03으로 작다.
- 해석: 생물 STDP는 정상 입력을 가정해 평생 적분하지만 여기서는 풀이 중 상태가 바뀌므로, 창 길이는 가짜 상관 제거(길게) 대 비정상 추적(짧게)의 편향-분산 절충이다. w 동결이 풀린 퍼즐을 깨는 것이 "너무 긴" 쪽의 증거.
- 사용자가 제기한 다음 질문(미답): 기억을 상태에 따라 선별해야 하지 않나(활동 의존 시정수). 후보 게이트는 관측량이어야 한다(v1.8·10-13 생성기 실패 교훈): 칸별 키 변위, 헤드별 ‖O‖.

### 6.3 해부 (`scripts/analyze.py` → `final.npz`(미커밋, 8 MB, 재생성), `plot_final.py`)

Grokking(모듈러 덧셈의 Fourier 분석)을 불 함수에 옮겼다: 9비트 창 위 Walsh–Hadamard 기저(512 부분집합). 32,768행 × 가운데 20칸.

- **정확한 광원뿔**: 출력 로짓 분산 중 반경 r 창이 설명하는 몫(ANOVA 보정 R²)이 r=3 0.49 → r=4 0.99. 4스텝 뒤 칸은 정확히 반경 4로 정해지고, 모델은 첫 블록부터 그만큼 모은다.
- **진리표 완성**: 문맥 평균 로짓의 부호로 만든 512칸 표가 2~12블록에서 전부 맞음. 정답 함수는 맨 왼쪽 칸(−4)에 의존하지 않아 Walsh 계수가 정확히 256개(나머지 8칸의 모든 부분집합)이고, 모델은 이를 재현(cos 0.991, 지지 밖 에너지 0.1%). −4를 5% 넘게 쓰는 FFN 유닛이 없다.
- **단계별 시뮬레이션은 선형으로 안 보임**: 은닉(32차원) 선형 탐침으로 x_t[i+d]: 자기 입력·정답은 100%, 중간 행(t 2, 3)은 81~85%(기저율 55~60%). 3칸 규칙 4번 합성보다는 표 조회에 가깝다(선형 수준 결론).
- **유닛**: 256개 모두 살아 있음. 대부분 가운데(−1~+1)를 읽고 1~2차(평균 2.5차). 출력의 3~5차는 조합에서 나옴. 모듈러 덧셈처럼 주파수 군집은 없다. 많은 유닛이 오른쪽 5칸 패턴 검출기.
- **읽기 커널**(q̃_i·k̃_j 평균): 1블록은 왼쪽 1~2칸 음, 오른쪽 1~2칸 양으로 이웃을 모음. 2블록부터 다른 모양(자기 −, +1 +, +3 −)으로 128블록까지 고정.
- **외삽 붕괴 = 표의 침식**: 128블록에서 Walsh cos 0.752, 66개 창 오답(오른쪽 5칸의 특정 패턴에 몰림), 3·4차 에너지가 줄고 2차가 커짐, R²(r=4) 0.995 → 0.835.

### 6.6 N번 반복해도 맞을 조건 (사용자와 정리한 일반형)

입력 x마다 시작 상태 s₀(x), 블록 사상 f_x, 읽기 r, 정답 집합 C_x = { s : r(s) = g⁴(x) }. 학습이 보장한 것은 b₀ ≤ b ≤ n에서 f_x^b(s₀) ∈ C_x.

모든 N ≥ b₀에서 r(f_x^N(s₀)) = g⁴(x)일 필요충분조건은 다음을 만족하는 A_x의 존재다(모든 x):

```
1) A_x ⊆ C_x
2) f_x(A_x) ⊆ A_x              (앞으로 불변)
3) 어떤 m ≤ n 에서 f_x^m(s₀) ∈ A_x
```

- 학습은 2)를 보장하지 않는다(n 이후의 f에 대한 조건). 실용형은 Lyapunov: L_x = {V_x ≤ c} ⊆ C_x, L_x 위에서 V_x(f_x(s)) ≤ V_x(s), 진입 V_x(f_x^m(s₀)) ≤ c. 특수형은 C_x 안의 끌어당기는 고정점(과도 구간도 C_x 안이어야 함), 수축 사상, C_x 안의 주기 끌개.
- 구조가 막는 것은 아니다: 입력은 매 블록 재주입되고, 시계 절대 시각 n·ωT는 쓰기에 차이로만 들어가고, W는 EMA 고정점을 갖는다. 지금 모델은 이미 고정점으로 수렴한다. 실패한 것은 1)과 2)를 함께 만족하는 것(끌개가 C_x 밖).
- 스도쿠에는 고정점 강제가 해로울 수 있다(v1.1 늦은 풀림은 w가 계속 움직여서 생김).

### 6.7 단조 손실 시험 (`scripts/train_mono.py`, 컴파일판 `train_mono_c.py`, 결과 `mono/`)

사용자 제안: n번째에 손실 0이 아니라 "n번째가 n−1번째보다 손실이 낮다"를 배워야 한다. 이는 V = 손실인 Lyapunov 조건이다(행 CE < log 2면 행 전체 정답).

- 구현: 9블록 펼침, CE는 1~8블록, 추가 항 Σ_{b=1..8} mean_rows relu(ℓ_{b+1} − sg(ℓ_b)), ℓ_b = 블록 b의 행 평균 CE, 가중치 1. 앞 블록은 기울기 차단(앞 블록을 나쁘게 만들어 차이를 줄이는 편법 방지).

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 기준 | 99.95% | 83.0% | 36.8% | 16.0% | 2.4% | 1.0% |
| 단조 손실 | 99.9% | 99.4% | 73.2% | 32.7% | 0.3% | 0.0% |

| ‖Δh‖ | 8 | 16 | 32 | 64 | 128 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기준 | 0.354 | 0.088 | 0.036 | 0.016 | 0.004 |
| 단조 손실 | 0.451 | 0.080 | 0.034 | 0.025 | 0.010 |

- 단조 항은 4~5k에 0이 되어 기울기를 주지 않았다. 16~32블록은 좋아졌지만 64블록 이후는 나빠졌다.
- 이유: (1) 정답 영역 깊숙이(행 CE ~1e-4)에서 CE가 평평해 감소 조건이 상태를 붙잡지 못함. (2) 강제 범위가 방문한 한 걸음(8→9)뿐. (3) 상태는 오히려 더 움직였다. → CE는 여기서 쓸모 있는 Lyapunov 함수가 아니다. 상태 자체에 거는 조건이 필요하다.
