# 인지 지도 규칙 시냅스(cmap) 첫 결과: Mini-ARC, URM과의 맞춘 비교 (2026-10-21)

설계: `docs/claude_2026-10-21_cognitive_map_rule_synapse.md` §12(명세 v2)에서 빠른 쪽을 선형 하나로 만든 판.
코드: `lt/cmap.py`, `lt/cmap_data.py`, `lt/cmap_train.py`, `tests/test_cmap.py`(6개 통과). URM: `lt/urm_vendor` + `toy_g/urm_harness.py`.

## 1. 구현에서 정한 것

- 빠른 쪽(과제별, 시범에서 추론): 공간 연산자 A_j(색 유지), 색 사상 Π, 틀 색 가중 Γ, 상수 출력 B̂. 읽기가 이 넷에 대해 선형이라
  쓰기는 볼록 lasso 하나이고, 재귀 걸음마다 근접 경사 한 걸음(델타 + 사전 중심 쪽 소프트 문턱 = 희소 LTD)을 한다.
- 느린 쪽으로 옮긴 것: 틀 쌍 선택 ω(항별), 색 항의 공간 읽기 ω_c(둘 다 l1 정규화).
- 걸음 크기: 립시츠 추정 대신 재귀 걸음별로 학습되는 상수 η_t ≤ 0.15. 정규화(단위 코드, 평균 기억, l1 정규화된 ω, 칸 평균
  손실)로 L이 구조적으로 약 12 이하(실측 2.1–7.8)라 η L < 2.
- 구현 중 버린 것(기록): 다중선형 블록 순회는 배율 대칭과 조건수 악화로 NaN이 났고, 되짚기·단체 제약으로 막았다가 선형 하나로
  단순화하면서 모두 뺐다. 블록 기울기는 편미분(새 잎 텐서)으로 구해야 한다(아니면 create_graph로 그래프가 블록마다 두 배).
- 확인된 성질(테스트): 증강판(D4 + 색 순열)에 대한 모델 전체의 정확한 등변성(군 평균 켬), 질의 출력 칸이 쓰기에 0 기여,
  쓰기 걸음마다 목적함수 감소.

## 2. 데이터와 평가

Mini-ARC(149과제, 모두 5×5), 전환적: 과제의 학습 쌍은 학습에, 시험 쌍 149개는 평가에. 원본판 한 번 예측, 정확 일치. 증강판
cmap 101판(실시간 생성), URM 104판(D4 8 × 색 순열 13). 시험 입력이 학습 입력과 겹치는 누설 0.

주의: 시험 쌍에서 입력과 출력이 같은 칸이 평균 64.5%라 칸 정확도는 베끼기만으로 0.65 가까이 나온다. 의미 있는 지표는 정확 개수.
LT의 문맥 평가(앞선 A/B 런)는 EOS 칸을 함께 세어 칸 정확도가 이 문서의 수치와 비교되지 않는다.

## 4. 해석

- **끝점(15,000스텝, 같은 파라미터·스텝·역전파·손실·감쇠):** cmap 21/149(14.1%) 대 URM 12/149(8.1%). 단측 피셔 p = 0.069.
  5,000스텝 이후 모든 평가에서 cmap이 정확 개수로 앞섰다(6,000–15,000에서 약 1.5–2배). 칸 정확도는 URM이 약간 높다.
- **퍼즐 임베딩을 0으로 두면 더 높다:** 같은 체크포인트에서 32/149(21.5%). 임베딩 켬 21개와의 짝 비교: 둘 다 18, 임베딩 없이만 14,
  임베딩으로만 3 → 맥니마 정확 검정 단측 p ≈ 0.006. URM 12개와는 단측 피셔 p = 0.0008.
  - 해석: 이 모델의 일반화는 과제별 기억(퍼즐 임베딩)이 아니라 시범을 읽고 규칙 시냅스에 쓰는 경로에서 온다. 과제별 사전 중심은
    학습 쌍에 맞춰져 있어 시험 쌍에서는 오히려 방해가 된다(학습 중 30% 드롭아웃으로 공유 사전 경로도 학습되어 있었다).
  - "퍼즐 임베딩보다 나은 편향"이라는 원래 목표에 대한 가장 직접적인 증거다. 참고로 같은 Mini-ARC에서 GPT-4 + 물체 표현이
    35/149(23.5%, Xu et al. 2023)를 보고했다(사전학습된 대형 모델이라 직접 비교 대상은 아님).
- 주의: 평가 집합이 149쌍 하나라 검정은 평가 쌍 표본 변동만 반영하고 시드 변동은 반영하지 않는다(런 하나씩). 임베딩 0 평가는
  끝점 체크포인트에서 한 번만 했다(조정 없음). 계산은 cmap이 스텝당 약 6배 비싸고, 같은 GPU 시간 비교는 하지 않았다.
- cmap_lin(작은 판)이 맞힌 과제 예(6,000스텝): 세기(count_green_and_color_red), 색 맞바꾸기, 모양 변환(ExpandnContract),
  shape_mapping, which_side_has_more_area, find_the_color_of_the_gray_pixels, One_Color_Sequence.
- 큰 판이 임베딩 0으로 맞힌 32개에는 이동(Simple_Box_Moving, push_to_top-right_by_one, pull_inner_gadget...), 채우기(FloodFill,
  Filling_Corner), 색 치환(Simple_color_substitution_by_max_object, find_the_most_frequent_color_then_color_with_it), 회전
  (Rotate_45_degree), 순서 바꾸기(Change_the_object_order, Switch_layer_order), 국소 집계(find_the_most_frequent_color_for_every_2x2)가 섞여 있다.

## 4b. 최종 판(`runs/cmap_noemb_sf_s0`, SDPA 틀 + 임베딩 없음 + 컴파일, 15,000스텝) 해석

**결과:** 평가 정확 0, 2, 10, 24, 26, 35, 36, 32, 35, 32, 35, 38, 35, 33 → 최종 **39/149(26.2%)**, 칸 0.847. 같은 GPU 시간 URM 최고 25.
분석 스크립트: `docs/evidence/2026-10-21/interp_cmap.py`, `interp_paths.py`.

**반복 외삽(학습 16걸음):** 8 → 4, 12 → 30, 16 → 39, 20 → 40, 24 → 37, 32 → 29, 48 → 25, 64 → 22. 걸음을 늘려도 더 맞히지 않는다(고정점이 불안정).

**규칙 시냅스 내용:** 순수 재색칠 과제에서 Π가 바뀐 색을 담는 비율이 낮고(OrangeToYellow 1/2), D4 과제 7개에서 A를 통한 공간 읽기
지도가 정답 출처와 맞는 칸이 25개 중 0–2개다. 격자 마스크는 거의 전체를 덮고(평균 0.81–0.91) 물체 특징과 상관이 약하다(≤ 0.26).

**경로 기여·절제(정확 / 149, 기준 39):**

| 끈 것 | 정확 |
|---|---|
| 규칙 시냅스 쓰기(초기값 그대로 읽기만, 시범이 시냅스에 안 들어감) | **0** |
| 규칙 읽기 전체(시범 → 질의 정보 차단) | **0** |
| 항 Γ(틀 색 결합) | **3** |
| 항 Π(색 사상) | 31 |
| 항 A(공간 연산자) | 33 |
| 항 B̂(상수) | 36 |
| 출력 출처: 규칙 읽기 | 0 |
| 출력 출처: 같은 자리 베끼기 / 배경 | 31 / 23 |
| 출력 출처: 칸별 틀 색 0–3 | 35 / 29 / 28 / 27 |

맞힌 쌍의 질의 출력 칸에서 정답 색 로짓의 주 기여원은 규칙 읽기 95%, 배경 3%, 틀 색 3%, 같은 자리 베끼기 0%.

- 해석: 성능은 전부 시범에서 쓰인 규칙 시냅스에서 온다(쓰기를 끄면 0). 느린 지각이 시범 없이 답을 외우는 지름길은 없다(경로 제한이
  구조대로 작동). 다만 시냅스 안에서 일하는 항은 Γ(틀이 고른 색 ↔ 출력 색의 결합)이고, 이론이 기대한 공간 연산자 A와 색 사상 Π는
  보조다(끄면 6–8개 감소). 즉 "학습된 틀 + 성긴 공간 연산자"가 아니라 "학습된 틀이 고른 색을 출력에 붙이는 결합"으로 푼다.
- 같은 자리 베끼기·배경은 주 기여원은 아니지만 끄면 8–16개가 떨어진다(정답 아닌 색을 누르는 데 쓰임).

## 5. 남은 일

1. 같은 GPU 시간 비교(URM을 약 6배 스텝).
2. 시드 반복(각 2–3개)으로 런 사이 변동 확인.
3. 학습 때 임베딩 드롭아웃을 더 높이거나 임베딩을 빼고 학습한 판(지금 결과는 임베딩이 방해가 됨을 시사).
4. ARC-1 ≤ 10(`data/arc1_ctx10_trans.npz`, 255과제, 평가 278쌍)과 ARC-AGI-1/2로 이전. 비전환적(평가 과제 학습 제외) 평가도 가능해짐.
