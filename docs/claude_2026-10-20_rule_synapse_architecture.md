# 2026-10-20 규칙 시냅스 LT: TEM과 bands 시냅스를 엮는 아키텍처 설계

> **성격**: Claude의 자유 설계 기록이다. 이론은 `docs/claude_2026-10-20_rule_synapse_theory.md`에 있다. 학습한 모델은 없다. 손으로 정한 가중치로 설계가 토이를 정확히 푸는지와 창 조건의 예측을 `toy_g/design_check.py`로 계산했다(5절).

## 1. 설계 원칙

1. **규칙은 빠른 시냅스에 산다.** 규칙은 과제마다 시범에서 Hebbian으로 쓴다. 과제별 느린 파라미터(퍼즐 임베딩)는 두지 않는다.
2. **TEM의 두 시냅스를 한 층 올려 쓴다.**
   - 같은 시점 내용 기억 M: 격자마다 "어디에 무엇이" 있는지
   - 시간차 시냅스 W: 과제마다 "어디가 어디를 읽는지"
3. **bands 창이 W를 맡는다.** 창은 한쪽 방향이고 l(0) = 0이다(이론 문서 명제 4, 5.2절 계산).
4. **두 시냅스는 더하지 않고 합성한다.** W로 주소를 얻고, M으로 그 주소를 읽는다.
5. **회전·반사는 전체 행렬이 맡는다.** 대각 위상 장치(RoPE, 극점)는 평행이동만 표현하므로, 회전·반사는 W와 정리 단계의 전체 행렬 연산자가 맡는다.

## 2. 표상

토큰은 칸 하나다. 시범 쌍 (I_1, O_1), …, (I_K, O_K), 질의 입력 I*, 질의 출력 자리 O*가 한 열로 들어간다.

| 표상 | 정의 | 토이 크기 |
|---|---|---|
| 구조 코드 g(x) | 고정판: 2D 푸리에 코드(RoPE와 같은 각 구조). 학습판: g(r, c) = W_down^r·W_right^c·g₀ (TEM의 경로 적분, 원점 = 격자 모서리) | d_g = 16 |
| 내용 코드 e(c) | 배경을 뺀 색 원-핫(배경 = 0 벡터). 확장하면 국소 특징 | 4 |
| 결합 코드 p = e(c) ⊗ g(x) | TEM의 p. 색과 위치의 텐서곱 | 64 (= d_model) |
| 역할 코드 ρ | 어느 격자인지(시범 k의 입력/출력, 질의 입력/출력) | 격자 수 |

**격자 요약:** V(I) = Σ_x p(I(x), x)이다. 격자 하나의 내용 기억 전체이고, 정규직교 코드에서 격자를 손실 없이 담는다.

## 3. 시냅스와 연산

### 3.1 내용 기억 M (같은 시점, 격자별)
- M = Σ_t p_t·ρ_tᵀ이다. 역할 ρ로 읽으면 V(ρ), 즉 그 격자의 요약이 나온다.
- LT 말로는 키 = 역할 코드, 값 = 결합 코드인 선형 어텐션 헤드다. 같은 블록 항만 쓰고 창은 없다.

### 3.2 규칙 시냅스 W (시간차, 과제별)
- 쓰기는 시범 출력 토큰만 한다(제3요인 게이트 m_t = 1[ρ_t = out_k]).
  - 블록 n의 키 = 자기 결합 코드 p_t
  - 블록 n+1의 값 = 짝 입력 격자의 요약 V(in_k)
- 이것은 bands 창이 (블록 n의 키, 블록 n+1의 값)을 짝짓는 것과 같다. 그 결과 W = Σ_k V(in_k)·U(out_k)ᵀ이고, U = Σ_{o ∈ O_k} p_o이다.
- 창의 조건: b = 0(값이 키보다 앞서는 쌍은 세지 않음), l(0) = Σ_r γ_r Re a_r = 0, l(1) ≠ 0. 대역이 2개 이상이면 된다.
- **규칙 연산자:** 규칙 (r, κ)는 결합 코드 위의 선형 연산자 T_{r,κ} = K_κ ⊗ P(r)ᵀ이다. U = T·V가 성립한다. 출력 격자 요약은 입력 격자 요약에 색 순열과 위치 연산자를 크로네커로 곱한 것이다.
  - 따라서 W = (Σ_k V_k·V_kᵀ)·Tᵀ이고, 정리 1(R = Ā·P)의 격자 단위판이다.

### 3.3 정리: 연산자 집합 위의 Hopfield
- 점수: s(T) = ⟨W, Tᵀ⟩ = Σ_k ⟨U_k, T·V_k⟩. 시범의 출력 칸 중 T가 설명하는 칸 수다.
- 계산할 때는 색 쌍 블록 R_ab = W[a, :, b, :]로 쪼개서 s(r, κ) = Σ_a ⟨R_{a, κ(a)}, P(r)⟩로 구한다.
- 사후확률은 π = softmax(β·s)이고, 정리된 연산자는 T̂ = Σ π·T이다.
- 규칙 집합:
  - 위치 연산자 P(r)는 생성자 단어의 곱이다. 고정판은 정확한 순열이고, 학습판은 학습된 생성자로 만들며 걸음마다 칸 공간으로 정리한다(이론 문서 4.4절).
  - 색 순열 K_κ는 열거하거나 Sinkhorn으로 완화한다.
- 블록에 걸친 대안(끌개): π_r ∝ exp(β·Σ_ab κ_ab·S_ab(r))와 κ = Sinkhorn(exp(β'·Σ_r π_r·S(r)))를 번갈아 갱신한다. TEM 끌개 반복에 해당한다.

### 3.4 적용 (질의 출력 토큰)
- 질의 입력 요약 V*는 M을 역할 in_*로 읽어 얻는다.
- 질의 출력 칸 o*의 색 c 점수는 ℓ(c) = ⟨e(c) ⊗ g(o*), T̂·V*⟩ = ⟨T̂ᵀ(e(c) ⊗ g(o*)), V*⟩이다.
  - 질의 "주소 r(o*)에 색 κ⁻¹(c)가 있는가"로 질의 입력의 기억을 읽는 것과 같다.
  - 배경 점수는 학습되는 상수다.
- 이것이 합성이다. W(정리 후 T̂)로 질의를 바꾸고, 그것으로 M을 읽는다.

## 4. LT와의 결합

### 4.1 판 A (혼성, 먼저 만들 판)
- 구조 경로를 재귀 밖에서 한 번 계산한다. 단계는 코드 → 격자 요약 → W → 정리 → 적용이다.
- 그 출력(토큰별 점수 ℓ_t와 주소 읽기 벡터)을 LT의 입력 주입에 더한다: inj += W_in·[ℓ_t; 읽기].
- LT 블록(선형 어텐션이든 bands든)은 이 출력을 다듬거나 무시한다. 기하 규칙이 아닌 과제는 기존 경로로 푼다.
- 학습되는 느린 파라미터: 생성자(학습판), β, 배경 상수, 주입 가중치. 손실은 질의 출력의 CE 하나이고, 변환 라벨은 쓰지 않는다.

### 4.2 판 B (완전 재귀, bands로 엮은 판)
- 공유 블록 하나에 헤드 넷을 둔다.
  - (i) 내용 기억 헤드: 같은 블록 Hebbian
  - (ii) 규칙 헤드: bands 창, 한쪽 방향, l(0) = 0, 역할 게이트 쓰기
  - (iii) 정리 헤드: 생성자 단어 연산자 위의 Hopfield
  - (iv) 적용 헤드
- 블록 일정:
  1. 모든 토큰이 M에 쓴다.
  2. 시범 출력 토큰이 V(in_k)를 읽는다. 창이 블록 1의 p와 블록 2의 V를 짝지어 W에 쓴다.
  3. 정리한다.
  4. 질의 출력 토큰이 T̂로 읽는다.
  5. 이후 블록은 범용 처리를 한다.
- 가중치가 공유되므로 일정은 상태로 정해져야 한다. 블록 위상 신호(LT의 위상 시계나 블록 임베딩)와 역할로 각 헤드의 쓰기와 읽기를 게이트한다.
- 판 A는 이 일정이 이상적으로 지켜진 판 B와 같다(5절 계산이 이 경우다).

### 4.3 느린 것과 빠른 것 (TEM 편향의 층위)

| | 무엇 |
|---|---|
| 느림 (과제 사이 공유) | 구조 코드나 생성자, 색·역할 임베딩, 투영, 극점과 계수(창의 모양), β, 게이트 |
| 빠름 (과제별) | 규칙 시냅스 W, 사후확률 π |
| 빠름 (격자별) | 내용 기억 M (격자 요약) |

## 5. 손으로 정한 가중치로 한 확인 (학습 없음)

`python -m toy_g.design_check`. 대상은 고정 인스턴스 3,072개로, 시범 3쌍을 문맥으로 주고 과제 ID는 주지 않는다. 구조 코드는 칸 원-핫(정규직교)이고, 규칙 집합은 128 × 24개이며, 점수가 최대인 연산자로 답한다.

| 설정 | 그룹 0 | 그룹 1 | 그룹 2 | 자기 역원 과제 (440) | 나머지 |
|---|---:|---:|---:|---:|---:|
| 격자 단위 W = Σ V·Uᵀ | 100% | 100% | 100% | 100% | 100% |
| bands 창 (재귀 그대로), 한쪽 방향 [l(−1), l(0), l(1)] = [0, 0, 1] | 100% | 100% | 100% | 100% | 100% |
| 홀수 STDP [−1, 0, 1] | 83.0% | 78.8% | 87.5% | 0% | 97.1% |
| 짝수 [1, 0, 1] | 15.5% | 19.3% | 11.5% | 100% | 1.1% |
| 한쪽 방향 + l(0) = 1 [0, 1, 1] | 0% | 0% | 0% | 0.2% | 0% |

- 자기 역원 과제는 r과 κ가 모두 자기 역원인 과제다(규칙 44개 × 색 순열 10개 = 440개).
- bands 창 행은 `lt/model.py`의 bands 재귀를 그대로 돌려서 얻었다. 실극점 둘(z = ±0.5)을 썼다.
- 한쪽 방향 창이면 처음 보는 조합(그룹 1)과 처음 보는 변환(그룹 2)도 문맥만으로 100%다. 과제별 파라미터는 없다.
- **홀수 창:** 참 연산자의 점수가 ⟨U, T·V⟩ − ⟨V, T·U⟩ = ‖V‖² − ⟨V, T²·V⟩이다. T² = I이면 정확히 0이 된다.
- **짝수 창:** r과 r⁻¹(그리고 κ와 κ⁻¹)를 구별하지 못한다.
- **l(0) ≠ 0:** 같은 블록 항 Σ(p·pᵀ + V·Vᵀ)가 입력을 보존하는 연산자 쪽으로 점수를 끌어간다. 이 일정에서는 출력 토큰 16개가 모두 V를 갖기 때문에 그 항이 압도한다.
- 이론 문서의 명제 4가 bands 재귀 그대로에서도 성립함을 보여 준다. 이것은 일정이 이상적이라는 가정 아래의 확인이고, 학습된 모델의 결과가 아니다.

**대조로 본 관찰** (단일 런, 조건이 다름에 주의): ID에 묶인 과제 코드를 SGD로 맞춘 구조 헤드판(`runs/lt_myloop_struct_fs3`)은 그룹 0을 100% 풀었다. 하지만 시범 3개만 학습에 넣은 그룹 1·2 과제는 0.7%와 1.0%에 그쳤다. 규칙을 과제별 느린 파라미터로 두는 것과, 문맥에서 빠른 시냅스로 쓰는 것의 차이와 맞는 방향이다.

## 6. ARC로의 확장 지점

1. **내용으로 정해지는 기준틀(물체):**
   - 닻 c(I)를 내용에서 계산한다(물체 모서리나 중심을 찾는 어텐션).
   - 코드를 g(x) → P(−c)·g(x)로 옮긴다. 푸리에 코드에서 평행이동은 위상 회전이므로, 이것은 내용 의존 이동량을 가진 RoPE("동적 RoPE")다.
   - 옮긴 코드로 W를 쓰면, 규칙이 기준틀 안에서 고정된다.
2. **국소 특징:** 앞쪽의 범용 LT 블록이 이웃 수나 모양 같은 국소 특징 f(x)를 계산하고, e(c) 대신 e(f(x))로 결합 코드를 만든다. 규칙은 위치 사상 + 특징 → 색 사상이 된다.
3. **크기 변화, 비가역 사상:** 정리 1은 성립한다. 자르기, 타일, 확대 같은 모노이드 생성자를 규칙 집합에 넣는다.
4. **한 과제 안의 여러 규칙:** 규칙 헤드를 여럿 두고 내용으로 게이트한다(색이나 물체별 규칙).
5. **모호성:** π가 남은 모호성을 표현하고, 적용 단계가 베이즈 평균을 한다.

### 8.1 판 A, 고정 구조 (β와 τ만 학습): `runs/rs/A_designed`
- β 0.1, τ 3에서 시작해 1,000~2,000스텝(24초) 만에 시범 3개 기준 세 그룹 모두 100%가 됐다. 처음 보는 조합과 처음 보는 변환도 포함한다.
- 시범 k개로 답이 정해지는 인스턴스는 k = 1, 2, 3 모두 100%다.

### 8.2 판 A, 학습 생성자 (d = 32, seed 1): `runs/rs/A_learned_{code,cell}_d32_s1`
| 합성 | 시범 3개: 그룹 0 / 1 / 2 | 구현된 서로 다른 변환 | 처음 보는 변환 구현 | 최소 여유 |
|---|---|---|---|---|
| 코드 공간 | 100 / 100 / 100 | 128 | 전부 | 0.106 |
| 칸 공간 (처음부터) | 43.1 / 40.5 / 43.5 | 32 (부분군) | 25% | 0.011 |

- 코드 공간 해는 생성자 단위로는 정확하지 않다. 가장 가까운 칸 순열과의 코사인이 회전 0.45, 반사 0.68, 오른쪽 0.60, 아래 0.97이고, 관계식 오차도 크다(rot⁴ 1.22). 그런데도 128개 단어의 곱은 모두 올바른 변환이다. 즉 단어 단위로 맞춘 해다.
- 같은 생성자를 칸 공간 합성으로 평가하면 52%다(`toy_g/rs_perturb.py`, ε = 0). 칸 공간 정리는 생성자마다 칸 순열에 가깝다고 가정하는데, 학습이 찾은 해는 그 가정을 만족하지 않는다.
- 학습된 생성자에 직교 섭동 ε을 넣었을 때 코드 공간 합성의 정확도(그룹 0 / 1 / 2): ε ≤ 0.1에서 100%, 0.2에서 99.6 / 99.4 / 94.3, 0.3에서 89.1 / 87.6 / 78.0, 0.5에서 약 27%. 이론의 충분조건(L·ε < 1/√2, 즉 ε < 0.071)보다 약 3배 튼튼하다. 단어의 오차가 같은 방향으로 쌓이지 않기 때문으로 보인다.
- 정리: 이론 문서 4.4절의 "칸 공간 정리가 오차 누적을 막는다"는 생성자 단위의 정확성을 전제한다. 규칙 시냅스 점수로 코드 공간에서 학습하면 단어 단위의 해가 나왔고, 이 해에는 칸 공간 정리가 맞지 않았다. 앞선 토이에서 칸 공간 합성이 73%를 100%로 고친 것은 로그우도 점수의 다른 런이다.

|---|---|---|---|---|
| 2블록, 홀수 시작 | [0, −1, 0, 1, 0] | [0.00, 0.06, 0.00, 5.94, 0.02] | 5.94 / 0.06 / 0.00 / 0.00 | 100% |

- **2블록:** 어느 쪽에서 시작해도 한쪽 방향이고 l(0) = 0인 창으로 수렴했다. 명제 4 그대로다.
- **3블록 지속:** 창 값 하나하나는 0이 아니다. 대신 실효 계수에서 역방향(l(−1) + l(−2))과 지속 자기 항(2l(0) + l(1) + l(−1))이 0이 되고 규칙 항(l(1) + l(2))만 남았다. 명제 4의 조건은 창 값이 아니라 쌍 종류별 실효 계수에 대한 것이다.
- **잔차형:** 키 투영은 자기 코드 절반(대각 평균 1.61, 다른 절반 0.02)을, 값 투영은 읽어 온 요약 절반(1.64, 다른 절반 0.21)을 골랐다.
  - 고른 절반의 투영은 비대각 성분이 크지만, 규칙군의 교환자에 가깝다(상대 거리: 키 0.055, 값 0.061. 무작위 행렬은 0.999). 규칙 구조를 깨지 않는 등변 혼합이다.
  - 역할이 투영으로 나뉘면 같은 블록 쌍이 곧 규칙 쌍(V, p)이 되므로, l(0) ≠ 0이 해롭지 않다.
- **과도 구간 진단** (`B_2block_odd_beta3`: β = 3에서 시작, lr 1e-3, 25스텝마다 평가):

  홀수 창에서는 자기 역원 과제만 0%에 머물렀다. 역방향 가중치가 순방향의 약 절반 아래로 줄자 회복했다. 예측한 진단 신호가 그대로 나왔다.

### 8.4 Mini-ARC 천장 측정: `toy_g/miniarc_ceiling.py`, `runs/miniarc_ceiling.json`
- 대상: Mini-ARC 149개 과제(5×5, 색 0~9). 원래 과제는 `data/miniarc.npz`의 원래 버전(과제 번호 × 32)에서 복원했다. 준비 스크립트의 난수를 다시 돌려 npz를 비트 단위로 재현하는 것을 확인했다.
- 질문: "출력 칸마다 내용과 무관한 고정 주소의 입력 칸 하나를 읽고, 색 사상을 적용한다"(전제 1, 2, 4)로 시범 전부와 시험이 설명되는 과제가 몇 개인가.
- 색 사상은 두 종류로 셌다: 임의의 함수(K_func)와, 배경을 고정한 1~9의 순열(K_perm).
- 판정 기준
  - 일치: 어떤 가설이 시범을 모두 재현한다.
  - 결정·정답: 시범과 일치하는 가설이 모두 같은 시험 출력을 내고, 그것이 정답이다. 시범에 나오지 않은 시험 색은 여러 예측으로 센다.
  - 신탁 정답: 일치하는 가설 중 하나가 시험을 맞힌다.

| 주소 계열 | K_func: 일치 / 결정·정답 / 신탁 정답 | K_perm: 일치 / 결정·정답 / 신탁 정답 |
|---|---|---|
| 항등 | 1 / 1 / 1 | 0 / 0 / 0 |
| D4 (8개) | 8 / 3 / 8 | 7 / 3 / 7 |
| D4 + 순환 이동 (200개) | 8 / 3 / 8 | 7 / 3 / 7 |
| D4 + 배경 채움 이동 (648개) | 8 / 3 / 8 | 7 / 3 / 7 |
| D4 + 물체 닻(경계상자 왼쪽 위) 이동 | 7 / 3 / 5 | 6 / 2 / 4 |
| D4 + 물체 닻(경계상자 중심) 이동 | 4 / 1 / 4 | 3 / 0 / 3 |
| 임의의 고정 주소 (칸마다 입력 칸 하나 또는 상수, 상한) | 59 / 4 / 42 | 52 / 4 / 37 |

- 토이의 규칙 계열(D4 × 평행이동 + 색 순열)로 설명되는 Mini-ARC 과제는 7~8개(약 5%)다. 일치하는 가설은 모두 순수 D4(이동량 0)였고, 평행이동은 아무것도 더하지 않았다.
- 결정·정답이 3개뿐인 것은 주소의 모호성 때문이 아니다. 시험에 시범에 없던 색이 나오기 때문이다. 시범에 없는 색은 그대로 둔다는 기본값을 쓰면 D4 계열의 결정·정답이 8 / 7개로 오른다(에이전트의 추가 진단).
- 물체 닻 이동이 더하는 과제는 1개(과제 8, 물체를 가운데로)다.
- 내용과 무관한 단일 칸 읽기 전체(구조 없는 상한)도 신탁 정답은 42 / 37개(약 28%)다. 결정·정답은 4개에 그친다. 상한이 느슨해서, 시범에는 맞고 시험에는 틀리는 과제가 17 / 15개 있다.
- 시험 쌍이 같은 중복 과제가 있다(105 = 106, 120 = 139).
- 정리
  - 이 아키텍처가 그대로 다루는 영역(전제 1~5)은 Mini-ARC의 아주 작은 부분이다.
  - 전제 1, 2를 유지한 채로도 상한이 28% 정도이므로, ARC 쪽으로 가려면 6절의 확장이 핵심이다. 주로 내용 의존 주소(물체 기준틀), 국소 특징, 여러 규칙이다.
  - 시범에 없는 색의 처리(색 사상의 사전분포)도 별도로 필요하다.
