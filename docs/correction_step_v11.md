# 8→6 전환 블록의 실행 순서 분석

2026-09-26. 기존 late-puzzle probe의 후속 분석이다. 기존 사례 58의 셀
3행9열(정답 6, 직전 예측 8), 전환 블록 T=4212를 그대로 사용한다.
새로운 사례를 고르거나 원래 분석을 사전 등록된 것처럼 수정하지 않는다.

## 추가 실행 전 정한 질문과 비교

`w→G`는 기억을 현재 목표로 대체하는 개입이지 이번 블록의 쓰기만
제거하는 개입이 아니다. 이번 쓰기, 값의 변화, 읽기 연결의 변화를
구분하기 위해 정상 T 직전 상태를 재생하고, T의 읽기에만 개입한다.

- 이번 쓰기 생략: 갱신 직전 w로 현재 v를 읽는다.
- 현재 G로 읽기: 기존 비교를 재현한다.
- 직전 블록의 v로 읽기: 연결과 잔차 상태는 T의 것을 유지한다.
  모든 v, 다른 셀의 v만, 자기 셀의 v만 교체하는 경우를 구분한다.
- 직전 블록의 a_psi로 읽기: 값과 기억은 T의 것을 유지한다.
- 잔차 입력 q만 직전 블록의 것으로 교체한다.

모두 같은 정상 상태에서 시작하는 단일 블록 개입이다. 이후 궤적이나
모델 전체의 일반 원리를 판정하지 않는다. 숫자 6의 실제 argmax와
6−8 로짓 차이를 함께 기록한다. 기본 재생은 원래 12문제 FP32 배치와
연산 순서를 유지하고 T−1, T의 전체 예측 일치를 확인한다.

쓰기 메시지는 이번에는 `lambda*w_before*v`와
`lambda*(w_after-w_before)*v`로 분해한다. 이전 분석의
`lambda*G*v`는 실제 이번 쓰기의 증분이 아니라 `w=G+(w-G)`라는
분해의 기준항이었다는 점을 구분한다.

T−1과 T의 전체 배치 예측이 저장된 기준 궤적과 정확히 일치했다.
원자료는 `runs/late_puzzle_probe_v11/case_58_26/forward_step.json`이다.

실제 쓰기 증분은 `eta*(G-w_before)`이다. 정상 T의 phi 분모를 공통으로
사용한 6−8 로짓 분해는 다음과 같다. 유한 크기 제거 개입은 phi 분모도
바꾸므로 위 표와 완전히 같은 차이가 되지는 않는다.

| 정상 T에서의 성분 | 6−8 기여 |
|---|---:|
| 준비된 셀 상태 q | −0.316571 |
| classifier bias | +0.008497 |
| 현재 a_psi로 현재 v를 읽는 메시지 | −1.087979 |

재구성 오차는 2.31e−6 미만이다. 이번 쓰기는 이 한 번의 6 전환에
필요하지 않았고, 고정된 현재 값에 대한 6 대 8 비교에서는 오히려
작은 음의 기여였다. 과거 블록에서의 쓰기가 불필요했다는 뜻은 아니다.

## 왜 이 블록에서 경계를 넘었는가

정상 궤적에서 T−1의 6−8 로짓 차이는 −0.199122, T는 +0.201145다.
마지막 두 블록의 출력 차이 +0.400268을 대수적으로 분해했다.
곱 `J*v`의 변화는 `평균(J)*변화(v) + 변화(J)*평균(v)`로 나누고,
정규화 배율의 변화도 별도 항으로 분리했다. 이 분해는 정확한 수치
장부이며 유일한 인과 분해나 분기 개입 효과가 아니다.

| 변화 항 | 6−8 로짓 변화 기여 |
|---|---:|
| 셀 자신의 준비된 상태 q 변화 | +2.665761 |
| 읽는 v 변화 | −2.288080 |
| a_psi 변화 | +0.059979 |
| w 변화 | −0.037401 |
| 정규화 배율 변화 | +0.000008 |

변화 재구성 오차는 2.79e−7 미만이다. q 변화 중 들어오는 h의 변화는
+1.034434, 셀 내부 MLP 출력 변화는 +1.631327이다. 퍼즐 입력은 동일하다.
직전 출력 숫자가 8이었다고 해서 내부 상태가 같은 벡터에 머물렀던
것은 아니다. q 잔차만 직전 값으로 되돌리는 개입에서도 실제 출력은
8이므로 이 분기의 변화는 정상 메시지들과 결합해 전환에 기여했다.
다만 q는 여전히 6−8 방향에서 음수이고, 기존 w가 운반하는 양의
메시지와 합쳐져야 정상 T의 양수 마진이 된다.

기존에 논의한 3행6열→3행9열, 세 번째 헤드에서도 w는 이번에
0.143549→0.153481로 변한다. 현재 G는 +0.483973이지만 갱신률은
0.029175다. 실제 이번 쓰기 증분의 6−8 기여는 −0.012091이다.
전체 읽기 계수는 정상 −0.153532, w→G에서는 −0.090698로 둘 다 음수다.

이 사례는 ‘변화한 셀 상태와 현재 값을 기존 연결로 읽는 과정에서
정답 경계를 넘는다’를 지지한다. 잘못된 상관관계가 전환 직전에
제거되었다거나, 이 연결 자체가 독립적으로 정답을 저장한다거나,
이후 영구 안정성을 보장한다는 결론은 이 단일 블록 분석으로 낼 수 없다.

## 같은 연결에서 쓰기부터 숫자 출력까지 연결하기

3행6열(정답·현재 예측 8)→3행9열(정답 6, 직전 예측 8), 세 번째
헤드의 정상 T 상태를 다시 재생했다. 전체 배치 예측은 기준과 일치했다.
원자료: `runs/late_puzzle_probe_v11/case_58_26/edge_forward_chain.json`.

1. gain 2.789472 × a_beta 0.292115 × agree 0.593944 = G 0.483973.
2. w_before 0.143549 + eta 0.029175 × (G − w_before) = w_after 0.153481.
3. a_psi −0.225605와 lambda 0.190123을 사용한 실제 읽기 계수는
   (1−lambda)×a_psi + lambda×w_after = −0.153532.
4. 소스 v를 출력 투영과 classifier까지 연결했을 때, 계수 +1의
   6점수 기여는 −0.755201, 8점수 기여는 +5.648178이다.
   정상 전체 출력의 phi 분모를 공통으로 사용하고 bias는 제외했다.
5. 실제 음의 계수로 읽으면 6점수 +0.115948, 8점수 −0.867177,
   따라서 6−8 기여 +0.983124다. 나머지 모든 성분(편향 포함)의
   6−8 기여 −0.781979와 합쳐 정상 출력 마진 +0.201145, argmax 6이다.
6. 이 연결의 w만 G로 대체하면 읽기 계수는 −0.090698로 약해진다.
   공통 분모에서 이 연결의 6−8 기여는 +0.580774로 감소한다.
   phi까지 다시 계산한 실제 출력도 argmax 8, 6−8 마진 −0.200909다.

이 연결에서 psi 경로는 이웃의 8 쪽 메시지를 음수로 전달하여 대상의
8을 낮추고 6을 높였다. 양의 w는 그 작용을 일부 상쇄한다. w를 더 큰
양의 G로 바꾸면 상쇄가 커져 6이 이기지 못한다. 이는 이 연결의 역할이며,
다른 연결까지 포함한 기억 전체의 역할과 동일시하지 않는다.
