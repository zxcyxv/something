# STDP 적분의 주파수 영역 표현과 위상차 커널의 대응

이 문서는 STDP 쌍 적분과 위상차 커널 사이의 주파수 영역 대응을 검토한다.
**2026-09-13 검토에서 전체 아키텍처에 대한 항등 주장과 동역학적 해석을 수정했다.**
**2026-09-26 실제 v1.1 검증:** 현재 주소를 공통 활동의 고정 시간주파수 흔적으로
동일시하는 가설은 정규화까지 허용한 필요조건을 위반했다.
[위상 개입·시간주파수 검사·풀이 개입 결과](phase_timing_research_v11.md)와
[필요조건 유도](phase_time_certificate_v11.md)를 참고한다.
직접적인 위상 활동 모델과 검산은 [위상 집단 활동 유도](phase_population_v11.md),
기저 전달과 가소성 상태의 구분은 [기저 결합 문서](baseline_plasticity_v11.md)를 참고한다.

> STDP 의 가중치 변화 `Δw = ΣΣ W(t′−τ) S_pre(τ) S_post(t′)` 를 바깥(시간 누적)과 안쪽(창의 합성곱)으로 나누면,
> 안쪽의 창을 주파수 영역으로 옮기면 복소 교차곱과 창의 스펙트럼이 나타난다.
> 이것은 우리 쓰기 창 `Σ_j r r cos(Δφ_j + β_j)`와 같은 수학적 형태다.
> 다만 학습된 주소를 시간 스펙트럼으로 보는 것, 바깥에 EMA 누수를 두는 것,
> 중첩된 시간 창을 다시 누적하는 것은 각각 추가 가정이므로 전체가 항등인 것은 아니다.

코드 대응: `lt/train.py` 의 `LT_Inner.step()`. 읽기 커널 `a = attn_xy(û, ψ)`, 쓰기 창 `a^β = attn_xy(û 또는 ẑ, β)`,
결합 기억 `w ← (1−η)w + η·g·a^β·agree`. 아래에서 `G` 는 `a^β·agree` 의 창 부분이다.

## §1. 규약

```
변환      f̂(ω) = Σ_m f(m) e^{-iωm}            (블록 축은 이산 → DTFT)
실수성    f 실수  ⟹  f̂(-ω) = f̂(ω)*
교차상관  C(s) = Σ_t S_pre(t) S_post(t+s)
n = pre (원천),  t = post (표적).    전달이 f_t = Σ_n a_tn v_n 이므로.
```

## §2. STDP 를 두 층으로 — 재배열뿐, 가정 없음

```
Δw = ΣΣ W(t′−τ) · S_n(τ) · S_t(t′)
```

바깥 변수를 **post 시각**으로 잡고 `u = t′ − τ` 로 치환하면

```
Δw = Σ_k  S_t(k) · [ Σ_u W(u) · S_n(k−u) ]
     └바깥┘ └post 지금┘ └──── pre 의 필터된 이력 = 흔적 x_n(k) ────┘

     바깥 = 절대 시간 위의 누적
     안쪽 = 창이 pre 이력에 거는 합성곱
```

이중합을 post 시각 기준으로 정렬하면 안쪽이 **자동으로** 합성곱이 된다.
"흔적 × 지금" 은 모형 선택이 아니라 재배열의 결과다.

(pre 시각 기준으로 정렬하면 다른 가지가 나온다. 창을 `W = W₊Θ(s) + W₋Θ(−s)` 로
쪼개 각 조각을 "나중에 온 쪽" 기준으로 정렬한 것이 표준 두-흔적 형태다.)

## §3. 우리 모델도 같은 두 층

```
바깥 :  w(k) = δ Σ_m (1−δ)^m · G(k−m)
안쪽 :  G_tn(k) = D(Δ) Σ_j r_{n,j}(k) r_{t,j}(k) cos( φ′_{t,j}(k) − φ′_{n,j}(k) + β_j )
```

바깥은 모두 갱신 신호를 시간에 걸쳐 누적하지만, §2의 단순 합에는 누수가 없다.
우리 EMA에 대응하려면 지수 망각과 갱신 크기를 추가로 선택해야 한다.
또 첫 쓰기로 초기화하는 실제 규칙에서는 최초 항의 계수가 후속 항과 다르다.
안쪽을 단시간 스펙트럼의 교차곱으로 구성할 때는 아래의 중첩 계수도 확인해야 한다.

## §4. 안쪽을 주파수로 — 유도

### 보조정리 A (상관 정리)

```
Ĉ(ω) = Ŝ_pre(ω)* · Ŝ_post(ω)
```

증명. `Ĉ(ω) = ΣΣ S_pre(t) S_post(t+s) e^{-iωs}`. `u = t+s` 치환:
`= [Σ_t S_pre(t) e^{+iωt}][Σ_u S_post(u) e^{-iωu}] = Ŝ_pre(-ω) Ŝ_post(ω)`.
`S_pre` 실수이므로 `Ŝ_pre(-ω) = Ŝ_pre(ω)*`. ∎

### 보조정리 B (플랑슈렐, 실함수 쌍)

```
f, g 실수  ⟹  Σ_s f(s) g(s) = (1/2π) ∫ f̂(ω)* ĝ(ω) dω
```

증명. `g(s) = (1/2π)∫ĝ(ω)e^{iωs}dω` 를 대입하고 `s` 합을 먼저 하면
`(1/2π)∫ĝ(ω) f̂(-ω) dω`, `f` 실수이므로 `f̂(-ω) = f̂(ω)*`. ∎

### 본 유도 — 성분합이 시간 이중합을 복원한다

토큰별 단시간 변환을 정의한다:

```
Z_t(j;k) = Σ_{m≥0} γ^m · x_t(k−m) · e^{-i ω_j m}
```

그리고 다음을 **전개해서** 무엇인지 확인한다 (pre 쪽을 켤레):

```
Σ_j  Z_n(j;k)* · Ŵ_j · Z_t(j;k)

 = Σ_j Ŵ_j · Σ_{m,m′} γ^{m+m′} · x_n(k−m′) · x_t(k−m) · e^{i ω_j (m′−m)}

 = Σ_{m,m′} γ^{m+m′} · x_n(k−m′) · x_t(k−m) · [ Σ_j Ŵ_j e^{i ω_j (m′−m)} ]
                                                └────── = W_J(m′−m) ────┘
                                                          유한 채널 재구성
```

`(k−m′)` 은 pre 시각, `(k−m)` 은 post 시각이고
`m′ − m = (k−m) − (k−m′) = post시각 − pre시각 = s` 이다.
`W_J`는 선택한 유한 주파수로 재구성한 창이다. 원래 W가 그 기저로 정확히
표현되거나 완전한 변환을 사용할 때만 `W_J=W`이며, 일반적으로는 근사다.
이 조건 아래에서

```
┌────────────────────────────────────────────────────────────────────┐
│  Σ_j Z_n(j)* Ŵ_j Z_t(j)                                            │
│      = Σ_{m,m′} γ^{m+m′} · S_n(pre시각) · S_t(post시각) · W(s)      │
│        └────────── §2 의 이중합 그 자체 (창 γ 로 자른) ──────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

**성분에 대한 합 `Σ_j` 가 시간 쌍에 대한 이중합 `Σ_{m,m′}` 을 복원한다.**
새 연산이 아니라 이중합을 주파수 기저에서 쓴 것이다.

이는 **한 시점 k의 창으로 가중한 이중합**에 대한 계산이다. 이 결과를 다시
모든 k에 대해 누적하면 동일한 활동 쌍을 중복하여 센다. 최종 T에서 시점 r,s의
쌍에 붙는 바깥 EMA까지의 계수는, `M=max(r,s)`라 할 때

`η γ^|r−s| ρ^(T−M) Σ_{j=0}^{T−M}(γ²/ρ)^j`

이다. 따라서 이 창의 이중합을 §2의 한 시점 갱신과 그대로 동일시할 수 없다.
위 식의 직접 합 검산은 [후속 유도 §4](phase_population_v11.md)에 있다.

## §5. 대응 사전

```
STDP 안쪽 :  Γ(k) = Re Σ_j  Z_n(j;k)*   · Ŵ_j        · Z_t(j;k)
우리 안쪽 :  G(k) = Re Σ_j  ẑ_{n,j}(k)* · e^{+iβ_j}  · ẑ_{t,j}(k)   × D(Δ)
```

| STDP (주파수 영역) | 아키텍처 | 근거 |
|---|---|---|
| 절대 시간 누적 `Σ_k` | `Σ_m (1−δ)^m` | **추가 가정** — 지수 망각과 갱신 크기 |
| 주파수 `ω` (>0) | 성분 인덱스 `j` | **가정** — `ẑ` 를 단시간 변환 계수 `Z` 로 보는 동일시 (아래 '다루지 않는 것') |
| `∫₀^∞ dω` | `Σ_j` | 가정 |
| `\|Z_pre\|·\|Z_post\|` | `r_{n,j} · r_{t,j}` | **부분** — 정규화로 총 크기 소거 |
| `Δθ(ω;k)` | `Δφ′_j(k)` | 가정과 함께 |
| `arg Ŵ(ω)` | `β_j` | **조건부 대응** — pre를 켤레로 두는 위 규약과 실제 코드의 `cos(Δφ+β)`에 맞춘 부호 |
| `\|Ŵ(ω)\|` | `D(Δ)·g` — **`j` 의존성 없음** | **불일치** — 창의 크기 스펙트럼 `c_j` 가 모델에 없다 (`\|Ŵ_j\| ≡ 1`) |

## §6. 정리 — 창의 패리티 ⟺ 변환의 실/허

```
W 짝함수 (W(−s) = +W(s))  ⟺  Ŵ(ω) ∈ ℝ   ⟺  β ∈ {0, π}
W 홀함수 (W(−s) = −W(s))  ⟺  Ŵ(ω) ∈ iℝ  ⟺  β = ∓π/2
```

증명. `Ŵ(ω) = Σ_s W(s)[cos(ωs) − i sin(ωs)]`.
`W` 짝 ⟹ `W(s)sin(ωs)` 홀함수 ⟹ 허수부 합 = 0 ⟹ `Ŵ` 실수.
`W` 홀 ⟹ `W(s)cos(ωs)` 홀함수 ⟹ 실수부 합 = 0 ⟹ `Ŵ` 순허수.
역은 짝/홀 분해와 선형성. ∎

**창의 대칭성에서 확정할 수 있는 것**

```
β = 0     +cos Δφ   대칭 창    → 대칭적인 쓰기
β = π     −cos Δφ   대칭 창    → 부호를 반전한 대칭 쓰기
β = ±π/2  ∓sin Δφ   반대칭 창  → 반대칭적인 쓰기
```

고정된 대칭 행렬의 고유값이 실수라는 사실만으로 이완·정답 고정점이 보장되지는 않는다.
고정된 반대칭 행렬은 연속시간 선형계 `dh/dt=Ah`에서 노름을 보존하지만,
이산 갱신 `h←h+Ah`에서는 일반적으로 그렇지 않다.
우리 모델은 기저 결합, 상태 의존 쓰기, 경계 MLP, 재주입, 정규화를 함께 갖는다.
따라서 창의 대칭성만으로 전체 모델의 에너지 함수·상태 저장·순서 저장을
유도할 수 없다. 이전 버전의 해당 주장은 적용 조건이 부족했다.

## §7. 표준 창의 명시적 변환 (검산)

이 절의 표준 지수 창은 연속 시차 s에 대한 식이므로 연속 푸리에 변환을 쓴다.
앞 절의 이산 블록 축과 구분해야 한다. 이산 지수 창을 사용하면 대응하는
변환은 적분이 아니라 기하급수 합으로 계산한다.

```
W(s) = A₊ e^{-s/τ₊} Θ(s)  −  A₋ e^{+s/τ₋} Θ(−s)

Ŵ(ω) =  A₊τ₊ / (1 + iωτ₊)   −   A₋τ₋ / (1 − iωτ₋)
```

극한 둘:

```
ω → 0 :   Ŵ(0) = A₊τ₊ − A₋τ₋  ∈ ℝ     DC 는 순수 짝수(동시성)
                                        균형 조건 A₊τ₊ = A₋τ₋ ⟺ Ŵ(0) = 0
                                        = 상수 활동의 DC 항이 기여하지 않음
ω → ∞ :   Ŵ(ω) ≈ −i(A₊+A₋)/ω  ∈ iℝ    고주파는 순수 홀수(인과)
```

저주파의 부호는 `A₊τ₊−A₋τ₋`에 달리고, 완전히 균형이면 DC 자체가 0이다.
위 변환 규약에서 고주파 위상은 양의 π/2가 아니라 −π/2로 접근한다.
따라서 모든 매개변수에서 위상이 0부터 단조롭게 이동한다는 주장은 성립하지 않는다.
DC 소거만으로 가중치의 자기정규화나 전체 동역학의 안정성이 보장되지는 않는다.

자기정합 검산: `A₊=A₋=A, τ₊=τ₋=τ` (완전 균형 = 홀함수) 이면
`Ŵ = −2iAωτ²/(1+ω²τ²) ∈ iℝ` — 모든 `ω` 에서 순허수. §6과 일치. ✓

## 이 문서가 다루지 않는 것

- **`ẑ ↔ Z` 의 동일시.** 유도의 좌변 `Z_t(j;k)` 는 토큰 `t` 의 이력 전체를 `γ^m e^{-iω_j m}` 로 필터한 단시간 변환 계수이고,
  모델의 `ẑ_t(k) = W_C h_t(k)/‖·‖` 는 재귀 상태 `h(k)` 의 한 시점 사영이다. `h(k)` 자체가 이력의 함수이므로 둘이
  같은 꼴일 수 있지만, 그것은 학습된 동역학에 대한 가정이지 이 유도에서 따라 나오는 것이 아니다.
  `use_trace` 판(v1.7)은 `ẑ` 자리에 명시적 뱅크 `z ← μ⊙z + √(1−ρ²)⊙u` 를 두어 이 동일시를 구성으로 만들지만,
  그것이 더 나은 모델이라는 근거는 없다 (README 의 결과 표 참조).
- **`agree = ⟨v̂_t, v̂_n⟩`.** 이 문서의 스칼라 활동 유도에는 나타나지 않는다.
  위상별 진폭이 내용 벡터로 분리되는 집단 활동을 가정하면 하나의 상관 적분 안에서
  유도할 수 있다. 이는 추가 활동 모델이며 [후속 문서](phase_population_v11.md)에 명시했다.
- **읽기 `a_eff = (1−λ)a + λw`.** 빠른-가중치 계보(Hinton & Plaut 1987; Ba et al. 2016; Miconi et al. 2018)의 형태이고
  STDP 에서 유도되지 않는다.
- 성능. 개별 항등식과 활동 모델 가정의 대응은 어떤 판이 더 잘 외삽하는지 말하지 않는다.
