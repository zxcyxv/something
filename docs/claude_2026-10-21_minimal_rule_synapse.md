## 0. 한 줄 요약

**규칙 = 과제마다 추론되는 성긴 연산자, 추론 = 근접 경사(델타 + 일정 LTD), 퍼즐 임베딩 = 그 추론의 시작점(사전 중심), 구조
코드 = ℓ1을 재는 좌표.** 최소형(M0)은 토큰 신경망도 어텐션도 없이, 시범 그림 쌍 위의 lasso 하나로 끝난다:

```
Ŵ_τ, Π_τ, B̂_τ = argmin  ½ Σ_i ‖ Ŷ_i − Ŵ Ẑ_i Πᵀ − B̂ ‖²  +  λ ‖Ŵ − Ŵ⁰_τ‖₁ + λ_Π ‖Π − Π⁰_τ‖₁ + λ_B ‖B̂ − B̂⁰_τ‖₁
         (시범 i = 1..k)                               (사전 중심 = 퍼즐 임베딩, 증강판은 켤레로 옮김)
질의:    크기 = K_τ [h*, w*, 1]ᵀ,   Ŷ* = Ŵ_τ Ẑ* Π_τᵀ + B̂_τ,   칸 o의 색 = softmax_c (Gᵀ Ŷ*)[o, :]
         (K_τ: 크기 시냅스, 같은 원리의 2×3 문제. Ẑ: 입력 그림을 네 모서리 틀에서 잰 주소로 쌓은 것)
```

- 위 최소화를 근접 경사로 T번 반복한 것이 "블록 T개"이고, 반복 한 번이 시냅스 가소성 한 번(델타 LTP/LTD + 일정 LTD +
  사전 중심으로의 하한)이다.
- 느린(과제 공유) 파라미터는 코드 G, 반복별 문턱, 공유 사전뿐이고, 반복을 펼친 역전파로 학습한다.
- 지지(표현 범위)는 M0에서 좁다. §9가 M0를 어텐션 헤드로 다시 쓰고, 층마다 국소 목표를 가진 규칙 헤드로 일반화한다
  (§5의 M2 꼴은 중간 목표가 없어 볼록성을 잃었다. §9.3이 그 대안이다).

## 1. 대상과 기호

- 격자 X: Ω → C. Ω는 최대 격자 좌표(N×N, Mini-ARC N = 5, ARC-1 ≤ 10판 N = 10), C = {색 0..9}(c = 10). 격자 밖 칸은
  색이 없다(영벡터). 격자 크기 (h, w)는 따로 다룬다(4.1의 크기 시냅스). EOS는 입력 형식에서 크기를 알려 주는 표시일 뿐,
  그림에는 넣지 않는다. n = |Ω| = N² (25, 100).
- 과제 τ: 시범 D_τ = {(X_i, Y_i)}_{i≤k}, 질의 X*. 출력 Y* = f_τ(X*)를 맞힌다.
- 증강판 v = (D4 원소 t_v, 색 순열 σ_v(색 0 고정)). 위치에는 순열 행렬 T_v, 색에는 σ_v로 작용한다.
- 코드 G ∈ O(n): Ω 위의 실직교 행렬(학습). 위치 벡터 e_p의 코드는 g(p) = G e_p.

## 2. 요구 조건의 범주화

설계 조건을 층으로 나누고, 각 층에서 **구조로 보장할 것**과 **학습에 거는 것**을 가른다. 학습에 거는 것은 실험으로만
판정된다. 구조로 보장할 것은 수식이 성립하면 끝난다.

| 층 | 조건 | 수학적 진술 | 보장 방식 |
|---|---|---|---|
| F 형식 | 시범의 짝, 역할, 축 구조를 형식에서 받는다 | 시범 i의 입력 칸 집합 in_i, 출력 칸 집합 out_i는 슬롯 번호로 정해진다 | 구조 |
| S 지지 | 목표 규칙이 표현 가능하다 | f_τ ∈ 𝓗 (가설 족) | 구조(족의 크기). M0 → M1 → M2로 넓힌다 |
| W 가중 | 짧은 규칙이 선택된다 | 선택 = argmin_{h ∈ 𝓗, h ⊨ D_τ} ‖G-좌표에서 h의 사전 중심 편차‖₁ | 구조(ℓ1 + 사전 중심) |
| I 식별 | 시범이 정답 규칙을 유일하게 고른다 | 시범 측정 사상 A_D의 영공간 성질(NSP)이 차수 s_τ로 성립 | **학습에 건다** (G에 달림) |
| L 법칙성 | ARC 법칙이 G-좌표에서 성기다 | ‖Δ_τ‖₀ 작음, 엉터리 대응은 조밀 | **학습에 건다** (G) |
| C 계산 | 반복이 선택된 해에 도달한다 | 근접 경사가 lasso 최소점으로 수렴 | 구조(걸음 = 1/립시츠 상수) |
| M 기억 | 퍼즐 임베딩은 과제 기술의 저장이다 | 사전 중심 Ŵ⁰_τ, 증강판은 정확한 켤레로 옮김 | 구조 |
| N 누설 없음 | 질의 답이 쓰기에 들어가지 않는다 | 쓰기 항은 시범 칸만으로 만들어진다 | 구조 |
| G 학습 | 느린 층(G 등)이 문턱 고정점을 통과한 기울기로 학습된다 | 펼친 반복 전체로 역전파 | 구조(반복이 작은 행렬 위에서 일어나 전부 펼칠 수 있음) |

**조건 사이의 논리 관계(정리 0, 충분조건).** 색 연산자 Π_τ와 상수 B̂_τ가 정해졌다고 하자(쌍선형의 한 블록). 다음이 모두
성립하면 M0의 예측은 질의에서 정확하다.

- S: f_τ ∈ 𝓗₀ (참 규칙의 위치 연산자 W_τ가 있다)
- L: Δ_τ = G-좌표의 W_τ − W⁰_τ가 s-희소
- I: 시범 측정 A_D가 G-좌표에서 차수 s의 영공간 성질을 만족
- C: 반복이 수렴하고 λ → 0⁺

증명: 시범은 A_D Δ_τ = b(관측)를 준다. λ → 0⁺에서 lasso 최소점은 "A_D Δ = b인 Δ 중 ‖Δ‖₁ 최소"로 간다. 영공간 성질에서
그 해는 Δ_τ 하나뿐이다(4.4의 정리). 그러므로 Ŵ = W_τ이고 질의 예측 W_τ Ẑ* Π_τᵀ + B̂_τ = f_τ(X*). ∎

- 필요성 쪽: S가 깨지면 어떤 선택 규칙도 정답을 낼 수 없다. I가 깨지면 시범과 맞고 ℓ1이 같거나 작은 다른 Δ'가 있어서,
  질의에서 다르게 답할 수 있다(반드시 다르게 답하지는 않는다. 질의 그림이 A_D의 영공간 방향과 직교하면 같다).
- W(ℓ1 선택)는 정리의 "선택 규칙" 자리이고, M(사전 중심)은 s를 "규칙 자체의 희소도"에서 "기억으로부터의 편차의 희소도"로
  바꾼다. N과 G는 추론이 아니라 학습의 건전성 조건이다(답이 쓰기에 새면 학습이 그 지름길을 배운다. 기울기가 반복을
  통과하지 않으면 L·I를 만드는 G가 학습되지 않는다).

지금 B와 대조하면: B는 N(질의 칸도 쓴다), C(걸음이 1 + Σw로 정규화될 뿐 립시츠 상수와 무관), G(마지막 블록만 역전파),
M(사전 중심이 증강판마다 따로)을 구조로 보장하지 않았고, F의 짝을 어텐션 목표 aₜ로 간접화했다.

## 3. 추상 설계: 근접 MAP 추론

모든 판(M0–M2)은 같은 문장이다.

> 과제 τ의 빠른 파라미터 θ_τ = argmin_θ  𝓛_{D_τ}(θ) + λ ‖𝒞(θ − θ⁰_τ)‖₁,   예측 ŷ* = F(x*; θ_τ).

- 𝓛_D: 시범 맞춤 손실(제곱). F: 느린 층이 정한 "기계". 𝒞: 구조 코드(좌표 변환). θ⁰_τ: 퍼즐 임베딩(사전 중심).
- 확률로 읽으면 가우스 우도 × 사전 중심 θ⁰_τ의 라플라스 사전에서의 MAP다. −log 사전 = λ‖𝒞(θ − θ⁰_τ)‖₁ + 상수는
  "사전에 대해 상대적인 기술 길이"다. 즉 퍼즐 임베딩이 있으면 비용은 K(f_τ | e_τ), 없으면(새 과제) K(f_τ | 공유 사전)다.
- 과제 전체의 학습은 두 부분 부호다: 공유 코드·기계(L(G, F))와 과제별 기술(Σ_τ λ‖Δ_τ‖₁)을 함께 줄이면서 질의를 맞춘다.
- 근접 경사 한 걸음: θ ← θ⁰ + S_{ηλ}(θ − θ⁰ − η ∇𝓛_D(θ)), S는 소프트 문턱(크기를 ηλ만큼 줄이고 0에서 자름).

## 4. 최소형 M0

### 4.1 그림(picture)과 틀(frame)

- 시범 i의 입력 그림: 틀 f ∈ {좌상, 우상, 좌하, 우하}마다
  Z_i^f = Σ_{s ∈ in_i} e_{addr_f(s)} x(s)ᵀ ∈ ℝ^{n×c}, addr_f(s)는 칸 s의 격자 안 좌표를 틀 f의 모서리에서 잰 것
  (예: 우하 틀이면 (h−1−r, w−1−c)). x(s)는 색 원-핫.
  코드로 옮겨 쌓는다: Ẑ_i = [G Z_i^{좌상}; G Z_i^{우상}; G Z_i^{좌하}; G Z_i^{우하}] ∈ ℝ^{4n×c}.
- 출력 그림: Ŷ_i = G Σ_{o ∈ out_i} e_o y(o)ᵀ ∈ ℝ^{n×c}. 출력 쪽은 틀 없이 N×N 영역의 절대 좌표다(원본판에서는 좌상 정렬,
  증강판에서는 변환된 자리). 출력 칸이 어느 주소에서 읽는지를 Ŵ가 정하므로 출력 쪽 틀은 필요 없다.
- 질의 입력 그림 Ẑ*는 같은 방식. 질의 출력 칸은 어디에도 쓰이지 않는다(조건 N, 구조로 성립).
- **크기 시냅스.** 출력 크기는 같은 원리의 작은 문제로 따로 푼다: [h_out, w_out]ᵀ = K [h_in, w_in, 1]ᵀ, K ∈ ℝ^{2×3}를
  시범 크기 쌍에서 사전 중심 K⁰_τ와 ℓ1로 맞춘다. 같은 크기(K = [I | 0]), 전치(행 교환), k배, 상수 크기가 원소 한두 개다.
  EOS를 그림의 색으로 두지 않는 이유: 반전에서 내용 칸은 아래 틀에서 읽어야 하는데 EOS 행은 제자리여야 해서, 위치 연산자
  하나로 둘을 같이 쓸 수 없다. 크기는 내용과 다른 축이므로 따로 둔다. 내용으로 정해지는 크기(물체 경계로 자르기)는 M1/M2.
- **틀이 넷인 이유(명제 1, 필요충분).** 크기가 다른 격자에 같은 규칙을 적용하려면 가설 족이 증강군에 닫혀 있어야 한다.
  절대 좌표(좌상 틀) 하나에서 "상하 반전"은 r ↦ h−1−r라 격자 크기 h마다 다른 연산자다.
  D4 원소 t는 입력 격자의 한 모서리 f_t를 출력의 좌상 모서리로 보낸다. 출력 좌상에서 잰 좌표는 입력 모서리 f_t에서 잰
  좌표(필요하면 전치)와 같으므로, t는 틀 f_t에서 크기와 무관한 고정 연산자다. f_t는 t마다 하나뿐이고, 네 모서리가 각각
  원소 둘씩을 맡는다. 그러므로 네 틀은 D4 전체에 충분하고, 하나라도 빼면 그 모서리를 맡는 원소 둘이 크기마다 다른
  연산자가 된다(필요). 수치 확인: 격자 크기 1–5의 모든 (h, w) 조합에서 8개 원소 각각이 정확히 한 틀에서만 단일 연산자다.
  틀은 손 사전이 아니다. 격자 크기(EOS로 주어짐)와 이미 데이터 증강에 쓰는 군에서 강제된다.
  예: 반시계 90° 회전은 출력 (r, c) ← 입력 (c, w−1−r)이고, 우상 틀 주소로는 (c, r)이다. 즉 "주소 전치" 하나로 크기와 무관하다.
- **증강은 N×N 영역 전체에 건다(형식 조건).** 지금 파이프라인은 격자를 변환한 뒤 슬롯 좌상에 다시 붙인다. 그러면 회전·반전이
  격자 크기마다 다른 순열이 되어, 출력 크기를 모르는 질의에서 사전 중심을 정확히 옮길 수 없다. N×N 영역 전체에 D4를
  걸면(변환된 격자는 다른 모서리에 놓인다) 위치에는 크기와 무관한 고정 순열 T_v로, 틀 주소에는 "모서리 재배치 + 주소
  (전치)"라는 고정 순열 P_v로 작용한다. 출력 격자의 범위는 크기 시냅스가 정하므로(아래) 문제없다.

### 4.2 가설 족

𝓗₀ = { X ↦ Gᵀ(Ŵ Ẑ(X) Πᵀ + B̂) : Ŵ ∈ ℝ^{n×4n}, Π ∈ ℝ^{c×c}, B̂ ∈ ℝ^{n×c} }.

- Ŵ: 위치 연산자("출력 칸 o는 어느 틀의 어느 주소에서 읽는가"). Π: 색 연산자. B̂: 상수 출력(입력과 무관하게 정해진 칸의
  색). 여기에 크기 시냅스 K가 붙는다. 위치·색의 곱 꼴은 ARC의 축 구조다(색별 분해, C·X·Wᵀ).
- 곱 꼴의 이득(셈): 결합 연산자는 미지수 (n c)(4n c)이고, 곱 꼴은 4n² + c² + nc다. 시범 하나는 n × (그 시범에 쓰인 색 수)개의
  방정식을 준다.

### 4.3 쓰기 = 근접 경사 (명제 2: 가소성과 같음)

U_i = Ẑ_i Πᵀ (4n×c), E_i = Ŷ_i − Ŵ U_i − B̂ 라 두면

```
Ŵ ← Ŵ⁰ + S_{η_W λ_t}( Ŵ − Ŵ⁰ + η_W Σ_i E_i U_iᵀ )                 η_W = 1 / ‖Σ_i U_i U_iᵀ‖₂
B̂ ← B̂⁰ + S_{η_B λ_t}( B̂ − B̂⁰ + η_B Σ_i E_i )                     η_B = 1 / k
Π ← Π⁰ + S_{η_Π λ_t}( Π − Π⁰ + η_Π Σ_i E_iᵀ Ŵ Ẑ_i )              η_Π = 1 / ‖Σ_i (ŴẐ_i)ᵀ(ŴẐ_i)‖₂
```

- E_i U_iᵀ는 "오차(post) × 입력(pre)" 외적 = 델타 규칙(예측 의존 LTP/LTD). S는 "일정량 LTD + 0 하한"이다. 하한은 0이 아니라
  사전 중심이다(편차가 0으로 간다).
- **수렴(조건 C).** Ŵ 블록만 보면 목적은 볼록이고, η_W ≤ 1/L(L = ‖Σ U Uᵀ‖₂)이면 근접 경사가 최소점 집합으로 수렴하며
  고정점 ⇔ KKT 조건 ⇔ 최소점이다(표준). 걸음을 시범 에너지로 나누므로 시범 수·격자 크기와 무관하게 같은 의미다.
  B의 1 + Σw 정규화는 이 상수가 아니었다.
- 셋을 번갈아 갱신하므로 전체(쌍선형)는 비볼록이다. 각 블록은 볼록이고 목적은 단조 감소한다. Π와 Ŵ의 배율 모호성
  (aŴ, Π/a)은 Π에 걸린 사전 중심과 문턱이 깬다.
- 반복 수 T가 유한하면 근사해다. 반복별 문턱 λ_t를 학습하면(LISTA, Gregor & LeCun 2010) 적은 반복에서 더 가까이 간다.

### 4.4 식별 (조건 I: 학습에 거는 것의 정확한 진술)

Π를 고정하면 시범은 선형 측정 A_D: Δ ↦ (Δ U_i)_i 다(Δ = Ŵ − Ŵ⁰). 표준 정리(영공간 성질):

> 모든 s-희소 Δ가 "A_D Δ' = A_D Δ를 만족하는 Δ' 중 ‖Δ'‖₁ 최소"의 유일한 해 ⇔
> A_D의 영공간의 모든 0 아닌 v와 |S| ≤ s인 모든 지지 S에 대해 ‖v_S‖₁ < ‖v_{Sᶜ}‖₁.

- 희소성(‖Δ‖₀)도 영공간 성질도 **G-좌표에서** 잰다. 그래서 G가 두 번 들어간다: 법칙을 성기게 만들어야 하고(L),
  시범이 그 희소 해를 정하게 만들어야 한다(I). 이것이 "구조 코드를 학습한다"의 정확한 내용이다.
- 사전 중심이 있으면 필요한 희소도는 s_τ = ‖G-좌표의 Ŵ_τ − Ŵ⁰_τ‖₀다. 학습 과제(전환적)는 편차가 작아 시범이 적어도 되고,
  새 과제는 공유 사전에서의 편차만큼 시범이 필요하다.

### 4.5 퍼즐 임베딩 = 사전 중심 (조건 M)

- 과제마다 θ⁰_τ = (Ŵ⁰_τ, Π⁰_τ, B̂⁰_τ)를 학습 표에 둔다(원본판 v = 0 하나만).
- **증강판 등변(명제 3).** 영역 전체 증강(4.1)에서, 규칙 (W, Π, B)가 원본 시범을 맞추면 판 v의 시범은
  (T_v W P_vᵀ, σ_v Π σ_vᵀ, T_v B σ_vᵀ)가 정확히 맞춘다. T_v는 출력 슬롯 위치의 순열, P_v는 입력 틀 주소의 순열이고 둘 다
  격자 크기와 무관하다. 증명: 판 v의 입력 그림은 Ẑ' = P_v Ẑ σ_vᵀ(코드 좌표에서는 G P_v Gᵀ로 켤레), 출력 그림은
  Ŷ' = T_v Ŷ σ_vᵀ이므로 Ŷ' = (T_v W P_vᵀ) Ẑ' (σ_v Π σ_vᵀ)ᵀ + T_v B σ_vᵀ가 원래 등식에 순열을 곱한 것과 같다.
  그러므로 판 v의 사전 중심은 원본 중심의 켤레이고, URM처럼 판마다 따로 둘 필요가 없다(표 크기 1/101).
  두 번째 이득: 같은 과제의 판 101개가 한 중심을 함께 학습한다.
- 새 과제는 공유 사전 θ⁰_∅를 쓴다. 공유 사전은 모든 증강에 불변이어야 하므로 불변 부분공간에 묶인다(아래 4.6).
  학습 중에는 일정 비율의 에피소드에서 과제 중심 대신 공유 사전으로 시작하게 해서(ID 드롭아웃) 공유 사전도 학습한다.
- 퍼즐 임베딩이 시냅스 경로 "안"에 있다는 것의 뜻: 따로 앞 토큰으로 넣는 것이 아니라, 추론(쓰기 반복)의 시작점이자
  LTD가 당기는 하한이다. 시범이 없으면 기억(사전)을 그대로 쓰고, 시범이 있으면 그 기억을 시범으로 고친다.

### 4.6 공유 사전의 자유도 (정확한 셈)

불변 연산자 공간의 차원 = 군이 순서쌍에 만드는 궤도 수 = (1/|군|) Σ_g (고정점 수)².

| 대상 | 전체 차원 | 증강 불변 차원 |
|---|---|---|
| 위치 연산자, N = 5 (위치 × 위치) | 625 | 91 |
| 위치 연산자, N = 10 (위치 × 위치) | 10,000 | 1,275 |
| 색 연산자 (색 1..9 순열, 색 0 고정) | 100 | 5 |

색 쪽 5차원의 기저는 다섯 항이다: 배경→배경, 배경→다른 색(1..9에 균등), 다른 색→배경(균등), 다른 색→같은 색(1..9 대각), 다른 색→다른 색(균등). 새 과제의 사전은 이 안에서만 움직이고, 과제별 내용(어떤 색이 어떤 색으로)은 전부 시범(편차)이 맡는다. 이것은 손으로 정한 제약이 아니라 증강 불변성의 귀결이다.
움직이고, 과제별 내용은 전부 시범(편차)이 맡는다. 이것은 손으로 정한 제약이 아니라 증강 불변성의 귀결이다.

### 4.7 읽기와 손실

- 크기 (ĥ, ŵ) = 반올림(K [h*, w*, 1]ᵀ). Ŷ* = Ŵ Ẑ* Πᵀ + B̂, 칸 o(예측 크기 안)의 점수 = (Gᵀ Ŷ*)[o, :] / 온도.
  손실: 참 출력 크기 안의 칸 색에 교차 엔트로피 + 크기 맞춤. EOS 표시는 예측 크기에서 만든다.
- 느린 파라미터: G(직교, 케일리 또는 지수 사상으로 매개화), λ_t(반복별), 온도, 공유 사전(불변 부분공간 좌표), 과제별
  사전 중심. 토큰 신경망은 없다.
- **학습(조건 G).** 반복 상태는 토큰이 아니라 작은 행렬(Ŵ: n×4n)이다. 그래서 T번을 전부 펼쳐 역전파할 수 있다
  (레인당 메모리 O(T·4n²); n = 100, T = 50, 배치 64에서 약 500 MB). 문턱 고정점을 통과한 기울기가 G에 그대로 간다.

### 4.8 B에서 사라지는 것

선형 어텐션 목표 aₜ(짝을 형식에서 직접 받으므로 불필요), 쓰기 게이트 wₜ와 1 + Σw 정규화(누가 쓰는지는 형식이 정함,
걸음은 립시츠 상수), 시냅스 키 κₜ(키 = 입력 그림, 값 = 출력 그림이라 답 누설이 구조적으로 불가능), rp_out과 잔차 혼합,
역할·쌍 임베딩(그림을 만들 때 슬롯 번호로 이미 쓰임), 토큰 재귀 블록·FFN·bands, 판마다 따로인 퍼즐 임베딩.
남는 것: 델타 + 소프트 문턱, 사전 중심, 학습된 위치 코드(G).

## 5. 지지 사다리 (조건을 깨지 않고 넓히기)

M0의 지지는 "틀 넷 위의 위치 재배치 × 색 대응 + 상수"다. 내용에 따라 다르게 움직이는 규칙(물체, 둘러싸임, 개수)은
없다. 넓히는 순서와 각 단계가 잃는 것:

| 판 | 바꾸는 것 | 유지되는 조건 | 잃는 것 |
|---|---|---|---|
| M1 국소 특징 | x(s) 대신 ψ(X)(s) ∈ ℝ^m: 격자 안 국소(3×3) 공유 신경망의 특징. Π: m → c | 전부. Ŵ에 대해 여전히 볼록 | 없음(ψ는 느린 층) |
| M1′ 항의 합 | Ŷ = Σ_{j≤r} Ŵ_j Ẑ_j Π_jᵀ + B̂ (특징 채널별로 다른 위치 연산자) | 전부. 각 Ŵ_j에 ℓ1 | 항 사이 식별이 약해짐(I가 더 어려움) |
| M2 합성 | 단계 ℓ = 1..L: H^{ℓ+1} = ψ_ℓ([H^ℓ, Gᵀ Ŵ_ℓ Ĥ^ℓ Π_ℓᵀ]); 빠른 파라미터는 단계마다, 시범 손실을 단계 전체로 역전파한 근접 경사로 추론 | W, M, N, G(층) | 볼록성(C가 국소 수렴으로 약해짐). L = 1, ψ = 항등이면 M0 |

- M2의 꼴은 "토큰 섞기(선형) ↔ 채널 섞기(비선형)"의 교대, 즉 MLP-Mixer와 같은 꼴이다. 차이는 **토큰 섞기 가중치가 과제마다
  시범에서 추론되는 성긴 빠른 가중치**이고, 채널 섞기만 공유된 느린 가중치라는 점이다. 규칙(과제별)은 전부 전역 섞기에,
  지식(공유)은 전부 국소 섞기에 있다. 깊이 L과 채널 m이 늘면 지지가 단조 증가하고, 무엇이 짧은지는 여전히 ℓ1과 G가
  정한다. 즉 지지는 소프트하게만 제한된다(10-21 원칙 문서 1.3의 "가중을 바꾼다").
- 이 꼴이 ARC 전체의 지지를 얼마나 덮는지는 증명하지 않았다(미검증). 정리할 수 있는 것은 단조성과, M0 ⊂ M1 ⊂ M2라는 것.

## 6. bands로 승격하기

델타 항을 펼치면 토큰 쌍의 합이다(Π = I, 틀 하나로 적음):

```
Σ_i E_i Ẑ_iᵀ = Σ_i Σ_{o∈out_i, s∈in_i} g(o) ⟨y(o), x(s)⟩ g(s)ᵀ   −   Ŵ Σ_i Σ_{s,s'∈in_i} g(s) ⟨x(s), x(s')⟩ g(s')ᵀ
                 (교차 쌍: 출력 칸 ↔ 같은 시범의 입력 칸)             (자기상관: 같은 입력 격자 안의 쌍)
```

- 두 항 모두 "위치 코드를 키로 한 헤브 외적을, 내용이 일치하는 쌍에 대해 더한 것"이다. bands가 하는 일(창으로 고른
  pre → post 쌍의 헤브 합)과 같은 종류다.
- 승격 조건: (a) 키 = 위치 코드(학습된 RoPE가 G 역할), (b) 창이 두 종류의 쌍(같은 시범의 입력 → 출력, 같은 입력 격자 안)을
  골라야 하고, (c) 누적기 + 근접 사상(소프트 문턱)이 있어야 한다.
- (b)에 대한 관찰: ARC에서 짝을 정하는 변수는 시간차가 아니라 슬롯 소속이다. 밀집 배치에서는 시간차 S²·(슬롯 차)가 소속과
  일대일이라 창으로 고를 수 있지만, 패킹하면 시간차가 격자 크기마다 달라져 창으로 고를 수 없다. 그러므로 승격은
  "시간 창"이 아니라 "슬롯 소속으로 고른 쌍"으로 해야 한다.

## 7. 학습에 거는 것과 그 검증

구조로 보장되지 않는 것은 L(법칙이 G에서 성김)과 I(그 희소 해를 시범이 정함) 둘뿐이다. 검증할 예측(손 기저 존재 확인은
하지 않는다):

1. M0를 Mini-ARC(전환적, 지금 A/B와 같은 분할)에서 학습한다. 비교: A(퍼즐 임베딩만).
2. 제거 실험: λ = 0(희소 LTD 없음), G를 시작값에 고정(구조 코드 학습 없음), 사전 중심 없음(퍼즐 임베딩 제거), 틀 하나.
   이론이 맞다면 λ = 0과 G 고정이 질의 정답에서 가장 크게 떨어지고, 틀 하나는 크기가 바뀌는 과제에서만 떨어진다.
3. 학습 후 G-좌표에서 학습 과제 연산자의 희소도와, 무작위 순열의 희소도를 비교한다(L의 직접 측정).
4. 지지와 일반화를 가른다: 시범을 정확히 맞추는 비율(지지)과 질의 정답률(선택)을 따로 잰다.
5. M0의 지지가 모자란 과제에서 M1(국소 특징)을 붙인다.

## 8. 열어 둔 문제

- 쌍선형(Ŵ, Π) 교대 최소화의 국소해. 사전 중심이 시작점이라 학습 과제에서는 문제가 작고, 새 과제에서 커질 수 있다.
- 틀 넷으로도 크기와 무관하게 쓰이지 않는 위치 규칙이 있다. 예: 타일링 출력 (r, c) ← 입력 (r mod h, c mod w)는 h, w에 따라
  다른 연산자다. 확대(r ↦ ⌊r/2⌋)나 고정 이동은 크기와 무관하다. 나머지 연산이 필요한 규칙은 M1/M2의 몫이다.
- 출력 크기가 입력 크기의 아핀 함수가 아닌 과제(물체 경계로 자르기, 개수만큼 늘이기)는 M1/M2가 필요하다.
- M2의 안쪽 추론은 단계 사이 신용 할당이 필요해 국소 가소성(델타)만으로는 안 된다. 생물학적 해석이 약해진다.
- n×4n 연산자는 ARC 원판(N = 30, n = 900)에서 커진다(레인당 324만 원소). 저랭크 + 희소 매개화가 필요할 수 있다.

## 9. 어텐션으로 다시 쓰기: 규칙 헤드 (사용자 요구: 어텐션 기반, 빠른 가중치와의 계보, bands에 붙일 수 있음)

### 9.1 M0는 이미 어텐션 헤드 하나다

토큰 단위로 펼치면 M0의 예측은 질의 출력 칸 o마다

```
ŷ(o) = Σ_{s ∈ 질의 입력}  Ŵ[o, addr(s)] · Π x(s)        =  Σ_s  score(o, s) · value(s)
```

즉 **점수 행렬이 빠른 가중치인 어텐션**이다. 보통 어텐션의 점수는 q(o)ᵀ W_QK k(s)이고 W_QK는 느린 가중치다. 여기서는
q(o) = g(o), k(s) = g(addr(s))(위치 코드)이고 그 사이의 쌍선형 형식 Ŵ가 과제마다 시범에서 쓰이는 빠른 가중치다.
값 쪽 Π도 같은 방식의 빠른 W_OV다. 규칙 = "과제마다 시범에서 추론되는 어텐션 헤드 하나"다.

### 9.2 쓰기(델타)는 어텐션 지도의 차이다

델타 쓰기의 경사를 토큰으로 펼치면(Π = I, 틀 하나, 코드 좌표 생략)

```
Σ_i E_i X_iᵀ  =  Σ_i Σ_{o∈out_i, s∈in_i} g(o) g(s)ᵀ ⟨y(o), x(s)⟩   −   Ŵ · Σ_i Σ_{s,s'∈in_i} g(s) g(s')ᵀ ⟨x(s), x(s')⟩
                 교차 어텐션 지도(시범 출력 → 같은 시범의 입력)       자기 어텐션 지도(시범 입력 안)
```

- 첫 항: 시범 출력 칸이 내용으로 자기 짝 입력의 출처를 찾는 **보통 어텐션**(내용 내적)을 위치 코드의 외적으로 쌓은 것.
  출력 칸은 답(내용)을 가지고 있어서 이 어텐션을 할 수 있다.
- 둘째 항: 같은 색 칸이 여럿이라 생기는 출처 모호성(입력 자기상관)을 지운다(10-20의 Ā 제거, Yule–Walker).
- 문턱(희소 LTD)은 시범 여러 개의 지도에서 공통으로 맞는 성긴 위치 대응만 남긴다.
- 질의 출력 칸은 내용이 없어 내용 어텐션을 못 한다. 대신 시범에서 증류된 빠른 지도 Ŵ로 읽는다.

**계보.** 선형 어텐션 = KV 외적으로 쓰는 빠른 가중치(Schlag, Irie & Schmidhuber 2021), 델타 규칙으로 쓰면 DeltaNet이다.
규칙 헤드는 그 계보에서 한 걸음이다: 빠른 가중치가 "값을 저장하는 기억"이 아니라 "**어텐션 지도(QK 형식)를 저장하는 기억**"
이고, 그 쓰기가 델타 + 근접 사상(희소 LTD)이며, 시작 상태가 퍼즐 임베딩이다.

### 9.3 일반 규칙 헤드 (층 ℓ, 헤드 h)

토큰 은닉 상태에서 느린 투영으로 값 v(t)를 만들고, 위치 코드 g를 쓴다.

```
쓰기 (과제마다, 시범 칸만):
   목표: 시범 출력 칸 o의 값 v(o)를, 같은 시범 입력 칸들의 값의 위치 혼합으로 설명한다
   min_Ŵ  ½ Σ_i Σ_{o∈out_i} ‖ v(o) − Σ_{s∈in_i} (g(o)ᵀ Ŵ g(addr(s))) v(s) ‖²  +  λ ‖Ŵ − Ŵ⁰_{τ,ℓ,h}‖₁
   반복: 근접 경사 (델타 = 교차 지도 − Ŵ·자기 지도, 걸음 = 1/립시츠, 문턱)
읽기 (모든 출력 칸, 질의 포함):
   r(o) = Σ_{s∈짝 입력} (g(o)ᵀ Ŵ g(addr(s))) v(s)  → 잔차에 더함
```

- **층마다 국소 목표가 있다.** M2에서 막혔던 점(중간 단계에 목표가 없음)이 사라진다. 각 층의 목표는 "그 층에서 시범 출력
  칸이 가진 값"이고, 시범 출력 칸은 내용이 있으니 언제나 정해진다. 안쪽 역전파가 필요 없고, 각 헤드의 쓰기는 그 층
  입력이 주어지면 볼록이다. 그래서 정리 0이 헤드마다 성립한다(지지·법칙성·영공간 성질은 그 층의 값 공간에서).
- **합성은 층을 쌓아서 얻는다.** 층 ℓ의 규칙 헤드가 질의 출력 칸에 채운 값이 층 ℓ+1의 입력이 된다. 느린 어텐션 헤드
  (내용 어텐션, 지각)와 규칙 헤드를 한 블록에 같이 둔다. 지지는 트랜스포머 꼴이 주고, 과제별 선택은 규칙 헤드의 ℓ1이 맡는다.
- **누설 없음(N)**: 쓰기의 합은 시범 칸뿐이다. 질의 출력 칸은 읽기만 한다.
- **퍼즐 임베딩**: 층·헤드마다 사전 중심 Ŵ⁰. 증강판 켤레(명제 3)도 그대로다.
- **M0와의 관계**: 층 하나, 값 = 색 원-핫, v(o) = 색 y(o)이면 9.1의 M0다.

### 9.4 bands에 붙이기

- 교차 지도와 자기 지도는 "위치 코드를 키로 한 헤브 외적을 내용 내적으로 가중한 합"이다. bands가 RoPE 키로 만드는
  헤브 합과 같은 종류다. 붙일 때 바꿀 것은 셋이다: (a) 쌍을 시간 창이 아니라 슬롯 소속(같은 시범의 입력 → 출력, 같은 입력
  격자 안)으로 고른다. (b) 누적기 W에 델타 항(자기 지도 빼기)과 근접 사상(문턱, 사전 중심)을 건다. (c) 읽기는 질의 출력
  칸에서 W를 점수로 써서 짝 입력의 값을 모은다.
- 즉 bands의 누적기 W가 규칙 헤드의 Ŵ가 되고, 나머지 bands(흔적, 창)는 느린 지각 헤드로 남는다.

## 10. 층 구성

### 10.1 원칙: 시범에서 질의로 가는 길은 빠른 가중치 하나뿐이다

- **느린 헤드(지각)는 격자 안에서만 본다.** 같은 격자의 토큰끼리만 어텐션한다(격자별 블록 대각 마스크).
- **규칙 헤드는 짝 사이에서만 본다.** 시범 i의 입력 → 시범 i의 출력, 질의 입력 → 질의 출력.
- 그 밖의 격자 사이 경로는 없다.

이유(명제 4): 느린 어텐션이 시범 격자와 질의 격자를 직접 이으면, 신경망이 느린 가중치로 문맥 안 학습을 해서 시범의 정보를
질의로 옮길 수 있다. 그러면 질의의 답을 정하는 선택 원리가 "ℓ1 + 사전 중심"이 아니라 느린 가중치 안의 무언가가 되고,
정리 0이 아무것도 보장하지 않는다. 격자 사이 경로를 규칙 헤드로만 두면, 질의 출력 칸이 받는 시범의 정보는 전부 빠른
가중치(Ŵ, Π)를 거친다. 그리고 빠른 가중치는 lasso의 해이므로, 선택 원리가 구조로 고정된다.

10-20의 "규칙(과제별)은 전역, 지식(공유)은 국소"를 "규칙은 격자 사이, 지식은 격자 안"으로 정확히 한 것이다.

### 10.2 토큰과 입력

- 토큰: 시범 쌍(입력, 출력) × k, 질의 입력, 질의 출력 캔버스(N×N 전체, 입력 = 빈칸). 패킹, 퍼즐 임베딩 앞 토큰은 없다.
- 첫 벡터: 색 임베딩 + 역할 임베딩(시범 입력/출력, 질의 입력/출력) + 쌍 번호 임베딩.
- 토큰마다 형식에서 받는 것: 격자 번호, 격자 크기 (h, w), 격자 안 좌표 (r, c), 영역 절대 좌표, 틀 주소 넷.
- 질의 출력 격자의 크기는 크기 시냅스가 맨 처음에 정한다(§4.1). 손실은 참 크기 안의 칸에만 건다.

### 10.3 블록 (공유 블록 하나를 R번 반복; 블록 안에 층 L개)

```
h ← h + 격자 안 어텐션(h)           느린 헤드 H_s개. softmax, 학습된 2D RoPE(격자 안 좌표), 격자별 마스크
h ← h + FFN(h)                       SwiGLU
h ← h + 위치 규칙 헤드(h)            빠른 헤드 H_p개. 짝 사이. 아래
h ← h + 내용 규칙 헤드(h)            빠른 헤드 1개. 같은 칸. 아래
```

**위치 규칙 헤드 (P, "어디서 읽나").** 헤드마다 느린 값 투영 v = W_V h (d_v 차원).

- 그림: 시범 i의 입력 그림 Ẑ_i = Σ_{s∈in_i} g4(s) v(s)ᵀ (4n × d_v, 틀 넷 위치 코드), 출력 그림 Ŷ_i = Σ_{o∈out_i} g(o) v(o)ᵀ (n × d_v).
- 쓰기: Ŵ (n × 4n)를 사전 중심 Ŵ⁰에서 시작해 T_in번 근접 경사로 푼다.
  min ½ Σ_i ‖Ŷ_i − Ŵ Ẑ_i‖² + λ‖Ŵ − Ŵ⁰‖₁, 걸음 1/‖Σ Ẑ Ẑᵀ‖₂(거듭제곱법 3회로 추정), 반복별 λ_t는 학습한다.
- 읽기: 모든 출력 칸(시범 출력 포함) o에 대해 r(o) = g(o)ᵀ Ŵ Ẑ_짝 (d_v)를 구하고, W_O r(o)를 잔차에 더한다.
  시범 출력에도 같은 읽기를 넣는 이유: 그래야 다음 층의 느린 가중치가 시범 출력과 질의 출력을 같은 종류의 입력으로 본다.
- 층 하나, 값 = 색 원-핫이면 M0의 위치 연산자다(§9.1).

**내용 규칙 헤드 (C, "무엇이 되나").** P가 출처를 가져온 다음, 그 내용을 과제마다 바꾸는 빠른 선형 사상이다.

- 키 = 그 층 P 헤드의 읽기 r(o)(출처 내용), 목표 = 출력 칸 자신의 값 u(o) = W_U h(o). 쓰기는 DeltaNet 그대로다:
  min ½ Σ_{시범 출력 o} ‖u(o) − Π r(o)‖² + λ_C‖Π − Π⁰‖₁, Π ∈ ℝ^{d_v×d_v}, 근접 경사 T_in번.
- 읽기: 모든 출력 칸에 Π r(o)를 W_O′로 잔차에 더한다.
- 1층에서 값이 색 원-핫이면 M0의 색 연산자 Π다.

**두 헤드로 나누는 이유.** M0의 곱 꼴(위치 × 색)을 한 문제로 풀면 쌍선형이라 비볼록이다. 위치 헤드(Π = I로 고정)를 먼저
풀고, 그 읽기를 키로 내용 헤드를 푸는 두 단계로 나누면, 각 단계가 볼록이고 정리 0이 단계마다 성립한다. 순서의 근거는
ARC의 축 구조다: 위치 대응이 정해져야 "어떤 색이 어떤 색이 되는지"를 짝지을 수 있다.

### 10.3a 반복: 결합 고정점

- 블록 하나(층 L개)를 R번 반복한다(LT 재귀). 빠른 상태(층·헤드마다 Ŵ, Π)는 반복과 세그먼트를 넘어 이어지고, 반복마다
  규칙 헤드는 근접 경사를 K걸음(1–2)만 한다(따뜻한 시작). 사전 중심(퍼즐 임베딩)은 반복 내내 고정이다.
- 반복 전체는 (은닉 h, 빠른 상태 Ŵ, Π)의 결합 사상 Φ의 고정점 반복이다. 고정점에서 은닉이 멈추면 그림(키·목표)도 멈추고,
  근접 경사의 고정점은 lasso의 해이므로 **정리 0은 "수렴한 표현에 대한 lasso 해"로서 그대로 성립한다.** 지각(느린 헤드)이
  표현을 다듬는 동안 규칙(빠른 가중치)도 함께 다듬어지고, 둘이 서로 맞는 곳에서 멈춘다.
- 학습: 고정점 (h*, Ŵ*, Π*) = Φ(h*, Ŵ*, Π*)의 암묵적 미분(DEQ, Bai et al. 2019)을 기본으로 한다. 고정점 방정식 안에 문턱이
  있으므로, 구조 코드 g와 문턱 λ에 "문턱 고정점을 통과한" 기울기가 정확히 간다(조건 G). 소프트 문턱은 거의 모든 곳에서
  미분 가능하다(지지 집합이 바뀌는 경계만 예외). 값싼 대안은 HRM식 1-step 기울기(마지막 반복만)이고, 이것은 암묵적 미분의
  1차 근사다.
- 수렴이 보장되지는 않는다(Φ가 축약 사상이라는 증명은 없다). 규칙 헤드 쪽은 걸음이 1/립시츠라 비확장 사상이고, 느린 쪽은
  rms 정규화로 크기가 묶인다. 고정점 잔차 ‖Φ(x) − x‖를 기록해서 수렴을 측정한다.

### 10.4 위치 코드 g

> **§11.3에서 바뀜:** 내용으로 정한 틀(부드러운 기준점)을 쓰려면 코드가 이동에 등변이어야 하고, 그러면 학습된 주파수의
> RoPE 꼴이 강제된다. 아래의 "일반 직교 코드" 선택은 모서리 틀만 쓸 때의 것이다.

- g(r, c) = g_N(r) ⊗ g_N(c). g_N은 N×N 실직교 행렬(케일리 매개화, 무작위 직교에서 시작)이고, 행과 열이 같은 g_N을 쓴다.
  같은 것을 써야 전치(D4의 원소)가 코드에서 두 인자를 맞바꾸는 것뿐이 된다. 위치를 행과 열로 나누는 것은 축 구조다.
- g4(s)는 네 틀 주소 각각에 g를 매기고 이어 붙인 것이다(4n).
- 느린 헤드의 학습된 RoPE와는 따로 둔다. RoPE는 위상이 몇 개의 주파수에 묶여 있어 n개 위치 위의 직교 기저가 되지 못하고,
  정리 0의 영공간 성질은 직교(또는 그에 가까운) 코드에서 잴 때 의미가 분명하다. bands로 승격할 때 둘을 합치는 문제는
  §9.4에 남긴다.
- g는 층·헤드에 공유한다(과제 전체의 "언어"가 하나라는 가정). 학습 신호가 모든 규칙 헤드에서 모인다.

### 10.5 퍼즐 임베딩 (사전 중심)

- 과제마다 벡터 e_τ ∈ ℝ^{d_e}(d_e = 64) 하나. 사전 중심은 층·헤드마다 공유 디코더로 만든다:
  Ŵ⁰_{ℓ,h} = A_{ℓ,h} e_τ (칸 좌표로 만든 뒤 코드로 옮김), Π⁰_ℓ = C_ℓ e_τ.
- 증강판 v: 위치 쪽 중심은 정확한 켤레(명제 3)로 옮긴다. 내용 쪽 Π⁰는 1층(값 = 색)에서만 색 순열 켤레가 정확하다. 2층부터는
  값 공간에서 색 순열이 어떻게 작용하는지 정해져 있지 않으므로, 2층부터 Π⁰는 공유 사전만 쓰고 과제 내용은 시범이 맡는다.
- 새 과제: e = 0(공유 사전). 공유 사전은 디코더의 편향 항이고, 증강 불변 부분공간에 묶는다(§4.6). 학습 중 일정 비율의
  에피소드에서 e를 0으로 두어 공유 사전을 학습한다.

### 10.6 크기와 비용 (제안값)

| | Mini-ARC (N = 5) | ARC-1 ≤ 10 (N = 10) |
|---|---|---|
| n / 4n | 25 / 100 | 100 / 400 |
| d, d_v | 256, 64 | 256, 64 |
| 블록 안 층 L, 반복 R, 느린 헤드 H_s, 위치 규칙 헤드 H_p | 2, 16, 4, 2 | 2, 16, 4, 2 |
| 반복당 근접 경사 걸음 K | 1 | 1 |
| Ŵ 원소 수 (레인·층·헤드당) | 2,500 | 40,000 |
| 빠른 상태 저장량 (배치 64, 층 2 × (헤드 2 Ŵ + Π)) | 약 5 MB | 약 43 MB |

- 안쪽 반복은 토큰이 아니라 그림(n × d_v, 4n × d_v)과 Ŵ 위에서 돈다. 토큰 계산은 층마다 그림을 한 번 만들고 읽기를 한 번
  하는 것뿐이라, T_in을 늘려도 토큰 비용은 늘지 않는다.
- 느린 어텐션은 격자 안에서만 하므로 격자 크기 제곱(최대 100²)의 블록 대각이다.

### 10.7 이 구성에서 정해진 것과 남은 선택

- 정해진 것: 격자 사이 경로 = 규칙 헤드뿐(명제 4). 위치 → 내용 두 단계(각 단계 볼록). 층마다 국소 목표(시범 출력 칸의 그 층
  값). 위치 코드 하나 공유. 퍼즐 임베딩 = 층·헤드별 사전 중심(위치는 켤레, 내용은 1층만).
- 남은 선택:
  - 블록 안 층 수 L과 반복 수 R의 배분(재귀는 기본이다. 10.3a).
  - 시범 출력에도 읽기를 넣는 것(10.3)이 시범 출력의 원래 내용과 섞여 목표를 흐리는지. 목표 u(o), v(o)는 읽기를 더하기
    전의 은닉에서 뽑는다.
  - 크기 시냅스를 넘는 크기 규칙(내용으로 정해지는 크기)은 이 구성에 아직 없다.

### 10.8 약점 목록 (2026-10-21 검토)

1. **목표 오염(재귀에서 특히).** 쓰기 목표 v(o)를 시범 출력 칸의 은닉에서 뽑는데, 재귀에서는 그 은닉에 이전 반복의 읽기
   (모델 자신의 예측)가 섞인다. 은닉이 읽기를 베끼면 오차가 규칙과 무관하게 0이 되는 퇴화 고정점이 생긴다.
   수정: 목표를 읽기가 닿지 않는 흐름에서 뽑는다(시범 출력 칸의 주어진 내용을 층마다 느린 투영으로 옮긴 것).
   목표 = "주어진 답"이라는 형식 사실에 고정된다.
2. **내용으로 정해지는 출력 크기.** 크기 시냅스는 입력 크기의 아핀 함수만 맞춘다. 경계 상자로 자르기, 개수만큼 늘이기
   등은 입력 크기와 무관하다. 수정: "질의 입력의 느린 특징 → 크기"의 성긴 선형 사상을 시범에서 맞춘다(같은 원리).
3. **내용에 따라 다른 위치 대응(가장 큼).** 위치 점수 g(o)ᵀ Ŵ g(s)는 과제마다 고정이고 입력 내용과 무관하다. 입력마다 다른
   이동(물체를 다른 물체에 닿을 때까지, 물체마다 다른 변환)은 표현되지 않는다. 틀이 격자 모서리뿐이기 때문이다.
   수정 방향: 내용에서 정해지는 틀(물체 기준점). 느린 헤드가 기준점을 찾고, 규칙 헤드의 주소를 그 기준점에서 잰다.
4. **위치를 먼저 풀 때 색이 방해함.** 색이 바뀌는 과제에서 같은 자리의 값끼리 맞지 않아 위치 대응을 못 찾는다(M0의 결합
   풀이에는 없던 문제). 수정: 위치 헤드의 값을 색 순열에 불변인 특징(배경 여부, 모양)으로 구조적으로 제한한다.
5. 학습에 거는 것(법칙성 L, 식별 I)은 그대로 실험으로만 판정된다.
6. 크기: Ŵ는 N⁴로 커진다(N = 30이면 헤드당 324만 원소). 저랭크/희소 매개화 필요.
7. 나머지 연산이 필요한 위치 규칙(타일링)은 틀로도 크기와 무관해지지 않는다.
8. 결합 고정점의 수렴은 증명되지 않았다(잔차로 측정).

## 11. 내용으로 정해지는 틀 (약점 3의 설계)

### 11.1 문제를 틀의 언어로

"빨간 물체를 파란 물체에 닿을 때까지 민다"에서 이동 거리는 입력마다 다르다. 그러나 **파란 물체를 기준으로 잰 출력 위치**와
**빨간 물체를 기준으로 잰 입력 위치** 사이의 대응은 입력과 무관한 고정 이동이다:
o − b = (s − r) + c (b, r: 파란·빨간 물체의 기준점, c: 고정 오프셋). 즉 기준점을 내용에서 잡으면, 내용에 따라 다른 위치
대응이 **고정된 성긴 연산자**로 돌아간다. 모서리 틀 넷(§4.1)은 이 원리에서 기준점이 격자 모서리인 특수한 경우다.

### 11.2 기준점

- **격자 기준점** a_m(격자), m = 1..M: 느린 헤드가 격자 안에서 찾는다. 학습된 질의 벡터 q_m이 격자 칸들에 어텐션해서 칸 좌표의
  기댓값을 낸다(부드러운 위치). 예: "가장 큰 물체의 좌상", "유일한 색 칸".
- **칸 기준점** a(s): 칸 s가 속한 물체의 기준점(같은 물체 칸들에 대한 어텐션 풀링). "물체마다 자기 안에서 같은 변환"(물체별
  반전 등)을 고정 연산자로 만든다.
- 기준점 질의는 색 순열에 불변인 특징 위에서 계산한다(약점 4와 같은 이유: 증강판마다 같은 기준점이 잡혀야 사전 켤레가 성립).
- 출력 쪽 기준점은 **짝 입력의 기준점**을 쓴다. 질의 출력은 내용이 없어 스스로 기준점을 찾을 수 없고, 시범 출력과 질의 출력이
  같은 방식으로 주소를 받아야 하기 때문이다.

### 11.3 코드가 이동에 등변이어야 한다 (명제 5)

기준점은 부드러운(정수가 아닌) 위치이므로, 코드가 상대 위치를 연속적으로 다뤄야 한다. 요구: 모든 이동 a에 대해
g(p − a) = R(a) g(p)이고 R(a)가 a에 연속인 직교 사상. 이 조건을 만족하는 연속 표현은 (실수에서) 회전 블록의 직합,
즉 g의 채널 쌍마다 e^{iθ_k·p} 꼴이다(가환군 ℝ²의 연속 유니터리 표현은 지표의 직합). 그러므로 **틀을 내용에서 잡으려면 위치
코드는 학습된 주파수의 RoPE 꼴이어야 한다.** §10.4에서 RoPE를 버리고 일반 직교 코드를 택한 것을 되돌린다.

- 대가: n개 격자 점 위의 정확한 직교성은 주파수가 2πk/N(DFT)일 때뿐이다. 학습된 주파수에서는 근사 직교다. 정리 0의 영공간
  성질은 조건수가 나쁘지 않은 코드에서 재면 된다. 주파수 θ_k를 학습하므로 손 기저는 아니다(무작위 시작).
- 기준점에서 잰 주소의 코드는 g(s − a) = R(a)ᵀ g(s): 코드를 기준점의 위상만큼 돌린 것이다. 이것은 frame_rope(내용으로 정한 위상
  F로 q, k를 돌림)와 같은 연산이다. 그 설계의 수학적 위치가 여기서 정해진다.
- 이 결론은 bands 승격(§9.4)도 쉽게 한다: bands는 이미 학습된 RoPE를 키로 쓴다.

### 11.4 규칙 헤드의 일반형

틀 집합 𝓕 = {격자 모서리 4} ∪ {격자 기준점 M} ∪ {칸 기준점 1}. 입력 그림은 틀마다 쌓는다: Ẑ_i = [Σ_s g(s − a_f(s)) v(s)ᵀ]_{f∈𝓕}
(|𝓕|·d_g × d_v). 출력 쪽도 짝 입력의 틀들에서 잰다: Ŷ_i = [Σ_o g(o − a_f) v(o)ᵀ]_{f}. 위치 연산자 Ŵ는 (출력 틀 × 입력 틀) 블록
행렬이고 ℓ1이 걸린다.

- ℓ1이 틀 선택을 겸한다: 규칙을 가장 짧게 쓰는 틀의 블록만 살아남는다. "어느 물체를 기준으로 보는가"가 따로 학습된 선택기가
  아니라 같은 단순성 원리로 정해진다.
- 증강판 켤레: 기준점이 등변으로 계산되면(D4가 기준점을 옮기는 대로 옮겨짐), 틀 블록은 고정 순열로 바뀐다. 명제 3이 유지된다.
- 비용: 틀 수 |𝓕| = 4 + M + 1에 대해 Ŵ는 |𝓕|² 블록이다. M = 3이면 64블록. 코드 차원 d_g를 n보다 작게(예: 32–64) 잡으면
  Ŵ는 헤드당 (|𝓕| d_g)² ≈ 25만 원소(d_g = 64)라, N에 무관해진다. 약점 6(N⁴ 증가)도 함께 풀린다.

### 11.5 남는 것

- 기준점 질의가 무엇을 찾을지는 느린 학습에 맡긴다(학습에 거는 것이 하나 늘어난다: 유용한 기준점).
- "닿을 때까지"처럼 거리가 기준점 둘의 관계로 정해지는 경우는 위 식으로 되지만, "장애물을 만날 때까지 반복"처럼 경로가
  필요한 규칙은 재귀 반복(같은 규칙을 여러 번 적용)에 맡겨야 한다. 이것이 표현되는지는 미검증이다.
