# 표현력 해체: A는 어떤 일반 형태의 특수한 경우인가

> **성격: Claude의 주장과 분석 (2026-10-15).**
> - 학습 실험으로 검증한 내용이 아니다.
> - 수치로 확인한 항등식은 [A]로 표시했다. `tests/test_model.py`가 이 항등식들을 검사한다.
> - 나머지는 유도 또는 해석이며 [주장]으로 표시했다.
> - 확정된 설명은 [architecture.md](architecture.md)에 있다. 이 문서의 주장은 실험으로 확인될 때만 그쪽으로 옮긴다.

선행 문서: [필수 성질](claude_essential_properties.md). 아래 확장은 그 체크리스트(D1~D4, C1~C5, L1~L3)를 통과하는지부터 따진다.

목적은 두 가지다.
- 런 A의 각 구성 요소가 어떤 더 일반적인 표현에서 어떤 제약을 건 것인지 적는다.
- 그 제약을 풀어 A를 정확히 포함하는 확장을 고를 때, 기존 정리가 유지되는 조건을 적는다.

확장마다 추가 계수를 0으로 초기화하면 정확히 A에서 시작한다. 따라서 표현력은 항상 A를 포괄한다.

## 0. 상위 형태

칸 t, 블록 b, V 채널 a, K 채널 j에 대해 다음과 같이 둔다.

    G_b[a,j] = Σ_t Σ_{p,q≥0} w_{p,q}(a,j) · v_{t,a}(b−p) · k̃_{t,j}(b−q)
    read_t   = q̃_t G_bᵀ

A의 w는 다음과 같다. Δa는 두 사건의 지연차이고, 흔적 재귀 = 쌍 합 정리([A], `TraceRecursion`)에서 바로 나온다.

| (p, q) | w_{p,q} | 의미 |
| --- | --- | --- |
| (0, 0) | 1 + α(1−λ) sin Δa | Hebb + 같은 블록 지연 |
| (0, q ≥ 1) | α(1−λ) λ^q sin(qωT + Δa) | pre가 먼저(LTP) |
| (p ≥ 1, 0) | −α(1−λ) λ^p sin(pωT − Δa) | post가 먼저(LTD) |
| 그 밖 | 0 | |

이 형태의 제약을 하나씩 풀면 아래 계층이 나온다.

## 1. 지연 지지 집합: L자 ⊂ 띠 ⊂ 전체 [주장]

| 모델 | 0이 아닌 w | 결과 |
| --- | --- | --- |
| B-only | (0, 0) | 기준선 |
| A | L자: p = 0 또는 q = 0 (적어도 한쪽이 현재 블록인 쌍) | 학습됨 |
| B | 띠: w_{m+p, m+q} = ρ^m w_{p,q} (STDP 성분만, 대각선 방향 기하 감쇠) | 학습됨. 다만 이륙이 A보다 늦음(2026-10-15 런, ρ 0.5) |
| 10-03 누적 M | 대각선 w_{m,m} = 1 (Hebb 운반자 자체를 무감쇠 누적) | 학습 역전, 재생 완답 0% |

"누적은 실패했는데 B는 학습된다"를 이 표로 설명할 수 있다.
- 실패한 쪽은 Hebb 항 (0,0)을 대각선 전체로 무감쇠 복제했다.
- B는 Hebb보다 작은(‖L‖/‖Hebb‖ ≈ 0.22) STDP 성분만 기하 감쇠로 복제한다.

## 2. 지연 커널: 단일 복소 극 ⊂ 대각 SSM

A의 지연 방향 가중치는 h(k) = (1−λ)(λe^{iωT})^k다. 극 z = λe^{iωT} 하나짜리 1차 IIR이다. 다른 말로, 고정 모드 하나의 대각 복소 선형 재귀(LRU/S4D형)다.

- 일반화는 h(k) = Σ_m r_m z_m^k (M개 극)이다. λ를 입력에 따라 바꾸면 Mamba형 선택적 SSM이 된다.
- 쌍 합 정리는 대각 선형 재귀이기만 하면 그대로 성립한다. [주장, 증명은 A의 경우와 같은 기하급수 전개]
- 고정점 이득 κ는 이 커널의 Poisson 합이다. κ = (1−λ)[1 + 2Σ_{k≥1} λ^k cos kωT] = 1.220523으로, 닫힌 식 (1−λ)(1−λ²)/(1 − 2λcos ωT + λ²)와 같다. [A]
- 일반 커널이면 κ = h(0) + 2 Re Σ_{k≥1} h(k)다. [주장]

## 3. 위상 창: 1차 사인 조화 ⊂ 푸리에 창 ⊂ 복소 학습률 [주장]

쌍 가중치 f(Δτ) = 1 + α sin Δτ는 2π 주기 창에서 직류 + 1차 홀수 조화만 남긴 것이다.

- 일반화 f(Δ) = Σ_r c_r e^{irΔ}: r차 조화는 태그를 r배한 복소 외적 하나로 구현된다.
- 학습률 α를 복소수 α̃ = α_r + iα_i로 넓히면 Im S와 함께 Re S(짝수 cos 창)가 들어온다. A는 "학습률의 위상을 π/2로 고정한" 경우다. 이것은 10-13의 "Hebb와 STDP의 차이는 복소 학습률의 위상"이라는 관찰과 같은 말이다.
- 현재 근거: 2차 조화를 빼면 ±2%로 차이가 없었다(10-10 §6). 짝수 창은 시험한 적이 없다.

## 4. 시계: 단일 주파수 블록 RoPE + 1차 지연

τ = nωT + c sin φ의 두 항은 각각 다음의 특수한 경우다.

**블록 간격 nωT [주장].** 모든 채널이 공유하는 공통 시계다. 위상차가 시간차가 되려면(φ = ωt에서 Δt = Δφ/ω), 짝을 이루는 pre와 post가 같은 주파수를 써야 한다.

- 쓰기는 외적이라 V 채널 a와 K 채널 j의 **모든 쌍**을 짝짓는다.
- 채널마다 주파수가 다르면 위상차가 τ_V,a(b) − τ_K,j(b−k) = kω_a + (b−k)(ω_a − ω_j)가 되어, 절대 시각에 비례하는 항이 생긴다. 창이 정상이 아니게 되고 LTP/LTD 부호가 깨진다.
- RoPE의 다중 주파수가 괜찮은 것은 내적이 같은 채널 쌍끼리만 짝짓기 때문이다. 이 비유는 외적 쓰기에는 성립하지 않는다(2026-10-15, 사용자 지적으로 정정).

이론을 지키는 다중 스케일은 두 가지다.
1. 헤드별 주파수 ω_h: 짝은 헤드 안에서만 맺히므로 위상차가 kω_h로 정상이다.
2. 모드별 주파수: §2의 다중 극으로, 같은 쌍을 M개 흔적에서 각각 n·ω_m으로 태그한다.

채널별 ω_j는 같은 주파수 그룹끼리만 짝짓도록 G를 블록 대각으로 제한해야 성립하는데, 이는 헤드를 쪼개는 것과 같다.

**지연 c sin φ [A].** 변위를 누적한 φ는 sin 안에서 경로와 무관하게 줄어든다.

    c·sin φ_b = c·sin(θ_b − θ_0)        θ_0 = 퍼즐 첫 블록의 쌍 각도

- 근거: wrap된 변위의 합은 mod 2π로 θ_b − θ_0다.
- 무작위 40블록에서 오차 1.8e−15였다(`Clock.test_reduces_to_relative_angle`).

이 항등식에서 따라 나오는 것 [주장]
- 누적 위상의 감김 수는 A에서 쓰이지 않는다.
- 지연은 "현재 단위 쌍과 퍼즐 시작 때 단위 쌍의 2D 외적"이라는 내용 특징이다.
- 시계 상태는 φ와 직전 위상자(4P) 대신 시작 위상자 z_0(2P)만 있으면 된다. 이것은 구현을 정리하는 것이지 표현을 바꾸지 않는다. 런 A와 수치가 같은지는 확인해야 한다.
- 10-13의 "누적 위상 시계"라는 해석은 A에서는 표현력을 더하지 않는다.

**지연의 일반화 [주장].** a = g(θ_b − θ_0)의 임의 유계 함수로 둘 수 있다. A는 g의 1차 홀수 조화다. 블록 순서(nωT)와 내용 의존 오프셋의 조합은 문맥 위치 인코딩(CoPE)형에 해당한다.

## 5. 지연부 L ≈ Hebb의 특징 확장 [A + 주장]

- [A] |Δa| ≤ 2c = 0.28이면 sin Δa와 Δa의 상대 오차는 최대 1.3%다.
- [주장] 그러면 고정점에서 다음이 된다. s는 각 쌍의 sin(θ − θ_0)를 채널마다 두 번 반복한 것이다.

      L ≈ κc[(v ⊙ s_V) k̃ᵀ − v (k̃ ⊙ s_K)ᵀ]

  s_K는 쌍마다 스칼라라서 RoPE와 교환된다.

정확도를 맡는 L은 사실상 값/키에 게이트된 특징을 하나씩 더한 다중 특징 선형 어텐션이다. 이 근사는 "STDP 고유성"이 아니라 1.3% 오차로 성립하는 특징 확장이다. 그러니 L의 정확도 기여를 STDP의 증거로 쓰지 않는 것이 맞다.

## 6. 순서부 O: 지연의 1차 유한차분 [주장]

O ≈ (v + αγΔv)(k̃ − αγΔk̃)ᵀ − Hebb이고, γ = Σ_k k·(1−λ)λ^k sin(kωT) = 0.662다(10-14 §6, 수치 [A]).

- 지연 커널 홀수부의 1차 모멘트만 효과를 내는 시간 Taylor 1차 절단이다.
- 일반화는 2차 이상 모멘트(Δ²v 등)까지 두는 것이다.
- 고정점에서 O ≡ 0이라는 정리는 홀수부를 시간 반전에 반대칭으로 세는 한, 지지 집합과 커널 모양에 무관하게 성립한다.

## 7. 칸 축 [주장]

- **STDP 짝은 같은 칸끼리만 맺는다(v_t ⊗ k_t).** 칸 사이는 읽기 ⟨k̃_s, q̃_t⟩로만 섞인다.
  - 일반화는 v_t(b−p) ⊗ k_s(b−q)에 공간 커널을 두는 공간×블록 2D 선형 어텐션이다.
  - 이것이 A의 가장 큰 표현 제약이다. "칸 s의 과거 키 → 칸 t의 값"이라는 시간 간선을 직접 쓰지 못한다.
- softmax 없는 읽기는 항등 특징맵 커널 어텐션이다. Q/K L2는 코사인 커널이다.
- 학습 2D RoPE는 상대 위치 쌍선형형 B(Δr, Δc)를 서로 가환인 2×2 회전의 직합 ⊕_j R(θ_row,j Δr + θ_col,j Δc)로 제한한 것이다.

## 8. 일반화할 때 정리들이 유지되는 조건 [주장]

| 정리 | 조건 |
| --- | --- |
| 블록 순서 = LTP/LTD 부호 | 짝을 이루는 pre·post가 같은 주파수를 써야 함(헤드별 또는 모드별; 채널별은 불가). 헤드별: 헤드마다 ω_h > 2c이고 K·ω_h + 2c < π. 다중 극: sin(kω_m) > 0인 범위에서 잔차 r_m ≥ 0 |
| 꼬리 부호 반전이 무시할 만함 | A에서 k ≥ 10 꼬리 무게 0.1% [A]. λ나 ρ를 키우면 이 조건부터 깨진다(B의 ρ 0.9 계획 시 확인) |
| O ≡ 0, L = κ·SB | 시불변 커널이면 유지. κ = h(0) + 2Re Σ h(k). B: κ_B = κ/(1−ρ) |

## 9. A를 정확히 포함하는 확장 후보 (비용 오름차순) [주장]

1. **복소 학습률 α̃**: 허수부를 0으로 초기화한다. 짝수 창(Re S)이 쓸모 있는지 바로 드러난다. 헤드당 파라미터 1개다.
2. **헤드별 블록 주파수 ω_h**: §8의 부호 조건 안에서 고정 다중 스케일로 둔다. 파라미터는 없다. 채널별 주파수는 창의 정상성을 깨므로 후보가 아니다(§4).
3. **지지 집합 확장**: 모델 B다.
4. **칸 사이 STDP 짝**: 표현력 확장이 가장 크고 비용도 가장 크다.
