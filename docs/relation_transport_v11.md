# v1.1: 어떤 과거 관계가 늦게 풀리는 빈칸을 움직이는가

## 이번에 확인한 범위

현재 체크포인트에서 외삽의 추가 해결을 크게 좌우한 것은 **위상 커널을 통해 읽는 값 관계 agree의 이력**이었다.
대칭 과거 보정에서 agree 변화에 해당하는 항을 제거하면 완답이 101→78,
위상 변화 항만 제거하면 101→100이었다. 현재 위상 커널 자체는 모든 이 비교에 남아 있다.

도움이 된 과거 보정에는 현재보다 강한 옛 관계를 유지하는 경우뿐 아니라,
**현재 갑자기 강해진 관계를 약하게 만드는 경우**도 많았다.
후자는 지금의 오답 표현과 잘 맞는 이웃 정보에 즉각적으로 더 큰 가중치를 주는 것을 완화할 수 있다.
실제 빈칸 전환에서 이 효과를 확인했고, 특정 연결 제거 후 긴 추론도 이어가 보았다.

이 결과는 학습된 v1.1의 동작에 대한 진단이다. 새로운 학습 없이 정답 관계를 판별하는
보편적 규칙을 증명하거나, 개선된 아키텍처를 학습해 검증한 결과는 아니다.

후속 [시점별 쓰기 분석](history_episodes_v11.md)에서는 이 사례를 더 분해했다.
현재 쓰기와 비교해 가장 도움이 된 연결과, 오답 구간에서 새롭게 유용하게 갱신된
연결은 달랐다. 과거 정답 상태의 잔존, 오답 구간의 새 갱신, 부호 있는 위상 커널이
만드는 억제·억제 완화를 구분한 결과를 해당 문서에서 설명한다.

## 1. 분석 방법과 정확한 분해

한 헤드에서 gain·거리·β를 포함한 **대칭 위상 커널**을 K,
정규화된 현재 값의 내적을 A=agree라 두면 현재 대칭 쓰기는 K⊙A다.
⊙는 칸 쌍별 원소 곱이며, 아래 곱은 모두 이 뜻이다.

같은 η로 보조 EMA를 계산해 다음을 얻었다.

\[
\bar K=\operatorname{EMA}(K),\quad
\bar A=\operatorname{EMA}(A),\quad
w^S=\operatorname{EMA}(KA).
\]

실제 과거 보정의 대칭 성분을 \(S=w^S-KA\)라 하면,

\[
\begin{aligned}
S&=S_{phase}+S_{agree}+S_{joint},\\
S_{phase}&=\tfrac12(\bar K-K)(\bar A+A),\\
S_{agree}&=\tfrac12(\bar A-A)(\bar K+K),\\
S_{joint}&=w^S-\bar K\bar A.
\end{aligned}
\]

마지막 항은 위상 커널과 agree가 함께 변한 EMA 공분산이다.
곱의 변화량을 두 인자에 순서를 정하지 않고 동등하게 배분한 항등식이다.
위상과 값 변화에 유일한 인과 원인을 배정하는 정리는 아니다.
코드는 합이 실제 S와 일치하도록 마지막 항을 잔차로 계산한다.

정상 모델은 보조 EMA를 읽지 않는다. 개입에서만 해당 항을 현재 읽기 기억에서 뺀다.
쓰기 갱신 자체와 순간 ψ 읽기, 순간 쓰기 G는 그대로 두며,
개입으로 바뀐 은닉 상태를 이용해 이후 계산과 기억 갱신을 계속한다.

실행 조건:

- `checkpoints/v1.1_step160000.npz`, EMA, FP32, autocast/TF32 off.
- held-out 앞 128문제, 배치 128을 모든 전체 추론 비교에서 유지.
- 동일한 16세그먼트 상태에서 분기해 128세그먼트까지 추론.
- 원래 정상 경로 75→101 완답을 재현. 이벤트 재실행에서도 측정 블록의 정상 예측 일치를 검사.
- 추론 규칙에 정답이나 Sudoku 제약을 추가하지 않음.
- 과거는 계산 블록의 이력을 뜻하며, 칸들의 물리적 발화 선후관계를 새로 가정하지 않음.

위 조건들은 처음 맞힌 75문제의 최종 정답을 모두 유지했다.

이 조건은 정상에서 풀던 4문제를 놓치고 다른 2문제를 새로 풀었으므로,
정상과 같은 문제를 동일하게 해결했다고 해석하지 않는다.

값 지연 개입은 **대칭 과거 보정 S에 곱하는 값만** 바꾼다.
순간 읽기와 현재 쓰기 계산에는 여전히 현재 값이 들어간다.
값 이력도 각 개입 경로에서 새로 갱신한다.

추가 대조로 기억의 읽기 기여 전체를 없애면,
\((1-\lambda)a\)만 남긴 조건과 계수까지 복원해 a만 남긴 조건 모두 완답이 0이었다.
따라서 아래 사례에서 순간 쓰기가 오답 방향을 보였다는 이유로
기억 경로 자체가 해롭거나 불필요하다고 해석할 수 없다.
이것은 기억과 함께 학습된 체크포인트의 의존성을 보여주는 제거 실험이다.

## 3. 실제 빈칸이 정답으로 넘어가는 순간

정상 추론에서 블록 128에 틀렸던 입력 빈칸 중,
마지막 오답 이후 끝까지 정답을 유지한 전환을 골랐다.
문제 전체도 최종 정답이어야 하고, 전환 뒤 최소 32블록이 남아야 한다.
이 조건에 해당한 것은 **25문제의 644개 빈칸 전환**이다.

전환 8·4·1블록 전과 전환 순간의 동일한 정상 상태에서,
각 메시지 성분을 제거한 바로 다음 출력을 비교했다.
아래 마진은 `정답 로짓 - 가장 큰 다른 로짓`이며,
값이 양수이면 원래 성분이 정답 마진에 도움이 됐다는 뜻이다.
문제 안의 전환들을 평균한 뒤 문제에 같은 가중치를 부여했다.

| 전환 순간 제거한 성분 | 원래 성분의 평균 정답 마진 기여 | 제거 시 그 순간 오답이 된 전환 |
|---|---:|---:|
| 대칭 과거 보정 전체 | +0.688 | 81 / 644 |
| agree 이력 | +0.696 | 82 / 644 |
| 위상 이력 | +0.0003 | 10 / 644 |
| 공분산 이력 | -0.006 | 0 / 644 |
| 단서 칸에서 오는 대칭 과거 보정 | +0.287 | 53 / 644 |
| 직전 출력이 정답인 다른 빈칸에서 오는 보정 | +0.497 | 53 / 644 |
| 직전 출력이 오답인 다른 빈칸에서 오는 보정 | -0.094 | 9 / 644 |
| 이웃 값 방향의 최근 8블록 변화분 | +0.319 | 48 / 644 |

출처 칸의 정답 여부는 직전 블록의 출력 기준이고,
그 칸의 은닉 메시지가 대상에게 유용하다는 뜻은 아니다.
출처 그룹은 진단에만 사용했다. 정답에 따른 메시지 선택 알고리즘을 실행한 것이 아니다.
여러 그룹의 동시 제거 효과는 비선형 정규화 때문에 단순히 더해지지 않는다.

전환 1블록 전에는 agree 이력을 제거해 오히려 일찍 정답이 되는 관측도 19건 있었다.
따라서 `과거 보정이 매 블록 단조롭게 정답으로 이동시킨다`는 설명도 성립하지 않는다.
644개 전환은 성공한 문제에서 고른 상관된 관측이며 독립적인 일반화 검증 644회가 아니다.

## 4. 어느 쪽 표현의 변화가 agree 이력을 만드는가

\(\mu_t=\operatorname{EMA}(\hat v_t)\)를 보조적으로 추적하면
\(\bar A-A\)를 다음 두 항으로 나눌 수 있다.

\[
\begin{aligned}
\Delta A_{target,tn}&=\tfrac12[\bar A_{tn}-A_{tn}
+\mu_t^T\hat v_n-\hat v_t^T\mu_n],\\
\Delta A_{source,tn}&=\tfrac12[\bar A_{tn}-A_{tn}
-\mu_t^T\hat v_n+\hat v_t^T\mu_n].
\end{aligned}
\]

이는 과거/현재의 대상과 출처 벡터를 교체하는 두 순서를 평균한 배분이다.
각 항에 \((\bar K+K)/2\)를 곱하면 agree 이력의 대상측·출처측 성분이 된다.
두 성분은 서로 전치 관계이며 합은 대칭이다. 각 성분 자체는 대칭일 필요가 없다.

| 제거한 agree 이력 성분 | 최종 완답 |
|---|---:|
| 대상측 변화 성분 | 81 |
| 출처측 변화 성분 | 91 |
| 단순히 agree 이력의 절반 | 85 |

전환 순간의 평균 정답 마진 기여는 대상측 +0.419, 출처측 +0.274였다.
따라서 `이웃만 새롭게 변하고 대상은 가만히 있는데, 옛 연결이 그 변화를 옮긴다`는 예시만으로
실제 동작을 전부 설명할 수 없다. 대상 표현이 변하면서 바뀌는 관계도 큰 역할을 한다.
절반 제거 대조 역시 성능을 크게 떨어뜨리므로, 삭제 성능 차이를 세기 변화와 분리된
유일한 인과 중요도 순위로 읽지 않는다.

## 5. 어떤 관계가 도움이 됐는가: 강화와 약화가 모두 존재

전환 순간에 실제 메시지 방향까지 고려한 1차 기여를 계산했다.
구체적으로 정상 정규화 전 은닉 상태에서 Φ의 야코비안을 통해
`정답 로짓 - 직전 오답 로짓`의 방향을 역전파하고,
각 \(\lambda S_{tn}W_{sh}^Tv_n\)와 내적했다.
이는 연결별 작은 변화의 방향을 설명하는 값이며,
앞 절의 실제 제거 결과 및 최종 완답 실험과 구분한다.

전체 대칭 과거 보정의 문제별 평균 순기여는 +0.681이었다.
그중 현재 쓰기와 기억의 부호가 같으면서 **현재 쓰기가 더 강한 연결을 약화하는 경우**가 +0.413,
옛 기억 쪽이 더 강한 관계를 유지하는 경우가 +0.165,
현재 쓰기와 기억의 부호가 다른 경우가 +0.103이었다.
이는 순기여의 합이며 연결 개수의 비율이나 각 분류의 유용성 예측 확률이 아니다.

정답 로짓 쪽 순기여는 +0.430, 직전 오답 로짓 쪽은 -0.251이었다.
따라서 현재 관측에서는 정답 후보를 높이는 작용과 오답 후보를 낮추는 작용이 함께 나타났다.
헤드 1·2(0부터 번호)의 순기여가 특히 컸지만,
이것을 해당 헤드의 고정된 의미적 역할로 확정하지 않는다.

## 6. 구체적인 연결을 제거한 사례

선택한 예시는 test index 1, 6행 4열의 빈칸이다.
블록 154에는 숫자 3을 출력했고 블록 155에 정답 1로 돌아왔다.
이는 처음 정답을 찾은 순간이 아니라 **마지막 오답에서 정답으로 돌아온 순간**이다.
대상은 블록 152·153에도 1을 출력했다. 또한 출처 8행 4열은
블록 129~147에는 4였고 블록 148부터 3이 됐다.
아래 헤드 번호는 0부터 센다. 숫자는 토큰 번호에서 원래 Sudoku 숫자로 변환했다.

이때 헤드 2가 8행 4열에서 받는 메시지를 보았다.
출처는 이미 숫자 3으로 맞게 풀린 빈칸이었다.

| 관계값 | 값 |
|---|---:|
| 현재 agree | 0.633 |
| 과거 EMA agree | 0.147 |
| 현재 대칭 위상 커널 K | 0.648 |
| 과거 EMA 위상 커널 | 0.792 |
| 현재 대칭 쓰기 G | 0.410 |
| 대칭 기억 w | 0.111 |
| 대칭 과거 보정 S=w-G | -0.299 |

0.633은 블록 155의 출력 **이전**, h154에 경계 MLP와 입력 주입을 적용한 뒤
계산하는 헤드 2 값 벡터 사이의 agree다. 출력 1이 만들어진 후의 유사도가 아니다.
0.147은 직전 블록의 agree가 아니라 현재 155블록 값까지 포함한 EMA다.
블록 154까지의 EMA는 0.132442이고, η≈0.029175로 현재 0.632904를 반영해 0.147043이 된다.
출력 숫자는 갱신 후 전체 은닉 상태의 분류 결과이고, agree는 갱신 전 한 헤드의 값 내적이므로
같은 숫자를 출력하는 것만으로 높은 agree가 보장되지는 않는다.
위 제거 실험은 agree나 v를 변경하지 않고, 동일한 현재 값에 적용되는 과거 보정을 제거한다.
실제 두 칸의 이력: `runs/relation_transport_v11/case_8_timing.json`.

현재 값 유사도만 반영하면 이 연결에 훨씬 큰 양의 쓰기가 생긴다.
과거 보정은 그 연결의 기여를 줄인다. 실제 제거 결과:

| 블록 155 계산 | 1의 로짓 | 3의 로짓 | 1−3 마진 | 출력 |
|---|---:|---:|---:|---:|
| 정상 | 11.178 | 10.864 | +0.314 | 1 |
| 그 연결 하나의 대칭 과거 보정만 제거 | 11.093 | 11.501 | -0.408 | 3 |

이 연결의 과거 보정은 주로 **3 쪽 신호를 낮춰서** 정답 전환에 기여했다.
출처의 3은 출처에게 맞는 답이지만, 대상에게는 틀린 답이었다.
따라서 올바른 출처를 더 강하게 읽는 것만으로 유용성을 설명할 수도 없다.

반대 방향의 예도 같은 순간에 존재한다. 8행 1열의 단서 1에서 받는 헤드 2 메시지는
현재 쓰기 -0.228, 기억 -0.108, 보정 +0.119였다.
그 보정을 제거하면 대상의 1 로짓이 11.178→10.861로 떨어지고 출력이 3으로 바뀌었다.
이는 현재의 더 강한 음의 결합을 완화하여 정답 쪽 신호를 살리는 사례다.

정상 상태의 공통 Φ 분모로 출력 마진을 대수적으로 나누면 다음과 같았다.

|---|---:|
| 경계 연산·입력 주입 후 은닉 상태 | -2.450 |
| 순간 ψ 읽기 | +3.841 |
| 순간 쓰기 G의 읽기 기여 | -2.290 |
| 전체 과거 보정 w−G | +1.236 |
| 분류기 bias | -0.023 |
| 합 | +0.314 |

이 표는 정상 계산에서의 정확한 대수 분해다.
각 항을 제거했을 때 Φ 분모도 바뀌므로 개입 효과를 그대로 더한 표는 아니다.
이 사례에서는 ψ 읽기가 정답 방향을 제공하는 한편, 순간 쓰기의 일부가 오답 방향을 보였고,
과거 보정이 그 영향을 상쇄했다. 전체 모델에서 항상 같은 부호가 성립한다는 주장은 하지 않는다.

### 제거한 뒤 추론을 계속하면

같은 블록 154 상태에서 시작해 블록 155의 메시지를 바꾸고 1024까지 계속했다.
변경은 선택한 대상 칸의 수신 메시지에만 적용했다.

- 가장 큰 기여의 연결 하나를 한 번 제거하거나 계속 제거하면, 대상은 블록 156에 다시 정답을 찾았다.
- 상위 연결 3개를 계속 제거해도 블록 156에 정답을 찾았다.
- 대상에게 들어오는 agree 이력 전체를 한 번 또는 계속 제거해도 블록 156에 정답을 찾았다.
- 모든 조건에서 문제 전체의 첫 완답은 블록 156이고 최종 정답도 유지됐다.

첫 완답 이후에도 잠시 오답이 재발했다. 정상과 `pulse_top1`은 블록 158·159에
8행 5열이 틀렸고 160부터 관측 끝까지 완답을 유지했다.
나머지 위 조건은 마지막 전체 오답이 블록 160이므로 정착 시작은 161이다.
따라서 첫 완답 시점이 같다는 결과를 정착 시점까지 같다는 뜻으로 읽으면 안 된다.
이 차이를 추적한 후속 분석은 [settling_v11.md](settling_v11.md)에 기록했다.

즉, 그 연결은 **블록 155의 전환에는 기여했지만 그 문제의 최종 해결에 필수적이지 않았다.**
다른 칸의 상태와 갱신 경로가 남아 있는 조건에서 다음 블록에 정답으로 회복되는 것을 관측했다.
단일 전환 사례의 필요성과 전체 관계 경로의 장기 필요성을 구분해야 한다.

## 7. 이론을 어떻게 좁힐 수 있는가

현재 자료에서 지지되는 설명은 다음과 같다.

1. 학습된 위상 커널이 어떤 칸의 어떤 관계를 어떤 부호로 반영할지 정한다.
2. 현재 값 유사도 agree는 그 관계의 쓰기 세기를 바꾼다.
3. agree의 이력은 현재 표현의 급격한 변화가 즉각 관계 강화·억제로 이어지는 것을 조절한다.
4. 조절된 관계로 현재 이웃 값을 읽으면 정답 쪽 정보가 살아나거나 오답 쪽 정보가 줄어드는 경우가 있다.
5. 이 변화가 다른 칸의 다음 표현과 관계에 다시 반영되며, 국소 경로가 없어도 대체 경로로 회복할 수 있다.

따라서 `안정된 위상은 정답 관계다`보다
**학습된 위상 관계 위에서, 현재 값 유사도에 따른 즉각적인 결합 변화를 과거 이력이 어떻게 조절하는가**가
다음 구조 개선을 위한 더 구체적인 분석 대상이다.

이 조절이 언제 도움이 되고 언제 유용한 새 관계의 형성을 지연시키는지는 아직 일반적으로 풀리지 않았다.
이번 성공 전환 집합에서도 역효과가 있었으므로, 모든 변화에 더 큰 관성을 주자는 설계 결론은 나오지 않는다.
