# 인지 지도로서의 규칙 시냅스: 하나의 원리에서 쌓은 설계 (2026-10-21)

> 앞 문서 `claude_2026-10-21_minimal_rule_synapse.md`(이하 "최소 문서")의 정리 0, 명제 1–4는 그대로 쓴다. 그 문서의
> §9–11은 약점마다 처방을 따로 붙였다(모서리 틀, 기준점 세 종류, 위치·내용 두 단계, 크기 시냅스, 색 불변 값). 이 문서는
> 그것들을 하나의 원리로 대체한다. 실험 결과는 근거로 쓰지 않는다.

## 0. 원리

> **규칙은 "내용이 정한 틀(기준틀) 안에서 고정된, 구조 코드 위의 성긴 작용"이다. 시범은 그 작용을 빠른 시냅스에 쓰고,
> 질의는 그 작용으로 자기 입력의 기억을 읽는다.**

영감은 두 곳이고, 둘은 같은 생각의 양면이다.

- **해마의 인지 지도(TEM).** Whittington et al.(*Cell* 2020)의 Tolman-Eichenbaum Machine은 환경마다 처음 보는 감각을, 환경
  사이에 공유되는 구조 코드(격자세포: 경로 적분에 등변인 주기적 위상 코드)와 헤브 외적으로 묶어 몇 번의 경험으로 일반화한다.
  이것을 트랜스포머로 다시 쓰면, 키·질의가 학습된 RoPE류 위치 코드이고 값이 감각인 어텐션이 된다(Whittington, Warren &
  Behrens, ICLR 2022). 구조(어디)와 내용(무엇)을 나누고, 결합은 빠른 기억에, 구조는 느린 학습에 둔다.
- **게이지 등변성과 학습된 정준화.** 칸마다 국소 기준틀을 두고 규칙을 그 틀에서 고정된 것으로 쓴다(Cohen et al., ICML 2019).
  입력을 내용이 정한 정준 틀로 옮겨 단순한 함수를 적용하고 되돌린다(Kaba et al., ICML 2023).

ARC에 옮기면: 격자 = 환경, 칸의 색 = 감각, 규칙 = 구조 코드 위의 행동(변환), 시범 = 그 환경에서의 경험, 질의 = 새 위치에서의
예측이다. 다른 점은 하나다. TEM에서 행동은 주어지고 지도가 학습되지만, ARC에서는 지도(코드)가 과제 사이에 공유되고 **행동
(규칙)을 시범에서 추론**한다.

## 1. 대칭군과 그 표현

ARC의 형식에 들어 있는 변환들은 하나의 군으로 묶인다.

```
𝔊 = (ℤ² 이동 ⋊ D4) × S(색)        (+ 틀의 배율: 아래 §3.3)
```

- **구조 코드는 𝔊의 공간 성분의 표현이다.** 위치 p의 코드 g(p) ∈ ℝ^{2K}, 채널 쌍 k마다 (cos θ_k·p, sin θ_k·p).
  - 이동 a는 대각 회전 R(a) = ⊕_k rot(θ_k·a)로 작용한다. 연속 기준점(§2)을 쓰려면 이 꼴이 강제된다(최소 문서 명제 5:
    ℝ²의 연속 직교 표현은 회전 블록의 직합).
  - D4는 주파수 집합에 작용한다(θ ↦ dθ). 주파수 집합을 D4에 닫히게 두면(기본 주파수 K/8개를 학습하고 그 D4 궤도를 씀),
    D4의 각 원소는 채널의 부호 있는 순열, 즉 단항 행렬로 작용한다. 이것은 손 사전이 아니라 데이터 증강에 이미 쓰는 군에
    표현을 맞추는 것이다. 주파수 값 자체는 학습된다(무작위 시작).
  - 그러면 **𝔊의 공간 원소는 모두 코드에서 성긴 행렬**(이동: 대각, D4: 단항)이다. "법칙이 코드에서 성기다"(조건 L)가 군
    원소에 대해서는 구조로 성립하고, 학습에 남는 것은 군 원소가 아닌 법칙들(합, 제한, 합성)이다.
- **내용 코드는 색의 원-핫**이다. 색 순열은 순열 행렬로 작용한다(성김).
- 규칙의 기본 단위는 군의 표현 원소 A ⊗ Π(공간 작용 ⊗ 색 작용)이고, 일반 규칙은 그런 항들의 성긴 합이다(§3.2).

## 2. 틀 = 내용이 정한 상자

- **틀은 상자다:** 기준점(위치), 범위(h, w), 방향(D4 원소). 격자 전체가 기본 틀이고, 그 네 모서리는 방향만 다른 같은 상자다
  (최소 문서 명제 1이 이 경우다).
- **느린 지각이 틀을 고른다.** 격자 안 어텐션(느린 헤드)이 상자 M개를 낸다. 상자 질의 벡터가 칸들에 어텐션해서 기준점(칸
  좌표의 부드러운 평균)과 범위(부드러운 최소·최대)를 계산한다. 칸마다 "자기가 속한 물체의 상자"도 같은 방식으로 낸다.
- **틀 안의 코드:** 상자 b 안의 칸 s는 g_b(s) = 상자 방향을 적용한 g(s − 기준점)이고, 상자 밖이면 0이다. 0이 되는 것이 곧
  "이 틀의 규칙은 상자 안에만 적용된다"는 마스크다.
- **등변:** 상자를 등변으로 계산하면(지각이 회전된 격자에서 회전된 상자를 냄) 틀은 군 작용을 따라 옮겨진다. 그래서 퍼즐
  임베딩의 증강판 켤레(최소 문서 명제 3)가 틀이 늘어나도 그대로 성립한다.

## 3. 규칙 시냅스

### 3.1 기억(그림)과 읽기 = 어텐션

- 격자의 **기억**: 틀 b마다 M_b(X) = Σ_s x(s) g_b(s)ᵀ (c × 2K). TEM의 해마 결합(내용 ⊗ 구조)이고, 최소 문서의 "그림"이다.
- **읽기**: 출력 칸 o의 내용 = Π M_b(X) A g_{b′}(o), 곧

  ```
  ĉ(o) = Π Σ_s x(s) ⟨ g_b(s),  A g_{b′}(o) ⟩         = 어텐션: 질의 A g(o), 키 g(s), 값 x(s)
  ```

  규칙 A는 **질의를 돌리는 빠른 가중치**(빠른 W_QK)다. 출력 칸의 틀 b′는 짝 입력의 상자에서 온다(질의 출력은 내용이 없어
  스스로 틀을 못 찾는다).

### 3.2 일반 규칙: 틀별 항의 성긴 합

```
ĉ(o) = Σ_{(b, b′)} Π_{b b′} M_b(X) A_{b b′} g_{b′}(o) + B̂ g(o)
```

- 항 하나 = (입력 틀 b, 출력 틀 b′)에서의 군 작용 쌍(A, Π). B̂는 입력과 무관한 상수(정해진 칸에 정해진 색).
- 정규화: 틀 블록마다 그룹 희소(‖A_{bb′}‖_F 합)와 블록 안 ℓ1. **그룹 희소가 틀을 고르고 ℓ1이 그 틀 안의 작용을 고른다.**
  "어느 물체를 기준으로 볼지"를 따로 학습된 선택기가 아니라 같은 단순성 원리가 정한다.
- 사전 중심: 퍼즐 임베딩 e_τ에서 디코딩한 (A⁰, Π⁰, B̂⁰). 새 과제는 공유 사전(증강 불변 부분공간, 최소 문서 §4.6).
  신경과학의 말로는 "도식(schema)"이다. 이미 아는 도식이 있으면 새 학습이 빠르다(Tse et al., *Science* 2007).

### 3.3 크기와 주기

- **출력 범위 = 규칙이 쓰는 출력 틀의 상자.** 같은 크기는 격자 상자, 물체 잘라 내기는 물체 상자, 전치는 상자의 방향, k배는
  상자 범위의 배율이다. 크기를 위한 별도 장치(최소 문서의 크기 시냅스)가 필요 없다.
- **배율 틀(정규화 좌표).** 상자 범위로 나눈 좌표 u = p / h에서도 코드를 둔다: g^{norm}_b(s) = (cos θ_k·u, sin θ_k·u).
  배율 변환은 u를 곱하는 것이라 주파수를 옮기는(채널 순열에 가까운) 작용이다. θ_k가 2π의 정수배 근처로 학습되면 코드가
  u에 주기 1, 곧 p에 주기 h가 되어 **타일링(p mod h)이 군 작용 하나**가 된다. 원환을 손으로 넣는 것이 아니다. 주파수는
  학습되고, 주기성이 쓸모 있는 과제에서만 그 근처로 간다. 이것이 표현되는지는 학습에 거는 것이다.

### 3.4 쓰기 = 근접 경사 (가소성)

- 시범 i의 관측: 입력 기억 M_b(X_i), 출력 칸들의 주어진 색 y(o).
- min Σ_i Σ_{o∈out_i} ½‖y(o) − ĉ_i(o)‖² + (그룹 희소 + ℓ1)(규칙 − 사전 중심). 블록(A, Π, B̂)을 번갈아 근접 경사로 푼다. 각
  블록은 볼록이고, 걸음은 블록별 립시츠 상수의 역수다(최소 문서 §4.3). 델타(오차 × 기억) + 일정 LTD + 사전 중심 하한이다.
- 정리 0이 각 블록에서 그대로 성립한다. 측정 사상의 영공간 성질은 구조 코드 위에서 잰다.

## 4. 토큰의 두 흐름과 재귀

- **관측 흐름**(고정): 토큰마다 주어진 색, 역할, 쌍 번호. 시범 출력 칸의 관측은 주어진 답이고, 질의 출력 칸의 관측은 비어 있다.
- **추론 흐름**(진화): 은닉 h. 느린 지각(격자 안 어텐션 + FFN)이 h를 다듬고 틀(상자)을 낸다. 규칙 시냅스의 읽기는 h에만 더한다.
- **쓰기의 목표와 기억은 언제나 관측 흐름에서 온다.** 틀(어디서 잴지)만 추론 흐름에서 온다. 그래서 목표가 모델 자신의 예측으로
  오염되는 퇴화 고정점(최소 문서 §10.8 약점 1)이 구조적으로 없다. TEM이 추론 경로(기억에서 예측)와 관측을 나누는 것과 같다.
- **재귀**: 블록 하나를 R번 반복한다. 반복마다 지각이 틀을 다듬고, 규칙 시냅스가 근접 경사를 한 걸음 이어서 한다(빠른 상태는
  반복·세그먼트를 넘어 이어짐). 결합 고정점에서 틀이 멈추면 규칙은 그 틀에서의 lasso 해다(최소 문서 §10.3a). 학습은 고정점의
  암묵적 미분이 기본, 1-step 기울기가 대안이다.
- **경로 적분.** "장애물까지 민다"처럼 경로가 필요한 규칙은 같은 작용을 반복 적용하는 것이다. 재귀가 그 반복을 준다. 질의
  출력 칸의 추론 흐름이 매 반복 읽기를 받아 갱신되므로, 작용 A를 R번 적용한 결과가 표현될 수 있다(표현됨이 증명된 것은 아니다).
- **격자 사이 경로는 규칙 시냅스뿐이다**(최소 문서 명제 4). 느린 지각은 격자 안에서만 본다.

## 5. 약점이 귀결로 떨어지는 모습

| 최소 문서 §10.8의 약점 | 이 원리에서 |
|---|---|
| 1. 목표 오염 | 관측 흐름과 추론 흐름의 분리. 목표는 관측에서만 |
| 2. 내용으로 정해지는 크기 | 출력 범위 = 출력 틀의 상자. 상자는 내용이 정함 |
| 3. 내용에 따라 다른 위치 | 틀을 내용이 정함(게이지). 틀 안에서 규칙은 고정 |
| 4. 위치를 풀 때 색이 방해 | 공간 작용 A와 색 작용 Π가 한 항의 두 인자(A ⊗ Π). 구조와 내용의 분리 |
| 5. 학습에 거는 것 | 셋으로 정리됨(§6) |
| 6. 크기에 따른 비용 | 코드 차원 2K가 격자 크기와 무관. 항당 A는 2K × 2K |
| 7. 타일링 | 배율 틀의 주기 코드 |
| 8. 고정점 수렴 | 그대로 남음(잔차로 측정) |

## 6. 구조로 보장되는 것과 학습에 거는 것

- **구조로 보장:** 형식(관측/추론 분리, 짝, 격자 사이 경로), 선택 원리(그룹 희소 + ℓ1 + 사전 중심), 블록별 수렴(걸음),
  누설 없음, 증강 켤레(틀이 등변일 때), 군 원소의 성김(이동은 대각, D4는 단항, 색 순열은 순열).
- **학습에 거는 것(셋):**
  1. 지각이 쓸모 있는 틀(상자)을 찾는다.
  2. 군 원소가 아닌 법칙(합, 제한, 합성)이 코드에서 성기다.
  3. 시범이 그 성긴 해를 정한다(영공간 성질).

## 7. 부품 목록

| 부품 | 느림/빠름 | 내용 |
|---|---|---|
| 구조 코드 g | 느림(공유) | 학습된 주파수, D4에 닫힌 주파수 집합. 절대 좌표판과 정규화 좌표판 |
| 지각 | 느림 | 격자 안 어텐션(RoPE = g) + FFN, 상자 M개와 칸별 물체 상자를 냄 |
| 기억(그림) | 매 반복 계산 | 관측 색 ⊗ 틀 코드의 합 |
| 규칙 시냅스 | 빠름(과제별) | 틀 쌍별 (A, Π)와 B̂, 근접 경사(델타 + LTD), 사전 중심 = 퍼즐 임베딩 |
| 재귀 | – | 지각과 규칙의 결합 고정점, 암묵적 미분 |

최소 문서의 M0는 이 구성에서 틀 = 격자 모서리 넷, 지각 없음, 정규화 좌표판 없음, 재귀 없음인 경우다.

## 8. bands로 승격

- 구조 코드 g = 학습된 RoPE. bands가 이미 키에 쓰는 것이다.
- 기억 M_b = Σ x(s) g_b(s)ᵀ는 RoPE 키의 헤브 합이다. bands의 흔적곱에서 시간 창을 "같은 격자, 같은 틀"의 소속으로 바꾼 것이다.
- 규칙 시냅스 = bands 누적기 W에 델타 항과 근접 사상(그룹 희소 + ℓ1, 사전 중심)을 건 것이다. 읽기는 질의를 A로 돌린 어텐션이다.
- 틀 = frame_rope의 일반화다(내용이 정한 위상으로 코드를 돌림 + 상자 마스크 + 방향).

## 9. 검증할 예측

1. 그룹 희소를 끄면(틀 선택 없음) 틀이 여럿인 과제에서 떨어진다.
2. 관측/추론 분리를 끄면(목표를 은닉에서 뽑음) 학습 손실은 내려가는데 질의 정답이 떨어진다(퇴화 고정점).
3. D4에 닫힌 주파수 집합을 풀면(주파수를 자유롭게) 회전·반전 과제의 시범 효율이 떨어진다.
4. 학습 후, 학습 과제의 규칙이 몇 개의 틀 블록에 모이고 블록 안이 성긴지(조건 L의 직접 측정).

## 10. 구체 명세 v1

> **§12(명세 v2)가 대체한다.** v1은 규칙 종류마다 그 규칙을 선형으로 만드는 표현(상자, 광선, 색 기준점, 개수)을 손으로
> 넣었다. 정리 0은 표현이 무엇이든 성립하므로 그럴 필요가 없었다. 아래는 그 과정의 기록이다.

§0–9는 원리와 부품까지였다. 아래는 구현할 수 있는 수준으로 정한 것이다. 정하지 못한 것은 10.9에 모았다.

### 10.1 중심 원점과 D4 (명제 6)

상자 중심 c_b를 원점으로 두면 D4 원소 d는 중심 좌표에 선형으로 작용한다: x = p − c_b ↦ d x. 주파수 집합 Θ가 D4에 닫혀
있으면(θ ∈ Θ ⇒ dᵀθ ∈ Θ) cos(θ·dx) = cos((dᵀθ)·x)이므로, d는 코드의 **고정된 채널 순열**이고 격자·상자 크기와 무관하다.
수치 확인: 무작위 기본 주파수 2개의 D4 궤도(16개), 크기 1–6의 모든 (h, w), D4 원소 8개 전부에서 최대 오차 2×10⁻¹⁶.

- 그러므로 방향을 위한 틀(최소 문서의 모서리 넷)은 필요 없다. 방향은 규칙 A 안의 단항 작용이다.
- 모서리는 "가장자리 기준 이동"(바닥으로 떨어뜨리기, 위쪽 가장자리에 붙이기)을 위해서만 원점으로 남긴다. 이런 이동은 중심
  기준으로는 크기에 따라 다르고, 해당 모서리 기준으로는 고정이다.

### 10.2 지각: 상자

격자마다, 추론 흐름 h(s)에서:

- **격자 상자** b_0: 격자 전체(소속 1).
- **내용 상자** b_1..b_M (M = 3): 상자 질의 q_m(느린, 학습)마다 소속 α_m(s) = σ(⟨q_m, W_α h(s)⟩).
  - 범위: 행 방향 부드러운 최소·최대 r_min = Σ_s softmax_s(−r_s/τ + log α_m(s)) r_s, r_max도 같은 방식(열도 같음).
  - 중심 c = ((r_min + r_max)/2, (c_min + c_max)/2), 범위 e = (r_max − r_min + 1, c_max − c_min + 1).
- **자기 물체 상자** b_obj(s): 칸 s마다 같은 격자의 칸 t에 대한 소속 α(s, t) = σ(⟨W_q h(s), W_k h(t)⟩)로 위와 같은 범위를 낸다.
- 상자 질의는 색에 불변인 특징에서 계산한다(색 순열 켤레가 성립하도록). 지각의 어텐션은 구조 코드 g를 RoPE로 쓴다.
- 소속 α 자체가 그 틀의 마스크다(직사각형이 아니라 물체 모양).
- 상자 번호 m은 질의 q_m으로 정해지므로, 에피소드가 달라도 "m번 상자"는 같은 종류다. 사전 중심의 색인이 의미를 갖는 근거다.

### 10.3 원점과 코드

- 상자마다 원점 6개: 중심(절대), 네 모서리(절대), 중심(정규화 u = x / e).
- 상자 5개(격자, 내용 3, 자기 물체) × 원점 6 = **입력 틀 30개**.
- 코드: g(x) = [cos θ·x, sin θ·x]_{θ∈Θ}, Θ = 기본 주파수 2개의 D4 궤도(16개) → 2K = 32차원. 기본 주파수는 학습(무작위 시작).
- 틀 f = (상자 b, 원점 z)에서 칸 s의 코드: g_f(s) = α_b(s) · g(p_s − z_b)(정규화 원점이면 (p_s − c_b) / e_b).

### 10.4 출력 쪽: 크기 먼저, 그다음 틀

- **크기**: e_out = Σ_b β_b ⊙ e_b + β_0, 후보는 짝 입력의 상자 5개의 범위(행·열 따로) + 상수. β는 시범 크기 쌍에 대해 같은
  근접 경사(사전 중심 + ℓ1)로 맞춘다. 같은 크기(β_격자 = 1), k배(β = k), 잘라 내기(β_물체 = 1), 고정 크기(β_0)가 원소 한두 개다.
  질의에서는 반올림한다. 학습 손실에는 참 크기를 쓴다.
- **출력 틀**: 출력 격자 자신의 원점 6개(크기를 알면 정해짐) + 짝 입력 상자들의 원점을 출력 캔버스로 옮긴 것(좌상 정렬,
  25개) = **출력 틀 31개**. 뒤쪽은 "파란 물체 기준 위치"처럼 출력 위치를 입력 물체에서 잴 때 쓴다.

### 10.5 규칙: 항 J개, 항마다 틀 쌍을 고른다

```
ĉ(o) = Σ_{j=1..J}  Π_j  Σ_{(f, f′)}  ω_j[f, f′]  M_f  A_j  g_{f′}(o)   +   B̂ g_out(o)
       M_f = Σ_{s∈짝 입력} x(s) g_f(s)ᵀ   (c × 2K, 관측 색으로 만든 기억)
```

- 항 하나 = (공간 작용 A_j ∈ ℝ^{2K×2K}, 색 작용 Π_j ∈ ℝ^{c×c}, 틀 쌍 가중 ω_j ∈ ℝ^{30×31}).
- 틀 쌍마다 A를 따로 두면 930블록이 된다. 대신 항마다 A 하나와 성긴 틀 쌍 가중을 둔다. 대부분의 규칙은 틀 쌍 한두 개에서
  하나의 작용이기 때문이다. 여러 부분이 다르게 움직이는 규칙은 항을 여럿 쓴다(J = 4).
- 정규화 = **희소 LTD**: ‖A_j − A⁰_j‖₁ + ‖Π_j − Π⁰_j‖₁ + ‖ω_j − ω⁰_j‖₁ + ‖B̂ − B̂⁰‖₁. 근접 사상은 원소별 소프트 문턱
  (사전 중심 쪽으로 일정량씩 깎는 LTD)이고, 틀 쌍 가중 ω에 거는 것은 틀 블록 단위로 깎는 그룹 문턱(틀 하나를 통째로 끄는 LTD)이다. 사전 중심은 퍼즐 임베딩 e_τ의 디코더에서 온다.
  새 과제는 공유 사전(A⁰ = I, Π⁰ = I, ω⁰ = 격자 중심 ↔ 출력 격자 중심의 한 칸)에서 시작한다.
- 풀이: 블록 (A_j), (Π_j), (ω_j), (B̂)를 번갈아 근접 경사 한 걸음씩. 각 블록은 다른 블록을 고정하면 선형 최소제곱 + ℓ1이라
  볼록이고, 걸음은 블록별 립시츠 상수의 역수(거듭제곱법 2–3회로 추정)다. 전체는 다중선형이라 비볼록이고, 사전 중심이
  시작점이자 끌개다.
- 항들 사이의 대칭(항 순서 바꾸기)은 사전 중심이 깬다(항 j의 중심이 서로 다름).

### 10.6 재귀 한 걸음

```
입력: 관측(색, 역할, 쌍), 추론 흐름 h, 빠른 상태 θ = {A_j, Π_j, ω_j, B̂, β}, 사전 중심 θ⁰
1. 지각:      h ← 격자 안 어텐션(h; RoPE = g) + FFN          (느린, 격자 안만)
2. 틀:        상자 5개/격자, 원점 6개 → 틀 코드 g_f(s); 출력 크기 e_out = β·(상자 범위)
3. 기억:      시범 입력·질의 입력마다 M_f = Σ x(s) g_f(s)ᵀ      (관측 색으로)
4. 쓰기:      θ ← 근접 경사 한 걸음 (시범 출력 칸의 관측 색을 목표로, 블록 번갈아)
5. 읽기:      모든 출력 칸 o에 ĉ(o) (위 식)
6. 되먹임:    h(o) ← h(o) + W_c ĉ(o)                       (추론 흐름에만)
출력: 질의 출력 칸 색 = softmax(ĉ(o)/τ), 크기 = 반올림(e_out)
```

- 쓰기(4)의 목표와 기억(3)은 관측에서만 온다. 지각(1)과 틀(2)만 추론 흐름을 쓴다. 되먹임(6)은 다음 반복의 지각이 "지금까지의
  예측"을 보게 해서 틀을 고칠 수 있게 한다.
- 손실: 질의 출력 칸 색의 교차 엔트로피(참 크기 안) + 크기 손실. 학습은 고정점의 암묵적 미분(대안: 1-step).

### 10.7 크기와 비용 (Mini-ARC, 배치 64)

| 항목 | 값 |
|---|---|
| 코드 2K | 32 |
| 입력 틀 / 출력 틀 | 30 / 31 |
| 빠른 상태 원소 (항 4개) | A 4×1,024 + Π 4×100 + ω 4×930 + B̂ 320 + β 12 ≈ 8.5천 |

빠른 상태가 작아 재귀 R = 16번 전부를 펼쳐도 부담이 없다. 토큰 신경망은 지각뿐이다.

### 10.8 최소 문서 M0와의 관계

M0 = 이 명세에서 상자 = 격자 하나, 원점 = 네 모서리(방향을 틀로 처리), 항 1개, 지각 없음, 재귀 없음. 10.1 이후로는 방향을 A가
맡으므로 원점 네 개가 하나(중심)로 줄고, 모서리는 가장자리 기준 이동용으로만 남는다.

### 10.9 아직 정하지 않은 것

1. **반복 적용 규칙(경로 적분)의 읽기 출처** — 10.10에서 광선 기준점으로 정함(쌓이는 경우만 미검증).
   원래 문제: 지금 질의 읽기는 질의 입력의 기억에서만 한다. "장애물까지 한 칸씩"을 같은 작용의
   반복으로 쓰려면, 다음 반복의 읽기가 "현재 예측한 출력"의 기억에서 와야 한다. 그런데 시범에서는 최종 출력만 관측된다.
   선택지: (a) 반복 횟수를 고정한 다단계 작용 A^k를 쓰기 목표로 맞춤(다중선형, 비볼록), (b) 지각이 경로의 끝(장애물 위치)을
   상자로 찾게 해서 한 번의 이동으로 바꿈(틀로 흡수). (b)가 이 원리에 맞지만 지각의 부담이 커진다.
2. 소속 α를 직사각형 상자로 할지 물체 모양으로 할지(지금은 물체 모양).
3. 상자 수 M과 항 수 J의 크기. 그룹 희소로 쓰이지 않는 상자는 꺼진다.
4. 출력 크기의 이산성: 반올림의 기울기(학습은 참 크기로 하므로 추론에서만 반올림).
5. 지각의 학습 신호는 전부 규칙 추론을 통해서 온다(지각 자체의 손실은 없음). 이것으로 충분한지는 학습에 거는 것이다.

### 10.10 반복 규칙("~에 닿을 때까지")의 처리: 광선 기준점

**관찰.** ARC의 "까지" 규칙(떨어뜨리기, 선 늘이기, 닿을 때까지 밀기)은 경로를 따라 반복하는 것처럼 보이지만, 결과만 보면
**경로의 끝점을 기준으로 한 고정 이동**이다. 떨어지는 물체: 출력 위치 − (아래쪽 첫 장애물) = 입력 위치 − (물체 바닥) + 상수.
선 늘이기: 출력 칸은 "벽까지의 광선 위에 있으면" 칠해진다. 끝점만 알면 규칙은 한 번의 작용이다.

**설계.** 끝점을 지각이 찾는 틀(기준점)로 둔다.

- 칸(또는 자기 물체 상자의 가장자리)마다 방향 δ ∈ 𝒟(상하좌우 + 대각 4 = 8방향, D4에 닫힘)로 광선을 쏘아, 처음 만나는
  배경 아닌 칸(또는 격자 경계)을 **광선 기준점** a_δ(s)로 둔다. 지각이 방향 마스크를 건 격자 안 어텐션(광선 위의 칸들에만
  어텐션, 가까운 칸에 큰 가중)으로 계산한다. 가중이 거리의 학습된 감소 함수라 손 규칙이 아니다.
- 광선 기준점은 틀 집합에 8개를 더한다(입력 틀 30 → 38). 출력 쪽에서도 짝 입력의 광선 기준점을 출력 캔버스로 옮겨 쓴다.
- 광선 위 여부(칸이 어떤 칸의 광선 위에 있나)는 그 기준점 틀의 소속(마스크)이 된다. "벽까지 칠하기" = 그 마스크 안에서 Π.
- D4 등변: 방향 집합이 D4에 닫혀 있으므로, 회전된 격자에서는 광선 기준점이 회전된 방향의 것과 바뀐다(틀의 고정 순열).
  명제 3(증강 켤레)이 유지된다.

**희소 LTD와의 관계.** 광선 기준점은 후보 틀을 늘릴 뿐이고, 어느 틀을 쓸지는 희소 LTD(틀 쌍 가중 ω의 그룹 문턱)가 고른다.
격자 틀에서 "닿을 때까지"는 시범마다 이동 거리가 달라 하나의 성긴 작용으로 맞지 않고(시범들을 평균한 조밀한 해가 된다),
광선 기준점 틀에서는 고정 이동 하나로 맞는다. 그러므로 가장 짧은 기술을 고르는 희소 LTD가 광선 틀을 고른다. 희소 LTD가
못 하는 것은 "…할 때까지"라는 정지 조건 자체를 선형 작용으로 만드는 것이다. 정지는 비선형(막힌 칸은 안 움직임)이라 후보
틀(지각)이 대신 준다.

**왜 이것이 원리에 맞나.** 반복(경로 적분)을 빠른 쪽(규칙)에 두면 시범에서 중간 상태가 관측되지 않아 쓰기가 비볼록해진다
(10.9의 선택지 (a)). 반복을 느린 쪽(지각)이 끝점을 찾는 계산으로 옮기면, 빠른 쪽은 여전히 "틀 안의 고정 작용 한 번"이고
쓰기는 블록별로 볼록하다. 지각의 반복은 재귀(R번 반복)가 준다: 광선 어텐션이 반복마다 다듬어진다.

**손 사전 표시.** 방향 8개와 "광선 위의 칸만 본다"는 마스크는 ARC 내용 지식("물체는 직선을 따라 가다 장애물에서
멈춘다")을 손으로 넣은 것이다(어텐션 그래프에서 같은 직선 위가 아닌 간선을 지움). 지지는 자르지 않는다(틀 후보를 더할
뿐). 학습된 대안: 칸마다 학습된 기준점 질의 K개(내용 항 + RoPE 상대 위치 항으로 점수, 간선을 지우지 않음, D4 상은 주파수
순열로 생성). 광선은 이것이 배울 수 있는 것 중 하나다. 현재 설계는 광선을 기본으로 둔다(2026-10-21 결정).

**남는 것.** 물체끼리 쌓이는 떨어뜨리기(위 물체의 끝점이 아래 물체가 떨어진 뒤의 위치에 달림)는 끝점이 출력에 의존한다.
되먹임(10.6의 6)으로 지각이 "지금까지 예측한 출력"을 보고 광선 기준점을 다시 계산하면 재귀 반복마다 한 층씩 정리될 수 있다.
이것이 실제로 수렴하는지는 미검증이다. 홍수 채우기처럼 끝점 하나로 줄지 않는 규칙(닫힌 영역 안)은 "닫힌 영역" 소속을
지각이 내는 상자(마스크)로 다룬다(10.2의 내용 상자).


### 10.11 색의 틀

**문제.** Π는 과제마다 고정된 색 사상이다. "작은 물체의 색으로 칠하기", "가장 많은 색을 배경으로" 같은 규칙에서는 목표 색이
시범마다 내용으로 정해져서 고정된 Π가 없다. 위치에서 "닿을 때까지"가 고정 이동이 아니었던 것과 같은 꼴이다.

**설계(게이지 원리를 색에 적용).** 지각이 격자마다 **색 기준점**을 낸다.

- 상자 m(§10.2)마다 그 상자의 색 분포 κ_m = Σ_s α_m(s) x(s) / Σ_s α_m(s) ∈ Δ(C). 격자 상자의 κ_0는 격자 전체의 색 분포다.
  지각이 상자 질의로 "작은 물체", "한 번만 나온 색" 같은 것을 잡으면, 그 색이 기준점이 된다.
- 칸의 색 코드를 넓힌다: x̃(s) = [x(s); ⟨x(s), κ_1⟩, …, ⟨x(s), κ_M⟩] (c + M 차원). 뒤쪽은 "이 칸의 색이 m번 기준 색인가".
- 출력 색 = Π_raw (원래 색 공간의 사상) + Σ_m Γ_m κ_m(짝 입력) (m번 기준 색을 내놓음). 둘 다 시범에서 같은 근접 경사 + 희소
  LTD로 맞춘다. 블록이 하나 늘 뿐 볼록성은 그대로다.
- "작은 물체의 색으로 칠하기" = 마스크 안에서 Γ_작은물체 = 1. 시범마다 그 색이 달라도 규칙은 고정이다.
- 색 순열 켤레: 기준 색 κ_m은 증강의 색 순열 σ_v를 따라 옮겨지므로, Γ는 증강에 불변이고 Π_raw만 σ_v로 켤레를 취한다.
  명제 3이 유지된다.

### 10.12 개수로 정해지는 크기

크기 후보(§10.4)에 상자 범위뿐 아니라 **지각이 내는 개수**를 더한다: 상자 m의 소속 칸 수, 서로 다른 색 수, 물체 수(칸별
물체 상자의 대표 칸 수를 부드럽게 셈). e_out = Σ β_b e_b + Σ β_n n + β_0, β는 같은 방식(사전 중심 + 희소 LTD)으로 맞춘다.
"물체 수만큼 n×1"은 β_물체수 = 1(높이), β_0 = 1(너비)이다.

### 10.13 퍼즐 임베딩 명세

- 과제마다 e_τ ∈ ℝ⁶⁴ 하나(원본판). 증강판 101개가 이것 하나를 공유한다(명제 3). URM의 판별 표(과제 × 101 × 512)가 과제 × 64가 된다.
- 선형 디코더가 빠른 상태 전체의 사전 중심을 낸다: (A⁰_j, Π⁰_raw,j, Γ⁰_j, ω⁰_j, B̂⁰, β⁰) = D e_τ + d₀. d₀(편향)가 공유 사전이다.
- 증강판 v의 중심 = 원본 중심의 켤레: A는 D4 원소의 채널 순열, ω는 광선 방향의 순열(D4가 8방향에 작용)과 상자 중심
  원점에서 항등, Π_raw는 σ_v 켤레, Γ·β는 불변.
- 학습 중 에피소드의 30%에서 e_τ를 0으로 둔다(공유 사전 학습). 임베딩이 작아 SignSGD가 필요 없고 보통의 AdamW로 학습한다.

### 10.14 학습 명세

- 손실: 질의 출력 칸 색의 교차 엔트로피(참 크기 안) + 크기의 L1(반올림 전). 보조 손실은 두지 않는다(지각의 손 감독 없음).
- 고정점: 순전파는 재귀 R = 16번(기울기 없이), 그다음 마지막 k = 2번만 기울기를 켜서 암묵적 미분을 근사한다(phantom gradient,
  Geng et al. 2021). 빠른 상태가 작아 k를 늘리는 비용이 작다.
- 기록할 것: 고정점 잔차 ‖Φ(x) − x‖, 항별 틀 선택 ω의 지지(몇 개의 틀이 살아 있나), 빠른 상태의 0 비율, 사전 중심으로부터의 편차.
- 배치: 에피소드 64, 패킹. 최적화: AdamW lr 1e-4(지각), 빠른 쪽 느린 파라미터(디코더, 문턱 λ, 주파수)도 같은 옵티마이저.

### 10.15 구현 계획과 첫 실험

**모듈.** (1) 위치 코드(D4에 닫힌 학습 주파수) (2) 지각(격자 안 어텐션 + FFN, 상자·광선·색 기준점·개수) (3) 틀 코드와 기억 그림
(4) 규칙 시냅스(블록별 근접 경사, 립시츠 추정, 희소 LTD, 사전 중심) (5) 크기 시냅스 (6) 재귀와 phantom gradient
(7) 데이터: 증강을 N×N 영역 전체에 거는 파이프라인(§4.1의 형식 조건).

**검사(구현 전에 수식이 맞는지).** 명제 3(증강 켤레)을 무작위 규칙으로 수치 검사, 근접 경사가 lasso 해(독립 풀이기)와 일치하는지,
중심 원점 코드의 D4 순열(명제 6)이 구현에서도 성립하는지, 관측 흐름이 쓰기 목표에만 들어가는지(질의 출력 칸이 쓰기에 0 기여).

**첫 실험(Mini-ARC, 전환적, A/B와 같은 분할).** 비교 대상 A(퍼즐 임베딩만). 제거 실험 네 가지(§9의 예측): 그룹 희소 끔, 관측/추론
분리 끔, 주파수 D4 닫힘 끔, 희소 LTD 끔(λ = 0). 그리고 광선 기준점 끔(손 사전의 기여).

### 10.16 남은 것 (갱신)

1. 순서가 있는 비군 합성(옮긴 결과를 보고 다시 칠하기): 시간 축 라우팅이 필요하고, 중간 단계가 관측되지 않는 문제가 다시 생긴다.
2. 물체끼리 쌓이는 떨어뜨리기(끝점이 출력에 의존): 되먹임으로 수렴하는지 미검증.
3. 상자 수 M, 항 수 J, 색 기준점 수의 크기.
4. 지각이 규칙 추론을 통한 신호만으로 쓸모 있는 틀(상자, 광선 끝, 색 기준점)을 배우는지.
5. 결합 고정점의 수렴.
6. bands로 승격하는 구체 절차(§8은 대응만 적었다).


## 12. 명세 v2: 구조는 형식·논리가 강제하는 것만, 나머지는 학습

### 12.1 기준

구조로 넣는 것은 다음 넷뿐이다. 그 밖의 모든 것(무엇이 물체인지, 어디서 멈추는지, 무엇을 세는지, 어떤 색이 기준인지)은
보편 근사기(격자 안 어텐션 + FFN, 재귀)가 학습한다.

| 구조 | 강제하는 것 |
|---|---|
| 관측 흐름과 추론 흐름의 분리 | 형식(무엇이 주어진 답인가). 목표 오염의 퇴화 고정점을 막는다 |
| 격자 사이 경로 = 규칙 시냅스뿐 (명제 4) | 논리. 시범 → 질의의 정보가 전부 희소 LTD의 해를 거치게 한다 |
| 희소 LTD + 사전 중심(퍼즐 임베딩) + 재귀·고정점 | 학습 기제 자체(단순성 원리). 원칙 문서에서 학습으로 풀 수 없는 유일한 것 |
| 증강군 등변 (D4, 색 순열) | 데이터 증강이 이미 가정하는 대칭 |

정리 0은 표현이 무엇이든 성립한다. 표현을 학습하면 전제 L(법칙이 그 표현에서 성김)과 I(시범이 그 해를 정함)가 학습에 거는
것이 될 뿐이다. 규칙 종류마다 표현을 손으로 짜서 L을 참으로 만드는 것은 손 사전이다.

### 12.2 부품

**(1) 토큰의 두 흐름.**
- 관측(고정): 배경 여부, 역할, 쌍 번호, 색의 정체(아래 (3)처럼 관계로만 씀). 질의 출력 칸의 관측은 비어 있다.
- 추론(진화): 은닉 h.

**(2) 구조 코드 g.** 학습된 주파수의 위상 코드(2K = 32), 주파수 집합은 D4에 닫힘(기본 주파수 K/8개의 D4 궤도). 격자 중심을
원점으로 한 좌표에서 잰다(격자 크기는 형식). 지각의 RoPE이자 규칙 시냅스의 키다.

**(3) 지각(느린, 격자 안).** 격자 안 어텐션(RoPE = g) + FFN을 층 몇 개.
- 색 등변: 색은 "같은 색인가"라는 관계(어텐션 점수에 더하는 같은 색 편향)와 배경 여부로만 들어간다. 색 이름(어느 색인가)은
  지각에 들어가지 않는다. 그래서 지각은 색 순열에 정확히 등변이다(색은 이름 없는 범주라는 것은 색 순열 증강이 이미 가정한 것).
- D4 등변: 군 평균으로 정확히 만든다. P̄(x) = (1/8) Σ_{d∈D4} d · P(d⁻¹ x). 아무 학습된 P에 대해 정확하다(수치 확인: 크기 1–5의
  모든 격자에서 등변 오차 9×10⁻¹⁶, 평균 전 1.4). 대가는 지각 비용 8배다. 가중치를 묶는 등변 층을 짤 필요가 없다.

**(4) 틀 = 학습된 마스크와 그 모멘트.** v1의 상자·광선·색 기준점·개수를 하나로 합친다.
- 칸 s마다 학습된 질의 K개가 같은 격자의 칸들에 마스크 m_k(s, t) ∈ [0, 1]을 낸다(지각과 같은 어텐션 기계, 점수 = 내용 항 +
  RoPE 상대 위치 항). 격자 단위 마스크(칸 s와 무관한 질의)도 같은 꼴이다.
- 마스크의 모멘트가 틀의 기술자다(수학적으로 일반적인 요약이고 ARC 지식이 아니다):
  - 0차: 질량 Σ_t m (개수)
  - 1차: 평균 위치 (기준점)
  - 2차: 퍼짐 (범위)
  - 색 분포: Σ_t m x(t) / Σ_t m (색 기준점)
- 칸 s의 틀 k 코드: g(p_s − 기준점_k(s)), 마스크 밖이면 0이 되도록 소속으로 곱한다.
- 마스크가 무엇을 잡을지(물체, 광선 위 첫 장애물, 닫힌 영역, 한 번 나온 색)는 전부 학습이다. 광선은 이 틀이 배울 수 있는 것
  중 하나일 뿐이다.
- 등변: 지각이 등변이므로 틀도 등변이다. 틀 번호 k는 증강판 사이에서 같은 의미를 가진다.

**(5) 규칙 시냅스(빠른, 격자 사이).** 항 J개, 항마다 (공간 작용 A_j ∈ ℝ^{2K×2K}, 색 작용 Π_j, 기준 색 가중 Γ_j, 틀 쌍 가중 ω_j).
- 기억: 짝 입력의 관측 색 ⊗ 틀 코드의 합(틀마다).
- 읽기: 출력 칸 o에 ĉ(o) = Σ_j [Π_j Σ_{(k,k′)} ω_j[k, k′] M_k A_j g_{k′}(o) + Σ_k Γ_j[k] κ_k] (κ_k: 틀 k의 색 분포).
- 쓰기: 시범 출력 칸의 관측 색을 목표로 블록별 근접 경사(델타) + 희소 LTD(원소별 문턱, ω에는 틀 단위 그룹 문턱),
  사전 중심 = 퍼즐 임베딩 디코더 출력.
- 출력 크기: 틀 모멘트(범위, 질량)와 상수의 성긴 선형 결합 β를 같은 방식으로 맞춘다.

**(6) 되먹임과 출력.** 읽기 ĉ(o)는 추론 흐름에만 더한다: h(o) ← h(o) + W_c ĉ(o). 출력 색은 h(o)의 분류기에서 낸다(ĉ에서 바로
내지 않는다). 그래서 지각의 FFN이 규칙의 읽기를 받아 "막히면 멈춤", "쌓이며 정리"처럼 고칠 수 있다. 이것들은 모든 과제에
공통인 동역학이라 느린 쪽의 몫이고, 재귀가 반복을 준다.

**(7) 재귀와 학습.** 블록(지각 → 틀 → 기억 → 쓰기 한 걸음 → 읽기 → 되먹임)을 R = 16번 반복한다. 마지막 몇 번만 기울기를 켜는
phantom gradient로 고정점의 암묵적 미분을 근사한다. 손실은 질의 출력 색 + 크기뿐이다.

### 12.3 증강 켤레 (명제 3, v2에서)

지각이 D4와 색 순열에 정확히 등변이므로 틀 번호의 의미가 판 사이에서 같다. 판 v의 사전 중심 = 원본 중심에서 A만 D4 원소의
채널 순열(명제 6)로, Π만 σ_v로 켤레를 취하고 ω, Γ, β는 그대로다. 과제마다 e_τ 하나를 판 101개가 공유한다.

### 12.4 v1에서 빠진 것

광선 방향과 방향 마스크, 상자의 의미(경계 상자, 자기 물체 상자), 원점 여섯 종, 정규화 좌표판(주기성은 학습된 주파수가 필요하면
배운다), 개수 특징의 정의, 위치·색 두 단계 분할. 부품 수: v1의 지각 산출물 네 종류 + 틀 38개 → v2의 학습된 마스크 K개와 그 모멘트.

### 12.5 학습에 거는 것 (정직한 목록)

1. 지각이 규칙을 짧게 만드는 마스크(틀)를 배운다. 신호는 질의 손실이 규칙 추론을 거쳐 오는 것뿐이다.
2. 그 틀에서 학습 과제의 규칙이 성기다(L), 시범이 그것을 정한다(I).
3. FFN이 재귀 안에서 정지·쌓임 같은 공통 동역학을 배운다.
4. 결합 고정점이 수렴한다.

구조는 이 넷이 학습될 수 있는 자리(경로, 원리, 대칭)만 만든다. 이것들이 학습 과제 약 1,000개에서 실제로 배워지는지가 원칙
문서의 "학습 상한"이고, 실험으로만 판정된다.

### 12.6 남은 설계 결정

- K(틀 질의 수), J(항 수), 지각 층 수, 2K(코드 차원).
- 군 평균의 비용 8배를 Mini-ARC에서 감당할지, 아니면 증강만으로 근사 등변에 맡기고 켤레를 근사로 둘지.
- bands로 승격하는 절차(§8의 대응은 v2에서도 그대로: 코드 = RoPE, 기억 = RoPE 키의 헤브 합, 규칙 = 누적기 + 근접 사상).
