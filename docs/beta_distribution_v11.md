## STDP 해석에 대한 의미

현재 코드의 쓰기 성분은

```
cos(δ+β) = cos β · cos δ − sin β · sin δ
```

이다. 칸 교환으로 δ의 부호가 바뀔 때 cos δ는 대칭, sin δ는 반대칭이다.
따라서 β=0 또는 π는 대칭 쓰기, β=±π/2는 반대칭 쓰기에 해당한다.
현재 분포는 **순서 반전에 따라 강화·약화 부호가 뒤집히는 반대칭 쓰기가
주도한다**는 설명을 지지하지 않는다.

전체 β의 평균 cos² β는 87.38%, 평균 sin² β는 12.62%다. 이것은 성분을
동일 가중한 파라미터 계수 통계다. 실제 쓰기나 기억 전달의 에너지 비율은
주소 진폭·위상차·agree·gain·값 벡터·성분 간 상쇄에 의존하므로 이 비율과 다르다.

`STDP이면 반드시 모든 β가 ±π/2여야 한다`는 조건은 정확히 홀함수인
시간 가소성 창을 가정할 때 성립한다. 일반적인 창의 짝/홀 분해와 Fourier
대응은 `stdp_fourier.md` §6–7을 참고한다. 또한 모델의 학습된 복소 주소가
실제 발화 시간의 Fourier 성분이라는 동일시는 분포만으로 입증되지 않는다.

초기화도 고려해야 한다. `lt/train.py`는 β를 N(0, 0.5²)로 초기화하므로
처음부터 0 중심이다. 이 초기분포의 기대 sin² β는 약 19.67%이고 v1.1의
관측치는 12.62%다. 다만 실제 초기 텐서와 학습 경로를 짝지어 추적하지 않았으므로
각 성분이 어디에서 어디로 이동했는지는 이 측정만으로 알 수 없다.

## 재현과 산출물

```bash
python -m lt.analyze_beta_distribution
```

- `runs/beta_distribution_v11/summary.json`: 체크포인트 SHA-256, 전체·헤드별 통계.
- `runs/beta_distribution_v11/*_beta_degrees.csv`: 각도 원자료, 행은 헤드.
- `runs/beta_distribution_v11/beta_comparison.png`: 세 체크포인트 비교.
- `runs/beta_distribution_v11/beta_v11_heads.png`: v1.1 헤드별 분포.

β 자체의 저장 dtype은 세 체크포인트 모두 float32다. v1.1의 큰 행렬이
fp16으로 압축되어 있다는 사실과 β의 저장 정밀도는 구분한다.
