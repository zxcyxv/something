# 후반 완성 퍼즐의 마지막 교정 사건: probe 계획

2026-09-26. 사용자 요청에 따라 완답률 중심 정책 비교를 실행 전에 대체했다.

## 질문과 사례 선택

후반에 완성된 퍼즐에서 오랫동안 해결되지 않았던 셀이 **어떤 작용으로
안정적으로 교정되었는지** 분석한다. 사례의 설명과 모델 전반의 일반 법칙을 구분한다.

완료된 BF16/배치2048 평가에서 첫 완답이 seg256 이후이고 마지막 64세그먼트
모두 완답인 퍼즐은 78개다. 원래 테스트 인덱스 오름차순 첫 12개를 FP32로
재현한다. 선택은 출력 궤적만 사용하며 agree·메시지 효과를 보고 고르지 않는다.
BF16의 전환 시점이 FP32에서도 같다고 가정하지 않는다.

FP32에서 충분히 늦은 안정 교정이 재현된 첫 3개 사례를 분석한다.
구체적으로 최종 256블록 동안 퍼즐 완답이 유지되고, 안정 완성 시작이
블록 2048 이후인 사례다. 안정 완성의 마지막 교정 셀들 중 직전 1024블록에서
오답이었던 비율이 가장 높은 셀을 고른다. 동률이면 셀 인덱스가 작은 것을 쓴다.
직전 1024블록에서 오답 비율 90% 이상인 것을 ‘장기 미해결’ 주 사례로 한다.
조건에 맞는 사례 수가 부족하면 그 사실을 보고하고 조건을 몰래 바꾸지 않는다.

## 관측

- 셀 예측, 다른 셀의 예측, 행·열·박스의 중복 충돌.
- 대상 셀에 들어오는 agree, 쓰기 창, G, w.
- 현재 읽기, 현재 쓰기, 과거 보정이 `정답 숫자 - 전환 직전 오답 숫자`의
  로짓 마진에 기여하는 양. 공통 phi 분모를 쓰는 대수 분해임을 명시한다.
- 같은 출력 숫자와 높은 숨은 값 agree를 동일시하지 않는다.
- 입력 단서와, 단서가 아닌 현재 정답 이웃, 계속 바뀌는 이웃을 구분한다.

## 전환에 대한 개입

기준 전환 블록 T의 128블록 전 같은 h,w에서 분기한다.
개입은 T까지 유지하고 T+128까지 원래 규칙으로 계속 실행한다.

1. 정상 대조.
2. 대상 셀과 연결된 agree를 개입 시작 값으로 고정하여 쓰기.
3. 해당 쓰기 창을 시작 값으로 고정하여 쓰기.
4. agree와 쓰기 창을 함께 고정하여 쓰기.
5. 대상 셀과 연결된 w의 갱신을 멈추고 시작 기억을 유지.
6. 대상 셀의 기억 읽기를 현재 G로 대체. 정상 기억 쓰기는 계속한다.
7. 대상 셀로 들어오는 다른 셀들의 value 방향을 시작 시점으로 고정.
   현재 value 노름은 유지하고, 쓰기는 현재 값을 사용한다.

쓰기 고정은 행과 열에 함께 적용한다. 읽기 개입은 대상의 들어오는 행에만
적용한다. 분기 이후는 각 분기의 상태에서 자유롭게 계산하며 정상 h를 재생하지 않는다.

같은 정상 상태에서 현재 쓰기·과거 보정 메시지를 한 번 제거하는 국소 비교도
시행한다. 이는 긴 자유 추론 개입과 별도로 보고한다.

## 판정 규칙

단순히 agree가 변한 뒤 셀이 고쳐졌다는 사실은 원인의 증거로 쓰지 않는다.
`최근 agree 변화가 이 사건의 교정에 기여했다`는 설명은 해당 변화 고정 시
교정이 방해되거나 늦어지는 결과로 뒷받침한다. 고정해도 같은 시점에 교정되면
이 구간의 agree 변화가 필요했다는 설명은 지지하지 않는다.

개입별로 T에서의 셀/퍼즐 정답, 고정된 마진, T 이후 128블록 중 셀 정답 비율,
32블록 연속 정답 시작 시점을 보고한다. 교정이 사라짐·늦어짐·유지됨·빨라짐을
분리한다. 즉시 전환 방해를 ‘영원히 못 푼다’로 확대하지 않는다.

메시지 기여의 대수 분해는 원인을 탐색하고 개입 결과를 설명하는 자료다.
기여 크기만으로 학습 규칙 전체의 우수성이나 일반적인 인과 메커니즘을 증명하지 않는다.
출력의 반복과 내부 h,w의 주기 궤도를 동일시하지 않는다.

## 수치 조건

v1.1 160k EMA, FP32, autocast/TF32 off. 초기 큰 가중치는 fp16 저장본이다.
같은 12문제 배치와 같은 연산 순서를 유지하여 snapshot 재생의 정상 출력이
baseline 모든 블록과 일치하는지 검증한다. 데이터와 체크포인트 해시, 원래
후보 인덱스, 모든 개입 궤적을 저장한다.
