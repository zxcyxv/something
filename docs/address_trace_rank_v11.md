# v1.1 주소의 단일 활동 시간 필터 가설: 기억 미분의 랭크 검사

후속 [위상·시간 연구](phase_timing_research_v11.md)는 독립적인 W 교란 없이 실제 풀이
궤적에서 검사하고, 주소 정규화·공통 위상 변화·여러 활동을 허용하는 필요조건까지 확장했다.

## 판정과 범위

체크포인트 `v1.1_step160000.npz`의 두 저장 상태에서, 대상 칸의 8개 헤드 모두
`현재 h 고정 → W 변화 → 다음 주소 변화`의 실수 야코비안이 랭크 1 조건을 크게 위반했다.
이는 **현재 주소 전체가 한 실수 활동의 고정 계수 시간 필터라는 식이 상태 근방의
항등식으로 성립한다**는 가설에 대한 수치 반례다.

시간 정보 일반의 부재, 다변량 활동의 시간 필터 부재, 다른 잠재 좌표의 모드 부재,
정상 풀이 궤적 위에서만 성립하는 근사 관계를 뜻하지 않는다. 교란한 상태는 정상
저장 상태 주변이지만, 독립적으로 바꾼 W가 정상 추론 이력으로 도달 가능한지는
이 검사에서 증명하지 않는다.

## 검사한 명제

한 셀, 한 헤드의 정규화 전 복소 주소를 z라 한다. 주파수 성분 j에 대해

\[
z_j(k+1)=\mu_j z_j(k)+b_j x(k+1),\qquad
\mu_j=\rho e^{-i\omega_j}
\]

가 같은 고정 계수 μ,b로 상태 근방에서 성립하는지 묻는다. x는 하나의 실수
활동이며, 무엇인지 미리 정하거나 추정하지 않았다. 실제로 이 필요조건 검사는
μ가 주파수 형태인지와 무관하고, 이전 z에 어떤 고정 선형 연산자를 적용하더라도 같다.

현재 주소는 `z = (A+iB) prepare(h)`이므로 h를 고정하면 W를 바꿔도 현재 z가
정확히 고정된다. 그러면 위 가설에서

\[
\frac{\partial z_{next}}{\partial W}
=b\frac{\partial x}{\partial W},
\qquad
\operatorname{rank}_{\mathbb R}\!\left(\frac{\partial z_{next}}{\partial W}\right)\le1.
\]

실수부와 허수부를 쌓아 실수 행렬로 계산했다. 단일 복소 활동이라면 상한은 2인데,
관측된 결과는 이 상한도 넘는다. 이 사실로 임의 차원의 벡터 활동까지 배제하지 않는다.

## 상태와 교란

- test puzzle index 1, 대상 6행 4열(0 기반 셀 48), 정답 1.
- 152블록 이후: 대상은 1, 전체 오답 3칸. 다음 블록의 주소를 측정.
- 192블록 이후: 전체 완답 상태. 다음 블록의 주소를 측정.
- 기존 `runs/settling_v11/snapshots.pt`를 사용했다. 새 장기 추론은 수행하지 않았다.
- 한 헤드의 주소는 복소 52성분, 실수 좌표로 104차원이다.
- 각 헤드에서 대상과 나머지 80칸의 연결을 대상으로
  `(E_i,n + E_n,i)/sqrt(2)`를 사용했다. 8개 헤드, 총 640개의 직교 단위 방향이다.
  대각 항을 고정하고 W 변화의 대칭성을 유지한다.
- 현재 h, 문제 입력, 현재 q/v/agree/G는 고정한다. 이전 기억의 변화는 실제 쓰기의
  `(1-eta)`를 거쳐 읽기에 들어간다.

## 결과

아래 랭크는 `sigma > 1e-6 * sigma_max`인 특이값의 수다. 괄호의 범위는 8개 헤드의 범위다.

| 저장 상태 | 정규화 전 주소 랭크 | 두 번째/첫 번째 특이값 | 최선의 랭크 1 근사 상대 오차 |
|---|---:|---:|---:|
| 152블록 이후 | 모든 헤드 104 | 0.4714–0.6025 | 0.6603–0.7900 |
| 192블록 이후 | 모든 헤드 104 | 0.4055–0.5738 | 0.6824–0.7548 |

상대 오차는 야코비안의 Frobenius 노름으로 나눈 최선의 랭크 1 근사 잔차다.
한 방향으로 설명되는 야코비안 제곱 노름의 비율은 각각 37.6–56.4%, 43.0–53.4%다.
이는 **선택한 직교 기억 교란 전체에 대한 미분의 비율**이며, 정상 풀이 궤적의
정보량이나 시간 표현의 비율이 아니다.

정규화 전 야코비안의 가장 작은 특이값도 첫 번째의 0.00183–0.00205(152),
0.000252–0.000373(192)이었다. 랭크 1 위반이 반올림 수준의 작은 성분에만 의존하지 않는다.

실제로 쓰기에 사용하는 정규화 주소도 검사했다.

| 저장 상태 | 정규화 주소의 수치 랭크 | 두 번째/첫 번째 특이값 |
|---|---:|---:|
| 152블록 이후 | 모든 헤드 103 | 0.5443–0.6561 |
| 192블록 이후 | 모든 헤드 103 | 0.4328–0.5344 |

정규화로 크기 방향이 크게 억제되지만, 다방향 응답은 남는다. 코드의 정규화 분모에
epsilon이 있으므로 수학적으로 크기 방향이 정확히 0이라고 주장하지 않는다.

동일한 헤드의 W만 바꾸는 80개 열로 제한해도 정규화 전 랭크는 78–80(152),
57–76(192)이었다. 다른 헤드에서 들어오는 변화만으로 생긴 결과도 아니다.

## 미분 계산과 검산

현재 h 고정 시, 읽기 직후 phi 이전 상태의 변화는

\[
\delta pre_i=\sum_h \ell_h(1-\eta_h)W_{sh,h}^{T}
\sum_n\delta W_{h,i,n}v_{n,h}
\]

이다. ell은 읽기에서 W를 혼합하는 계수다. 여기에 실제 `phi → 다음 boundary MLP
→ 입력 주입 → 주소 사영`의 미분을 곱해 104×640 야코비안을 헤드별로 얻었다.
다음 주소는 다음 블록의 쓰기에 쓰이는 주소이며, 다음 블록의 읽기까지 수행하지 않는다.

- CPU FP64로 계산했고 CUDA는 초기화하지 않았다.
- 생산 코드 `LT_Inner.step`과 중간 계산을 비교했다.
- 두 저장 상태와 다음 한 블록의 분류는 원래 GPU 기록과 모두 일치했다(불일치 0).
- 야코비안의 두 주된 오른쪽 특이벡터와 사전 고정한 한 연결 방향에서,
  전체 블록을 직접 통과하는 JVP로 독립 검산했다.
- 분해해서 계산한 야코비안과 전체 블록 JVP의 최대 상대 오차: `1.89e-15`.
- 실제 W를 `±1e-4`, `±5e-5`만큼 바꾼 중심 차분의 최대 상대 오차: `1.81e-9`.
- 이 수치는 부동소수점 미분 검산이며, 구간 연산으로 인증한 형식 증명은 아니다.

## 해석

이번 검사는 주파수나 활동을 피팅하지 않았다. 미지의 주파수와 공통 활동이 어떤
값이든 반드시 만족해야 하는 랭크 조건을 먼저 검사했고, 그 조건이 위반됐다.
따라서 **원래 주소 전체를 문서의 단일 활동 푸리에 뱅크와 그대로 동일시하는
일반적인 갱신식**은 이 체크포인트의 상태 근방에서 성립하지 않는다는 결과다.

임의의 기억 교란에 대한 국소 응답이므로, 실제 궤적에 제한된 시간 구조나 일부
주소 부분공간의 시간 모드를 따로 발견할 가능성과 모순되지 않는다. 이 결과로
W의 시간 평균이나 일관성 선택 기능의 유무를 판정하지 않는다.
