# v1.1: 과거 결합으로 전달되는 현재 정보

## 질문의 수정

`w`는 과거 숫자 배치나 과거 값 벡터를 저장하지 않는다. 저장되는 것은 칸 사이 결합이며,
읽기에 쓰는 값 `v`는 매 블록의 현재 은닉상태에서 다시 계산한다.
그러므로 과거 관계를 유지하면서 다른 칸의 새 정보를 전달할 수 있다.
완전연결 상호작용이 존재하는 모델에서 한 칸의 잘못된 선택이 강화된다는 사실만으로
전체 배치가 고착된다고 결론 내릴 수 없다.

이 분석의 질문은 **과거 결합 보정이 다른 칸에서 오는 현재 정보의 전달을 어떻게 바꾸는가**이다.

## 실험

- v1.1 160k EMA, 테스트 앞 128개, FP32, autocast/TF32 끔. 정상 완답은 seg16 75개 → seg128 101개.
- 정상 궤적의 매 블록에서 `D = updated_w - current_write_target`을 계산한다.
- D의 원천 칸을 네 그룹으로 분할: 입력 단서 / 직전 블록에서 정답을 출력한 빈칸 / 오답을 출력한 빈칸 / 자기 자신.
- 다른 칸 그룹에서는 대각 원소를 제외한다. 네 그룹의 행렬 합이 D와 일치함을 확인했다.
- 각 그룹의 보정만 빼서 한 블록 출력을 계산하고, 정상 궤적으로 돌아온다. 순간 읽기 및 현재 쓰기 목표는 유지한다.
- 정상 궤적은 기존 분석과 모든 블록의 완답 여부가 일치했다.
- 라벨은 분석용 그룹과 출력 점수 계산에만 사용했다. 정상 추론 및 장기 실행에 정답 기반 게이트를 넣지 않았다.
- 칸 출력의 정오는 그 칸의 은닉 메시지가 유용한지와 동일하지 않다. 그룹 이름은 출력 기준이다.

## 정답 전이 직전의 관측

seg16 이후 새로 풀린 26개 중 첫 블록 완답 직전 8블록이 관측 범위에 있는 25개를 분석했다.
최초 완답 블록 자체는 제외했다. 표는 **직전 블록에서 오답이었던 빈칸**의 다음 출력 오답률 변화다.
각 퍼즐에서 해당 칸·블록에 대해 평균하고, 퍼즐 사이에서는 동일 가중치를 사용했다.

| 제거한 과거 보정의 원천 | 제거 후 오답률 변화 | 퍼즐 재표집 95% 구간 |
|---|---:|---:|
| 전체 | +0.795%p | -0.335 ~ +1.935%p |
| 다른 단서 칸 | +0.473%p | -0.352 ~ +1.375%p |
| 다른, 현재 맞게 출력한 빈칸 | **+1.405%p** | +0.617 ~ +2.285%p |
| 다른, 현재 틀리게 출력한 빈칸 | **-0.967%p** | -1.539 ~ -0.414%p |
| 자기 자신 | +0.121%p | 0 ~ +0.364%p |

재표집은 25개 퍼즐을 5,000번 복원추출, seed=0이다. 정상 궤적의 성공으로 선택한 탐색 표본이므로
미관측 퍼즐 일반화나 독립적인 확증 실험의 의미를 부여하면 안 된다.
맞게 출력한 다른 빈칸의 보정 제거 효과는 11개에서 악화, 12개에서 변화 없음, 2개에서 개선이었다.
틀리게 출력한 다른 빈칸의 보정 제거는 10개에서 개선, 14개에서 변화 없음, 1개에서 악화였다.

이는 **다른 칸의 상호작용으로 오답을 고칠 수 있다**는 설명과 부합한다.
과거 관계 보정이 그런 전달을 돕는 경우와 방해하는 경우가 모두 관측되었다.
단, 유한한 한 블록 제거 효과들이 손실/정확도에서 가산적일 필요는 없다.

## 단순한 오답 확신 억제 가설은 맞지 않는다

같은 직전 8블록에서, 정상 기억은 아직 틀린 칸의 이전 선택 마진을 평균적으로 +0.359만큼 높였다.
반면 이미 맞게 출력한 빈칸에서는 정답 마진을 +0.952만큼 높였다.
정답 마진과 오답률의 결과가 단순하게 일치하지 않는 것은, 평균 마진 변화와 argmax 경계 통과가 서로 다른 통계이기 때문이다.

따라서 `기억 → 오답 확신 감소 → 정답`이라는 단일 설명을 채택할 근거는 없다.
현재 관계로 읽는 기본 경로와 과거 관계로 현재 값을 읽는 경로가 함께 여러 칸을 변화시키는 과정을 보아야 한다.

## 다음 설계에 연결하기 위한 남은 질문

이 결과로 정답 여부를 사용하는 게이트를 설계해서는 안 된다. 정답은 추론 시 알 수 없다.
다음에는 도움이 된 연결과 방해한 연결에서, 모델이 이미 관측 가능한 위상차·주소 진폭·값의 agree·관계 변화 이력이
어떻게 다른지를 확인해야 한다. 그 차이가 일관되게 발견되어야 선택적 쓰기나 관계 해제 규칙을 제안할 수 있다.

재현:

```bash
python lt/analyze_message_sources.py --n 128 --segs 128 --out runs/message_sources_v11
```

원자료는 `runs/message_sources_v11/effects.npz`, 집계는 같은 폴더의 `summary.json`에 저장된다.
