# v1.1: hidden 섭동 순서를 바꾼 쌍 상호작용 검사

**해석 정정:** 아래 자극은 hidden 벡터 가산이며, 모델의 pre/post 활동이나
주소에 표현된 시간차와 대응시키지 않았다. 이 결과를 STDP 시차 규칙의 유무 판정에
사용하지 않는다. 주소 위상만 통제한 후속 실험과 실제 시간주파수 검증은
[위상·시간 연구 보고서](phase_timing_research_v11.md)에 있다.

## 결과

현재 체크포인트에는 **두 셀에 가한 신호의 순서에 따라 쓰기와 기억의 쌍 상호작용이
달라지는 동작**이 있다. 단독 자극의 효과를 뺀 뒤에도 관측됐다.
그러나 조사한 조건에서 **출처가 먼저면 양수, 대상이 먼저면 음수**라는 일관된
방향별 규칙은 나오지 않았다. 같은 시작 상태·헤드에서도 시차에 따라 그 부호가 반대가 됐다.

이는 조건부 순서 민감성의 관측이다. 고정된 STDP 창, 학습으로 이 성질이 새로
생겼다는 인과 주장, 시간 푸리에 좌표의 존재, 정답 개선의 원인을 입증한 것은 아니다.

## 자극과 비교

- 모델: `checkpoints/v1.1_step160000.npz`, CPU FP64, 추론 가중치 고정.
- 문제: test index 1. 저장 상태 152블록 이후와 192블록 이후.
- 셀 A: 8행 4열(인덱스 66), 셀 B: 6행 4열(인덱스 48).
- 검사한 고정 방향: `W[B,A]`와 `W[A,B]`, 8개 헤드 모두.
- 자극: boundary MLP 직전에 해당 셀의 **시작 상태 은닉 벡터의 0.2% 또는 0.1%를 가산**.
  같은 시작 상태에서는 모든 시차·순서에 동일한 두 벡터를 사용한다.
  정답이나 최종 결과로 자극 방향을 고르지 않았다.
- 간격: 0, 1, 2, 4, 8, 16블록. 첫 자극은 저장 상태 바로 다음 블록에 넣는다.
- 두 번째 자극 후 8블록을 더 진행한다.

각 순서·시차·자극 크기마다 같은 시작 상태에서 다음 네 조건을 비교한다.

1. 두 자극 모두.
2. 첫 번째 자극만, 같은 시각.
3. 두 번째 자극만, 같은 시각.
4. 무자극.

각 연결의 쌍 상호작용을

\[
C_Y(\Delta;s_0)=
\frac{Y_{both}-Y_{first}-Y_{second}+Y_{none}}{\epsilon^2}
\]

로 정의했다. Y는 G 또는 W이며, Δ는 B의 자극 시각에서 A의 자극 시각을 뺀 값이다.
양수 Δ가 `A 먼저 → B 나중`이다. 두 번째 자극을 기준으로 같은 지평에서 비교한다.
표의 값은 작은 자극 크기로 얻은 국소 혼합 응답의 유한 차분 근사다.

이 차감은 개별 자극의 독립적인 효과와 그 효과에 대한 단순 EMA의 시각 가중 차이를
제거한다. 반면 정상 배경 상태의 시간 변화와 모델의 비선형 상호작용은 남는다.
따라서 측정한 것은 `C(Δ; 시작 상태, 자극 방향, 지평)`이며, 시차만의 보편적인 K(Δ)가 아니다.

**양수 C_W는 두 자극의 상호작용이 단독 효과의 합보다 W를 더 양수로 만든다는 뜻이다.**
전체 W의 부호나 전체 `W_after - W_before`의 부호와 동일하지 않으며,
읽기 메시지가 정답 방향으로 강화된다는 뜻도 아니다.

## 사전에 정한 주 지표

주 지표는 두 번째 자극 후 8블록에서의 C_W다. 즉시 쓰기의 C_G와 C_W도 기록했다.
0 간격은 순서가 없으므로 순서 판정 집계에서 제외한다.

자극 크기를 절반으로 줄였을 때:

- 크기 수렴: 두 추정치 차이가 `max(1e-6, 큰 응답의 10%)` 이하.
- 부호 신뢰 기준: 응답 크기가 `max(1e-6, 추정치 차이의 5배)`보다 큼.
- 순서 차이 기준: 두 순서의 차이가 `max(1e-6, 두 추정치 차이 합의 5배)`보다 큼.

이것은 수치·자극 크기 민감도를 점검하는 결정론적 기준이지 통계적 신뢰구간이 아니다.
전체 80조건은 2상태×5시차×8헤드이며 독립적인 80개 문제 표본이 아니다.

## 관측값

고정 연결 `8행4열 → 6행4열`에서 80조건 중 78조건이 순서 차이 기준을 통과했다.
두 자극 크기 간 수렴 기준은 80조건 모두 통과했다.

| 주 지표의 부호 패턴 | 조건 수 |
|---|---:|
| 출처 먼저 양수 / 대상 먼저 음수 | 9 |
| 출처 먼저 음수 / 대상 먼저 양수 | 22 |
| 양쪽 순서 모두 양수 | 25 |
| 양쪽 순서 모두 음수 | 22 |
| 약하거나 부호가 불확실 | 2 |

어느 시작 상태에서도, 측정한 모든 비영 시차에서 계속 `출처 먼저 양수 / 대상 먼저 음수`인
헤드는 없었다. 이 범위에서 단순한 고정 부호 규칙에 대한 반례가 나온 것이며,
더 넓은 다른 시차 창이나 다른 활동 패턴에 대한 전역 부재를 뜻하지 않는다.

### 같은 상태와 헤드에서 부호가 바뀌는 예

152블록 이후 상태, 헤드 3, `8행4열 → 6행4열`의 C_W:

| 자극 간격 | 출처 먼저 | 대상 먼저 |
|---|---:|---:|
| 1블록 | +0.003557 | −0.013958 |
| 2블록 | −0.061126 | −0.034295 |
| 4블록 | −0.018741 | +0.018647 |
| 8블록 | −0.011304 | +0.006103 |
| 16블록 | +0.005099 | +0.000239 |

1블록 간격에서는 주장한 부호 배열이 나오지만, 4·8블록에서는 반대다.
시작 상태를 192로 바꾸면 같은 헤드의 1블록 간격은 양쪽 순서 모두 양수가 된다.

### 양방향 연결

두 방향 연결 모두 두 순서의 부호가 신뢰 기준을 통과한 조건은 76개였다.
같은 실제 자극 순서에서 두 방향 연결이 같은 부호로 변한 것은
A 먼저일 때 71/76, B 먼저일 때 66/76이었다.

예를 들어 152블록·헤드3·1블록 간격에서 A 먼저일 때:

- `W[B,A]` 쌍 상호작용: +0.003557.
- `W[A,B]` 쌍 상호작용: +0.008274.

B 먼저이면 각각 −0.013958, −0.016697이었다.
이 예에서는 **두 방향 연결이 함께 양수/음수로 바뀐다.**
같은 사건 쌍에 대해 시간 방향에 맞춰 한쪽을 강화하고 반대 연결을 약화하는 규칙과 구분된다.

### 즉시 쓰기와 뒤의 기억

두 번째 자극 시점의 C_G에서도 80조건 중 77조건에 순서 차이가 있었다.
따라서 최종 W에 남은 단순한 최근성만 관측한 결과가 아니다.
즉시 쓰기와 8블록 후 기억의 부호가 같다는 보장은 없으며 둘을 따로 보관했다.

첫 자극 뒤, 두 번째 자극 전에는 쌍 효과가 0이어야 한다. 실제로 최대 절대값은
`2.48e-15` 미만이었다. 두 번째 자극 시점에는 `C_W = eta C_G`가 되고,
그 이후에는 원래 EMA의 선형성에 따라

\[
C_W(k)=(1-\eta)C_W(k-1)+\eta C_G(k)
\]

를 만족한다. 스케일 보정 전 항등식의 최대 절대 오차는 `4.90e-17` 미만이었다.

## 어디까지 결론낼 수 있는가

현재 학습된 모델에서, 이 두 활동의 순서를 바꾸면 쌍 쓰기가 달라지는 동작은 확인했다.
단일 활동의 푸리에 뱅크라는 주소 가정을 쓰지 않고 얻은 관측이다.
일정한 방향별 강화·약화 부호 규칙은 이 조건들에서 성립하지 않았다.

이 결과만으로 학습이 순서 민감성을 새로 만들었다고 주장하지 않는다.
초기 체크포인트와의 대조가 없으며, 일반적인 비선형 재귀도 순서 민감성을 가질 수 있다.
다른 셀 쌍·활동 방향·큰 자극·정상 추론 이력 전반으로 확대하지 않는다.
이 미소 상호작용이 정답 수정이나 외삽 성능에 중요한지는 여기서 측정하지 않았다.
